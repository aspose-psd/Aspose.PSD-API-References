```csharp
public static bool operator !=(Rectangle left, Rectangle right)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| left | Rectangle | بنية [`Rectangle`](../) التي تقع إلى يسار عامل عدم المساواة. |
| right | Rectangle | الهيكل [`Rectangle`](../) الذي يقع إلى يمين عامل عدم المساواة. |
