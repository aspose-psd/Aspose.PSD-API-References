## Pen.CompoundArray property

يحصل أو يعيّن مصفوفة القيم التي تحدد قلمًا مركبًا. القلم المركب يرسم خطًا مركبًا مكوّنًا من خطوط متوازية وفراغات.

```csharp
public float[] CompoundArray { get; set; }
```

### Property Value

مصفوفة من الأعداد الحقيقية التي تحدد المصفوفة المركبة. يجب أن تكون العناصر في المصفوفة بترتيب تصاعدي، لا تقل عن 0 ولا تزيد عن 1.
