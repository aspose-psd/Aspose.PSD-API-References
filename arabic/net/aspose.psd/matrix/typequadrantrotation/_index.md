## Matrix.TypeQuadrantRotation field

تشير هذه البتة flag إلى أن التحويل المحدد بواسطة هذا الكائن يقوم بدوران ربعي بضعف من 90 درجة بالإضافة إلى التحويلات المشار إليها بواسطة بتات flag الأخرى. يغير الدوران زوايا المتجهات بنفس المقدار بغض النظر عن الاتجاه الأصلي للمتجه ودون تغيير طول المتجه. هذه البتة flag لا يمكن استخدامها مع علم TypeGeneralRotation.

```csharp
public const int TypeQuadrantRotation;
```
