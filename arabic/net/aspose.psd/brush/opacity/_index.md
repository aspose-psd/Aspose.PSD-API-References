## Brush.Opacity property

يحصل أو يضبط شفافية الفرشاة. يجب أن تكون القيمة بين 0 و 1. القيمة 0 تعني أن الفرشاة مرئية بالكامل، والقيمة 1 تعني أن الفرشاة معتمة بالكامل.

```csharp
public float Opacity { get; set; }
```

### Property Value

قيمة شفافية الفرشاة.
