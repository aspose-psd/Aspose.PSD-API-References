## LinkDataSource.IsLibraryLink property

يحصل على قيمة تشير إلى ما إذا كان مصدر بيانات ربط PSD هذا يربط إلى عنصر مكتبة Adobe® Photoshop® СС.

```csharp
public bool IsLibraryLink { get; }
```

### Property Value

`true` إذا كان هذا الكائن رابط مكتبة Adobe® Photoshop® СС؛ وإلا `false`.
