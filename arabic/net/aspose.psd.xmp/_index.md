النطاق يحتوي على فئات ومناهج مساعدة متعلقة بـ XMP.

## الفئات

| فئة | الوصف |
| --- | --- |
| [LangAlt](./langalt/) | يمثل بديل لغة XMP. |
| [Namespaces](./namespaces/) | يحتوي على مساحات الأسماء المستخدمة في مستند RDF. |
| [XmpArray](./xmparray/) | يمثل مصفوفة Xmp في [`XmpPackage`](../aspose.psd.xmp/xmppackage/). TODO: قد تحتوي المصفوفة على بيانات معقدة. |
| [XmpArrayHelper](./xmparrayhelper/) | فئة المساعدة لمعالجة منطق RDF. |
| [XmpElementBase](./xmpelementbase/) | يمثل عنصر xmp الأساسي الذي يحتوي على سمات. |
| [XmpHeaderPi](./xmpheaderpi/) | يمثل تعليمات معالجة رأس XMP. |
| [XmpMeta](./xmpmeta/) | يمثل xmpmeta. اختياري. هدف هذا العنصر هو تحديد بيانات XMP الوصفية داخل نص XML عام قد يحتوي على استخدامات RDF غير XMP. |
| [XmpPackage](./xmppackage/) | يحدد فئة XmpPackage التي تمثل التجريد الأساسي لحزمة XMP. |
| [XmpPackageBaseCollection](./xmppackagebasecollection/) | يمثل مجموعة من [`XmpPackage`](../aspose.psd.xmp/xmppackage/). |
| [XmpPacketWrapper](./xmppacketwrapper/) | يحتوي على حزمة xmp مسلسلة تشمل الرأس والذيل. |
| [XmpRdfRoot](./xmprdfroot/) | يمثل عنصر rdf:RDF. يجب تسلسل حزمة XMP واحدة باستخدام عنصر XML rdf:RDF واحد. يجب أن يتكون محتوى عنصر rdf:RDF من صفر أو أكثر من عناصر rdf:Description فقط. |
| [XmpTrailerPi](./xmptrailerpi/) | يمثل تعليمات معالجة ذيل XMP. |
