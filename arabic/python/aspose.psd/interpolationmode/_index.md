التعداد [InterpolationMode](/psd/python-net/aspose.psd/interpolationmode/) يحدد الخوارزمية التي تُستخدم عندما يتم تحجيم أو تدوير الصور.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.InterpolationMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **اسم العضو** | **الوصف** |
| :- | :- |
| BICUBIC | يحدد الاستيفاء الثنائي المكعب. لا يتم إجراء أي تصفية مسبقة. هذا الوضع غير مناسب لتصغير الصورة إلى أقل من 25٪ من حجمها الأصلي. |
| BILINEAR | يحدد الاستيفاء الثنائي الخطي. لا يتم إجراء أي تصفية مسبقة. هذا الوضع غير مناسب لتصغير الصورة إلى أقل من 50٪ من حجمها الأصلي. |
| الافتراضي | يحدد الوضع الافتراضي. |
| HIGH | يحدد الاستيفاء عالي الجودة. |
| HIGH_QUALITY_BICUBIC | يحدد الاستيفاء عالي الجودة، بيكوبك. يتم تطبيق الترشيح المسبق لضمان تصغير عالي الجودة. ينتج هذا الوضع أعلى جودة للصور المحوّلة. |
| HIGH_QUALITY_BILINEAR | يحدد الاستيفاء عالي الجودة، ثنائي الخطوط. يتم تطبيق الترشيح المسبق لضمان تصغير عالي الجودة. |
| INVALID | وضع استيفاء غير صالح. |
| LOW | يحدد استيفاء منخفض الجودة. |
| NEAREST_NEIGHBOR | يحدد استيفاء أقرب جار. |
