表示 PNG 图像颜色类型。

**Module:** [aspose.psd.fileformats.png](/psd/python-net/aspose.psd.fileformats.png/)

**Full Name:** aspose.psd.fileformats.png.PngColorType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **成员名称** | **Description** |
| :- | :- |
| GRAYSCALE | 表示每个像素为灰度样本的颜色类型。 |
| GRAYSCALE_WITH_ALPHA | 表示每个像素为灰度样本后跟随一个 alpha 样本的颜色类型。 |
| INDEXED_COLOR | 表示每个像素为调色板索引的颜色类型；应出现 PLTE 块。 |
| TRUECOLOR | 表示每个像素为 R,G,B 三元组的颜色类型。 |
| TRUECOLOR_WITH_ALPHA | 表示每个像素为 R,G,B 三元组后跟 alpha 采样的颜色类型。 |
