指定如何在 [GraphicsPath](/psd/python-net/aspose.psd/graphicspath/) 对象中包含的图形（子路径）里连接连续的直线或曲线段。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.LineJoin

**Aspose.PSD Version:** 24.12.0

## **Members**
| **成员名称** | **Description** |
| :- | :- |
| BEVEL | 指定斜角连接。这会产生一个对角角。 |
| MITER | 指定斜接连接。这会产生锐角或被裁剪的角，取决于斜接长度是否超过斜接限制。 |
| MITER_CLIPPED | 指定斜接连接。这会产生锐角或斜角，取决于斜接长度是否超过斜接限制。 |
| ROUND | 指定圆形连接。这会在直线之间产生平滑的圆弧。 |
