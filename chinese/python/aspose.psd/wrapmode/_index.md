指定当纹理或渐变小于填充区域时的平铺方式。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.WrapMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **成员名称** | **Description** |
| :- | :- |
| CLAMP | 纹理或渐变未平铺。 |
| TILE | 平铺渐变或纹理。 |
| TILE_FLIP_X | 水平翻转纹理或渐变，然后平铺纹理或渐变。 |
| TILE_FLIP_XY | 水平和垂直翻转纹理或渐变，然后平铺纹理或渐变。 |
| TILE_FLIP_Y | 垂直翻转纹理或渐变，然后平铺该纹理或渐变。 |
