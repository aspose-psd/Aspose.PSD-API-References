指定文本字符串相对于其布局矩形的对齐方式。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringAlignment

**Aspose.PSD Version:** 24.12.0

## **Members**
| **成员名称** | **Description** |
| :- | :- |
| CENTER | 指定文本在布局矩形的中心对齐。 |
| FAR | 指定文本相对于布局矩形的原点位置对齐在远端。<br/>            在从左到右的布局中，远端位置在右侧。<br/>            在从右到左的布局中，远端位置在左侧。 |
| NEAR | 指定文本在布局的近端对齐。<br/>            在从左到右的布局中，近端位置在左侧。<br/>            在从右到左的布局中，近端位置在右侧。 |
