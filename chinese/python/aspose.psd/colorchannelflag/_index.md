**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorChannelFlag

**Aspose.PSD Version:** 24.12.0

## **Members**

| :- | :- |
| COLOR_CHANNEL_C | 青色通道。 |
| COLOR_CHANNEL_K | 黑色通道。 |
| COLOR_CHANNEL_LAST | 应使用最后选择的通道。 |
| COLOR_CHANNEL_M | 品红通道。 |
| COLOR_CHANNEL_Y | 黄色通道。 |
