指定给定数据的计量单位。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.GraphicsUnit

**Aspose.PSD Version:** 24.12.0

## **Members**
| **成员名称** | **Description** |
| :- | :- |
| DISPLAY | 指定显示设备的计量单位。通常视频显示器使用像素，打印机使用 1/100 英寸。 |
| DOCUMENT | 指定文档单位（1/300 英寸）作为计量单位。 |
| 英寸 | 指定英寸作为计量单位。 |
| MILLIMETER | 指定毫米为计量单位。 |
| PIXEL | 指定设备像素为计量单位。 |
| POINT | 指定打印机点（1/72 英寸）为计量单位。 |
| WORLD | 指定世界坐标系单位为计量单位。 |
