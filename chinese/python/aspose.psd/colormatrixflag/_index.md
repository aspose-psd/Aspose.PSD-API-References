指定受 [ImageAttributes](/psd/python-net/aspose.psd/imageattributes/) 的颜色和灰度调整设置影响的图像和颜色类型。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorMatrixFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **成员名称** | **Description** |
| :- | :- |
| ALT_GRAYS | 仅调整灰色阴影。 |
| 默认 | 所有颜色值，包括灰色阴影，均通过相同的颜色调整矩阵进行调整。 |
| SKIP_GRAYS | 所有颜色均已调整，但灰色阴影未被调整。灰色阴影是指红、绿、蓝分量值相同的任何颜色。 |
