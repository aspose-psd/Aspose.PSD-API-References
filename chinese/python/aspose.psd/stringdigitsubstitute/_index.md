枚举指定如何根据用户的地区或语言替换字符串中的数字。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringDigitSubstitute

**Aspose.PSD Version:** 24.12.0

## **Members**
| **成员名称** | **Description** |
| :- | :- |
| 国家 | 指定与用户区域设置的官方国家语言相对应的替代数字。 |
| NONE | 指定禁用替代。 |
| 传统 | 指定与用户本土文字或语言相对应的替代数字，该语言可能与用户区域设置的官方国家语言不同。 |
| 用户 | 指定用户定义的替代方案。 |
