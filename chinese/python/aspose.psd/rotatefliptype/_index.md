指定图像旋转的角度以及用于翻转图像的轴。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.RotateFlipType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **成员名称** | **Description** |
| :- | :- |
| ROTATE_180_FLIP_NONE | 指定 180 度顺时针旋转且不翻转. |
| ROTATE_180_FLIP_X | 指定 180 度顺时针旋转后进行水平翻转. |
| ROTATE_180_FLIP_XY | 指定 180 度顺时针旋转后进行水平和垂直翻转. |
| ROTATE_180_FLIP_Y | 指定 180 度顺时针旋转后进行垂直翻转. |
| ROTATE_270_FLIP_NONE | 指定 270 度顺时针旋转且不翻转. |
| ROTATE_270_FLIP_X | 指定 270 度顺时针旋转后进行水平翻转. |
| ROTATE_270_FLIP_XY | 指定 270 度顺时针旋转后进行水平和垂直翻转. |
| ROTATE_270_FLIP_Y | 指定 270 度顺时针旋转后进行垂直翻转. |
| ROTATE_90_FLIP_NONE | 指定 90 度顺时针旋转且不翻转. |
| ROTATE_90_FLIP_X | 指定 90 度顺时针旋转后进行水平翻转. |
| ROTATE_90_FLIP_XY | 指定 90 度顺时针旋转后进行水平和垂直翻转. |
| ROTATE_90_FLIP_Y | 指定顺时针旋转90度，然后进行垂直翻转。 |
| ROTATE_NONE_FLIP_NONE | 指定不进行顺时针旋转，也不进行翻转。 |
| ROTATE_NONE_FLIP_X | 指定不进行顺时针旋转，然后进行水平翻转。 |
| ROTATE_NONE_FLIP_XY | 指定不进行顺时针旋转，然后进行水平和垂直翻转。 |
| ROTATE_NONE_FLIP_Y | 指定不进行顺时针旋转，然后进行垂直翻转。 |
