指定如何从无法完全适配布局形状的字符串中修剪字符。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringTrimming

**Aspose.PSD Version:** 24.12.0

## **Members**
| **成员名称** | **Description** |
| :- | :- |
| 字符 | 指定将文本裁剪到最近的字符。 |
| ELLIPSIS_CHARACTER | 指定将文本裁剪到最近的字符，并在裁剪行的末尾插入省略号。 |
| ELLIPSIS_PATH | 从裁剪的行中移除中心并用省略号替代。该算法尽可能保留行中最后一个斜杠分隔段的尽可能多内容。 |
| ELLIPSIS_WORD | 指定将文本裁剪到最近的单词，并在裁剪行的末尾插入省略号。 |
| NONE | 指定不进行裁剪。 |
| 单词 | 指定将文本裁剪到最近的单词。 |
