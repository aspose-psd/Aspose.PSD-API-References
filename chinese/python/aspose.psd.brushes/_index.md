该模块提供帮助类和方法，以处理不同的画笔类型。

## **Classes**
| **类** | **Description** |
| :- | :- |
| [HatchBrush](/psd/python-net/aspose.psd.brushes/hatchbrush/) | 定义具有交叉线样式、前景色和背景色的矩形画笔。此类不可被继承。 |
| [LinearGradientBrush](/psd/python-net/aspose.psd.brushes/lineargradientbrush/) | 封装一个带有线性渐变的 [Brush](/psd/python-net/aspose.psd/brush/)。此类不可被继承。 |
| [LinearGradientBrushBase](/psd/python-net/aspose.psd.brushes/lineargradientbrushbase/) | 表示具有渐变功能和相应属性的 [Brush](/psd/python-net/aspose.psd/brush/)。 |
| [LinearMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/linearmulticolorgradientbrush/) | 表示由多种颜色和相应位置定义的线性渐变的 [Brush](/psd/python-net/aspose.psd/brush/)。此类不可被继承。 |
| [PathGradientBrush](/psd/python-net/aspose.psd.brushes/pathgradientbrush/) | 封装一个带有渐变的 [Brush](/psd/python-net/aspose.psd/brush/) 对象。此类不可被继承。 |
| [PathGradientBrushBase](/psd/python-net/aspose.psd.brushes/pathgradientbrushbase/) | 表示具有基础路径渐变功能的 [Brush](/psd/python-net/aspose.psd/brush/)。 |
| [PathMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/pathmulticolorgradientbrush/) | 封装一个带有渐变的 [Brush](/psd/python-net/aspose.psd/brush/) 对象。此类不可被继承。 |
| [SolidBrush](/psd/python-net/aspose.psd.brushes/solidbrush/) | 实心画笔用于使用特定颜色连续绘制。此类不可被继承。 |
| [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) | 每个 [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) 类的属性都是使用图像填充形状内部的 [Brush](/psd/python-net/aspose.psd/brush/) 对象。此类不可被继承。 |
| [TransformBrush](/psd/python-net/aspose.psd.brushes/transformbrush/) | 具有变换功能的 [Brush](/psd/python-net/aspose.psd/brush/)。 |
