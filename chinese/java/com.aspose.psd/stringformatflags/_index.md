### FitBlackBox {#FitBlackBox}
```
public static final int FitBlackBox
```


允许字符的部分超出字符串的布局矩形。默认情况下，字符会重新定位以避免任何超出。

### LineLimit {#LineLimit}
```
public static final int LineLimit
```


仅在格式化矩形中布局完整行。默认情况下，布局会持续到文本结束，或直到由于裁剪导致没有更多行可见，以先出现者为准。请注意，默认设置允许最后一行被格式化矩形部分遮挡，若该矩形的高度不是行高的整数倍。为确保仅显示完整行，请指定此值，并确保提供的格式化矩形高度至少等于一行的高度。

### MeasureTrailingSpaces {#MeasureTrailingSpaces}
```
public static final int MeasureTrailingSpaces
```


包括每行末尾的空格。默认情况下，MeasureString 方法返回的边界矩形会排除每行末尾的空格。设置此标志以在测量中包含该空格。

### NoClip {#NoClip}
```
public static final int NoClip
```


允许显示超出排版矩形的字形悬挂部分和未换行的文本。默认情况下，所有超出排版矩形的文本和字形部分都会被裁剪。

### NoFontFallback {#NoFontFallback}
```
public static final int NoFontFallback
```


已禁用对请求字体不支持的字符使用备用字体的回退。任何缺失的字符将使用字体的缺失字形显示，通常为一个空方框。

### NoWrap {#NoWrap}
```
public static final int NoWrap
```


在矩形内排版时，行间换行已被禁用。当传入点而非矩形，或指定的矩形行长度为零时，此标志会自动生效。
