```
public class JpegLsPresetCodingParameters
```

定义 JPEG-LS 预设编码参数，依据 ISO/IEC 14495-1, C.2.4.1.1。JPEG-LS 定义了一组默认参数，但可以使用自定义参数。使用时，这些参数会写入已编码的比特流，以满足解码过程的需求。
