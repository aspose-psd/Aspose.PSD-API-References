## PsdImage.HasTransparencyData property

获取或设置一个值，指示在指定图层数据时，第一个 alpha 通道是否包含合并结果的透明度数据。

```csharp
public bool HasTransparencyData { get; set; }
```

### Property Value

`true` 如果在指定图层数据时，第一个 alpha 通道包含合并结果的透明度数据；否则为 `false`。
