该命名空间包含与 XMP 相关的帮助类和方法。

## 类

| 类 | 描述 |
| --- | --- |
| [LangAlt](./langalt/) | 表示 XMP 语言替代。 |
| [Namespaces](./namespaces/) | 包含在 RDF 文档中使用的命名空间。 |
| [XmpArray](./xmparray/) | 在 [`XmpPackage`](../aspose.psd.xmp/xmppackage/) 中表示 Xmp 数组。TODO: 数组可能包含复杂数据。 |
| [XmpArrayHelper](./xmparrayhelper/) | 用于处理 RDF 逻辑的辅助类 |
| [XmpElementBase](./xmpelementbase/) | 表示包含属性的基础 xmp 元素。 |
| [XmpHeaderPi](./xmpheaderpi/) | 表示 XMP 头部处理指令。 |
| [XmpMeta](./xmpmeta/) | 表示 xmpmeta。可选。此元素的目的是在可能包含其他非 XMP RDF 用法的通用 XML 文本中标识 XMP 元数据。 |
| [XmpPackage](./xmppackage/) | 定义了 XmpPackage 类，该类表示 XMP 包的基础抽象。 |
| [XmpPackageBaseCollection](./xmppackagebasecollection/) | 表示 [`XmpPackage`](../aspose.psd.xmp/xmppackage/) 的集合。 |
| [XmpPacketWrapper](./xmppacketwrapper/) | 包含已序列化的 xmp 包，包括头部和尾部。 |
| [XmpRdfRoot](./xmprdfroot/) | 表示 rdf:RDF 元素。单个 XMP 包应使用单个 rdf:RDF XML 元素进行序列化。rdf:RDF 元素的内容应仅由零个或多个 rdf:Description 元素组成。 |
| [XmpTrailerPi](./xmptrailerpi/) | 表示 XMP 尾部处理指令。 |
## 接口

| 接口 | 描述 |
| --- | --- |
| [IXmlValue](./ixmlvalue/) | 将 xmp 值转换为 XML 字符串表示。 |
