## GifOptions.MaxDiff property

获取或设置允许的最大像素差异。如果大于零，将使用有损压缩。最佳有损压缩的推荐值为 80。30 为非常轻度压缩，200 为重度压缩。仅在引入的损失很小的情况下效果最佳，并且由于压缩算法的限制，非常高的损失水平不会带来太多收益。允许值的范围是 [0, 1000]。

```csharp
public int MaxDiff { get; set; }
```
