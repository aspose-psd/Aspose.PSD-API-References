## TransformBrush.IsTransformChanged property

获取一个值，指示转换是否以某种方式被更改。例如设置转换矩阵或调用任何修改转换矩阵的方法。此属性为向后兼容 GDI+ 而引入。

```csharp
public bool IsTransformChanged { get; }
```

### Property Value

`True` 如果变换已更改；否则为 `false`。
