该命名空间提供帮助类和方法，以处理不同的画笔类型。

## 类

| 类 | 描述 |
| --- | --- |
| [HatchBrush](./hatchbrush/) | 定义具有交叉线样式、前景色和背景色的矩形画笔。此类不可继承。 |
| [LinearGradientBrush](./lineargradientbrush/) | 封装一个带有线性渐变的 [`Brush`](../aspose.psd/brush/)。此类不可继承。 |
| [LinearGradientBrushBase](./lineargradientbrushbase/) | 表示一个具有渐变功能和相应属性的 [`Brush`](../aspose.psd/brush/)。 |
| [LinearMulticolorGradientBrush](./linearmulticolorgradientbrush/) | 表示一个由多种颜色和相应位置定义的线性渐变的 [`Brush`](../aspose.psd/brush/)。此类不可继承。 |
| [PathGradientBrush](./pathgradientbrush/) | 封装一个带有渐变的 [`Brush`](../aspose.psd/brush/) 对象。此类不可继承。 |
| [PathGradientBrushBase](./pathgradientbrushbase/) | 表示一个具有基础路径渐变功能的 [`Brush`](../aspose.psd/brush/)。 |
| [PathMulticolorGradientBrush](./pathmulticolorgradientbrush/) | 封装一个带有渐变的 [`Brush`](../aspose.psd/brush/) 对象。此类不可继承。 |
| [SolidBrush](./solidbrush/) | 实心画笔用于使用特定颜色持续绘制。此类不可继承。 |
| [TextureBrush](./texturebrush/) | [`TextureBrush`](../aspose.psd.brushes/texturebrush/) 类的每个属性都是一个使用图像填充形状内部的 [`Brush`](../aspose.psd/brush/) 对象。此类不可继承。 |
| [TransformBrush](./transformbrush/) | 具有变换功能的 [`Brush`](../aspose.psd/brush/)。 |
