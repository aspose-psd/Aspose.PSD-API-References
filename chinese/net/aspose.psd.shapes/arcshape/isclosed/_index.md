## ArcShape.IsClosed property

获取或设置一个值，指示有序形状是否闭合。处理闭合的有序形状时，起始点和结束点没有意义。

```csharp
public bool IsClosed { get; set; }
```

### Property Value

`True` 如果此有序形状闭合；否则，`false`。
