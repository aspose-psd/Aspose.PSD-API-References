## IPlacedLayerResource.IsCustom property

获取或设置一个值，以指示此实例的扭曲样式是否为自定义。如果为 true，则包含网格点；如果设置为 false，则会删除网格点。

```csharp
public bool IsCustom { get; set; }
```

### Property Value

`true` 如果已放置或智能对象图层资源具有自定义样式；否则为 `false`。
