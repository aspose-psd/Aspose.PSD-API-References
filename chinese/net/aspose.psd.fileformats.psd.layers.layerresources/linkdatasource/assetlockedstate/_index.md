## LinkDataSource.AssetLockedState property

获取或设置指示 PSD 资产是否被锁定的值。资产锁定状态，适用于 Adobe® Photoshop® СС Libraries 资产。

```csharp
public bool AssetLockedState { get; set; }
```

### Property Value

`true` 表示 Adobe® Photoshop® 资产已锁定；否则为 `false`。
