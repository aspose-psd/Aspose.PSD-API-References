## LinkDataSource.IsLibraryLink property

获取一个值，指示此 PSD 链接数据源是否链接到 Adobe® Photoshop® СС Library 项目。

```csharp
public bool IsLibraryLink { get; }
```

### Property Value

`true` 表示此实例是 Adobe® Photoshop® СС 库链接；否则为 `false`。
