## LinkDataSource.OriginalCompId property

获取子文档当前选定的 Comp 的原始 ID，如果未选中则为 -1。此属性获取智能对象的原始图层 Comp 选择标识符。[Layer comps in Smart Objects](https://helpx.adobe.com/photoshop/using/layer-comps.html)

```csharp
public int OriginalCompId { get; }
```

### Property Value

当前子文档中已选取的 comp 的原始 ID，如果未选取则为 -1。
