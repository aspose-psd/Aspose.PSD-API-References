## OSTypeStructuresRegistry.GetFirstSupportedDescriptorByTypeName method

```csharp
public static IOSTypeStructureLoader GetFirstSupportedDescriptorByTypeName(
    string descriptorTypeName)
```

| 参数 | 类型 | 描述 |
