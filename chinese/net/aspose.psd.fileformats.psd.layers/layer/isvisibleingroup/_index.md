## Layer.IsVisibleInGroup property

获取一个值，指示此实例在组中是否可见（如果图层不在组中，则表示根组）。

```csharp
public virtual bool IsVisibleInGroup { get; }
```

### Property Value

`true` 表示此实例在组中可见；否则为 `false`。
