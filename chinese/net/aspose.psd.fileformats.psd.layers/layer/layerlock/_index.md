## Layer.LayerLock property

获取或设置图层锁定。注意，如果设置了标志 LayerFlags.TransparencyProtected，它将被图层锁定标志覆盖。要返回 LayerFlags.TransparencyProtected 标志，需要对图层选项使用 layer.Flags &#x7C;= LayerFlags.TransparencyProtected

```csharp
public LayerLockType LayerLock { get; set; }
```

### Property Value

层锁。
