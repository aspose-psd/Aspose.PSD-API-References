## Layer.Flags property

获取或设置图层标志。位 0 = 透明受保护；位 1 = 可见；位 2 = 已废弃；位 3 = 对 Photoshop 5.0 及更高版本为 1，指示位 4 是否包含有用信息；位 4 = 像素数据与文档外观无关。

```csharp
public LayerFlags Flags { get; set; }
```

### Property Value

图层标志。
