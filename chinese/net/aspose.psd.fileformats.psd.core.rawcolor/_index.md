该命名空间包含 PSD RawColor 类层次结构，包括 ColorComponent。

## 类

| 类 | 描述 |
| --- | --- |
| [ColorComponent](./colorcomponent/) | 颜色组件是对通道值的抽象。任何颜色都是由 ColorComponent 数组组成的。 |
| [RawColor](./rawcolor/) | Raw Color Class 用于存储任意通道数、任意颜色模式和任意位深的颜色。请注意，某些内部类在将 RawColor 转换为其本机格式时可能会出现问题，因此如果 API 为您提供 CMYK 颜色，使用提供的格式更可靠。此外，在某些情况下也可以转换 Raw Color。 |
| [RawColorHelper](./rawcolorhelper/) | Raw Color Helper Class 可帮助更快地创建 RawColor，使用预定义的通道元数据。 |
