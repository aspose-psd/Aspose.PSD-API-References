## PsdLoadOptions.ReadOnlyMode property

获取或设置一个值，指示是否 [use read only mode]。这是只读模式，支持与 Adobe Photoshop 完全兼容。当此选项被设置时，对图层所做的所有更改将不会保存到最终图像。所有数据均来自 ImageData 部分，因此与 Photoshop 完全相同。默认情况下，所有加载的图像都不完全兼容 Adobe Photoshop。

```csharp
public bool ReadOnlyMode { get; set; }
```

### Property Value

`true` 如果 [use photoshop compatibility mode]；否则为 `false`。
