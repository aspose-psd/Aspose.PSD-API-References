## PsdLoadOptions.LoadEffectsResource property

获取或设置一个值，指示是否 [load effects resource]（默认情况下资源未加载）。设置此选项后，仅支持的效果将渲染到最终合并图像。

```csharp
public bool LoadEffectsResource { get; set; }
```

### Property Value

`true` 如果 [load effects resource]；否则为 `false`。
