## ThumbnailResource.JpegOptions property

获取或设置 JPEG 选项。仅在缩略图资源保存为 JPEG 文件格式时适用。当定义为 RAW 格式时，此选项无效。

```csharp
public JpegOptions JpegOptions { get; set; }
```

### Property Value

JPEG 选项。
