## GraphicsUnit enumeration

指定给定数据的计量单位。

```csharp
public enum GraphicsUnit
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| World | `0` | 指定世界坐标系单位作为计量单位。 |
| Display | `1` | 指定显示设备的计量单位。通常视频显示为像素，打印机为 1/100 英寸。 |
| Pixel | `2` | 指定设备像素为计量单位。 |
| Point | `3` | 指定打印机的点（1/72 英寸）为计量单位。 |
| Inch | `4` | 指定英寸为计量单位。 |
| Document | `5` | 指定文档单位（1/300 英寸）为计量单位。 |
| Millimeter | `6` | 指定毫米为计量单位。 |
