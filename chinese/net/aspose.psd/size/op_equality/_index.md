## Size Equality operator

测试两个 [`Size`](../) 结构是否相等。

```csharp
public static bool operator ==(Size size1, Size size2)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| size1 | Size | 等号运算符左侧的 [`Size`](../) 结构。 |
| size2 | Size | 等号运算符右侧的 [`Size`](../) 结构。 |

### 返回值

如果 *size1* 和 *size2* 的宽度和高度相等，则为 True；否则为 false。
