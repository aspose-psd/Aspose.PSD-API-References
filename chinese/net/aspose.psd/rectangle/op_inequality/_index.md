## Rectangle Inequality operator

测试两个 [`Rectangle`](../) 结构在位置或大小上是否不同。

```csharp
public static bool operator !=(Rectangle left, Rectangle right)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| left | Rectangle | 位于不等式运算符左侧的 [`Rectangle`](../) 结构。 |
| right | Rectangle | 位于不等式运算符右侧的 [`Rectangle`](../) 结构。 |

### 返回值

如果两个 [`Rectangle`](../) 结构的任一 [`X`](../x/)、[`Y`](../y/)、[`Width`](../width/) 或 [`Height`](../height/) 属性不相等，则此运算符返回 true；否则返回 false。
