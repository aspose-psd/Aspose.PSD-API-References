## PixelDataFormat.RgbIndexed4Bpp property

获取定义为每种颜色 4 位索引的 [`PixelDataFormat`](../)。索引像素数据存储旨在在使用调色板的所有地方实现数据的存储和检索。使用时请谨慎，因为可能需要在不同调色板之间或在 RGBA 与索引颜色模型之间进行转换。

public static PixelDataFormat RgbIndexed4Bpp { get; }
