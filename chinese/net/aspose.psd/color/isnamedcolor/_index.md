## Color.IsNamedColor property

获取一个值，指示此 [`Color`](../) 结构是命名颜色还是 [`KnownColor`](../../knowncolor/) 枚举的成员。

```csharp
public bool IsNamedColor { get; }
```

### Property Value

如果此 [`Color`](../) 是通过使用 [`FromName`](../fromname/) 方法或 [`FromKnownColor`](../fromknowncolor/) 方法创建的，则为 true；否则为 false。
