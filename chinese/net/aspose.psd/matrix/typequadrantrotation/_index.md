## Matrix.TypeQuadrantRotation field

此标志位表示，由此对象定义的变换在执行其他标志位指示的转换之外，还会进行以 90 度的若干倍为单位的象限旋转。旋转会在不改变向量长度的前提下，使向量的角度统一改变相同的量，无论向量的原始方向如何。此标志位与 TypeGeneralRotation 标志互斥。

```csharp
public const int TypeQuadrantRotation;
```
