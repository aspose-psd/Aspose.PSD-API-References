## FileStreamContainer.IsTemporal property

获取或设置指示流是否为临时的值。

```csharp
public bool IsTemporal { get; set; }
```

### Property Value

`true` 表示流是临时的；否则为 `false`。

## 备注

临时流在释放时会自行删除。如果流基于内存，则此属性无效。流可以标记为临时或持久，前提是它是显式创建的，否则会抛出相应的异常。
