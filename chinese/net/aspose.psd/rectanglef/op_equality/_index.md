## RectangleF Equality operator

测试两个 [`RectangleF`](../) 结构的位置和大小是否相等。

```csharp
public static bool operator ==(RectangleF left, RectangleF right)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| left | RectangleF | 等号运算符左侧的 [`RectangleF`](../) 结构。 |
| right | RectangleF | 等号运算符右侧的 [`RectangleF`](../) 结构。 |

### 返回值

如果两个指定的 [`RectangleF`](../) 结构的 [`X`](../x/)、[`Y`](../y/)、[`Width`](../width/) 和 [`Height`](../height/) 属性相等，则此运算符返回 true。
