## StringDigitSubstitute enumeration

此枚举指定如何根据用户的地区或语言替换字符串中的数字。

```csharp
public enum StringDigitSubstitute
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| User | `0` | 指定用户定义的替换方案。 |
| None | `1` | 指定禁用替换。 |
| National | `2` | 指定与用户所在地区官方国家语言对应的替换数字。 |
| Traditional | `3` | 指定与用户本土文字或语言对应的替换数字，这可能与用户所在地区的官方国家语言不同。 |
