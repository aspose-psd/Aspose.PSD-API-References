ISO/IEC 14495-1, C.2.4.1.1에 정의된 JPEG-LS 사전 코딩 매개변수를 정의합니다. JPEG-LS는 기본 매개변수 집합을 정의하지만, 사용자 지정 매개변수를 사용할 수 있습니다. 사용될 경우 이러한 매개변수는 디코딩 과정에 필요하도록 인코딩된 비트 스트림에 기록됩니다.
