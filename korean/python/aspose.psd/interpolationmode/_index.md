The [InterpolationMode](/psd/python-net/aspose.psd/interpolationmode/) 열거형은 이미지가 확대되거나 회전될 때 사용되는 알고리즘을 지정합니다.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.InterpolationMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **멤버 이름** | **설명** |
| :- | :- |
| BICUBIC | bicubic 보간법을 지정합니다. 사전 필터링이 수행되지 않습니다. 이 모드는 이미지 크기를 원본 크기의 25% 이하로 축소할 때 적합하지 않습니다. |
| BILINEAR | bilinear 보간법을 지정합니다. 사전 필터링이 수행되지 않습니다. 이 모드는 이미지 크기를 원본 크기의 50% 이하로 축소할 때 적합하지 않습니다. |
| 기본값 | 기본 모드를 지정합니다. |
| HIGH | 고품질 보간법을 지정합니다. |
| HIGH_QUALITY_BICUBIC | 고품질의 bicubic 보간법을 지정합니다. 고품질 축소를 보장하기 위해 사전 필터링이 수행됩니다. 이 모드는 가장 높은 품질의 변환된 이미지를 생성합니다. |
| HIGH_QUALITY_BILINEAR | 고품질의 bilinear 보간법을 지정합니다. 고품질 축소를 보장하기 위해 사전 필터링이 수행됩니다. |
| INVALID | 잘못된 보간 모드입니다. |
| LOW | 저품질 보간법을 지정합니다. |
| NEAREST_NEIGHBOR | 최근접 이웃 보간을 지정합니다. |
