## **Members**
| **멤버 이름** | **설명** |
| :- | :- |
| ASSOCIATED | 알파 값은 사전 곱셈 형태로 저장됩니다. 알파를 복원할 때 약간의 반올림 효과가 발생할 수 있으며 복원된 값이 원본과 다를 수 있습니다. |
| UNASSOCIATED | 알파 값은 비연관 형태로 저장됩니다. 이는 복원된 알파가 TIFF에 저장된 값과 정확히 동일함을 의미합니다. |
| UNSPECIFIED | 알파가 지정되지 않았으며 tiff 파일에 저장됩니다. |
