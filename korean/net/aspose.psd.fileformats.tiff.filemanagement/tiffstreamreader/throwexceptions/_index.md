## TiffStreamReader.ThrowExceptions property

잘못된 데이터 처리(스트림 읽기 또는 쓰기) 시 예외가 발생하는지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool ThrowExceptions { get; set; }
```

### Property Value

`true`는 데이터 처리 오류가 발생했을 때 예외가 발생함을 의미하고, 그렇지 않으면 오류 상황이 조용히 무시됩니다.
