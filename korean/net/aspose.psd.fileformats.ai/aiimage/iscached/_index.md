## AiImage.IsCached property

객체의 데이터가 현재 캐시되어 있어 데이터 읽기가 필요하지 않은지를 나타내는 값을 가져옵니다.

```csharp
public override bool IsCached { get; }
```

### Property Value

`true`이면 객체 데이터가 캐시된 경우; 그렇지 않으면 `false`.
