네임스페이스는 다양한 브러시 유형을 다루기 위한 도우미 클래스와 메서드를 제공합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [HatchBrush](./hatchbrush/) | 해치 스타일, 전경 색 및 배경 색을 가진 사각형 브러시를 정의합니다. 이 클래스는 상속될 수 없습니다. |
| [LinearGradientBrush](./lineargradientbrush/) | 선형 그라디언트를 가진 [`Brush`](../aspose.psd/brush/)를 캡슐화합니다. 이 클래스는 상속될 수 없습니다. |
| [LinearGradientBrushBase](./lineargradientbrushbase/) | 그라디언트 기능과 적절한 속성을 가진 [`Brush`](../aspose.psd/brush/)를 나타냅니다. |
| [LinearMulticolorGradientBrush](./linearmulticolorgradientbrush/) | 여러 색상과 적절한 위치로 정의된 선형 그라디언트를 가진 [`Brush`](../aspose.psd/brush/)를 나타냅니다. 이 클래스는 상속될 수 없습니다. |
| [PathGradientBrush](./pathgradientbrush/) | 그라디언트를 가진 [`Brush`](../aspose.psd/brush/) 객체를 캡슐화합니다. 이 클래스는 상속될 수 없습니다. |
| [PathGradientBrushBase](./pathgradientbrushbase/) | 기본 경로 그라디언트 기능을 가진 [`Brush`](../aspose.psd/brush/)를 나타냅니다. |
| [PathMulticolorGradientBrush](./pathmulticolorgradientbrush/) | 그라디언트를 가진 [`Brush`](../aspose.psd/brush/) 객체를 캡슐화합니다. 이 클래스는 상속될 수 없습니다. |
| [SolidBrush](./solidbrush/) | 솔리드 브러시는 특정 색상으로 지속적으로 그리기 위해 설계되었습니다. 이 클래스는 상속될 수 없습니다. |
| [TextureBrush](./texturebrush/) | [`TextureBrush`](../aspose.psd.brushes/texturebrush/) 클래스의 각 속성은 이미지로 도형 내부를 채우는 [`Brush`](../aspose.psd/brush/) 객체입니다. 이 클래스는 상속될 수 없습니다. |
| [TransformBrush](./transformbrush/) | 변환 기능을 가진 [`Brush`](../aspose.psd/brush/)입니다. |
