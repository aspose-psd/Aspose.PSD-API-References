## SetBlendTriangularShape(float) {#setblendtriangularshape}

중심 색상과 하나의 주변 색상으로 선형 감쇠되는 그라디언트를 생성합니다.

```csharp
public void SetBlendTriangularShape(float focus)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 초점 | 단일 | 0부터 1까지의 값으로, 경로 중심에서 경계까지의 방사선 상에서 중심 색상의 최대 강도가 위치하는 지점을 지정합니다. 값 1(기본값)은 경로 중심에 최대 강도를 배치합니다. |

## SetBlendTriangularShape(float, float) {#setblendtriangularshape_1}

중심 색상과 각 주변 색상으로 선형 감쇠되는 그라디언트를 생성합니다.

```csharp
public void SetBlendTriangularShape(float focus, float scale)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 초점 | 단일 | 0부터 1까지의 값으로, 경로 중심에서 경계까지의 방사선 상에서 중심 색상의 최대 강도가 위치하는 지점을 지정합니다. 값 1(기본값)은 경로 중심에 최대 강도를 배치합니다. |
| scale | 단일 | 0부터 1까지의 값으로, 경계 색상과 혼합되는 중심 색상의 최대 강도를 지정합니다. 값 1은 가능한 가장 높은 중심 색상 강도를 발생시키며, 기본값입니다. |
