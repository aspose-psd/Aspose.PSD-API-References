## PsdOptions.RefreshImagePreviewData property

다른 PSD 이미지 뷰어와의 호환성을 최대화하기 위해 사용되는 옵션인 [refresh image preview data] 여부를 가져오거나 설정합니다. Compact Framework 플랫폼에서는 텍스트 레이어를 최종 레이아웃에 그리는 것이 지원되지 않음을 참고하십시오.

```csharp
public bool RefreshImagePreviewData { get; set; }
```

### Property Value

`true`이면 [refresh image preview data]; 그렇지 않으면 `false`.
