## GifOptions.DoPaletteCorrection property

팔레트 보정이 적용되는지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool DoPaletteCorrection { get; set; }
```

### Property Value

`true`이면 팔레트 보정이 적용됩니다; 그렇지 않으면 `false`입니다.

## 비고

팔레트 보정은 이미지를 GIF로 내보낼 때마다 원본 이미지 색상이 최적의 일치 팔레트를 만들기 위해 분석된다는 의미입니다(이미지 Palette가 없거나 옵션에 지정되지 않은 경우). 분석 과정에는 시간이 걸리지만, 출력 이미지가 최적의 색상 팔레트를 갖게 되어 시각적으로 더 나은 결과를 제공합니다.
