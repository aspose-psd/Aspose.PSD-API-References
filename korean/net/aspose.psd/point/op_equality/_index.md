## Point Equality operator

두 [`Point`](../) 객체를 비교합니다. 결과는 두 [`Point`](../) 객체의 [`X`](../x/)와 [`Y`](../y/) 속성 값이 동일한지 여부를 지정합니다.

```csharp
public static bool operator ==(Point point1, Point point2)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| point1 | Point | 비교할 첫 번째 [`Point`](../). |
| point2 | Point | 비교할 두 번째 [`Point`](../). |

### 반환 값

두 *point1*과 *point2*의 [`X`](../x/) 및 [`Y`](../y/) 값이 동일하면 true; 그렇지 않으면 false.
