## Write(byte[], int, int) {#write_1}

바이트 시퀀스를 현재 스트림에 쓰고, 쓰여진 바이트 수만큼 이 스트림 내 현재 위치를 이동합니다.

```csharp
public virtual void Write(byte[] buffer, int offset, int count)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| buffer | Byte[] | 바이트 배열. 이 메서드는 *buffer*에서 현재 스트림으로 *count* 바이트를 복사합니다. |
| offset | Int32 | 현재 스트림으로 바이트 복사를 시작할 *buffer*의 0부터 시작하는 바이트 오프셋. |
| count | Int32 | 현재 스트림에 기록될 바이트 수. |
