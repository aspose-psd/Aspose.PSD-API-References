## Rectangle Inequality operator

두 [`Rectangle`](../) 구조가 위치 또는 크기가 다른지 테스트합니다.

```csharp
public static bool operator !=(Rectangle left, Rectangle right)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| left | Rectangle | 부등호 연산자의 왼쪽에 있는 [`Rectangle`](../) 구조입니다. |
| right | Rectangle | 부등호 연산자의 오른쪽에 있는 [`Rectangle`](../) 구조입니다. |

### 반환 값

이 연산자는 두 [`Rectangle`](../) 구조의 [`X`](../x/), [`Y`](../y/), [`Width`](../width/) 또는 [`Height`](../height/) 속성 중 하나라도 서로 다르면 true를 반환하고, 그렇지 않으면 false를 반환합니다.
