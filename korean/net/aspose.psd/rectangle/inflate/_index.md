## Inflate(Rectangle, int, int)

지정된 [`Rectangle`](../) 구조의 확대된 복사본을 생성하고 반환합니다. 복사본은 지정된 양만큼 확대됩니다. 원본 [`Rectangle`](../) 구조는 수정되지 않습니다.

```csharp
public static Rectangle Inflate(Rectangle rect, int x, int y)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| rect | Rectangle | 시작할 [`Rectangle`](../)입니다. 이 사각형은 수정되지 않습니다. |
| x | Int32 | 이 [`Rectangle`](../)을 가로 방향으로 확대할 양. |
| y | Int32 | 이 [`Rectangle`](../)을 세로 방향으로 확대할 양. |

### 반환 값

확대된 [`Rectangle`](../).
