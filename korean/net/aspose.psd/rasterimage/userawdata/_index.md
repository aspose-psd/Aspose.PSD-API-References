## RasterImage.UseRawData property

원시 데이터 로딩이 가능할 때 원시 데이터 로딩을 사용할지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public virtual bool UseRawData { get; set; }
```

### Property Value

`true` 원시 데이터 로딩이 가능한 경우 원시 데이터 로딩을 사용하는 경우; 그렇지 않으면 `false`.
