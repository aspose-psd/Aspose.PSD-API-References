## Pen.CompoundArray property

복합 펜을 지정하는 값 배열을 가져오거나 설정합니다. 복합 펜은 평행선과 간격으로 구성된 복합 라인을 그립니다.

```csharp
public float[] CompoundArray { get; set; }
```

### Property Value

복합 배열을 지정하는 실수 배열입니다. 배열의 요소는 오름차순이어야 하며 0보다 작지 않고 1보다 크지 않아야 합니다.
