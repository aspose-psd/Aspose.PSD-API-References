## GraphicsUnit enumeration

```csharp
public enum GraphicsUnit
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| World | `0` | 월드 좌표계 단위를 측정 단위로 지정합니다. |
| Display | `1` | 디스플레이 장치의 측정 단위를 지정합니다. 일반적으로 비디오 디스플레이는 픽셀이며 프린터는 1/100 인치입니다. |
| Pixel | `2` | 디바이스 픽셀을 측정 단위로 지정합니다. |
| Point | `3` | 프린터 포인트(1/72 인치)를 측정 단위로 지정합니다. |
| Inch | `4` | 인치를 측정 단위로 지정합니다. |
| Document | `5` | 문서 단위(1/300 인치)를 측정 단위로 지정합니다. |
| Millimeter | `6` | 밀리미터를 측정 단위로 지정합니다. |
