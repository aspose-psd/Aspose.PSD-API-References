## Figure.IsClosed property

이 도형이 닫혀 있는지 여부를 나타내는 값을 가져오거나 설정합니다. 닫힌 도형은 첫 번째와 마지막 도형의 모양이 연속적인 경우에만 차이가 있습니다. 이러한 경우 첫 번째 모양의 첫 번째 점이 마지막 모양의 마지막 점에서 직선으로 연결됩니다.

```csharp
public bool IsClosed { get; set; }
```

### Property Value

`True` 이 도형이 닫혀 있는 경우; 그렇지 않으면 `false`.
