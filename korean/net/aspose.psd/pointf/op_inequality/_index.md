```csharp
public static bool operator !=(PointF point1, PointF point2)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| point1 | PointF | 비교할 첫 번째 [`PointF`](../). |
| point2 | PointF | 비교할 두 번째 [`PointF`](../). |

### 반환 값
