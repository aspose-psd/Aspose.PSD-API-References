| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| size1 | Size | 부등호 연산자 왼쪽에 있는 [`Size`](../) 구조체. |
| size2 | Size | 부등호 연산자 오른쪽에 있는 [`Size`](../) 구조체. |
