## IImageExporterDescriptor.CanExport method

이미지 내보내기가 저장 옵션으로 지정된 이미지 형식으로 지정된 이미지를 내보낼 수 있는지 여부를 결정합니다.

```csharp
public bool CanExport(Image image, ImageOptionsBase optionsBase)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| image | Image | 내보낼 이미지. |
| optionsBase | ImageOptionsBase | 옵션 기본. |

### 반환 값

`True` 이 설명자에 의해 생성된 내보내기가 지정된 이미지를 지정된 파일 형식으로 내보낼 수 있는 경우; 그렇지 않으면 `false`.
