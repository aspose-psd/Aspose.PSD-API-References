## SetOutputChannelColorProfile(string) {#setoutputchannelcolorprofile}

기본 카테고리의 출력 채널 색 프로파일 파일을 설정합니다.

```csharp
public void SetOutputChannelColorProfile(string colorProfileFilename)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| colorProfileFilename | String | 색상 프로파일 파일의 경로 이름입니다. 색상 프로파일 파일이 %SystemRoot%\System32\Spool\Drivers\Color 디렉터리에 있는 경우, 이 매개변수는 파일 이름일 수 있습니다. 그렇지 않으면, 이 매개변수는 전체 경로 이름이어야 합니다. |
