## Equals(object)

지정된 Object가 이 인스턴스와 같은지 여부를 판단합니다.

```csharp
public override bool Equals(object obj)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| obj | Object | 이 인스턴스와 비교할 Object. |

### 반환 값

`true`이면 지정된 Object가 이 인스턴스와 같고, 그렇지 않으면 `false`.
