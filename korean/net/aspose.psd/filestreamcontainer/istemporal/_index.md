## FileStreamContainer.IsTemporal property

스트림이 일시적인지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool IsTemporal { get; set; }
```

### Property Value

`true`이면 스트림이 일시적이며, 그렇지 않으면 `false`.

## 비고

일시적인 스트림은 폐기될 때 자체를 제거합니다. 스트림이 메모리 기반인 경우 이 속성은 영향을 미치지 않습니다. 스트림이 명시적으로 생성된 경우 일시적 또는 영구적으로 표시할 수 있으며, 그렇지 않으면 적절한 예외가 발생합니다.
