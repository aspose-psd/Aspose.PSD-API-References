## Inflate(RectangleF, float, float)

지정된 [`RectangleF`](../) 구조의 확대된 복사본을 생성하고 반환합니다. 복사본은 지정된 양만큼 확대됩니다. 원본 사각형은 수정되지 않습니다.

```csharp
public static RectangleF Inflate(RectangleF rect, float x, float y)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| rect | RectangleF | 복사할 [`RectangleF`](../)입니다. 이 사각형은 수정되지 않습니다. |
| x | 단일 | 사각형 복사본을 수평으로 확대할 양입니다. |
| y | 단일 | 사각형 복사본을 수직으로 확대할 양입니다. |

### 반환 값

확대된 [`RectangleF`](../)입니다.
