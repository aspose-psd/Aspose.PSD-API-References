네임스페이스에는 핵심 PSD 구성 요소에서 발생하는 예외가 포함됩니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [CompressorException](./compressorexception/) | 압축기 예외. |
| [DataMissmatchError](./datamissmatcherror/) | 데이터 불일치 예외 클래스 |
| [FrameworkException](./frameworkexception/) | PSD 프레임워크 예외. 이 클래스는 모든 Aspose.PSD 예외에 대한 핵심 클래스입니다. Aspose.PSD 엔진에서 발생하는 예외와 기타 모든 예외 유형을 구분하기 위해 도입되었습니다. |
| [ImageCreateException](./imagecreateexception/) | 이미지 생성 예외. 이미지 생성 중에 발생합니다. |
| [ImageException](./imageexception/) | 이미지 예외. |
| [ImageLoadException](./imageloadexception/) | 이미지 로드 예외. 이미지 로드 중에 발생합니다. |
| [ImageSaveException](./imagesaveexception/) | 이미지 저장 예외. 이미지 저장 중에 발생합니다. |
| [IndexOutOFRangeException](./indexoutofrangeexception/) | 압축기 예외. |
| [LimitMemoryException](./limitmemoryexception/) | 메모리 제한 예외. 메모리 사용량을 줄여야 할 때 발생합니다. |
| [OperationInterruptedException](./operationinterruptedexception/) | 작업이 중단될 때 발생합니다. |
| [RdOptimizationError](./rdoptimizationerror/) | RD 최적화 오류 예외 클래스 |
| [StreamReadException](./streamreadexception/) | 스트림 읽기 예외. 잘못된 오프셋 및 바이트 수 요청으로 스트림 읽기에 실패했을 때 발생합니다. |
| [XmpException](./xmpexception/) | XMP 구조가 유효하지 않을 때 발생하는 예외. |
