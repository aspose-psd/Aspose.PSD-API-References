네임스페이스는 PSD 파일 형식 처리를 담당합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [BaseGradient](./basegradient/) | 기본 그라디언트 정의 클래스. 솔리드와 노이즈 두 유형의 그라디언트에 공통적인 속성을 포함합니다. |
| [NoiseGradient](./noisegradient/) | 노이즈 그라디언트 정의 클래스입니다. |
| [SolidGradient](./solidgradient/) | 그라디언트 채우기 효과 설정입니다. |
## 열거형

| 열거형 | 설명 |
| --- | --- |
| [GradientKind](./gradientkind/) | 그라디언트 유형 열거형입니다. |
| [NoiseColorModel](./noisecolormodel/) | 색상 모델: 'Gradient type'이 'Noise'인 경우, 'Color Model'을 RGB/SHB/LAB(3/4/6) 중 하나로 지정할 수 있습니다. |
