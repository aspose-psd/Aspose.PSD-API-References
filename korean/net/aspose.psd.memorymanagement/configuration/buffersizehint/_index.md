## Configuration.BufferSizeHint property

모든 내부 버퍼에 대해 정의된 최대 허용 크기인 버퍼 크기 힌트를 가져오거나 설정합니다.

```csharp
public static int BufferSizeHint { get; set; }
```

### Property Value

버퍼 크기 힌트(메가바이트 단위). 0 이하 값은 내부 버퍼에 메모리 제한이 없음을 의미합니다.
