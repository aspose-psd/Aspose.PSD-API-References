## IPlacedLayerResource.IsCustom property

이 인스턴스의 왜곡 스타일이 사용자 지정인지 여부를 나타내는 값을 가져오거나 설정합니다. true이면 메시 포인트를 포함하고, false로 설정하면 메시 포인트를 삭제합니다.

```csharp
public bool IsCustom { get; set; }
```

### Property Value

`true`이면 배치된 레이어 또는 스마트 오브젝트 레이어 리소스가 사용자 지정 스타일을 가지고 있습니다; 그렇지 않으면 `false`입니다.
