## LinkDataSource.IsLibraryLink property

이 PSD 링크 데이터 소스가 Adobe® Photoshop® СС Library 항목에 연결되는지 여부를 나타내는 값을 가져옵니다.

```csharp
public bool IsLibraryLink { get; }
```

### Property Value

`true` 이 인스턴스가 Adobe® Photoshop® СС 라이브러리 링크인 경우; 그렇지 않으면 `false`.
