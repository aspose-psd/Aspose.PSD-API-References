## LinkDataSource.AssetLockedState property

PSD 자산이 잠겨 있는지 여부를 나타내는 값을 가져오거나 설정합니다. Adobe® Photoshop® CC 라이브러리 자산에 대한 잠금 상태입니다.

```csharp
public bool AssetLockedState { get; set; }
```

### Property Value

`true`이면 Adobe® Photoshop® 자산이 잠겨 있습니다; 그렇지 않으면 `false`입니다.
