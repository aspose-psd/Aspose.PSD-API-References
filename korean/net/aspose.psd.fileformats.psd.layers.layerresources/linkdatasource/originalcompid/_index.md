## LinkDataSource.OriginalCompId property

현재 선택된 자식 문서의 컴프 원래 ID를 가져옵니다. 선택된 것이 없으면 -1이 됩니다. 이 속성은 스마트 오브젝트에 대한 원래 레이어 컴프 선택 식별자를 가져옵니다. [Layer comps in Smart Objects](https://helpx.adobe.com/photoshop/using/layer-comps.html)

```csharp
public int OriginalCompId { get; }
```

### Property Value

현재 선택된 자식 문서의 comp 원래 ID이며, 선택된 것이 없으면 -1이 됩니다.
