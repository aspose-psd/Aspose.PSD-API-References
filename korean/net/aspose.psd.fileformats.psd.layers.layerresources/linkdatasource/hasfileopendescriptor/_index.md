## LinkDataSource.HasFileOpenDescriptor property

이 링크 데이터 소스에 파일 열기 설명자(CompId 및 OriginalCompId)가 있는지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool HasFileOpenDescriptor { get; set; }
```

### Property Value

`true`이면 이 인스턴스에 파일 열기 디스크립터가 있습니다; 그렇지 않으면 `false`입니다.
