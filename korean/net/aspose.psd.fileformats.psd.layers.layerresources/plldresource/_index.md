## PlLdResource class

PlLdResource 클래스를 정의하며, PSD 파일에서 배치 레이어에 대한 정보를 포함합니다. 이는 Adobe® Photoshop® 이미지에서 스마트 오브젝트 레이어를 지원하는 데 사용됩니다. Adobe® Photoshop® CS3에서 SoLdResource로 대체되었습니다.

```csharp
public class PlLdResource : PlacedResource
```
