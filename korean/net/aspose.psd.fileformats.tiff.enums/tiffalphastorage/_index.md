## TiffAlphaStorage enumeration

tiff 문서의 알파 저장 방식을 지정합니다.

```csharp
public enum TiffAlphaStorage : ushort
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Unspecified | `0` | 알파가 지정되지 않았으며 tiff 파일에 저장됩니다. |
| Associated | `1` | 알파 값이 사전 곱셈 형태로 저장됩니다. 알파를 복원할 때 반올림 효과가 발생할 수 있으며 복원된 값이 원본과 다를 수 있습니다. |
| Unassociated | `2` | 알파 값이 비연관 형태로 저장됩니다. 이는 복원된 알파가 tiff에 저장된 것과 정확히 동일함을 의미합니다. |
