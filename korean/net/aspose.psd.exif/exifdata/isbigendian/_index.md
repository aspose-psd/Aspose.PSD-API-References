## ExifData.IsBigEndian property

스트림에서 생성된 EXIF 데이터가 빅 엔디안인지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool IsBigEndian { get; set; }
```

### Property Value

`true`는 스트림에서 생성된 EXIF 데이터가 빅 엔디안인 경우; 그렇지 않으면 `false`.
