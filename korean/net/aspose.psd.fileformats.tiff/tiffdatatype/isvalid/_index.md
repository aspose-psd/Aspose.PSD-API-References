## TiffDataType.IsValid property

태그 데이터가 유효한지 여부를 나타내는 값을 가져옵니다. 유효한 태그는 보존될 수 있는 데이터를 포함합니다. 유효하지 않은 태그는 저장될 수 없습니다.

```csharp
public bool IsValid { get; }
```

### Property Value

`true` 태그 데이터가 유효하면; 그렇지 않으면 `false`.
