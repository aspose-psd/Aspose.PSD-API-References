## Layer.Flags property

레이어 플래그를 가져오거나 설정합니다. bit 0 = 투명도 보호; bit 1 = 표시; bit 2 = 사용되지 않음; bit 3 = Photoshop 5.0 이후 버전에서는 1이며, bit 4에 유용한 정보가 있는지 알려줍니다; bit 4 = 문서 외관에 영향을 주지 않는 픽셀 데이터.

```csharp
public LayerFlags Flags { get; set; }
```

### Property Value

레이어 플래그.
