## Layer.IsVisibleInGroup property

이 인스턴스가 그룹 내에서 표시되는지 여부를 나타내는 값을 가져옵니다(레이어가 그룹에 없으면 루트 그룹을 의미합니다).

```csharp
public virtual bool IsVisibleInGroup { get; }
```

### Property Value

`true`이면 이 인스턴스가 그룹에 표시되고, 그렇지 않으면 `false`입니다.
