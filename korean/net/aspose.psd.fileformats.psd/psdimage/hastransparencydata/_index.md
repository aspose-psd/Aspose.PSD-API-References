## PsdImage.HasTransparencyData property

레이어 데이터를 지정할 때 첫 번째 알파 채널이 병합 결과에 대한 투명도 데이터를 포함하는지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool HasTransparencyData { get; set; }
```

### Property Value

`true`이면 레이어 데이터를 지정할 때 병합 결과에 대한 투명도 데이터를 첫 번째 알파 채널이 포함합니다; 그렇지 않으면 `false`.
