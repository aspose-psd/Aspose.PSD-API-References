さまざまなビットマップ圧縮方法を指定します。

**Module:** [aspose.psd.fileformats.bmp](/psd/python-net/aspose.psd.fileformats.bmp/)

**Full Name:** aspose.psd.fileformats.bmp.BitmapCompression

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| ALPHA_BITFIELDS | RGBA ビットフィールド。16 ビットまたは 32 ビット/ピクセルのビットマップでのみ使用できます。 |
| BITFIELDS | RGBビットフィールド。16ビットおよび32ビット/ピクセルのビットマップでのみ使用できます。 |
| DXT1 | DXT1圧縮。ビットマップにはテクスチャが含まれています。 |
| JPEG | JPEG圧縮。ビットマップにはJPEG画像が含まれています。 |
| PNG | PNG圧縮。ビットマップにはPNG画像が含まれています。 |
| RGB | 圧縮なし。 |
| RLE4 | RLE 4ビット/ピクセル圧縮。4ビット/ピクセルのビットマップでのみ使用できます。 |
| RLE8 | RLE 8ビット/ピクセル圧縮。8ビット/ピクセルのビットマップでのみ使用できます。 |
