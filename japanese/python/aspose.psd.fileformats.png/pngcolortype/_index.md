PNG 画像のカラタイプを表します。

**Module:** [aspose.psd.fileformats.png](/psd/python-net/aspose.psd.fileformats.png/)

**Full Name:** aspose.psd.fileformats.png.PngColorType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| GRAYSCALE | 各ピクセルがグレースケールサンプルである色タイプを表します。 |
| GRAYSCALE_WITH_ALPHA | 各ピクセルがグレースケールサンプルに続いてアルファサンプルがある色タイプを表します。 |
| INDEXED_COLOR | 各ピクセルがパレットインデックスであるカラータイプを表します。PLTE チャンクが存在する必要があります。 |
| TRUECOLOR | 各ピクセルが R,G,B の三要素であるカラータイプを表します。 |
| TRUECOLOR_WITH_ALPHA | 各ピクセルが R,G,B の三要素に続いてアルファサンプルがあるカラータイプを表します。 |
