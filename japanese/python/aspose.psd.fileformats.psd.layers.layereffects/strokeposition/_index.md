この位置設定は、[StrokeEffect](/psd/python-net/aspose.psd.fileformats.psd.layers.layereffects/strokeeffect/) で適用されるレイヤーに対するストロークの配置を制御します。

**Module:** [aspose.psd.fileformats.psd.layers.layereffects](/psd/python-net/aspose.psd.fileformats.psd.layers.layereffects/)

**Full Name:** aspose.psd.fileformats.psd.layers.layereffects.StrokePosition

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| CENTER | ストロークはシェイプのエッジから作成され、内側と外側の両方に広がります。 |
| INSIDE | ストロークはシェイプのエッジから作成され、内側に向かってオブジェクトの中心へ伸びます。 |
| OUTSIDE | ストロークはシェイプのエッジから作成され、外側に向かってオブジェクトから離れます。 |
