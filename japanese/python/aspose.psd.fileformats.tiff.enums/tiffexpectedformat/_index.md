## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| デフォルト | デフォルトの tiff フォーマットは、圧縮なしで B/W 1 ビット/ピクセルのみの形式です。この設定を使用して空のオプションを取得し、タグやその他の設定で初期化することもできます。 |
| TIFF_CCITT_FAX3 | tiff の CCITT FAX3 エンコーディングです。その方式では B/W 1 ビット/ピクセルのみがサポートされます。 |
| TIFF_CCITT_FAX4 | tiff の CCITT FAX4 エンコーディングです。その方式では B/W 1 ビット/ピクセルのみがサポートされます。 |
| TIFF_CCIT_RLE | tiff の CCITT RLE エンコーディングです。その方式では B/W 1 ビット/ピクセルのみがサポートされます。 |
| TIFF_DEFLATE_BW | deflate 圧縮を使用し、B/W 1 ビット/ピクセルのみの形式を持つ tiff です。 |
| TIFF_DEFLATE_RGB | deflate 圧縮を使用し、RGB カラー形式を持つ tiff です。 |
| TIFF_DEFLATE_RGBA | deflate 圧縮を使用し、RGBA カラー形式を持つ tiff です。 |

| TIFF_LZW_CMYK | LZW cmyk の tiff。 |
| TIFF_LZW_RGB | LZW 圧縮と RGB カラー形式を持つ tiff。 |
| TIFF_LZW_RGBA | LZW 圧縮と透過カラー形式の RGBA を持つ tiff。 |
| TIFF_NO_COMPRESSION_BW | 圧縮されていない tiff と B/W 1 ビット/ピクセル のみの形式。 |
| TIFF_NO_COMPRESSION_RGB | 圧縮されていない tiff と RGB カラー形式。 |
| TIFF_NO_COMPRESSION_RGBA | 圧縮されていない tiff と透過カラー形式の RGBA。 |
