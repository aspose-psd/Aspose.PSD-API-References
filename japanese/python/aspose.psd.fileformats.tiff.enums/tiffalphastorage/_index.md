TIFF ドキュメントのアルファストレージを指定します。

**Module:** [aspose.psd.fileformats.tiff.enums](/psd/python-net/aspose.psd.fileformats.tiff.enums/)

**Full Name:** aspose.psd.fileformats.tiff.enums.TiffAlphaStorage

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| ASSOCIATED | アルファ値は事前乗算形式で保存されます。アルファを復元すると、丸め誤差が生じる可能性があり、復元された値が元の値と異なる場合があります。 |
| UNASSOCIATED | アルファ値は非関連形式で保存されます。つまり、復元されたアルファは TIFF に保存されたものと完全に同じです。 |
| UNSPECIFIED | アルファが指定されておらず、tiff ファイルに保存されています。 |
