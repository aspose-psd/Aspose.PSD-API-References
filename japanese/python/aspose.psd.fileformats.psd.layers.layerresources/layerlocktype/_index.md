レイヤーロックオプション

**Module:** [aspose.psd.fileformats.psd.layers.layerresources](/psd/python-net/aspose.psd.fileformats.psd.layers.layerresources/)

**Full Name:** aspose.psd.fileformats.psd.layers.layerresources.LayerLockType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| LOCK_ALL | レイヤーのすべてのプロパティをロックします |
| LOCK_IMAGE_PIXELS | レイヤーを部分的にロックします - ペイントツールを使用したレイヤーのピクセルの変更を防止します |
| LOCK_POSITION | レイヤーを部分的にロックします - レイヤーのピクセルが移動するのを防止します |
| LOCK_TRANSPARENT_PIXELS | レイヤーを部分的にロックします - 編集をレイヤーの不透明部分に限定します。<br/>            このオプションは、以前のバージョンの Photoshop の「透明度を保持」オプションと同等です。 |
| NONE | レイヤーロックなし |
