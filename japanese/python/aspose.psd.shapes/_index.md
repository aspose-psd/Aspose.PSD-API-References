このモジュールには、シェイプセグメントから結合されたさまざまな形状が含まれています。

## **Classes**
| **Class** | **説明** |
| :- | :- |
| [ArcShape](/psd/python-net/aspose.psd.shapes/arcshape/) | 円弧形状を表します。 |
| [BezierShape](/psd/python-net/aspose.psd.shapes/beziershape/) | ベジエスプラインを表します。 |
| [CurveShape](/psd/python-net/aspose.psd.shapes/curveshape/) | 曲線スプライン形状を表します。 |
| [EllipseShape](/psd/python-net/aspose.psd.shapes/ellipseshape/) | 楕円形状を表します。 |
| [PieShape](/psd/python-net/aspose.psd.shapes/pieshape/) | パイ形状を表します。 |
| [PolygonShape](/psd/python-net/aspose.psd.shapes/polygonshape/) | 多角形形状を表します。 |
| [RectangleProjectedShape](/psd/python-net/aspose.psd.shapes/rectangleprojectedshape/) | 特定の向きに回転させた矩形上に投影される形状を表します。<br/>            同じ辺の長さと隣接する辺の間が90度になるように、空間内で回転可能な4つの点で指定されます。 |
| [RectangleShape](/psd/python-net/aspose.psd.shapes/rectangleshape/) | 矩形形状を表します。 |
| [TextShape](/psd/python-net/aspose.psd.shapes/textshape/) | テキスト形状を表します。 |
