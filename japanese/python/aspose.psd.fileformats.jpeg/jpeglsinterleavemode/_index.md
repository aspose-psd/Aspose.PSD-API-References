マルチコンポーネント（カラー）ピクセルデータのインターリーブモードを定義します。

**Module:** [aspose.psd.fileformats.jpeg](/psd/python-net/aspose.psd.fileformats.jpeg/)

**Full Name:** aspose.psd.fileformats.jpeg.JpegLsInterleaveMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| ライン | インタリーブモードは行単位です。各コンポーネントのフルラインがエンコードされ、次の行に移ります。 |
| NONE | データはコンポーネントごとにエンコードされ、RRRGGGBBB として保存されます。 |
| サンプル | データはサンプル単位でエンコードされ、保存されます。カラー画像の場合、これは RGBRGBRGB のような形式です。 |
