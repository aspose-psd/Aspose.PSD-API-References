テキスト文字列の表示およびレイアウト情報を指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringFormatFlags

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| DIRECTION_RIGHT_TO_LEFT | テキストは右から左へ表示されます。 |
| DIRECTION_VERTICAL | テキストは垂直方向に配置されます。 |
| DISPLAY_FORMAT_CONTROL | 左から右へのマークなどの制御文字は、出力で代表的なグリフとして表示されます。 |
| EXACT_ALIGNMENT | 正確な配置と正しいパディング（GDI+）です。 |
| FIT_BLACK_BOX | 文字の一部が文字列のレイアウト矩形からはみ出すことが許可されています。デフォルトでは、文字ははみ出しを防ぐように再配置されます。 |
| LINE_LIMIT | 書式矩形内には完全な行のみが配置されます。デフォルトでは、テキストの末尾まで、またはクリッピングの結果として表示できる行がなくなるまでレイアウトが続き、いずれか早い方が適用されます。<br/>            デフォルト設定では、行の高さの整数倍でない書式矩形により、最後の行が部分的に隠れることがあります。完全な行だけが表示されるようにするには、<br/>            この値を指定し、少なくとも1行分の高さと同等の書式矩形を提供するよう注意してください。 |
| MEASURE_TRAILING_SPACES | 各行の末尾にあるトレーリングスペースを含めます。デフォルトでは、MeasureString メソッドが返す境界矩形は各行の末尾のスペースを除外します。このフラグを設定すると、測定にそのスペースを含めることができます。 |
| NO_CLIP | グリフのはみ出した部分や、書式矩形の外に達した折り返しされていないテキストの表示が許可されます。デフォルトでは、書式矩形の外に出たすべてのテキストとグリフの部分はクリップされます。 |
| NO_FONT_FALLBACK | 要求されたフォントでサポートされていない文字に対する代替フォントへのフォールバックは無効化されています。欠落した文字は、通常は空白の四角形で表されるフォントの欠損グリフで表示されます。 |
| NO_WRAP | 矩形内での書式設定時に行間のテキストラップは無効化されています。このフラグは、矩形の代わりに点が渡された場合、または指定された矩形の行長さがゼロの場合に暗黙的に適用されます。 |
