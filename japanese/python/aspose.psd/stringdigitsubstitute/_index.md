この列挙体は、ユーザーのロケールまたは言語に従って文字列内の数字を置換する方法を指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringDigitSubstitute

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| NATIONAL | ユーザーのロケールの公式な国語に対応する置換数字を指定します。 |
| NONE | 置換を無効にすることを指定します。 |
| TRADITIONAL | ユーザーのロケールの公式な国語とは異なる場合がある、ユーザーの母語または文字体系に対応する置換数字を指定します。 |
| USER | ユーザー定義の置換スキームを指定します。 |
