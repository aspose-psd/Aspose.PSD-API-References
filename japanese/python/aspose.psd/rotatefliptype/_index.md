画像がどれだけ回転するか、そして画像を反転させる際に使用される軸を指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.RotateFlipType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| ROTATE_180_FLIP_NONE | 180 度の時計回り回転を、反転せずに指定します。 |
| ROTATE_180_FLIP_X | 180 度の時計回り回転の後に水平フリップを行うことを指定します。 |
| ROTATE_180_FLIP_XY | 180 度の時計回り回転の後に水平および垂直フリップを行うことを指定します。 |
| ROTATE_180_FLIP_Y | 180 度の時計回り回転の後に垂直フリップを行うことを指定します。 |
| ROTATE_270_FLIP_NONE | 270 度の時計回り回転を、反転せずに指定します。 |
| ROTATE_270_FLIP_X | 270 度の時計回り回転の後に水平フリップを行うことを指定します。 |
| ROTATE_270_FLIP_XY | 270 度の時計回り回転の後に水平および垂直フリップを行うことを指定します。 |
| ROTATE_270_FLIP_Y | 270 度の時計回り回転の後に垂直フリップを行うことを指定します。 |
| ROTATE_90_FLIP_NONE | 90 度の時計回り回転を、反転せずに指定します。 |
| ROTATE_90_FLIP_X | 90 度の時計回り回転の後に水平フリップを行うことを指定します。 |
| ROTATE_90_FLIP_XY | 90 度の時計回り回転の後に水平および垂直フリップを行うことを指定します。 |
| ROTATE_90_FLIP_Y | 90度の時計回り回転の後に垂直方向のフリップを行うことを指定します。 |
| ROTATE_NONE_FLIP_NONE | 時計回りの回転もフリップも行わないことを指定します。 |
| ROTATE_NONE_FLIP_X | 時計回りの回転は行わず、水平フリップを行うことを指定します。 |
| ROTATE_NONE_FLIP_XY | 時計回りの回転は行わず、水平および垂直フリップを行うことを指定します。 |
| ROTATE_NONE_FLIP_Y | 時計回りの回転は行わず、垂直フリップを行うことを指定します。 |
