使用するキャッシュのタイプを指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.CacheType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| AUTO | 自動キャッシュタイプを指定します。自動キャッシュスキームは、まずメモリ内にキャッシュし、次にディスクにキャッシュしようとします。 |
| CACHE_IN_MEMORY_ONLY | メモリ内キャッシュのみです。 |
| CACHE_ON_DISK_ONLY | ディスクキャッシュのみです。 |
