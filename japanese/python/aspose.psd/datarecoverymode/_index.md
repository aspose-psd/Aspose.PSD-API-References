データ復旧モードです。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.DataRecoveryMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| CONSISTENT_RECOVER | 一貫したリカバリーモードは、破損がファイル形式を壊さない限りすべてのデータを復元し、正しい後続処理を可能にします。 |
| MAXIMAL_RECOVER | 最大リカバリーモードは、ファイル形式が破損した構造であってもすべてのデータを復元し、後続の処理が予期しない影響を及ぼす可能性があります。 |
| NONE | データのリカバリーは行われません。ファイル形式に破損したデータがある場合は、適切な例外がスローされます。 |
