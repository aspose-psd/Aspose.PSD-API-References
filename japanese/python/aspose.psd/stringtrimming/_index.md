レイアウト形状に完全に収まらない文字列から文字をどのようにトリミングするかを指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringTrimming

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| CHARACTER | テキストが最も近い文字まで切り詰められることを指定します。 |
| ELLIPSIS_CHARACTER | テキストが最も近い文字まで切り詰められ、切り詰められた行の末尾に省略記号が挿入されることを指定します。 |
| ELLIPSIS_PATH | 切り詰められた行の中央が削除され、省略記号で置き換えられます。アルゴリズムは、可能な限り最後のスラッシュ区切りセグメントを多く保持します。 |
| ELLIPSIS_WORD | テキストが最も近い単語まで切り詰められ、切り詰められた行の末尾に省略記号が挿入されることを指定します。 |
| NONE | 切り詰めを行わないことを指定します。 |
| WORD | テキストが最も近い単語まで切り詰められることを指定します。 |
