テキスト文字列がレイアウト矩形に対してどのように配置されるかを指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringAlignment

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| CENTER | テキストがレイアウト矩形の中央に配置されることを指定します。 |
| FAR | テキストがレイアウト矩形の基準位置から遠くに配置されることを指定します。<br/>            左から右へのレイアウトでは、遠い位置は右になります。<br/>            右から左へのレイアウトでは、遠い位置は左になります。 |
| NEAR | テキストがレイアウトの近くに配置されることを指定します。<br/>            左から右へのレイアウトでは、近い位置は左になります。<br/>            右から左へのレイアウトでは、近い位置は右になります。 |
