テクスチャまたはグラデーションが塗りつぶし領域より小さい場合のタイル配置方法を指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.WrapMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| CLAMP | テクスチャまたはグラデーションはタイル状に繰り返されません。 |
| TILE | グラデーションまたはテクスチャをタイル状に繰り返します。 |
| TILE_FLIP_X | テクスチャまたはグラデーションを水平方向に反転させ、次にタイル状に繰り返します。 |
| TILE_FLIP_XY | テクスチャまたはグラデーションを水平方向および垂直方向に反転させ、次にタイル状に繰り返します。 |
| TILE_FLIP_Y | テクスチャまたはグラデーションを垂直方向に反転し、その後テクスチャまたはグラデーションをタイル状に配置します。 |
