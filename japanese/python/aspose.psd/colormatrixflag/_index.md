画像とカラーの調整設定およびグレースケール調整設定の影響を受ける画像とカラーのタイプを [ImageAttributes](/psd/python-net/aspose.psd/imageattributes/) で指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorMatrixFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| ALT_GRAYS | 灰色のシェードのみが調整されます。 |
| デフォルト | 灰色のシェードを含むすべてのカラー値は、同じカラー調整マトリックスで調整されます。 |
| SKIP_GRAYS | すべての色が調整されますが、灰色のシェードは調整されません。灰色のシェードとは、赤、緑、青の各成分の値が同じである任意の色のことです。 |
