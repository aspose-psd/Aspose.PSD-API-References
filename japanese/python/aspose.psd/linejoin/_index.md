[GraphicsPath](/psd/python-net/aspose.psd/graphicspath/) オブジェクトに含まれる図形（サブパス）内の連続する直線または曲線セグメントをどのように結合するかを指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.LineJoin

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| BEVEL | ベベル結合を指定します。これにより斜めの角が生成されます。 |
| MITER | マイター結合を指定します。マイターの長さがマイター制限を超えるかどうかに応じて、鋭い角または切り取られた角が生成されます。 |
| MITER_CLIPPED | マイター結合を指定します。マイターの長さがマイター制限を超えるかどうかに応じて、鋭い角またはベベル角が生成されます。 |
| ROUND | 円形結合を指定します。これにより線間に滑らかな円弧が生成されます。 |
