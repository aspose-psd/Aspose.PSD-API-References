[Pen](/psd/python-net/aspose.psd/pen/) オブジェクトで描画される破線のスタイルを指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.DashStyle

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| カスタム | ユーザー定義のカスタムダッシュスタイルを指定します。 |
| DASH | ダッシュで構成された線を指定します。 |
| DASH_DOT | ダッシュとドットの繰り返しパターンで構成された線を指定します。 |
| DASH_DOT_DOT | ダッシュ・ドット・ドットの繰り返しパターンで構成された線を指定します。 |
| DOT | ドットで構成された線を指定します。 |
| SOLID | 実線を指定します。 |
