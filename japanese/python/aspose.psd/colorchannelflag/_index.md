CMYK（シアン、マゼンタ、イエロー、ブラック）カラースペースの個々のチャンネルを指定します。この列挙は SetOutputChannel メソッドで使用されます。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorChannelFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| COLOR_CHANNEL_C | シアン カラーチャネルです。 |
| COLOR_CHANNEL_K | ブラック カラーチャネルです。 |
| COLOR_CHANNEL_LAST | 最後に選択されたチャネルを使用すべきです。 |
| COLOR_CHANNEL_M | マゼンタ カラーチャネルです。 |
| COLOR_CHANNEL_Y | イエロー カラーチャネルです。 |
