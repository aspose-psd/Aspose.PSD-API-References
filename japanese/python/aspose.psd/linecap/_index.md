ラインの終端に使用できる [Pen](/psd/python-net/aspose.psd/pen/) オブジェクトの利用可能なキャップスタイルを指定します。

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.LineCap

**Aspose.PSD Version:** 24.12.0

## **Members**
| **メンバー名** | **説明** |
| :- | :- |
| ANCHOR_MASK | カスタムラインキャップを指定します。 |
| ARROW_ANCHOR | 矢印形状のアンカーキャップを指定します。 |
| カスタム | ラインキャップがアンカーキャップかどうかを確認するために使用されるマスクを指定します。 |
| DIAMOND_ANCHOR | ダイヤモンド形状のアンカーキャップを指定します。 |
| FLAT | フラットなラインキャップを指定します。 |
| NO_ANCHOR | アンカーなしを指定します。 |
| ROUND | 丸いラインキャップを指定します。 |
| ROUND_ANCHOR | 丸いアンカーキャップを指定します。 |
| SQUARE | 四角形のラインキャップを指定します。 |
| SQUARE_ANCHOR | 四角形のアンカーラインキャップを指定します。 |
| TRIANGLE | 三角形のラインキャップを指定します。 |
