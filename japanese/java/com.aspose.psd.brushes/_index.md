このパッケージは、さまざまなブラシタイプを扱うためのヘルパークラスとメソッドを提供します。


## クラス

| クラス | 説明 |
| --- | --- |
| [HatchBrush](../com.aspose.psd.brushes/hatchbrush) | ハッチスタイル、前景色、背景色を持つ矩形ブラシを定義します。 |
| [LinearGradientBrush](../com.aspose.psd.brushes/lineargradientbrush) | 線形グラデーションを持つ Aspose.Imaging.Brush をカプセル化します。 |
| [LinearGradientBrushBase](../com.aspose.psd.brushes/lineargradientbrushbase) | グラデーション機能と適切なプロパティを持つ Brush を表します。 |
| [LinearMulticolorGradientBrush](../com.aspose.psd.brushes/linearmulticolorgradientbrush) | 複数の色と適切な位置で定義された線形グラデーションを持つ Brush を表します。 |
| [PathGradientBrush](../com.aspose.psd.brushes/pathgradientbrush) | グラデーションを持つ Aspose.Imaging.Brush オブジェクトをカプセル化します。 |
| [PathGradientBrushBase](../com.aspose.psd.brushes/pathgradientbrushbase) | ベースパスグラデーション機能を持つ  Brush  を表します。 |
| [PathMulticolorGradientBrush](../com.aspose.psd.brushes/pathmulticolorgradientbrush) | グラデーションを持つ Aspose.Imaging.Brush オブジェクトをカプセル化します。 |
| [SolidBrush](../com.aspose.psd.brushes/solidbrush) | ソリッドブラシは、特定の色で継続的に描画することを目的としています。 |
| [TextureBrush](../com.aspose.psd.brushes/texturebrush) | Aspose.Imaging.Brushes.TextureBrush クラスの各プロパティは、画像を使用してシェイプの内部を塗りつぶす Aspose.Imaging.Brush オブジェクトです。 |
| [TransformBrush](../com.aspose.psd.brushes/transformbrush) | 変換機能を備えた  Brush  。 |
