ISO/IEC 14495-1、C.2.4.1.1 で定義されている JPEG-LS プリセットコーディングパラメータを定義します。JPEG-LS はデフォルトのパラメータセットを定義していますが、カスタムパラメータも使用できます。使用されると、これらのパラメータはデコード処理に必要なときにエンコードされたビットストリームに書き込まれます。
