## フィールド

| フィールド | 説明 |
| --- | --- |
| [DirectionRightToLeft](#DirectionRightToLeft) | テキストは右から左へ表示されます。 |
| [DirectionVertical](#DirectionVertical) | テキストは垂直に配置されています。 |
| [DisplayFormatControl](#DisplayFormatControl) | 左から右へのマークなどの制御文字は、出力で代表的なグリフで表示されます。 |
| [EnumSeparatorCharArray](#EnumSeparatorCharArray) |  |
| [FitBlackBox](#FitBlackBox) | 文字の一部が文字列のレイアウト矩形からはみ出すことが許可されています。 |

| [MeasureTrailingSpaces](#MeasureTrailingSpaces) | 各行の末尾のスペースを含みます。 |
| [NoClip](#NoClip) | グリフのはみ出した部分や、書式設定矩形の外に達する折り返しされていないテキストの表示が許可されています。 |
| [NoFontFallback](#NoFontFallback) | 要求されたフォントでサポートされていない文字に対する代替フォントへのフォールバックは無効化されています。 |
| [NoWrap](#NoWrap) | 矩形内で書式設定する際の行間のテキスト折り返しは無効です。 |

### FitBlackBox {#FitBlackBox}
```
public static final int FitBlackBox
```


文字の一部が文字列のレイアウト矩形からはみ出すことが許可されています。デフォルトでは、はみ出しを防ぐために文字が再配置されます。

### LineLimit {#LineLimit}
```
public static final int LineLimit
```


書式設定矩形には全行のみがレイアウトされます。デフォルトでは、テキストの末尾まで、またはクリッピングの結果として表示可能な行がなくなるまでレイアウトが続き、どちらか早い方が適用されます。デフォルト設定では、行の高さの整数倍でない書式設定矩形により、最後の行が部分的に隠れることがあります。全行のみが表示されるようにするには、この値を指定し、少なくとも1行分の高さの書式設定矩形を提供するよう注意してください。

### MeasureTrailingSpaces {#MeasureTrailingSpaces}
```
public static final int MeasureTrailingSpaces
```


各行の末尾のスペースを含みます。デフォルトでは、MeasureString メソッドが返す境界矩形は各行の末尾のスペースを除外します。このフラグを設定すると、測定にそのスペースを含めることができます。

### NoClip {#NoClip}
```
public static final int NoClip
```


グリフのはみ出した部分や、書式設定矩形の外に達する折り返しされていないテキストの表示が許可されています。デフォルトでは、書式設定矩形の外に出たすべてのテキストとグリフの部分はクリップされます。

### NoFontFallback {#NoFontFallback}
```
public static final int NoFontFallback
```


要求されたフォントでサポートされていない文字に対する代替フォントへのフォールバックは無効です。欠落した文字は、通常は空白の四角形であるフォントの欠損グリフで表示されます。

### NoWrap {#NoWrap}
```
public static final int NoWrap
```


矩形内で書式設定する際の行間のテキスト折り返しは無効です。このフラグは、矩形の代わりに点が渡された場合や、指定された矩形の行長さがゼロの場合に暗黙的に適用されます。
