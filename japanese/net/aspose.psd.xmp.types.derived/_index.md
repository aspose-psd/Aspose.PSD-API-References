名前空間には、XMP プロパティの派生型の値を表すクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [Rational](./rational/) | XMP Rational を表します。 |
| [RenditionClass](./renditionclass/) | XMP Rendition を表します。 |
| [XmpAgentName](./xmpagentname/) | エージェント名、ソフトウェア組織などを表します。 |
| [XmpChoise&lt;T&gt;](./xmpchoise-1/) | 語彙からの値を表します。 |
| [XmpGuid](./xmpguid/) | XMP グローバル一意識別子を表します。 |
| [XmpLocale](./xmplocale/) | 言語コードを表します。 |
| [XmpMimeType](./xmpmimetype/) | MIME タイプを表します。 |
