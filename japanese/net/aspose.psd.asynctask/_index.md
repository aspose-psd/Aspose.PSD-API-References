この名前空間は AsyncTask の処理を扱います。

## クラス

| クラス | 説明 |
| --- | --- |
| [AsyncTask](./asynctask/) | 非同期タスクを作成するための静的ファクトリクラスです。 |
| [AsyncTaskAction](./asynctaskaction/) | 結果を返さない非同期タスク用の長時間操作デリゲートです。 |
| [AsyncTaskException](./asynctaskexception/) | 非同期タスク用の例外です。 |
| [AsyncTaskFunc](./asynctaskfunc/) | 汎用型結果を持つ非同期タスク用の長時間操作デリゲートです。 |
| [AsyncTaskProgress](./asynctaskprogress/) | 非同期タスクの進捗情報を提供します。 |
| [CompleteCallback](./completecallback/) | タスク完了イベントを受け取るコールバック関数。 |
| [ProgressCallback](./progresscallback/) | タスクの進捗変更イベントを受け取るコールバック関数。 |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IAsyncTask](./iasynctask/) | 非同期タスクです。 |
| [IAsyncTaskState](./iasynctaskstate/) | 非同期タスクの状態へのアクセスを提供します。 |
