名前空間には、シェイプセグメントから結合されたさまざまな形状が含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [ArcShape](./arcshape/) | 弧形状を表します。 |
| [BezierShape](./beziershape/) | ベジエスプラインを表します。 |
| [CurveShape](./curveshape/) | 曲線スプライン形状を表します。 |
| [EllipseShape](./ellipseshape/) | 楕円形状を表します。 |
| [PieShape](./pieshape/) | パイ形状を表します。 |
| [PolygonShape](./polygonshape/) | 多角形形状を表します。 |
| [RectangleProjectedShape](./rectangleprojectedshape/) | 特定の向きに回転させた矩形上に投影された形状を表します。4 つの点で指定され、空間内で回転させてもエッジの長さは同じで、隣接エッジ間は 90 度を保ちます。 |
| [RectangleShape](./rectangleshape/) | 矩形形状を表します。 |
| [TextShape](./textshape/) | テキスト形状を表します。 |
