## TiffStreamReader.ThrowExceptions property

不正なデータ処理（ストリームの読み取りまたは書き込み）時に例外がスローされるかどうかを示す値を取得または設定します。

```csharp
public bool ThrowExceptions { get; set; }
```

### Property Value

`true` はデータ処理の誤り時に例外がスローされる場合を示し、そうでない場合はエラー状態が黙って無視されます。
