## PngFilterType enumeration

PNG フィルタタイプ。

```csharp
public enum PngFilterType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | `0` | null-filter は、画像データ行に対してフィルタリングを行わないことを意味します。 |
| Sub | `1` | sub filter は、画像データに減算フィルタリングが適用されることを意味します。 |
| Up | `2` | up filter は、行ごとに減算フィルタが適用されることを意味します。 |
| Avg | `3` | avg filter は、画像データに平均フィルタが適用されることを意味します。 |
| Paeth | `4` | paeth predictor フィルタです。 |
| Adaptive | `5` | 適応フィルタリングは、保存処理が各データ行に最適なフィルタを選択することを意味します。最高の圧縮率、最も遅い実行時間です。 |
