## TiffDataType.IsValid property

タグデータが有効かどうかを示す値を取得します。有効なタグは保持できるデータを含みます。無効なタグは保存できません。

```csharp
public bool IsValid { get; }
```

### Property Value

`true` タグデータが有効な場合; それ以外の場合は `false`。
