## TiffDataType.CompareTo method

現在のインスタンスを同じ型の別のオブジェクトと比較し、現在のインスタンスがソート順で前、後、または同じ位置にあるかを示す整数を返します。

```csharp
public int CompareTo(object obj)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| obj | Object | このインスタンスと比較するオブジェクト。 |

### 戻り値

比較対象のオブジェクトの相対順序を示す 32 ビット符号付き整数。戻り値の意味は次のとおりです：値 意味 0 未満 このインスタンスは *obj* より小さいです。 0 このインスタンスは *obj* と等しいです。 0 超 このインスタンスは *obj* より大きいです。
