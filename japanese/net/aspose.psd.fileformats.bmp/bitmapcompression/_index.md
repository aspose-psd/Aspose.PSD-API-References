## BitmapCompression enumeration

さまざまなビットマップ圧縮方法を指定します。

```csharp
public enum BitmapCompression : uint
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Rgb | `0` | 圧縮なし。 |
| Rle8 | `1` | RLE 8ビット/ピクセル圧縮。8ビット/ピクセルのビットマップでのみ使用できます。 |
| Rle4 | `2` | RLE 4ビット/ピクセル圧縮。4ビット/ピクセルのビットマップでのみ使用できます。 |
| Bitfields | `3` | RGB ビットフィールド。16ビットおよび32ビット/ピクセルのビットマップでのみ使用できます。 |
| Jpeg | `4` | JPEG 圧縮。ビットマップは JPEG 画像を含みます。 |
| Png | `5` | PNG 圧縮。ビットマップは PNG 画像を含みます。 |
| AlphaBitfields | `6` | RGBA ビットフィールド。16 ビットおよび 32 ビット/ピクセルのビットマップでのみ使用できます。 |
| Dxt1 | `827611204` | DXT1 圧縮。ビットマップにはテクスチャが含まれています。 |
