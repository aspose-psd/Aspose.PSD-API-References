## LinkDataSource.HasFileOpenDescriptor property

取得または設定します このリンクデータソースがファイルオープン記述子（CompId と OriginalCompId）を持つかどうかを示す値を取得または設定します。

```csharp
public bool HasFileOpenDescriptor { get; set; }
```

### Property Value

`true` はこのインスタンスがファイルオープンディスクリプタを持つ場合、そうでなければ `false` です。
