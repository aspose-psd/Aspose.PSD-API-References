## PdfCoreOptions.ExpandedOutlineLevels property

PDF ファイルを表示したときに、ドキュメントアウトラインを展開して表示するレベル数を指定します。0 - アウトラインを展開しない。1 - 第1レベルの項目が展開され、以降同様。デフォルトは 0 です。

```csharp
public int ExpandedOutlineLevels { get; set; }
```
