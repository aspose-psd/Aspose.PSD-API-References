## Jpeg2000Options.CompressionRatios property

圧縮率の配列を取得または設定します。連続するレイヤーごとに異なる圧縮率があります。各品質レベルで指定されたレートは希望する圧縮係数です。圧縮率は低くする必要があります。

```csharp
public int[] CompressionRatios { get; set; }
```

### Property Value

圧縮率。
