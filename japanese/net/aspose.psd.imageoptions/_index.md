この名前空間には、さまざまなファイル形式のエクスポート、保存、作成に適したクラスが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [BmpOptions](./bmpoptions/) | bmp ファイル形式の作成オプションです。 |
| [CmxRasterizationOptions](./cmxrasterizationoptions/) | CMX エクスポーターオプションです。 |
| [GifOptions](./gifoptions/) | gif ファイル形式の作成オプションです。 |
| [GraphicsOptions](./graphicsoptions/) | 埋め込みビットマップのグラフィックオプションを表します。 |
| [Jpeg2000Options](./jpeg2000options/) | Jpeg2000 ファイル形式のオプション。 |
| [JpegOptions](./jpegoptions/) | jpeg ファイル形式の作成オプション。 |
| [MultiPageOptions](./multipageoptions/) | 複数ページをサポートする形式の基底クラス |
| [PdfOptions](./pdfoptions/) | PDF のオプション。 |
| [PngOptions](./pngoptions/) | png ファイル形式の作成オプション。 |
| [PsdOptions](./psdoptions/) | psd ファイル形式の作成オプション。 |
| [RdOptimizerSettings](./rdoptimizersettings/) | RD オプティマイザ設定クラス |
| [RenderResult](./renderresult/) | レンダリング結果に関する情報を表します |
| [TiffOptions](./tiffoptions/) | tiff ファイル形式のオプションです。幅と高さのタグは、画像作成時に幅と高さのパラメータによって上書きされるため、直接指定する必要はありません。多くのオプションはデフォルト値を返しますが、これはそのオプションがタグ値として明示的に設定されていることを意味しません。タグが存在するか確認するには、Tags プロパティまたは対応する IsTagPresent メソッドを使用してください。 |
| [TiffOptionsUtils](./tiffoptionsutils/) | tiff ファイル形式オプションユーティリティクラスです。 |
| [VectorRasterizationOptions](./vectorrasterizationoptions/) | ベクトル ラスタライズ オプションです。 |
