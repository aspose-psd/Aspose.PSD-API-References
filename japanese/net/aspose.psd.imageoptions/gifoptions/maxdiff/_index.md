## GifOptions.MaxDiff property

許容される最大ピクセル差を取得または設定します。0 より大きい場合、非可逆圧縮が使用されます。最適な非可逆圧縮の推奨値は 80 です。30 は非常に軽い圧縮、200 は重い圧縮です。損失が少ない場合に最も効果的で、圧縮アルゴリズムの制限により非常に高い損失レベルではそれほど効果が得られません。許容値の範囲は [0, 1000] です。

```csharp
public int MaxDiff { get; set; }
```
