この名前空間には、コア PSD コンポーネントのいずれかからスローされる例外が含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [CompressorException](./compressorexception/) | コンプレッサー例外です。 |
| [DataMissmatchError](./datamissmatcherror/) | データ不一致例外クラス |
| [FrameworkException](./frameworkexception/) | PSD フレームワーク例外です。このクラスはすべての Aspose.PSD 例外のコアクラスです。Aspose.PSD エンジンからスローされる例外と他のすべての例外タイプを区別するために導入されました。 |
| [ImageCreateException](./imagecreateexception/) | 画像作成例外です。画像の作成中に発生します。 |
| [ImageException](./imageexception/) | 画像例外です。 |
| [ImageLoadException](./imageloadexception/) | 画像読み込み例外です。画像の読み込み中に発生します。 |
| [ImageSaveException](./imagesaveexception/) | 画像保存例外です。画像の保存中に発生します。 |
| [IndexOutOFRangeException](./indexoutofrangeexception/) | コンプレッサー例外です。 |
| [LimitMemoryException](./limitmemoryexception/) | メモリ制限例外です。メモリ使用量を削減すべきときに発生します。 |
| [OperationInterruptedException](./operationinterruptedexception/) | 操作が中断されたときに発生します。 |
| [RdOptimizationError](./rdoptimizationerror/) | RD 最適化エラー例外クラス |
| [StreamReadException](./streamreadexception/) | ストリーム読み取り例外です。オフセットやバイト数の要求が正しくないためにストリームの読み取りが失敗したときに発生します。 |
| [XmpException](./xmpexception/) | XMP の構造が無効なときにスローされる例外です。 |
