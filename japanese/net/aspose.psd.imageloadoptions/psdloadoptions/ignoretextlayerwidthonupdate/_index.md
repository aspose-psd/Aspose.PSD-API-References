## PsdLoadOptions.IgnoreTextLayerWidthOnUpdate property

取得または設定するのは、UpdateText 操作の実行時に PSD テキストレイヤーの固定幅を無視するかどうかを示す値です。

```csharp
public bool IgnoreTextLayerWidthOnUpdate { get; set; }
```

### Property Value

`true` は [ignore text layer width] の場合; それ以外は `false`。
