## Jpeg2000LoadOptions.MaximumDecodingTime property

取得または設定するのは、最大デコード時間（秒）です（このオプションは、メモリが非常に遅いマシンで、解像度が 5500x6500 ピクセルを超える非常に大きな画像の処理がハングするのを防ぐために使用できます）。

```csharp
public int MaximumDecodingTime { get; set; }
```

### Property Value

最大デコード時間。
