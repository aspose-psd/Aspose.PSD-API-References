この名前空間には PSD 調整レイヤーが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [Frame](./frame/) | タイムラインフレーム項目のオプションです。 |
| [LayerState](./layerstate/) | タイムラインレイヤー状態のオプションです。 |
| [LayerStateEffects](./layerstateeffects/) | レイヤー状態のエフェクトです。 |
| [Timeline](./timeline/) | タイムラインオプションモデルです。 |
## 列挙

| 列挙 | 説明 |
| --- | --- |
| [FrameDisposalMethod](./framedisposalmethod/) | フレーム破棄方法は、次のフレームを表示する前に現在のフレームを破棄するかどうかを指定します。背景の透過を含むアニメーションでは、破棄方法を選択して、現在のフレームが次のフレームの透過領域を通して表示されるかどうかを指定します。 |
