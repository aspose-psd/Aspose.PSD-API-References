この名前空間は、さまざまなブラシタイプで作業するためのヘルパークラスとメソッドを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [HatchBrush](./hatchbrush/) | ハッチスタイル、前景色、背景色を持つ矩形ブラシを定義します。このクラスは継承できません。 |
| [LinearGradientBrush](./lineargradientbrush/) | 線形グラデーションを持つ [`Brush`](../aspose.psd/brush/) をカプセル化します。このクラスは継承できません。 |
| [LinearGradientBrushBase](./lineargradientbrushbase/) | グラデーション機能と適切なプロパティを持つ [`Brush`](../aspose.psd/brush/) を表します。 |
| [LinearMulticolorGradientBrush](./linearmulticolorgradientbrush/) | 複数の色と適切な位置で定義された線形グラデーションを持つ [`Brush`](../aspose.psd/brush/) を表します。このクラスは継承できません。 |
| [PathGradientBrush](./pathgradientbrush/) | グラデーションを持つ [`Brush`](../aspose.psd/brush/) オブジェクトをカプセル化します。このクラスは継承できません。 |
| [PathGradientBrushBase](./pathgradientbrushbase/) | ベースパスグラデーション機能を持つ [`Brush`](../aspose.psd/brush/) を表します。 |
| [PathMulticolorGradientBrush](./pathmulticolorgradientbrush/) | グラデーションを持つ [`Brush`](../aspose.psd/brush/) オブジェクトをカプセル化します。このクラスは継承できません。 |
| [SolidBrush](./solidbrush/) | ソリッドブラシは特定の色で継続的に描画することを目的としています。このクラスは継承できません。 |
| [TextureBrush](./texturebrush/) | Each property of the [`TextureBrush`](../aspose.psd.brushes/texturebrush/) クラスは、画像を使用してシェイプの内部を塗りつぶす [`Brush`](../aspose.psd/brush/) オブジェクトです。このクラスは継承できません。 |
| [TransformBrush](./transformbrush/) | 変換機能を持つ [`Brush`](../aspose.psd/brush/)。 |
