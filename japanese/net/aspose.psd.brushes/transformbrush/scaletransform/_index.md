## ScaleTransform(float, float) {#scaletransform}

ローカル幾何変換を指定された量だけ拡大縮小します。このメソッドは拡大縮小行列を変換の先頭に追加します。

```csharp
public void ScaleTransform(float sx, float sy)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| sx | シングル | x 軸方向に変換を拡大縮小する量。 |
| sy | シングル | y 軸方向に変換を拡大縮小する量。 |

## ScaleTransform(float, float, MatrixOrder) {#scaletransform_1}

```csharp
public void ScaleTransform(float sx, float sy, MatrixOrder order)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| sx | シングル | x 軸方向に変換を拡大縮小する量。 |
| sy | シングル | y 軸方向に変換を拡大縮小する量。 |
| order | MatrixOrder | 拡大縮小行列を後置するか前置するかを指定する [`MatrixOrder`](../../../aspose.psd/matrixorder/)。 |
