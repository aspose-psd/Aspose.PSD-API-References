## ThumbnailResource.JpegOptions property

JPEG オプションを取得または設定します。サムネイルリソースが JPEG ファイル形式でのみ保存される場合に適しています。このオプションは RAW 形式が定義されている場合は効果がありません。

```csharp
public JpegOptions JpegOptions { get; set; }
```

### Property Value

JPEG オプションです。
