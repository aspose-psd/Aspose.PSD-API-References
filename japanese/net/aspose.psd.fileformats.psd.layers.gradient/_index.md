この名前空間は PSD ファイル形式の処理を行います。

## クラス

| クラス | 説明 |
| --- | --- |
| [BaseGradient](./basegradient/) | 基本的なグラデーション定義クラスです。ソリッドとノイズの両方のグラデーションタイプに共通するプロパティを含みます。 |
| [NoiseGradient](./noisegradient/) | ノイズグラデーション定義クラスです。 |
| [SolidGradient](./solidgradient/) | グラデーション塗りつぶしエフェクト設定です。 |
## 列挙

| 列挙 | 説明 |
| --- | --- |
| [GradientKind](./gradientkind/) | グラデーションタイプ列挙体です。 |
| [NoiseColorModel](./noisecolormodel/) | カラー モデル: 'Gradient type' = 'Noise' の場合、'Color Model' を RGB/SHB/LAB (3/4/6) に割り当てることができます。 |
