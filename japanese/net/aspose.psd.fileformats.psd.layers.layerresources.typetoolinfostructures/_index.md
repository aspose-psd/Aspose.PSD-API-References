この名前空間には PSD ファイル形式のタイプツールリソースエンティティが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [AliasStructure](./aliasstructure/) | エイリアス構造です。 |
| [BooleanStructure](./booleanstructure/) | ブール構造です。 |
| [ClassStructure](./classstructure/) | クラス構造です。 |
| [DescriptorStructure](./descriptorstructure/) | ディスクリプタ構造 |
| [DoubleStructure](./doublestructure/) | ダブル構造です。 |
| [EnumeratedDescriptorStructure](./enumerateddescriptorstructure/) | 列挙ディスクリプタ構造です。 |
| [EnumeratedReferenceStructure](./enumeratedreferencestructure/) | 列挙参照構造です。 |
| [IntegerStructure](./integerstructure/) | 整数構造です。 |
| [ListStructure](./liststructure/) | リスト構造です。 |
| [NameStructure](./namestructure/) | Name 構造 (キー: 0x6E616D65、ASCII で "name" と綴られます) は、レイヤー、パス、または調整などの要素の名前を表す Unicode または Pascal 形式の文字列を格納するために使用されるシンプルな構造です。 |
| [ObjectArrayStructure](./objectarraystructure/) | ObjectArrayStructure クラスを定義します。このクラスは通常、[`UnitArrayStructure`](../aspose.psd.fileformats.psd.layers.layerresources.typetoolinfostructures/unitarraystructure/) 配列を保持します。PSD ファイルのリソース（PlLd リソースや SoLd リソースなど）で使用されます。 |
| [OffsetStructure](./offsetstructure/) | オフセット構造です。 |
| [PathStructure](./pathstructure/) | パス構造です。 |
| [PropertyStructure](./propertystructure/) | プロパティ構造です。 |
| [RawDataStructure](./rawdatastructure/) | 生データ構造です。 |
| [ReferenceStructure](./referencestructure/) | 参照構造。 |
| [StringStructure](./stringstructure/) | 文字列構造。 |
| [UnitArrayStructure](./unitarraystructure/) | UnitArrayStructure クラスは Double 値の配列とその測定単位を保持します。これは PSD ファイルリソースで使用され、通常は [`ObjectArrayStructure`](../aspose.psd.fileformats.psd.layers.layerresources.typetoolinfostructures/objectarraystructure/) によって使用されます。 |
| [UnitStructure](./unitstructure/) | 単位構造。 |
| [UnknownStructure](./unknownstructure/) | 不明な構造。 |
