## XmpRdfRoot class

rdf:RDF 要素を表します。単一の XMP パケットは単一の rdf:RDF XML 要素を使用してシリアライズされます。rdf:RDF 要素の内容は、0 個以上の rdf:Description 要素のみで構成されます。

```csharp
public sealed class XmpRdfRoot : XmpElementBase, IXmlValue
```
