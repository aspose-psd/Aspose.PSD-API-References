名前空間には、XMP 関連のヘルパークラスとメソッドが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [LangAlt](./langalt/) | XMP 言語代替を表します。 |
| [Namespaces](./namespaces/) | RDF ドキュメントで使用される名前空間を含みます。 |
| [XmpArray](./xmparray/) | [`XmpPackage`](../aspose.psd.xmp/xmppackage/) の中の Xmp 配列を表します。TODO: 配列には複雑なデータが含まれる可能性があります。 |
| [XmpArrayHelper](./xmparrayhelper/) | RDF ロジックを処理するためのヘルパークラスです。 |
| [XmpElementBase](./xmpelementbase/) | 属性を含む基本 xmp 要素を表します。 |
| [XmpHeaderPi](./xmpheaderpi/) | XMP ヘッダー処理命令を表します。 |
| [XmpMeta](./xmpmeta/) | xmpmeta を表します。オプションです。この要素の目的は、RDF の他の非 XMP 用法を含む可能性のある一般的な XML テキスト内で XMP メタデータを識別することです。 |
| [XmpPackage](./xmppackage/) | XMP パッケージの基本抽象化を表す XmpPackage クラスを定義します。 |
| [XmpPackageBaseCollection](./xmppackagebasecollection/) | [`XmpPackage`](../aspose.psd.xmp/xmppackage/) のコレクションを表します。 |
| [XmpPacketWrapper](./xmppacketwrapper/) | ヘッダーとトレーラを含むシリアライズされた xmp パッケージを含みます。 |
| [XmpRdfRoot](./xmprdfroot/) | rdf:RDF 要素を表します。単一の XMP パケットは単一の rdf:RDF XML 要素を使用してシリアライズされます。rdf:RDF 要素の内容は、0 個以上の rdf:Description 要素のみで構成されます。 |
| [XmpTrailerPi](./xmptrailerpi/) | XMP トレーラ処理命令を表します。 |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IXmlValue](./ixmlvalue/) | xmp 値を XML 文字列表現に変換します。 |
