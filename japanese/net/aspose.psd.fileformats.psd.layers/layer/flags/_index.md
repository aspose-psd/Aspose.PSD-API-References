## Layer.Flags property

レイヤーフラグを取得または設定します。ビット0 = 透明保護; ビット1 = 表示; ビット2 = 旧式; ビット3 = Photoshop 5.0以降の場合は1で、ビット4に有用な情報があるかを示します; ビット4 = ドキュメントの外観に関係しないピクセルデータ。

```csharp
public LayerFlags Flags { get; set; }
```

### Property Value

レイヤーフラグ。
