## Layer.LayerLock property

レイヤーロックを取得または設定します。フラグ LayerFlags.TransparencyProtected が設定されている場合、レイヤーロックフラグによって上書きされることに注意してください。LayerFlags.TransparencyProtected フラグを返すには、レイヤーオプション layer.Flags &#x7C;= LayerFlags.TransparencyProtected を適用する必要があります。

```csharp
public LayerLockType LayerLock { get; set; }
```

### Property Value

レイヤーロックです。
