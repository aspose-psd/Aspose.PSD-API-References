## Layer.IsVisibleInGroup property

このインスタンスがグループ内で表示されているかどうかを示す値を取得します（レイヤーがグループに属していない場合はルートグループを意味します）。

```csharp
public virtual bool IsVisibleInGroup { get; }
```

### Property Value

このインスタンスがグループ内で可視の場合は `true`、それ以外の場合は `false`。
