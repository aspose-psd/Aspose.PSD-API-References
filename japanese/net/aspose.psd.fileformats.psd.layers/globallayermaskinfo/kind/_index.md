## GlobalLayerMaskInfo.Kind property

種類を取得または設定します。0 = カラー選択（つまり反転）；1 = カラー保護；128 = レイヤーごとに保存された値を使用。この値が推奨されます。他はベータ版との下位互換性のためです。

```csharp
public byte Kind { get; set; }
```

### Property Value

種類。
