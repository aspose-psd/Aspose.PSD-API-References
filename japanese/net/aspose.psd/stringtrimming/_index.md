## StringTrimming enumeration

レイアウト形状に完全に収まらない文字列から文字をトリミングする方法を指定します。

```csharp
public enum StringTrimming
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | `0` | トリミングなしを指定します。 |
| Character | `1` | テキストが最も近い文字単位でトリムされることを指定します。 |
| Word | `2` | テキストが最も近い単語単位でトリムされることを指定します。 |
| EllipsisCharacter | `3` | テキストが最も近い文字単位でトリムされ、トリムされた行の末尾に省略記号が挿入されることを指定します。 |
| EllipsisWord | `4` | テキストが最も近い単語単位でトリムされ、トリムされた行の末尾に省略記号が挿入されることを指定します。 |
| EllipsisPath | `5` | トリムされた行の中央が削除され、省略記号で置き換えられます。アルゴリズムは、行の最後のスラッシュ区切りセグメントを可能な限り多く保持します。 |
