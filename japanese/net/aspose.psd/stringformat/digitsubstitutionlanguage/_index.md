## StringFormat.DigitSubstitutionLanguage property

ローカル数字が西洋数字に置き換えられる際に使用される言語を取得または設定します。

```csharp
public int DigitSubstitutionLanguage { get; set; }
```

### Property Value

ローカル数字が西洋数字に置き換えられる際に使用される言語を識別する、National Language Support (NLS) 言語識別子です。CultureInfo オブジェクトの LCID プロパティを NLS 言語識別子として渡すことができます。例えば、文字列 \"ar-EG\" を CultureInfo コンストラクタに渡して CultureInfo オブジェクトを作成したとします。その CultureInfo オブジェクトの LCID プロパティを StringDigitSubstitute メソッドに渡すと、表示時にアラビア・インディック数字が西洋数字に置き換えられます。
