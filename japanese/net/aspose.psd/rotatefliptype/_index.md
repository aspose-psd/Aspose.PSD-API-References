## RotateFlipType enumeration

画像が回転する角度と、画像を反転させる際に使用する軸を指定します。

```csharp
public enum RotateFlipType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| RotateNoneFlipNone | `0` | 時計回りの回転も反転も行わないことを指定します。 |
| Rotate90FlipNone | `1` | 90度時計回りの回転を指定し、フリップは行いません。 |
| Rotate180FlipNone | `2` | 180度時計回りの回転を指定し、フリップは行いません。 |
| Rotate270FlipNone | `3` | 270度時計回りの回転を指定し、フリップは行いません。 |
| RotateNoneFlipX | `4` | 時計回りの回転なしで水平フリップを指定します。 |
| Rotate90FlipX | `5` | 90度時計回りの回転の後に水平フリップを指定します。 |
| Rotate180FlipX | `6` | 180度時計回りの回転の後に水平フリップを指定します。 |
| Rotate270FlipX | `7` | 270度時計回りの回転の後に水平フリップを指定します。 |
| RotateNoneFlipY | `8` | 時計回りの回転なしで垂直フリップを指定します。 |
| Rotate90FlipY | `9` | 90度時計回りの回転の後に垂直フリップを指定します。 |
| Rotate180FlipY | `10` | 180度時計回りの回転の後に垂直フリップを指定します。 |
| Rotate270FlipY | `11` | 270度時計回りの回転の後に垂直フリップを指定します。 |
| RotateNoneFlipXY | `12` | 時計回りの回転なしで水平および垂直フリップを指定します。 |
| Rotate90FlipXY | `13` | 90度時計回りの回転の後に水平および垂直フリップを指定します。 |
| Rotate180FlipXY | `14` | 180度時計回りの回転の後に水平および垂直フリップを指定します。 |
| Rotate270FlipXY | `15` | 270度時計回りの回転の後に水平および垂直フリップを指定します。 |
