## DataRecoveryMode enumeration

データ復旧モードです。

```csharp
public enum DataRecoveryMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | `0` | データ復旧は行われません。ファイル形式に破損したデータがある場合は、適切な例外がスローされます。 |
| ConsistentRecover | `1` | 一貫した復旧モードは、破損がファイル形式を壊さない限りすべてのデータを復元し、正しい後続処理を可能にしようとします。 |
| MaximalRecover | `2` | 最大回復モードは、ファイル形式が破損した構造であってもすべてのデータを復元し、さらに処理を行うと予期しない影響が生じる可能性があります。 |
