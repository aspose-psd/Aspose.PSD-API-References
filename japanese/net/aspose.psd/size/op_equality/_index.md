## Size Equality operator

2 つの [`Size`](../) 構造体が等しいかどうかをテストします。

```csharp
public static bool operator ==(Size size1, Size size2)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| size1 | Size | 等価演算子の左側にある [`Size`](../) 構造体です。 |
| size2 | Size | 等価演算子の右側にある [`Size`](../) 構造体です。 |

### 戻り値

*size1* と *size2* の幅と高さが等しい場合は true、そうでない場合は false です。
