## RectangleF.FromPoints method

指定された 2 つの点から新しい [`Rectangle`](../../rectangle/) を作成します。作成された [`Rectangle`](../../rectangle/) の 2 つの頂点は、渡された *point1* と *point2* に等しくなります。これらは通常、対角の頂点です。

```csharp
public static RectangleF FromPoints(PointF point1, PointF point2)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| point1 | PointF | 新しい rectangle の最初の [`Point`](../../point/)です。 |
| point2 | PointF | 新しい rectangle の 2 番目の [`Point`](../../point/)です。 |

### 戻り値

新しく作成された [`Rectangle`](../../rectangle/)です。
