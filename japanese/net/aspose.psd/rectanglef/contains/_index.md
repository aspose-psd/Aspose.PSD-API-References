## Contains(float, float) {#contains_2}

指定された点がこの [`RectangleF`](../) 構造体に含まれているかどうかを判断します。

```csharp
public bool Contains(float x, float y)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| x | シングル | テストする点の x 座標です。 |
| y | シングル | テストする点の y 座標です。 |

### 戻り値

このメソッドは、*x* と *y* で定義された点がこの [`RectangleF`](../) 構造体に含まれている場合に true を返し、そうでない場合は false を返します。
