## Inflate(RectangleF, float, float)

指定された [`RectangleF`](../) 構造体の拡張コピーを作成して返します。コピーは指定された量だけ拡張されます。元の矩形は変更されません。

```csharp
public static RectangleF Inflate(RectangleF rect, float x, float y)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| rect | RectangleF | コピー対象の [`RectangleF`](../)。この矩形は変更されません。 |
| x | シングル | 矩形のコピーを水平方向に拡張する量。 |
| y | シングル | 矩形のコピーを垂直方向に拡張する量。 |

### 戻り値

拡張された [`RectangleF`](../)。
