## RectangleF Equality operator

2 つの [`RectangleF`](../) 構造体が同じ位置とサイズかどうかをテストします。

```csharp
public static bool operator ==(RectangleF left, RectangleF right)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| left | RectangleF | 等価演算子の左側にある [`RectangleF`](../) 構造体です。 |
| right | RectangleF | 等価演算子の右側にある [`RectangleF`](../) 構造体です。 |

### 戻り値

指定された 2 つの [`RectangleF`](../) 構造体が同じ [`X`](../x/)、[`Y`](../y/)、[`Width`](../width/)、[`Height`](../height/) プロパティを持つ場合、この演算子は true を返します。
