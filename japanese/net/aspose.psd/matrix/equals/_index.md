## Equals(object)

指定された Object がこのインスタンスと等しいかどうかを判断します。

```csharp
public override bool Equals(object obj)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| obj | Object | このインスタンスと比較する Object。 |

### 戻り値

`true`：指定された Object がこのインスタンスと等しい場合。そうでなければ `false`。

| 例外 | 条件 |
| --- | --- |
| NullReferenceException | *obj* パラメーターが null です。 |
