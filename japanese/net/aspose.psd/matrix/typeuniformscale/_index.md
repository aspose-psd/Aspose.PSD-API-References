## Matrix.TypeUniformScale field

均一スケールは、ベクトルの長さを x 方向と y 方向の両方で同じ量だけ乗算し、ベクトル間の角度は変えません。このフラグビットは TypeGeneralScale フラグと相互排他的です。

```csharp
public const int TypeUniformScale;
```
