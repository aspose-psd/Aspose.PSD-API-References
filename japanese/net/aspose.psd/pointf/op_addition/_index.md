## operator + {#op_addition}

指定された [`Size`](../../size/) によって [`PointF`](../) を平行移動します。

```csharp
public static PointF operator +(PointF point, Size size)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| point | PointF | 平行移動する対象の [`PointF`](../)。 |
| size | Size | 座標に加える 2 つの数値のペアを指定する [`Size`](../../size/)（*point* 用）。 |

### 戻り値
