## Color.IsKnownColor property

この [`Color`](../) 構造体が既定の色かどうかを示す値を取得します。既定の色は [`KnownColor`](../../knowncolor/) 列挙体の要素で表されます。

```csharp
public bool IsKnownColor { get; }
```

### Property Value

この [`Color`](../) が [`FromName`](../fromname/) メソッドまたは [`FromKnownColor`](../fromknowncolor/) メソッドのいずれかを使用して既定の色から作成された場合は true、そうでない場合は false です。
