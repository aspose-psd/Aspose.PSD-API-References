## Color Inequality operator

指定された [`Color`](../) 構造体が異なるかどうかをテストします。

```csharp
public static bool operator !=(Color left, Color right)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| left | Color | 不等号演算子の左側にある [`Color`](../) です。 |
| right | Color | 不等号演算子の右側にある [`Color`](../) です。 |

### 戻り値

2 つの [`Color`](../) 構造体が異なる場合は true、そうでない場合は false です。
