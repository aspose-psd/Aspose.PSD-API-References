## TransparencySupporter.Opacity property

オブジェクトの不透明度を取得または設定します。値は 0 から 1 の間である必要があります。0 の値はオブジェクトが完全に可視であることを意味し、1 の値はオブジェクトが完全に不透明であることを意味します。

```csharp
public float Opacity { get; set; }
```

### Property Value

不透明度の値です。
