## LineJoin enumeration

[`GraphicsPath`](../graphicspath/) オブジェクトに含まれる図形（サブパス）内で、連続する直線または曲線セグメントを結合する方法を指定します。

```csharp
public enum LineJoin
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Miter | `0` | マイタージョインを指定します。マイタの長さがマイタ制限を超えるかどうかに応じて、鋭い角または切り取られた角が生成されます。 |
| Bevel | `1` | ベベルジョインを指定します。対角線の角が生成されます。 |
| Round | `2` | 円形ジョインを指定します。線間に滑らかな円弧が生成されます。 |
| MiterClipped | `3` | マイタージョインを指定します。マイタの長さがマイタ制限を超えるかどうかに応じて、鋭い角またはベベル角が生成されます。 |
