## SizeF Inequality operator

2 つの [`SizeF`](../) 構造体が異なるかどうかをテストします。

```csharp
public static bool operator !=(SizeF size1, SizeF size2)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| size1 | SizeF | 不等号演算子の左側にある [`SizeF`](../) 構造体です。 |
| size2 | SizeF | 不等号演算子の右側にある [`SizeF`](../) 構造体です。 |

### 戻り値

この演算子は、*size1* と *size2* が幅または高さのいずれかで異なる場合は true を返し、*size1* と *size2* が等しい場合は false を返します。
