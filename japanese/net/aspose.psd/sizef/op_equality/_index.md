## SizeF Equality operator

2 つの [`SizeF`](../) 構造体が等しいかどうかをテストします。

```csharp
public static bool operator ==(SizeF size1, SizeF size2)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| size1 | SizeF | 等価演算子の左側にある [`SizeF`](../) 構造体です。 |
| size2 | SizeF | 等価演算子の右側にある [`SizeF`](../) 構造体です。 |

### 戻り値

この演算子は、*size1* と *size2* の幅と高さが等しい場合に true を返し、そうでない場合は false を返します。
