## IImageCreatorDescriptor interface

画像クリエイターディスクリプタはクリエイターのプロパティを指定します。クリエイターディスクリプタは、各画像クリエイターインスタンスをメモリに保持する必要性やマルチスレッドの問題を回避するために使用されます。

```csharp
public interface IImageCreatorDescriptor : IImageDescriptor
```
