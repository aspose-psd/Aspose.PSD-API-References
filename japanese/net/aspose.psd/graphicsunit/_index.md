## GraphicsUnit enumeration

指定されたデータの測定単位を指定します。

```csharp
public enum GraphicsUnit
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| World | `0` | 世界座標系の単位を測定単位として指定します。 |
| Display | `1` | ディスプレイデバイスの測定単位を指定します。通常、ビデオディスプレイはピクセル、プリンターは 1/100 インチです。 |
| Pixel | `2` | デバイスピクセルを測定単位として指定します。 |
| Point | `3` | プリンターのポイント（1/72 インチ）を測定単位として指定します。 |
| Inch | `4` | インチを測定単位として指定します。 |
| Document | `5` | 文書単位（1/300 インチ）を測定単位として指定します。 |
| Millimeter | `6` | ミリメートルを測定単位として指定します。 |
