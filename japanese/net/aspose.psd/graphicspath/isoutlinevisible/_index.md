## IsOutlineVisible(float, float, Pen) {#isoutlinevisible_6}

指定された [`Pen`](../../pen/) で描画されたときに、この [`GraphicsPath`](../) のアウトラインの下に指定された点が含まれるかどうかを示します。

```csharp
public bool IsOutlineVisible(float x, float y, Pen pen)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| x | シングル | テストする点の x 座標です。 |
| y | シングル | テストする点の y 座標です。 |
| pen | Pen | テスト対象の [`Pen`](../../pen/) です。 |

### 戻り値

このメソッドは、指定された [`Pen`](../../pen/) で描画されたときに、指定された点がこの [`GraphicsPath`](../) のアウトライン内に含まれる場合は true を返し、そうでない場合は false を返します。
