## Write(byte[], int, int) {#write_1}

バイトのシーケンスを現在のストリームに書き込み、書き込んだバイト数だけこのストリーム内の現在位置を進めます。

```csharp
public virtual void Write(byte[] buffer, int offset, int count)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| buffer | Byte[] | バイト配列。このメソッドは *buffer* から現在のストリームへ *count* バイトをコピーします。 |
| offset | Int32 | *buffer* 内のゼロベースのバイトオフセットで、現在のストリームへのコピーを開始する位置です。 |
| カウント | Int32 | 現在のストリームに書き込まれるバイト数。 |
