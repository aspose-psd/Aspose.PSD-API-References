## StreamContainer.ReadByte method

ストリームから1バイトを読み取り、ストリーム内の位置を1バイト進めます。ストリームの末尾に達した場合は -1 を返します。

```csharp
public virtual int ReadByte()
```

### 戻り値

ストリームの末尾に達した場合は -1、そうでない場合は unsigned バイトを Int32 にキャストした値です。
