## Rectangle.FromPoints method

指定された 2 つの点から新しい [`Rectangle`](../) を作成します。作成された [`Rectangle`](../) の 2 つの垂直辺は、渡された *point1* と *point2* に等しくなります。これらは通常、対角の頂点です。

```csharp
public static Rectangle FromPoints(Point point1, Point point2)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| point1 | Point | 新しい rectangle の最初の [`Point`](../../point/)です。 |
| point2 | Point | 新しい rectangle の 2 番目の [`Point`](../../point/)です。 |

### 戻り値

新しく作成された [`Rectangle`](../) です。
