## Rectangle.Equals method

*obj* がこの [`Rectangle`](../) 構造体と同じ位置とサイズを持つかどうかをテストします。

```csharp
public override bool Equals(object obj)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| obj | Object | テストするオブジェクトです。 |

### 戻り値

このメソッドは、*obj* が [`Rectangle`](../) 構造体であり、その [`X`](../x/)、[`Y`](../y/)、[`Width`](../width/)、[`Height`](../height/) プロパティがこの [`Rectangle`](../) 構造体の対応するプロパティと等しい場合に true を返します。そうでない場合は false を返します。
