## DrawClosedCurve(Pen, PointF[]) {#drawclosedcurve}

[`PointF`](../../pointf/)構造体の配列で定義された閉じたカーディナル スプラインを描画します。このメソッドはデフォルトのテンション 0.5 と Alternate 塗りつぶしモードを使用します。

```csharp
public void DrawClosedCurve(Pen pen, PointF[] points)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| pen | Pen | [`Pen`](../../pen/) は曲線の色、幅、および高さを決定します。 |
| points | PointF[] | スプラインを定義する [`PointF`](../../pointf/) 構造体の配列です。 |

### 例外

| 例外 | 条件 |
| --- | --- |
| ArgumentNullException | *pen* は null です。-or- *points* は null です。 |

## DrawClosedCurve(Pen, PointF[], float) {#drawclosedcurve_1}

```csharp
public void DrawClosedCurve(Pen pen, PointF[] points, float tension)
```

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| pen | Pen | [`Pen`](../../pen/) は曲線の色、幅、および高さを決定します。 |
| points | PointF[] | スプラインを定義する [`PointF`](../../pointf/) 構造体の配列です。 |
| テンション | シングル | 曲線のテンションを指定する、0.0F 以上の値です。 |
