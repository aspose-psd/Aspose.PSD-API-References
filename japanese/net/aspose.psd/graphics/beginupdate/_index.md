## Graphics.BeginUpdate method

以下のグラフィック操作のキャッシュを開始します。その後に適用されるグラフィック効果はすぐには適用されず、代わりに EndUpdate が呼び出されたときにすべての効果が一度に適用されます。

```csharp
public void BeginUpdate()
```

## 備考

BeginUpdate が呼び出された後の効果は、EndUpdate が呼び出されない限り適用されないことに注意してください。
