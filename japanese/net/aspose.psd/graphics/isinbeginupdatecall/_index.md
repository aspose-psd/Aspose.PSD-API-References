## Graphics.IsInBeginUpdateCall property

グラフィックが BeginUpdate 呼び出し状態にあるかどうかを示す値を取得します。

```csharp
public bool IsInBeginUpdateCall { get; }
```

### Property Value

`True` はグラフィックスが BeginUpdate 呼び出し状態にある場合です。そうでなければ `false` です。
