## Pen.CompoundArray property

複合ペンを指定する値の配列を取得または設定します。複合ペンは平行線と間隔で構成された複合線を描画します。

```csharp
public float[] CompoundArray { get; set; }
```

### Property Value

複合配列を指定する実数の配列です。配列の要素は昇順で、0 未満でも 1 超過でもいけません。
