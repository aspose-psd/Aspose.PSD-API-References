## PsdImage.HasTransparencyData property

レイヤーデータを指定したときに、最初のアルファチャンネルが合成結果の透過データを含むかどうかを示す値を取得または設定します。

```csharp
public bool HasTransparencyData { get; set; }
```

### Property Value

`true` レイヤーデータを指定したときに、マージ結果の透過データが最初のアルファチャンネルに含まれている場合; それ以外の場合は `false`。
