## PsdImage.VerticalResolution property

この [`PsdImage`](../) の垂直解像度（ピクセル/インチ）を取得または設定します。

```csharp
public override double VerticalResolution { get; set; }
```

### Property Value

垂直解像度です。

### 例外

| 例外 | 条件 |
| --- | --- |
| [PsdImageException](../../../aspose.psd.coreexceptions.imageformats/psdimageexception/) | ResolutionInfo リソースが見つからず、適切な解像度を設定できません。 |

## 備考

PSD のデフォルト値は 72 です。そのため、[`ResolutionInfoResource`](../../../aspose.psd.fileformats.psd.resources/resolutioninforesource/) が見つからなかった場合、この値が返されます。
