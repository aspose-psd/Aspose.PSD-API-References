## RawColor.GetBitDepth method

Raw Color のビット深度を取得します。例えば、各チャンネル/コンポーネントが 8 ビットの ARGB カラーの場合、ビット深度は 32 ビットです。各チャンネル/コンポーネントが 16 ビットのフル ARGB カラーの場合、ビット深度は 64 ビットになります。ビット深度は各チャンネルのビット深度の合計として蓄積されます。異なるチャンネルが異なるビット深度を持つことも可能です。

```csharp
public int GetBitDepth()
```

### 戻り値

すべてのチャンネルのビット深度の合計
