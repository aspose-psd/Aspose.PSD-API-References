```
public class JpegLsPresetCodingParameters
```

Definieert de JPEG-LS preset coderingsparameters zoals gedefinieerd in ISO/IEC 14495-1, C.2.4.1.1. JPEG-LS definieert een standaardset parameters, maar aangepaste parameters kunnen worden gebruikt. Wanneer ze worden gebruikt, worden deze parameters geschreven in de gecodeerde bitstroom zoals ze nodig zijn voor het decoderen.
