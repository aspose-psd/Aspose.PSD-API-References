Het pakket biedt hulpprogrammaklassen en -methoden om met verschillende penseeltypen te werken.

| --- | --- |

| [LinearGradientBrush](../com.aspose.psd.brushes/lineargradientbrush) | Omvat een  Aspose.Imaging.Brush  met een lineaire gradient. |
| [LinearGradientBrushBase](../com.aspose.psd.brushes/lineargradientbrushbase) | Vertegenwoordigt een  Brush  met gradient-mogelijkheden en passende eigenschappen. |
| [LinearMulticolorGradientBrush](../com.aspose.psd.brushes/linearmulticolorgradientbrush) | Vertegenwoordigt een  Brush  met lineaire gradient gedefinieerd door meerdere kleuren en passende posities. |
| [PathGradientBrush](../com.aspose.psd.brushes/pathgradientbrush) | Omvat een  Aspose.Imaging.Brush  object met een gradient. |
| [PathGradientBrushBase](../com.aspose.psd.brushes/pathgradientbrushbase) | Stelt een  Brush  voor met basispadverloopfunctionaliteit. |
| [PathMulticolorGradientBrush](../com.aspose.psd.brushes/pathmulticolorgradientbrush) | Omvat een  Aspose.Imaging.Brush  object met een gradient. |
| [SolidBrush](../com.aspose.psd.brushes/solidbrush) | Solid brush is bedoeld om continu te tekenen met een specifieke kleur. |
| [TextureBrush](../com.aspose.psd.brushes/texturebrush) | Elke eigenschap van de  Aspose.Imaging.Brushes.TextureBrush  klasse is een  Aspose.Imaging.Brush  object dat een afbeelding gebruikt om het interieur van een vorm te vullen. |
| [TransformBrush](../com.aspose.psd.brushes/transformbrush) | Een  Brush  met transformatiefuncties. |
