De gegevensherstelmodus.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.DataRecoveryMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Lidnaam** | **Beschrijving** |
| :- | :- |
| CONSISTENT_RECOVER | De consistente herstelmodus probeert alle gegevens te herstellen zolang corruptie het bestandsformaat niet breekt en correcte verdere verwerking mogelijk maakt. |
| MAXIMAL_RECOVER | De maximale herstelmodus herstelt alle gegevens, zelfs als de bestandsstructuur corrupt is, en verdere verwerking kan ongewenste effecten opleveren. |
| NONE | Er wordt geen gegevensherstel geïmpliceerd. Wanneer het bestandsformaat enige corrupte gegevens bevat, wordt de juiste uitzondering gegooid. |
