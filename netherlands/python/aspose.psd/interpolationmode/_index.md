De [InterpolationMode](/psd/python-net/aspose.psd/interpolationmode/) enumeratie specificeert het algoritme dat wordt gebruikt wanneer afbeeldingen worden geschaald of geroteerd.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.InterpolationMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Lidnaam** | **Beschrijving** |
| :- | :- |
| BICUBIC | Specificeert bicubische interpolatie. Er wordt geen prefiltering uitgevoerd. Deze modus is niet geschikt om een afbeelding te verkleinen tot minder dan 25 procent van de oorspronkelijke grootte. |
| BILINEAR | Specificeert bilineaire interpolatie. Er wordt geen prefiltering uitgevoerd. Deze modus is niet geschikt om een afbeelding te verkleinen tot minder dan 50 procent van de oorspronkelijke grootte. |
| DEFAULT | Specificeert de standaardmodus. |
| HIGH | Specificeert interpolatie van hoge kwaliteit. |
| HIGH_QUALITY_BICUBIC | Specificeert interpolatie van hoge kwaliteit, bicubic. Prefiltering wordt uitgevoerd om verkleining van hoge kwaliteit te waarborgen. Deze modus levert de hoogste kwaliteit getransformeerde afbeeldingen. |
| HIGH_QUALITY_BILINEAR | Specificeert interpolatie van hoge kwaliteit, bilinear. Prefiltering wordt uitgevoerd om verkleining van hoge kwaliteit te waarborgen. |
| INVALID | Ongeldige interpolatiemodus. |
| LOW | Specificeert interpolatie van lage kwaliteit. |
| NEAREST_NEIGHBOR | Specificeert nearest-neighbor interpolatie. |
