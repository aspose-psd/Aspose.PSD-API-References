Specificeert hoe tekens uit een string worden getrimd die niet volledig in een layoutvorm passen.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringTrimming

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Lidnaam** | **Beschrijving** |
| :- | :- |
| TEKEN | Specificeert dat de tekst wordt bijgesneden tot het dichtstbijzijnde teken. |
| ELLIPSIS_TEKEN | Specificeert dat de tekst wordt bijgesneden tot het dichtstbijzijnde teken, en dat er een ellipsis wordt ingevoegd aan het einde van een bijgesneden regel. |
| ELLIPSIS_PAD | Het midden wordt verwijderd uit bijgesneden regels en vervangen door een ellipsis. Het algoritme behoudt zoveel mogelijk van het laatste door schuine strepen gescheiden segment van de regel. |
| ELLIPSIS_WOORD | Specificeert dat de tekst wordt bijgesneden tot het dichtstbijzijnde woord, en dat er een ellipsis wordt ingevoegd aan het einde van een bijgesneden regel. |
| NONE | Specificeert geen bijsnijden. |
| WOORD | Specificeert dat de tekst wordt bijgesneden tot het dichtstbijzijnde woord. |
