De enumeratie specificeert hoe cijfers in een string worden vervangen volgens de locale of taal van een gebruiker.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringDigitSubstitute

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Lidnaam** | **Beschrijving** |
| :- | :- |
| NATIONAAL | Specificeert substitutiecijfers die overeenkomen met de officiële nationale taal van de gebruikerslocale. |
| NONE | Specificeert om substituties uit te schakelen. |
| TRADITIONEEL | Specificeert substitutiecijfers die overeenkomen met het moedscript of de moedertaal van de gebruiker, die kan verschillen van de officiële nationale taal van de gebruikerslocale. |
| GEBRUIKER | Specificeert een door de gebruiker gedefinieerd substitutieschema. |
