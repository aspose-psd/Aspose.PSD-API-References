Specificeert de typen afbeeldingen en kleuren die worden beïnvloed door de kleur- en grijstintaanpassingsinstellingen van een [ImageAttributes](/psd/python-net/aspose.psd/imageattributes/).

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorMatrixFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Lidnaam** | **Beschrijving** |
| :- | :- |
| ALT_GRAYS | Alleen grijstinten worden aangepast. |
| DEFAULT | Alle kleurwaarden, inclusief grijstinten, worden aangepast door dezelfde kleurcorrectiematrix. |
| SKIP_GRAYS | Alle kleuren worden aangepast, maar grijstinten worden niet aangepast. Een grijstint is elke kleur die dezelfde waarde heeft voor de rode, groene en blauwe componenten. |
