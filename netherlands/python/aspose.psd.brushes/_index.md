De module biedt helperklassen en -methoden om met verschillende penseeltypen te werken.

## **Classes**
| **Klasse** | **Beschrijving** |
| :- | :- |
| [HatchBrush](/psd/python-net/aspose.psd.brushes/hatchbrush/) | Definieert een rechthoekige penseel met een hatch‑stijl, een voorgrondkleur en een achtergrondkleur. Deze klasse kan niet worden geërfd. |
| [LinearGradientBrush](/psd/python-net/aspose.psd.brushes/lineargradientbrush/) | Omvat een [Brush](/psd/python-net/aspose.psd/brush/) met een lineaire gradiënt. Deze klasse kan niet worden geërfd. |
| [LinearGradientBrushBase](/psd/python-net/aspose.psd.brushes/lineargradientbrushbase/) | Stelt een [Brush](/psd/python-net/aspose.psd/brush/) met gradiëntmogelijkheden en passende eigenschappen voor. |
| [LinearMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/linearmulticolorgradientbrush/) | Stelt een [Brush](/psd/python-net/aspose.psd/brush/) met een lineaire gradiënt gedefinieerd door meerdere kleuren en passende posities voor. Deze klasse kan niet worden geërfd. |
| [PathGradientBrush](/psd/python-net/aspose.psd.brushes/pathgradientbrush/) | Omvat een [Brush](/psd/python-net/aspose.psd/brush/) object met een gradiënt. Deze klasse kan niet worden geërfd. |
| [PathGradientBrushBase](/psd/python-net/aspose.psd.brushes/pathgradientbrushbase/) | Stelt een [Brush](/psd/python-net/aspose.psd/brush/) met basispad‑gradiëntfunctionaliteit voor. |
| [PathMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/pathmulticolorgradientbrush/) | Omvat een [Brush](/psd/python-net/aspose.psd/brush/) object met een gradiënt. Deze klasse kan niet worden geërfd. |
| [SolidBrush](/psd/python-net/aspose.psd.brushes/solidbrush/) | Solide penseel is bedoeld voor continu tekenen met een specifieke kleur. Deze klasse kan niet worden geërfd. |
| [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) | Elke eigenschap van de [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) klasse is een [Brush](/psd/python-net/aspose.psd/brush/) object dat een afbeelding gebruikt om het binnenste van een vorm te vullen. Deze klasse kan niet worden geërfd. |
| [TransformBrush](/psd/python-net/aspose.psd.brushes/transformbrush/) | Een [Brush](/psd/python-net/aspose.psd/brush/) met transformatiefuncties. |
