Definieert de interleavemodus voor meercomponent (kleur) pixelgegevens.

**Module:** [aspose.psd.fileformats.jpeg](/psd/python-net/aspose.psd.fileformats.jpeg/)

**Full Name:** aspose.psd.fileformats.jpeg.JpegLsInterleaveMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Lidnaam** | **Beschrijving** |
| :- | :- |
| LINE | De interleavemodus is per regel. Een volledige regel van elk component wordt gecodeerd voordat naar de volgende regel wordt gegaan. |
| NONE | De gegevens worden gecodeerd en opgeslagen als component per component: RRRGGGBBB. |
| SAMPLE | De gegevens worden gecodeerd en opgeslagen per monster. Voor kleurafbeeldingen is dit het formaat zoals RGBRGBRGB. |
