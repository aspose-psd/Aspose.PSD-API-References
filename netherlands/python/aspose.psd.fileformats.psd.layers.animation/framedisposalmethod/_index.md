De frameverwijderingsmethode geeft aan of het huidige frame moet worden verwijderd voordat het volgende frame wordt weergegeven.<br/>            U selecteert een verwijderingsmethode voor animaties die achtergrondtransparantie bevatten om aan te geven of het huidige<br/>            frame zichtbaar zal zijn door de transparante gebieden van het volgende frame.

**Module:** [aspose.psd.fileformats.psd.layers.animation](/psd/python-net/aspose.psd.fileformats.psd.layers.animation/)

**Full Name:** aspose.psd.fileformats.psd.layers.animation.FrameDisposalMethod

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Lidnaam** | **Beschrijving** |
| :- | :- |
| AUTOMATISCH | Bepaalt automatisch een verwijderingsmethode voor het huidige frame, waarbij het huidige frame wordt weggegooid als het volgende frame laagtransparantie bevat.<br/>            Voor de meeste animaties levert de automatische optie (standaard) de gewenste resultaten op. |
| VERWIJDEREN | Verwijdert het huidige frame van het scherm voordat het volgende frame wordt weergegeven.<br/>            Er wordt te allen tijde slechts één frame weergegeven (en het huidige frame verschijnt niet door de transparante gebieden van het volgende frame). |
| NIET_VERWIJDEREN | Behoudt het huidige frame terwijl het volgende frame aan het scherm wordt toegevoegd.<br/>            Het huidige frame (en voorgaande frames) kan door transparante gebieden van het volgende frame zichtbaar zijn. |
