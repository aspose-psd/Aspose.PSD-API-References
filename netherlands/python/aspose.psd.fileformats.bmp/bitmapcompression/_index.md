Specificeert verschillende bitmap‑compressiemethoden.

**Module:** [aspose.psd.fileformats.bmp](/psd/python-net/aspose.psd.fileformats.bmp/)

**Full Name:** aspose.psd.fileformats.bmp.BitmapCompression

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Lidnaam** | **Beschrijving** |
| :- | :- |
| ALPHA_BITFIELDS | RGBA-bitvelden. Kan alleen worden gebruikt met 16- en 32-bit/pixel-bitmaps. |
| BITFIELDS | RGB-bitvelden. Kan alleen worden gebruikt met 16- en 32-bit/pixel-bitmaps. |
| DXT1 | DXT1-compressie. De bitmap bevat een textuur. |
| JPEG | JPEG-compressie. De bitmap bevat een JPEG-afbeelding. |
| PNG | PNG-compressie. De bitmap bevat een PNG-afbeelding. |
| RGB | Geen compressie. |
| RLE4 | RLE 4-bit/pixel-compressie. Kan alleen worden gebruikt met 4-bit/pixel-bitmaps. |
| RLE8 | RLE 8-bit/pixel-compressie. Kan alleen worden gebruikt met 8-bit/pixel-bitmaps. |
