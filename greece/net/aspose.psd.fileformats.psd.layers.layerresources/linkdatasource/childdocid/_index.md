## LinkDataSource.ChildDocId property

Λαμβάνει ή ορίζει το αναγνωριστικό του θυγατρικού εγγράφου στην πηγή δεδομένων liFE ή liFD του πόρου Lnk2 / LnkE Adobe® Photoshop®.

```csharp
public string ChildDocId { get; set; }
```

### Property Value

Το αναγνωριστικό του παιδικού εγγράφου στην πηγή δεδομένων liFE ή liFD του πόρου PSD Lnk2 / LnkE.
