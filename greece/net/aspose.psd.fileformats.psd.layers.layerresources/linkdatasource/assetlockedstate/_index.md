## LinkDataSource.AssetLockedState property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το στοιχείο PSD είναι κλειδωμένο. Η κατάσταση κλειδώματος του στοιχείου, για στοιχεία Adobe® Photoshop® СС Libraries.

```csharp
public bool AssetLockedState { get; set; }
```

### Property Value

`true` εάν το στοιχείο Adobe® Photoshop® είναι κλειδωμένο· διαφορετικά, `false`.
