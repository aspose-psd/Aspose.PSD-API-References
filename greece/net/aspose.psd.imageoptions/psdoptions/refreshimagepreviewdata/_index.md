## PsdOptions.RefreshImagePreviewData property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν [refresh image preview data] - επιλογή που χρησιμοποιείται για μεγιστοποίηση της συμβατότητας με άλλους προβολείς εικόνων PSD. Παρακαλώ σημειώστε ότι η σχεδίαση των στρωμάτων κειμένου στην τελική διάταξη δεν υποστηρίζεται για την πλατφόρμα Compact Framework.

```csharp
public bool RefreshImagePreviewData { get; set; }
```

### Property Value

`true` εάν [refresh image preview data]; διαφορετικά, `false`.
