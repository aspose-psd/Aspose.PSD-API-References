## GifOptions.DoPaletteCorrection property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν εφαρμόζεται διόρθωση παλέτας.

```csharp
public bool DoPaletteCorrection { get; set; }
```

### Property Value

`true` εάν εφαρμόζεται η διόρθωση παλέτας· διαφορετικά, `false`.

## Σχόλια

Η διόρθωση παλέτας σημαίνει ότι κάθε φορά που η εικόνα εξάγεται σε GIF, τα χρώματα της αρχικής εικόνας θα αναλυθούν προκειμένου να δημιουργηθεί η καλύτερη ταιριαστή παλέτα (σε περίπτωση που η Palette της εικόνας δεν υπάρχει ή δεν έχει οριστεί στις επιλογές). Η διαδικασία ανάλυσης διαρκεί κάποιο χρόνο, ωστόσο η τελική εικόνα θα έχει την καλύτερη ταιριαστή χρωματική παλέτα και το αποτέλεσμα θα είναι οπτικά καλύτερο.
