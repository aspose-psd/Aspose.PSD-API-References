## PsdLoadOptions.ReadOnlyMode property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει αν [use read only mode]. Αυτό είναι λειτουργία μόνο για ανάγνωση, υποστηριζόμενη για πλήρη συμβατότητα με το Adobe Photoshop. Όταν αυτή η επιλογή οριστεί, όλες οι αλλαγές που εφαρμόζονται στα επίπεδα δεν θα αποθηκευτούν στην τελική εικόνα. Όλα τα δεδομένα προέρχονται από την ενότητα ImageData, έτσι είναι ταυτόσημα με το Photoshop. Από προεπιλογή όλες οι φορτωμένες εικόνες δεν είναι πλήρως συμβατές με το Adobe Photoshop.

```csharp
public bool ReadOnlyMode { get; set; }
```

### Property Value

`true` εάν [χρησιμοποιήσετε λειτουργία συμβατότητας με Photoshop]; διαφορετικά, `false`.
