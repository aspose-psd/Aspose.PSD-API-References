## PsdImage.HasTransparencyData property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το πρώτο κανάλι άλφα περιέχει τα δεδομένα διαφάνειας για το συγχωνευμένο αποτέλεσμα όταν καθορίζονται δεδομένα στρωμάτων.

```csharp
public bool HasTransparencyData { get; set; }
```

### Property Value

`true` εάν το πρώτο κανάλι άλφα περιέχει τα δεδομένα διαφάνειας για το συγχωνευμένο αποτέλεσμα όταν καθορίζονται δεδομένα στρωμάτων· διαφορετικά, `false`.
