### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| None | `0` | Το null-filter, σημαίνει ότι δεν υπάρχει φιλτράρισμα για τις σειρές δεδομένων εικόνας. |
| Sub | `1` | Το sub filter, σημαίνει ότι θα εφαρμοστεί αφαιρετικό φιλτράρισμα στα δεδομένα εικόνας. |
| Up | `2` | Το up filter, σημαίνει ότι θα εφαρμοστεί φίλτρο αφαίρεσης γραμμή-προς-γραμμή. |
| Avg | `3` | Το avg filter, σημαίνει ότι το μέσο φίλτρο θα εφαρμοστεί στα δεδομένα εικόνας. |
| Paeth | `4` | Το paeth predictor filter. |
| Adaptive | `5` | Το προσαρμοστικό φιλτράρισμα, σημαίνει ότι η διαδικασία αποθήκευσης θα επιλέξει το πιο κατάλληλο φίλτρο για κάθε σειρά δεδομένων. Καλύτερη συμπίεση, πιο αργός χρόνος εκτέλεσης. |
