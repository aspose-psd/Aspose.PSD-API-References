## Brush.Opacity property

Αποκτά ή ορίζει τη διαφάνεια του πινέλου. Η τιμή πρέπει να βρίσκεται μεταξύ 0 και 1. Τιμή 0 σημαίνει ότι το πινέλο είναι πλήρως ορατό, τιμή 1 σημαίνει ότι το πινέλο είναι πλήρως αδιαφανές.

```csharp
public float Opacity { get; set; }
```

### Property Value

Η τιμή διαφάνειας του πινέλου.
