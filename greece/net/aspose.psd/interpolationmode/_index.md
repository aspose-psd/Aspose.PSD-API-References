## InterpolationMode enumeration

Η `InterpolationMode` αρίθμηση καθορίζει τον αλγόριθμο που χρησιμοποιείται όταν οι εικόνες κλιμακώνονται ή περιστρέφονται.

```csharp
public enum InterpolationMode
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Invalid | `-1` | Μη έγκυρη λειτουργία παρεμβολής. |
| Default | `0` | Καθορίζει την προεπιλεγμένη λειτουργία. |
| Low | `1` | Καθορίζει παρεμβολή χαμηλής ποιότητας. |
| High | `2` | Καθορίζει παρεμβολή υψηλής ποιότητας. |
| Bilinear | `3` | Καθορίζει διγραμμική παρεμβολή. Δεν γίνεται προφίλτρισμα. Αυτή η λειτουργία δεν είναι κατάλληλη για τη σμίκρυνση μιας εικόνας κάτω από το 50 % του αρχικού μεγέθους. |
| Bicubic | `4` | Καθορίζει δικοπική παρεμβολή. Δεν γίνεται προφίλτρισμα. Αυτή η λειτουργία δεν είναι κατάλληλη για τη σμίκρυνση μιας εικόνας κάτω από το 25 % του αρχικού μεγέθους. |
| NearestNeighbor | `5` | Καθορίζει παρεμβολή κοντινότερου γείτονα. |
| HighQualityBilinear | `6` | Καθορίζει υψηλής ποιότητας, διγραμμική παρεμβολή. Πραγματοποιείται προφίλτρισμα για να εξασφαλιστεί η σμίκρυνση υψηλής ποιότητας. |
| HighQualityBicubic | `7` | Καθορίζει υψηλής ποιότητας, δικοπική παρεμβολή. Πραγματοποιείται προφίλτρισμα για να εξασφαλιστεί η σμίκρυνση υψηλής ποιότητας. Αυτή η λειτουργία παράγει τις εικόνες υψηλότερης ποιότητας μετά τη μετασχηματισμό. |
