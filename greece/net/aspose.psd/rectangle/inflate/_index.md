```csharp
public static Rectangle Inflate(Rectangle rect, int x, int y)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |

| y | Int32 | Το ποσό για φούσκωμα αυτού του [`Rectangle`](../) κάθετα. |
