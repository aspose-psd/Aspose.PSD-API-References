## Matrix.TypeIdentity field

Ένας μετασχηματισμός ταυτότητας είναι αυτός όπου οι συντεταγμένες εξόδου είναι πάντα ίδιες με τις συντεταγμένες εισόδου. Εάν αυτός ο μετασχηματισμός δεν είναι ο μετασχηματισμός ταυτότητας, ο τύπος θα είναι είτε η σταθερά GENERAL_TRANSFORM είτε ένας συνδυασμός των κατάλληλων bits σημαίας για τις διάφορες μετατροπές συντεταγμένων που εκτελεί αυτός ο μετασχηματισμός.

```csharp
public const int TypeIdentity;
```
