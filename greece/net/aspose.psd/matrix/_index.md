## Σχόλια

Οι περισσότερες αλγόριθμοι προέρχονται από το AffineTransform.java της Sun. Τα ονόματα της Java για τα στοιχεία του πίνακα που χρησιμοποιούνται εσωτερικά. Χάρτης των ονομάτων Java σε αντίστοιχα .net με περιγραφή: m00 M11 Κλίμακα X m10 M12 Κάμψη Y m01 M21 Κάμψη X m11 M22 Κλίμακα Y m02 M31 Μετάθεση X m12 M32 Μετάθεση Y
