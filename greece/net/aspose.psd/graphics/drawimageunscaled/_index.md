## DrawImageUnscaled(Image, Rectangle) {#drawimageunscaled_1}

Σχεδιάζει μια καθορισμένη εικόνα χρησιμοποιώντας το αρχικό φυσικό της μέγεθος σε μια καθορισμένη θέση.

```csharp
public void DrawImageUnscaled(Image sourceImage, Rectangle rect)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| sourceImage | Εικόνα | Η εικόνα με την οποία θα σχεδιαστεί. |
| rect | Rectangle | `[`Rectangle`](../../rectangle/) που καθορίζει την πάνω αριστερή γωνία της σχεδιασμένης εικόνας. Οι ιδιότητες X και Y του ορθογωνίου καθορίζουν την πάνω αριστερή γωνία. Οι ιδιότητες Width και Height αγνοούνται. |
