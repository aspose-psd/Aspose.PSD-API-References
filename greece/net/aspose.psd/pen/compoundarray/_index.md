## Pen.CompoundArray property

Λαμβάνει ή ορίζει έναν πίνακα τιμών που καθορίζει ένα σύνθετο στυλό. Ένα σύνθετο στυλό σχεδιάζει μια σύνθετη γραμμή που αποτελείται από παράλληλες γραμμές και κενά.

```csharp
public float[] CompoundArray { get; set; }
```

### Property Value

Ένας πίνακας πραγματικών αριθμών που καθορίζει τον σύνθετο πίνακα. Τα στοιχεία του πίνακα πρέπει να είναι σε αυξανόμενη σειρά, όχι μικρότερα από 0 και όχι μεγαλύτερα από 1.
