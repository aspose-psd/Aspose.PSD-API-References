
### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| None | `0` | Δεν υπονοείται ανάκτηση δεδομένων. Όποτε η μορφή αρχείου περιέχει κατεστραμμένα δεδομένα, εκτοξεύεται η κατάλληλη εξαίρεση. |
| ConsistentRecover | `1` | Η συνεπής λειτουργία ανάκτησης προσπαθεί να ανακτήσει όλα τα δεδομένα όσο η κατεστραμμένη κατάσταση δεν διασπά τη μορφή αρχείου και επιτρέπει σωστή περαιτέρω επεξεργασία. |
| MaximalRecover | `2` | Η μέγιστη λειτουργία ανάκτησης ανακτά όλα τα δεδομένα ακόμη και αν η μορφή αρχείου έχει κατεστραμμένη δομή και η περαιτέρω επεξεργασία μπορεί να προκαλέσει ανεπιθύμητα αποτελέσματα. |
