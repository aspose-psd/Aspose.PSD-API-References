## Inflate(RectangleF, float, float)

```csharp
public static RectangleF Inflate(RectangleF rect, float x, float y)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| rect | RectangleF | Το [`RectangleF`](../) που θα αντιγραφεί. Αυτό το ορθογώνιο δεν τροποποιείται. |
| x | Single | Το ποσό για τη φούσκωση του αντιγράφου του ορθογωνίου οριζόντια. |
| y | Single | Το ποσό για τη φούσκωση του αντιγράφου του ορθογωνίου κάθετα. |
