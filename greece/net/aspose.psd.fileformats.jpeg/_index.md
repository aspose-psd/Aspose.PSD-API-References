Ο χώρος ονομάτων διαχειρίζεται την επεξεργασία μορφής αρχείου Jpeg.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [JFIFData](./jfifdata/) | Το τμήμα jfif. |
| [JpegLsPresetCodingParameters](./jpeglspresetcodingparameters/) | Ορίζει τις προρυθμισμένες παραμέτρους κωδικοποίησης JPEG-LS όπως ορίζονται στο ISO/IEC 14495-1, C.2.4.1.1. Το JPEG-LS ορίζει ένα προεπιλεγμένο σύνολο παραμέτρων, αλλά μπορούν να χρησιμοποιηθούν προσαρμοσμένες παράμετροι. Όταν χρησιμοποιούνται, αυτές οι παράμετροι γράφονται στο κωδικοποιημένο ρεύμα bit όπως απαιτούνται για τη διαδικασία αποκωδικοποίησης. |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [JfifDensityUnits](./jfifdensityunits/) | Οι μονάδες πυκνότητας jfif. |
| [JpegCompressionColorMode](./jpegcompressioncolormode/) | Λειτουργία χρώματος για εικόνες jpeg. |
| [JpegCompressionMode](./jpegcompressionmode/) | Λειτουργία συμπίεσης για εικόνες jpeg. |
| [JpegLsInterleaveMode](./jpeglsinterleavemode/) | Ορίζει τη λειτουργία διαπλέξης για πολυσυστατικά (χρωματικά) δεδομένα εικονοστοιχείου. |
| [SampleRoundingMode](./sampleroundingmode/) | Ορίζει έναν τρόπο με τον οποίο μια τιμή n-bit μετατρέπεται σε τιμή 8-bit. |
