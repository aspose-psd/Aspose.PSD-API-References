Ο χώρος ονομάτων παρέχει βοηθητικές κλάσεις και μεθόδους για εργασία με διαφορετικούς τύπους πινέλων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [HatchBrush](./hatchbrush/) | Ορίζει ένα ορθογώνιο πινέλο με στυλ διαγράμμισης, χρώμα προσκηνίου και χρώμα φόντου. Αυτή η κλάση δεν μπορεί να κληρονομηθεί. |
| [LinearGradientBrush](./lineargradientbrush/) | Ενσωματώνει ένα [`Brush`](../aspose.psd/brush/) με γραμμική διαβάθμιση. Αυτή η κλάση δεν μπορεί να κληρονομηθεί. |
| [LinearGradientBrushBase](./lineargradientbrushbase/) | Αντιπροσωπεύει ένα [`Brush`](../aspose.psd/brush/) με δυνατότητες διαβάθμισης και κατάλληλες ιδιότητες. |
| [LinearMulticolorGradientBrush](./linearmulticolorgradientbrush/) | Αντιπροσωπεύει ένα [`Brush`](../aspose.psd/brush/) με γραμμική διαβάθμιση που ορίζεται από πολλαπλά χρώματα και κατάλληλες θέσεις. Αυτή η κλάση δεν μπορεί να κληρονομηθεί. |
| [PathGradientBrush](./pathgradientbrush/) | Ενσωματώνει ένα αντικείμενο [`Brush`](../aspose.psd/brush/) με διαβάθμιση. Αυτή η κλάση δεν μπορεί να κληρονομηθεί. |
| [PathGradientBrushBase](./pathgradientbrushbase/) | Αντιπροσωπεύει ένα [`Brush`](../aspose.psd/brush/) με λειτουργικότητα διαβάθμισης βάσης διαδρομής. |
| [PathMulticolorGradientBrush](./pathmulticolorgradientbrush/) | Ενσωματώνει ένα αντικείμενο [`Brush`](../aspose.psd/brush/) με διαβάθμιση. Αυτή η κλάση δεν μπορεί να κληρονομηθεί. |
| [SolidBrush](./solidbrush/) | Το συμπαγές πινέλο προορίζεται για συνεχή σχεδίαση με συγκεκριμένο χρώμα. Αυτή η κλάση δεν μπορεί να κληρονομηθεί. |
| [TextureBrush](./texturebrush/) | Κάθε ιδιότητα της κλάσης [`TextureBrush`](../aspose.psd.brushes/texturebrush/) είναι ένα αντικείμενο [`Brush`](../aspose.psd/brush/) που χρησιμοποιεί μια εικόνα για να γεμίσει το εσωτερικό ενός σχήματος. Αυτή η κλάση δεν μπορεί να κληρονομηθεί. |
| [TransformBrush](./transformbrush/) | Ένα [`Brush`](../aspose.psd/brush/) με δυνατότητες μετασχηματισμού. |
