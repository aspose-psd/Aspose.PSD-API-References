## PdfCoreOptions.ExpandedOutlineLevels property

Καθορίζει πόσα επίπεδα του περιγράμματος του εγγράφου θα εμφανίζονται αναπτυγμένα όταν προβάλλεται το αρχείο PDF. 0 - το περίγραμμα του εγγράφου δεν είναι αναπτυγμένο. 1 - τα στοιχεία του πρώτου επιπέδου είναι αναπτυγμένα κ.ο.κ. Η προεπιλογή είναι 0.

```csharp
public int ExpandedOutlineLevels { get; set; }
```
