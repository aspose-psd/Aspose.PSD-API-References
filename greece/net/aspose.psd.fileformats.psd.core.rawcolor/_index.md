Ο χώρος ονομάτων περιέχει τη ιεραρχία της κλάσης PSD RawColor, συμπεριλαμβανομένου του ColorComponent

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ColorComponent](./colorcomponent/) | Το στοιχείο χρώματος είναι μια αφαίρεση πάνω στην Channel Value και Channel Value. Κάθε χρώμα αποτελείται από έναν πίνακα του ColorComponent |
| [RawColor](./rawcolor/) | Η Raw Color Class βοηθά στην αποθήκευση χρωμάτων με οποιονδήποτε αριθμό καναλιών, οποιαδήποτε λειτουργία χρώματος και οποιοδήποτε βάθος bit. Παρακαλώ σημειώστε ότι ορισμένες εσωτερικές κλάσεις μπορεί να έχουν προβλήματα με τη μετατροπή του RawColor στη φυσική του μορφή, έτσι εάν το API παρέχει για εσάς χρώμα CMYK, είναι πιο αξιόπιστο να χρησιμοποιήσετε τη δοθείσα μορφή. Επίσης, μπορεί να υπάρξουν κάποιες περιπτώσεις όπου το Raw Color μπορεί να μετατραπεί |
| [RawColorHelper](./rawcolorhelper/) | Η Raw Color Helper Class βοηθά στη γρήγορη δημιουργία του RawColor, χρησιμοποιώντας προορισμένα μεταδεδομένα καναλιού |
