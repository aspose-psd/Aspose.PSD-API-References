Ο χώρος ονομάτων περιέχει διαφορετικά σχήματα που συνδυάζονται από τμήματα σχήματος.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ArcShape](./arcshape/) | Αναπαριστά ένα σχήμα τόξου. |
| [BezierShape](./beziershape/) | Αναπαριστά μια καμπύλη Bézier. |
| [CurveShape](./curveshape/) | Αναπαριστά ένα σχήμα καμπυλωτής καμπύλης. |
| [EllipseShape](./ellipseshape/) | Αναπαριστά ένα σχήμα έλλειψης. |
| [PieShape](./pieshape/) | Αναπαριστά ένα σχήμα πίτας. |
| [PolygonShape](./polygonshape/) | Αναπαριστά ένα σχήμα πολυγώνου. |
| [RectangleProjectedShape](./rectangleprojectedshape/) | Αναπαριστά ένα σχήμα που προβάλλεται πάνω σε ορθογώνιο προσανατολισμένο σε συγκεκριμένη κατεύθυνση. Καθορίζεται από τέσσερα σημεία που μπορούν να περιστραφούν στο χώρο διατηρώντας το ίδιο μήκος των πλευρών και 90 μοίρες μεταξύ των γειτονικών πλευρών. |
| [RectangleShape](./rectangleshape/) | Αναπαριστά ένα ορθογώνιο σχήμα. |
| [TextShape](./textshape/) | Αναπαριστά ένα σχήμα κειμένου. |
