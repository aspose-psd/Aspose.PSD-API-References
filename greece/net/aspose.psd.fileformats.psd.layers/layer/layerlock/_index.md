## Layer.LayerLock property

Λαμβάνει ή ορίζει το κλείδωμα του στρώματος. Σημειώστε ότι εάν η σημαία LayerFlags.TransparencyProtected είναι ορισμένη, θα αντικατασταθεί από τη σημαία κλειδώματος στρώματος. Για να επιστραφεί η σημαία LayerFlags.TransparencyProtected, πρέπει να εφαρμοστεί η επιλογή στρώματος layer.Flags &#x7C;= LayerFlags.TransparencyProtected

```csharp
public LayerLockType LayerLock { get; set; }
```

### Property Value

Το κλείδωμα του επιπέδου.
