Μπορείτε να κλιμακώσετε, περιστρέψετε, κλίνετε, παραμορφώσετε, να κάνετε προοπτική μετασχηματισμό ή παραμόρφωση (warp) ενός στρώματος<br/>            χωρίς να χάσετε τα αρχικά δεδομένα εικόνας ή την ποιότητα, επειδή οι μετασχηματισμοί δεν επηρεάζουν τα αρχικά δεδομένα.<br/>            Να εργάζεστε με διανυσματικά δεδομένα, όπως διανυσματικά γραφικά από το Illustrator, που διαφορετικά θα rasterize (μετατραπούν σε bitmap).<br/>            Να εκτελείτε μη καταστροφικό φιλτράρισμα.
