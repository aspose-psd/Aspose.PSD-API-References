Καθορίζει το στυλ των διακεκομμένων γραμμών που σχεδιάζονται με ένα αντικείμενο [Pen](/psd/python-net/aspose.psd/pen/).

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.DashStyle

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| CUSTOM | Καθορίζει ένα προσαρμοσμένο στυλ παύλας ορισμένο από τον χρήστη. |
| DASH | Καθορίζει μια γραμμή που αποτελείται από παύλες. |
| DASH_DOT | Καθορίζει μια γραμμή που αποτελείται από επαναλαμβανόμενο μοτίβο παύλα-τελεία. |
| DASH_DOT_DOT | Καθορίζει μια γραμμή που αποτελείται από επαναλαμβανόμενο μοτίβο παύλα-τελεία-τελεία. |
| DOT | Καθορίζει μια γραμμή που αποτελείται από τελείες. |
| SOLID | Καθορίζει μια συμπαγή γραμμή. |
