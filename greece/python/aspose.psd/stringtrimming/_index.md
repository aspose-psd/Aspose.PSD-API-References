Καθορίζει πώς να περικοπούν χαρακτήρες από μια συμβολοσειρά που δεν ταιριάζει πλήρως σε ένα σχήμα διάταξης.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringTrimming

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| CHARACTER | Καθορίζει ότι το κείμενο περικόπτεται στον πλησιέστερο χαρακτήρα. |
| ELLIPSIS_CHARACTER | Καθορίζει ότι το κείμενο περικόπτεται στον πλησιέστερο χαρακτήρα και προστίθεται μια τριπλή τελεία στο τέλος της περικομμένης γραμμής. |
| ELLIPSIS_PATH | Το κέντρο αφαιρείται από τις περικομμένες γραμμές και αντικαθίσταται από μια τριπλή τελεία. Ο αλγόριθμος διατηρεί όσο το δυνατόν περισσότερο το τελευταίο τμήμα της γραμμής που χωρίζεται με κάθετο. |
| ELLIPSIS_WORD | Καθορίζει ότι το κείμενο περικόπτεται στην πλησιέστερη λέξη και προστίθεται μια τριπλή τελεία στο τέλος της περικομμένης γραμμής. |
| NONE | Καθορίζει ότι δεν υπάρχει περικοπή. |
| WORD | Καθορίζει ότι το κείμενο περικόπτεται στην πλησιέστερη λέξη. |
