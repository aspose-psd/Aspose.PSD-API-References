Καθορίζει μεμονωμένα κανάλια στο χρωματικό χώρο CMYK (κυανό, ματζέντα, κίτρινο, μαύρο). Αυτή η απαρίθμηση χρησιμοποιείται από τις μεθόδους SetOutputChannel.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorChannelFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| COLOR_CHANNEL_C | Το κυανό κανάλι χρώματος. |
| COLOR_CHANNEL_K | Το μαύρο κανάλι χρώματος. |
| COLOR_CHANNEL_LAST | Πρέπει να χρησιμοποιηθεί το τελευταίο επιλεγμένο κανάλι. |
| COLOR_CHANNEL_M | Το ματζέντα κανάλι χρώματος. |
| COLOR_CHANNEL_Y | Το κίτρινο κανάλι χρώματος. |
