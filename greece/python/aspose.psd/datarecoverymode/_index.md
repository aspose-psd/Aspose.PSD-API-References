Η λειτουργία ανάκτησης δεδομένων.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.DataRecoveryMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| CONSISTENT_RECOVER | Η συνεπής λειτουργία ανάκτησης προσπαθεί να ανακτήσει όλα τα δεδομένα όσο η διαφθορά δεν διασπά τη μορφή αρχείου και επιτρέπει σωστή περαιτέρω επεξεργασία. |
| MAXIMAL_RECOVER | Η μέγιστη λειτουργία ανάκτησης ανακτά όλα τα δεδομένα ακόμη και αν η μορφή αρχείου έχει κατεστραμμένη δομή και η περαιτέρω επεξεργασία μπορεί να προκαλέσει ανεπιθύμητα αποτελέσματα. |
| NONE | Δεν υποτίθεται ανάκτηση δεδομένων. Όποτε η μορφή αρχείου περιέχει κατεστραμμένα δεδομένα, η κατάλληλη εξαίρεση ρίχνεται. |
