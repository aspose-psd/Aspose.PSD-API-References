Καθορίζει τους τύπους εικόνων και χρωμάτων που θα επηρεαστούν από τις ρυθμίσεις προσαρμογής χρώματος και κλίμακας του γκρι ενός [ImageAttributes](/psd/python-net/aspose.psd/imageattributes/).

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorMatrixFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| ALT_GRAYS | Προσαρμόζονται μόνο οι γκρι αποχρώσεις. |
| ΠΡΟΕΠΙΛΕΓΜΕΝΟ | Όλες οι τιμές χρώματος, συμπεριλαμβανομένων των γκρι αποχρώσεων, προσαρμόζονται από τον ίδιο πίνακα προσαρμογής χρώματος. |
| SKIP_GRAYS | Όλα τα χρώματα προσαρμόζονται, αλλά οι γκρι αποχρώσεις δεν προσαρμόζονται. Μια γκρι απόχρωση είναι οποιοδήποτε χρώμα που έχει την ίδια τιμή για τα κόκκινα, πράσινα και μπλε συστατικά του. |
