Καθορίζει πώς τοποθετείται σε μοτίβο μια υφή ή διαβάθμιση όταν είναι μικρότερη από την περιοχή που γεμίζεται.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.WrapMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| CLAMP | Η υφή ή η διαβάθμιση δεν είναι επαναλαμβανόμενη. |
| TILE | Δημιουργεί πλακίδια για τη διαβάθμιση ή την υφή. |
| TILE_FLIP_X | Αναστρέφει την υφή ή τη διαβάθμιση οριζόντια και στη συνέχεια δημιουργεί πλακίδια για την υφή ή τη διαβάθμιση. |
| TILE_FLIP_XY | Αναστρέφει την υφή ή τη διαβάθμιση οριζόντια και κάθετα και στη συνέχεια δημιουργεί πλακίδια για την υφή ή τη διαβάθμιση. |
| TILE_FLIP_Y | Αναστρέφει την υφή ή τη διαβάθμιση κάθετα και στη συνέχεια δημιουργεί πλακίδια για την υφή ή τη διαβάθμιση. |
