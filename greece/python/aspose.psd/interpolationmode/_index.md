Η απαρίθμηση [InterpolationMode](/psd/python-net/aspose.psd/interpolationmode/) καθορίζει τον αλγόριθμο που χρησιμοποιείται όταν οι εικόνες κλιμακώνονται ή περιστρέφονται.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.InterpolationMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| BICUBIC | Καθορίζει δι-κυβική παρεμβολή. Δεν γίνεται προφιλτράρισμα. Αυτή η λειτουργία δεν είναι κατάλληλη για τη σμίκρυνση μιας εικόνας κάτω από το 25 τοις εκατό του αρχικού της μεγέθους. |
| BILINEAR | Καθορίζει διγραμμική παρεμβολή. Δεν γίνεται προφιλτράρισμα. Αυτή η λειτουργία δεν είναι κατάλληλη για τη σμίκρυνση μιας εικόνας κάτω από το 50 τοις εκατό του αρχικού της μεγέθους. |
| ΠΡΟΕΠΙΛΕΓΜΕΝΟ | Καθορίζει την προεπιλεγμένη λειτουργία. |
| HIGH | Καθορίζει παρεμβολή υψηλής ποιότητας. |
| HIGH_QUALITY_BICUBIC | Καθορίζει υψηλής ποιότητας, bicubic παρεμβολή. Εκτελείται προφίλτρινγκ για να εξασφαλιστεί η υψηλής ποιότητας συρρίκνωση. Αυτή η λειτουργία παράγει τις υψηλότερης ποιότητας μετασχηματισμένες εικόνες. |
| HIGH_QUALITY_BILINEAR | Καθορίζει υψηλής ποιότητας, bilinear παρεμβολή. Εκτελείται προφίλτρινγκ για να εξασφαλιστεί η υψηλής ποιότητας συρρίκνωση. |
| INVALID | Μη έγκυρη λειτουργία παρεμβολής. |
| LOW | Καθορίζει παρεμβολή χαμηλής ποιότητας. |
| NEAREST_NEIGHBOR | Καθορίζει παρεμβολή πλησιέστερου γείτονα. |
