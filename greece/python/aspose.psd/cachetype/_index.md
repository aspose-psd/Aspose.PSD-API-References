Καθορίζει τον τύπο κρυφής μνήμης που θα χρησιμοποιηθεί.

**Full Name:** aspose.psd.CacheType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| AUTO | Καθορίζει τύπο αυτόματης προσωρινής μνήμης. Το σχήμα αυτόματης προσωρινής μνήμης θα προσπαθήσει να αποθηκεύσει στη μνήμη πρώτα και μετά στο δίσκο. |

| CACHE_ON_DISK_ONLY | Μόνο η προσωρινή μνήμη στο δίσκο. |
