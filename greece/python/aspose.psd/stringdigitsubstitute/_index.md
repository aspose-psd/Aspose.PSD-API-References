Η απαρίθμηση καθορίζει πώς να αντικατασταθούν τα ψηφία σε μια συμβολοσειρά σύμφωνα με την τοπική ρύθμιση ή τη γλώσσα του χρήστη.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringDigitSubstitute

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| NATIONAL | Καθορίζει ψηφία αντικατάστασης που αντιστοιχούν στην επίσημη εθνική γλώσσα της τοπικής ρύθμισης του χρήστη. |
| NONE | Καθορίζει την απενεργοποίηση των αντικαταστάσεων. |
| TRADITIONAL | Καθορίζει ψηφία αντικατάστασης που αντιστοιχούν στο εγγενές σύστημα γραφής ή τη γλώσσα του χρήστη, η οποία μπορεί να διαφέρει από την επίσημη εθνική γλώσσα της τοπικής ρύθμισης του χρήστη. |
| USER | Καθορίζει ένα σχήμα αντικατάστασης ορισμένο από τον χρήστη. |
