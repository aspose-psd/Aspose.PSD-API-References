Καθορίζει την αποθήκευση alpha για έγγραφα tiff.

**Module:** [aspose.psd.fileformats.tiff.enums](/psd/python-net/aspose.psd.fileformats.tiff.enums/)

**Full Name:** aspose.psd.fileformats.tiff.enums.TiffAlphaStorage

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Όνομα μέλους** | **Περιγραφή** |
| :- | :- |
| ASSOCIATED | Η τιμή άλφα αποθηκεύεται σε προπολλαπλασιασμένη μορφή. Όταν η άλφα επαναφέρεται, μπορεί να υπάρξουν κάποιες στρογγυλοποιήσεις και η επαναφερθείσα τιμή μπορεί να διαφέρει από την αρχική. |
| UNASSOCIATED | Η τιμή άλφα αποθηκεύεται σε μη συσχετισμένη μορφή. Αυτό σημαίνει ότι η επαναφερθείσα άλφα είναι ακριβώς η ίδια με αυτή που αποθηκεύτηκε στο tiff. |
| UNSPECIFIED | Το άλφα δεν καθορίζεται και αποθηκεύεται στο αρχείο tiff. |
