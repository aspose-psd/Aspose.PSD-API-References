Αναπαριστά το στοιχείο rdf:RDF. Ένα μόνο πακέτο XMP πρέπει να σειριοποιηθεί χρησιμοποιώντας ένα μόνο στοιχείο XML rdf:RDF. Το περιεχόμενο του στοιχείου rdf:RDF πρέπει να αποτελείται από μηδέν ή περισσότερα στοιχεία rdf:Description.
