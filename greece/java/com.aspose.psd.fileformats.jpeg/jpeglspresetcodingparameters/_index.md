```
public class JpegLsPresetCodingParameters
```

Ορίζει τις προεπιλεγμένες παραμέτρους κωδικοποίησης JPEG-LS όπως ορίζονται στο ISO/IEC 14495-1, C.2.4.1.1. Το JPEG-LS ορίζει ένα προεπιλεγμένο σύνολο παραμέτρων, αλλά μπορούν να χρησιμοποιηθούν προσαρμοσμένες παράμετροι. Όταν χρησιμοποιούνται, αυτές οι παράμετροι γράφονται στο κωδικοποιημένο ρεύμα bit όπως απαιτείται για τη διαδικασία αποκωδικοποίησης.
