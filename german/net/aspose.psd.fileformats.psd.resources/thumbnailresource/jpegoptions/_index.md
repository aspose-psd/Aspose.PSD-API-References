## ThumbnailResource.JpegOptions property

Liest oder setzt die JPEG-Optionen. Geeignet, wenn die Thumbnail-Ressource ausschließlich im JPEG-Dateiformat gespeichert wird. Diese Option hat keine Wirkung, wenn das RAW-Format definiert ist.

```csharp
public JpegOptions JpegOptions { get; set; }
```

### Property Value

Die JPEG-Optionen.
