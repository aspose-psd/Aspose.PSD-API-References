Der Namespace enthält Klassen, die für den Export, das Speichern oder die Erstellung verschiedener Dateiformate geeignet sind.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [BmpOptions](./bmpoptions/) | Die BMP-Dateiformat-Erstellungsoptionen. |
| [CmxRasterizationOptions](./cmxrasterizationoptions/) | Die CMX-Exportoptionen. |
| [GifOptions](./gifoptions/) | Die GIF-Dateiformat-Erstellungsoptionen. |
| [GraphicsOptions](./graphicsoptions/) | Stellt Grafikoptionen für eingebettete Bitmaps dar. |
| [Jpeg2000Options](./jpeg2000options/) | Die Jpeg2000-Datei-Formatoptionen. |
| [JpegOptions](./jpegoptions/) | Die JPEG-Datei-Format-Erstellungsoptionen. |
| [MultiPageOptions](./multipageoptions/) | Basisklasse für Formate, die mehrere Seiten unterstützen |
| [PdfOptions](./pdfoptions/) | Die PDF-Optionen. |
| [PngOptions](./pngoptions/) | Die PNG-Datei-Format-Erstellungsoptionen. |
| [PsdOptions](./psdoptions/) | Die PSD-Datei-Format-Erstellungsoptionen. |
| [RdOptimizerSettings](./rdoptimizersettings/) | RD-Optimizer-Einstellungs-Klasse |
| [RenderResult](./renderresult/) | Stellt Informationen mit den Rendering-Ergebnissen dar |
| [TiffOptions](./tiffoptions/) | Die TIFF-Datei-Formatoptionen. Hinweis: Die Breiten- und Höhen-Tags werden bei der Bildgenerierung durch die Breiten- und Höhen-Parameter überschrieben, sodass sie nicht direkt angegeben werden müssen. Hinweis: Viele Optionen geben einen Standardwert zurück, was nicht bedeutet, dass diese Option explizit als Tag-Wert gesetzt ist. Um zu überprüfen, ob das Tag vorhanden ist, verwenden Sie die Tags‑Eigenschaft oder die entsprechende IsTagPresent‑Methode. |
| [TiffOptionsUtils](./tiffoptionsutils/) | Die TIFF-Datei-Formatoptionen-Hilfsklasse. |
| [VectorRasterizationOptions](./vectorrasterizationoptions/) | Die Vektor-Rasterisierungsoptionen. |
