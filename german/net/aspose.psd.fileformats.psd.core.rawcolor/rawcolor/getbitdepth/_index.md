## RawColor.GetBitDepth method

Liefert die Bit-Tiefe von Raw Color. Zum Beispiel hat eine ARGB-Farbe mit 8 Bit pro Kanal/Komponente eine Bit-Tiefe von 32, die vollständige ARGB-Farbe mit 16 Bit pro Kanal/Komponente hat 64. Die Bit-Tiefe ergibt sich aus der Summe der Bit-Tiefen der Kanäle. Dies ist möglich, wenn verschiedene Kanäle unterschiedliche Bit-Tiefen haben.

```csharp
public int GetBitDepth()
```

### Rückgabewert

Die Summe aller Kanal-Bit-Tiefen
