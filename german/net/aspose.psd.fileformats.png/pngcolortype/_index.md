## PngColorType enumeration

Stellt den PNG-Bildfarbtyp dar.

```csharp
public enum PngColorType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Grayscale | `0` | Stellt den Farbtyp dar, bei dem jedes Pixel ein Graustufen‑Sample ist. |
| Truecolor | `2` | Stellt den Farbtyp dar, bei dem jedes Pixel ein R,G,B‑Tripel ist. |
| IndexedColor | `3` | Stellt den Farbtyp dar, bei dem jedes Pixel ein Paletten‑Index ist; ein PLTE‑Chunk muss vorhanden sein. |
| GrayscaleWithAlpha | `4` | Stellt den Farbtyp dar, bei dem jedes Pixel ein Graustufen‑Sample gefolgt von einem Alpha‑Sample ist. |
| TruecolorWithAlpha | `6` | Stellt den Farbtyp dar, bei dem jedes Pixel ein R,G,B‑Tripel gefolgt von einem Alpha‑Sample ist. |
