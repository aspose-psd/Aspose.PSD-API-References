## GlobalLayerMaskInfo.Kind property

Liest oder setzt den Typ. 0 = Farbe ausgewählt – d.h. invertiert; 1 = Farbe geschützt; 128 = pro Ebene gespeicherten Wert verwenden. Dieser Wert wird bevorzugt. Die anderen dienen der Abwärtskompatibilität mit Beta‑Versionen.

public byte Kind { get; set; }
