## VscgResource.KeyForData property

Liest den ganzzahligen Schlüssel, der definiert, welche Art von Füllungseinstellungen in der Ressource gespeichert ist: * Color - 0x536f436f - SoCoResource.TypeToolKey * Gradient - 0x4764466c - GdFlResource.TypeToolKey * Pattern - 0x5074466c - PtFlResource.TypeToolKey Warning! Der Wert der Eigenschaft KeyForData sollte dem Typ der in den Items-Strukturen gespeicherten Füllungseinstellungen entsprechen.

public int KeyForData { get; }
