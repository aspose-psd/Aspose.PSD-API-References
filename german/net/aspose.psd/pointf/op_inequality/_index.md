## PointF Inequality operator

Bestimmt, ob die Koordinaten der angegebenen Punkte nicht gleich sind.

```csharp
public static bool operator !=(PointF point1, PointF point2)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| point1 | PointF | Ein erstes [`PointF`](../) zum Vergleichen. |
| point2 | PointF | Ein zweites [`PointF`](../) zum Vergleichen. |

### Rückgabewert

True, um anzugeben, dass die [`X`](../x/) und [`Y`](../y/) Werte von *point1* und *point2* ungleich sind; andernfalls false.
