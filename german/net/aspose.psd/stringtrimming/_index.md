## StringTrimming enumeration

Gibt an, wie Zeichen aus einer Zeichenfolge abgeschnitten werden, die nicht vollständig in eine Layoutform passt.

```csharp
public enum StringTrimming
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Gibt an, dass kein Trimmen erfolgt. |
| Character | `1` | Gibt an, dass der Text bis zum nächsten Zeichen getrimmt wird. |
| Word | `2` | Gibt an, dass der Text bis zum nächsten Wort getrimmt wird. |
| EllipsisCharacter | `3` | Gibt an, dass der Text bis zum nächsten Zeichen getrimmt wird und ein Auslassungszeichen am Ende einer getrimmten Zeile eingefügt wird. |
| EllipsisWord | `4` | Gibt an, dass der Text bis zum nächsten Wort getrimmt wird und ein Auslassungszeichen am Ende einer getrimmten Zeile eingefügt wird. |
| EllipsisPath | `5` | Der Mittelteil wird aus getrimmten Zeilen entfernt und durch ein Auslassungszeichen ersetzt. Der Algorithmus behält so viel wie möglich vom letzten durch Schrägstrich getrennten Segment der Zeile bei. |
