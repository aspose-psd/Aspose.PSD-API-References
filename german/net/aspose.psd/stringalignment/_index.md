## StringAlignment enumeration

Gibt die Ausrichtung einer Textzeichenfolge relativ zu ihrem Layoutrechteck an.

```csharp
public enum StringAlignment
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Near | `0` | Gibt an, dass der Text nahe am Layout ausgerichtet wird. In einem von links nach rechts verlaufenden Layout ist die nahe Position links. In einem von rechts nach links verlaufenden Layout ist die nahe Position rechts. |
| Center | `1` | Gibt an, dass der Text in der Mitte des Layout-Rechtecks ausgerichtet ist. |
| Far | `2` | Gibt an, dass der Text weit von der Ursprungposition des Layout-Rechtecks ausgerichtet wird. In einem von links nach rechts verlaufenden Layout ist die ferne Position rechts. In einem von rechts nach links verlaufenden Layout ist die ferne Position links. |
