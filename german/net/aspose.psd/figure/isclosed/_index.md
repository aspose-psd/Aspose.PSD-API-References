## Figure.IsClosed property

Liest oder setzt einen Wert, der angibt, ob diese Figur geschlossen ist. Eine geschlossene Figur macht nur einen Unterschied, wenn die ersten und letzten Formen der Figur kontinuierliche Formen sind. In einem solchen Fall wird der erste Punkt der ersten Form durch eine gerade Linie mit dem letzten Punkt der letzten Form verbunden.

```csharp
public bool IsClosed { get; set; }
```

### Property Value

`True` wenn diese Figur geschlossen ist; andernfalls `false`.
