## Point Inequality operator

Vergleicht zwei [`Point`](../)-Objekte. Das Ergebnis gibt an, ob die Werte der [`X`](../x/)- oder [`Y`](../y/)-Eigenschaften der beiden [`Point`](../)-Objekte ungleich sind.

```csharp
public static bool operator !=(Point point1, Point point2)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| point1 | Point | Ein erstes [`Point`](../) zum Vergleichen. |
| point2 | Point | Ein zweites [`Point`](../) zum Vergleichen. |

### Rückgabewert

Wahr, wenn die Werte der [`X`](../x/)- oder [`Y`](../y/)-Eigenschaften von *point1* und *point2* unterschiedlich sind; andernfalls falsch.
