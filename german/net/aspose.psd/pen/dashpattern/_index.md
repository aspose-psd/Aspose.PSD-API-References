## Pen.DashPattern property

Liest oder legt ein Array benutzerdefinierter Striche und Lücken fest.

```csharp
public float[] DashPattern { get; set; }
```

### Property Value

Ein Array aus Gleitkommazahlen, das die Längen abwechselnder Striche und Lücken in gestrichelten Linien angibt.

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentException | Die `DashPattern`-Eigenschaft wird bei einem unveränderlichen [`Pen`](../) festgelegt, wie zum Beispiel bei denen, die von der [`Pen`](../)-Klasse zurückgegeben werden. |
