## Pen.SetLineCap method

Legt die Werte fest, die den Stil der Endkappe bestimmen, die zum Abschluss von Linien verwendet wird, die von diesem [`Pen`](../) gezeichnet werden.

```csharp
public void SetLineCap(LineCap startCap, LineCap endCap, DashCap dashCap)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| startCap | LineCap | Ein [`LineCap`](../../linecap/), das den Kappenstil darstellt, der am Anfang von Linien verwendet wird, die mit diesem [`Pen`](../) gezeichnet werden. |
| endCap | LineCap | Ein [`LineCap`](../../linecap/), das den Kappenstil darstellt, der am Ende von Linien verwendet wird, die mit diesem [`Pen`](../) gezeichnet werden. |
| dashCap | DashCap | Ein [`LineCap`](../../linecap/), das den Kappenstil darstellt, der am Anfang oder Ende von gestrichelten Linien verwendet wird, die mit diesem [`Pen`](../) gezeichnet werden. |
