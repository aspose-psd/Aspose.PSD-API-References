## Pen.Transform property

Gibt eine Kopie der geometrischen Transformation für diesen [`Pen`](../) zurück oder legt sie fest.

```csharp
public Matrix Transform { get; set; }
```

### Property Value

Eine Kopie der [`Matrix`](../../matrix/), die die geometrische Transformation für diesen [`Pen`](../) darstellt.

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentException | Die `Transform`-Eigenschaft wird bei einem unveränderlichen [`Pen`](../) festgelegt, wie bei denen, die von der [`Pen`](../)-Klasse zurückgegeben werden. |
