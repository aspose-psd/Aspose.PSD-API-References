## Pen.DashCap property

Ruft den Cap-Stil am Ende der Striche ab, die gestrichelte Linien bilden, die mit diesem [`Pen`](../) gezeichnet werden, oder legt ihn fest.

```csharp
public DashCap DashCap { get; set; }
```

### Property Value

Einer der `DashCap`-Werte, der den Cap-Stil am Anfang und Ende der Striche darstellt, die gestrichelte Linien bilden, die mit diesem [`Pen`](../) gezeichnet werden.

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| ArgumentException | Die `DashCap`-Eigenschaft wird bei einem unveränderlichen [`Pen`](../) festgelegt, wie z. B. bei denen, die von der [`Pen`](../)-Klasse zurückgegeben werden. |
