## PixelDataFormat Inequality operator

Gibt das Ergebnis der Ungleichheit für zwei [`PixelDataFormat`](../)-Klassen zurück.

```csharp
public static bool operator !=(PixelDataFormat pixelFormat1, PixelDataFormat pixelFormat2)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| pixelFormat1 | PixelDataFormat | Das erste [`PixelDataFormat`](../) zum Vergleichen. |
| pixelFormat2 | PixelDataFormat | Das zweite [`PixelDataFormat`](../) zum Vergleichen. |

### Rückgabewert

Wahr, wenn sowohl *pixelFormat1* als auch *pixelFormat2* nicht gleiche Daten enthalten oder einer der Parameter null ist.
