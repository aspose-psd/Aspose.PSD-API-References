## PixelDataFormat.RgbIndexed2Bpp property

Gibt das [`PixelDataFormat`](../) zurück, das für indizierte 2‑Bit‑Farben definiert ist. Der indizierte Pixeldatenspeicher ist dafür vorgesehen, Daten überall dort zu speichern und abzurufen, wo die Farbpalette verwendet wird. Mit Vorsicht verwenden, da möglicherweise eine Konvertierung von einer Palette zur anderen oder von RGBA zum indizierten Farbmodell erforderlich ist.

```csharp
public static PixelDataFormat RgbIndexed2Bpp { get; }
```

### Property Value

Das [`PixelDataFormat`](../), das für indizierte 2‑Bit‑Farben definiert ist.
