## PixelDataFormat.RgbIndexed4Bpp property

Gibt das [`PixelDataFormat`](../) zurück, das für indizierte 4-Bit-Farben definiert ist. Der indizierte Pixeldatenspeicher ist dafür vorgesehen, Daten überall dort zu speichern und abzurufen, wo die Farbpalette verwendet wird. Mit Vorsicht verwenden, da möglicherweise eine Konvertierung von einer Palette zur anderen oder von RGBA zu einem indizierten Farbmodell erforderlich ist.

```csharp
public static PixelDataFormat RgbIndexed4Bpp { get; }
```

### Property Value

Das [`PixelDataFormat`](../), das für indizierte 4-Bit-Farben definiert ist.
