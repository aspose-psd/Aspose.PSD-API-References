## PixelDataFormat.RgbIndexed1Bpp property

Liefert das [`PixelDataFormat`](../), das für indiziertes 1‑Bit‑pro‑Farbe definiert ist. Die indizierte Pixeldatenspeicherung ist dafür vorgesehen, Daten überall dort zu speichern und abzurufen, wo die Farbpalette verwendet wird. Mit Vorsicht verwenden, da eine Konvertierung von einer Palette zur anderen oder von RGBA zum indizierten Farbmodell erforderlich sein kann.

```csharp
public static PixelDataFormat RgbIndexed1Bpp { get; }
```

### Property Value

Das [`PixelDataFormat`](../), das für indiziertes 1‑Bit‑pro‑Farbe definiert ist.
