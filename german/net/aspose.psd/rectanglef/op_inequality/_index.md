## RectangleF Inequality operator

Prüft, ob sich zwei [`RectangleF`](../)-Strukturen im Ort oder in der Größe unterscheiden.

```csharp
public static bool operator !=(RectangleF left, RectangleF right)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| left | RectangleF | Die [`RectangleF`](../)-Struktur, die links vom Ungleichheitsoperator steht. |
| right | RectangleF | Die [`RectangleF`](../)-Struktur, die rechts vom Ungleichheitsoperator steht. |

### Rückgabewert

Dieser Operator gibt true zurück, wenn einer der [`X`](../x/)-, [`Y`](../y/)-, [`Width`](../width/)- oder [`Height`](../height/)-Eigenschaften der beiden [`RectangleF`](../)-Strukturen ungleich ist; andernfalls false.
