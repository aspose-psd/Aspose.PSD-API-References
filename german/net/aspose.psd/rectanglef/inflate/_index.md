## Inflate(RectangleF, float, float)

Erstellt und gibt eine aufgeblähte Kopie der angegebenen [`RectangleF`](../)-Struktur zurück. Die Kopie wird um den angegebenen Betrag aufgebläht. Das ursprüngliche Rechteck bleibt unverändert.

```csharp
public static RectangleF Inflate(RectangleF rect, float x, float y)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| rect | RectangleF | Das zu kopierende [`RectangleF`](../). Dieses Rechteck wird nicht verändert. |
| x | Single | Der Betrag, um den die Kopie des Rechtecks horizontal aufgebläht wird. |
| y | Single | Der Betrag, um den die Kopie des Rechtecks vertikal aufgebläht wird. |

### Rückgabewert

Das aufgeblähte [`RectangleF`](../).
