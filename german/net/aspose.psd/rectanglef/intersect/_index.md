## Intersect(RectangleF, RectangleF)

Gibt eine [`RectangleF`](../)-Struktur zurück, die die Schnittmenge zweier Rechtecke darstellt. Wenn keine Schnittmenge existiert, wird ein leeres [`RectangleF`](../) zurückgegeben.

```csharp
public static RectangleF Intersect(RectangleF a, RectangleF b)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| a | RectangleF | Ein erstes Rechteck zum Schneiden. |
| b | RectangleF | Ein zweites Rechteck zum Schneiden. |

### Rückgabewert

Eine dritte [`RectangleF`](../)-Struktur, deren Größe den überlappenden Bereich der beiden angegebenen Rechtecke darstellt.
