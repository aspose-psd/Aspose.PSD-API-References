## Size Inequality operator

Prüft, ob zwei [`Size`](../) Strukturen unterschiedlich sind.

```csharp
public static bool operator !=(Size size1, Size size2)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| size1 | Size | Die [`Size`](../) Struktur auf der linken Seite des Ungleichheitsoperators. |
| size2 | Size | Die [`Size`](../) Struktur auf der rechten Seite des Ungleichheitsoperators. |

### Rückgabewert

Wahr, wenn *size1* und *size2* sich entweder in Breite oder Höhe unterscheiden; falsch, wenn *size1* und *size2* gleich sind.
