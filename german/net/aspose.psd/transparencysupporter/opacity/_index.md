## TransparencySupporter.Opacity property

Liest oder setzt die Deckkraft des Objekts. Der Wert sollte zwischen 0 und 1 liegen. Ein Wert von 0 bedeutet, dass das Objekt vollständig sichtbar ist, ein Wert von 1 bedeutet, dass das Objekt vollständig undurchsichtig ist.

```csharp
public float Opacity { get; set; }
```

### Property Value

Der Opazitätswert.
