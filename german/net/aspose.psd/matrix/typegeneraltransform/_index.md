## Matrix.TypeGeneralTransform field

Diese Konstante gibt an, dass die von diesem Objekt definierte Transformation eine beliebige Umwandlung der Eingabekoordinaten durchführt. Wenn diese Transformation durch eine der oben genannten Konstanten klassifiziert werden kann, ist der Typ entweder die Konstante TypeIdentity oder eine Kombination der entsprechenden Flag‑Bits für die verschiedenen Koordinatenumwandlungen, die diese Transformation ausführt.

public const int TypeGeneralTransform;
