## Save(Stream, int, long) {#save_2}

Speichert (kopiert) die Daten des Streams in den angegebenen Stream.

```csharp
public virtual void Save(Stream destinationStream, int bufferSize, long length)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| destinationStream | Stream | Der Stream, in dem die Daten gespeichert werden. |
| bufferSize | Int32 | Die Puffergröße. Standardmäßig wird der Wert [`ReadWriteBytesCount`](../readwritebytescount/) verwendet. |
| length | Int64 | Die zu kopierende Länge der Stream-Daten. Standardmäßig wird die Länge auf den Wert [`Length`](../length/) gesetzt. |
