## StreamContainer.Seek method

Setzt die Position im aktuellen Stream.

```csharp
public virtual long Seek(long offset, SeekOrigin origin)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| offset | Int64 | Ein Byte-Offset relativ zum *origin*-Parameter. Dieser Wert stellt den Offset von der beim Konstruktor von StreamContainer übergebenen Startposition des Streams dar. |
| origin | SeekOrigin | Ein Wert vom Typ SeekOrigin, der den Bezugspunkt angibt, der zur Ermittlung der neuen Position verwendet wird. |

### Rückgabewert

Die neue Position im aktuellen Stream.
