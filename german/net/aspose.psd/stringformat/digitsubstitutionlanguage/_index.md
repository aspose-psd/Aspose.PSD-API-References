## StringFormat.DigitSubstitutionLanguage property

Ruft die Sprache ab oder legt sie fest, die verwendet wird, wenn lokale Ziffern durch westliche Ziffern ersetzt werden.

```csharp
public int DigitSubstitutionLanguage { get; set; }
```

### Property Value

Ein National Language Support (NLS)-Sprachbezeichner, der die Sprache identifiziert, die verwendet wird, wenn lokale Ziffern durch westliche Ziffern ersetzt werden. Sie können die LCID-Eigenschaft eines CultureInfo-Objekts als NLS-Sprachbezeichner übergeben. Zum Beispiel, wenn Sie ein CultureInfo-Objekt erstellen, indem Sie den String "ar-EG" an einen CultureInfo-Konstruktor übergeben. Wenn Sie die LCID-Eigenschaft dieses CultureInfo-Objekts zusammen mit der StringDigitSubstitute)-Methode übergeben, werden arabisch‑indische Ziffern zur Anzeigzeit durch westliche Ziffern ersetzt.

## Hinweise

Der Setter wurde für die veraltete Methode SetDigitSubstitution eingeführt.
