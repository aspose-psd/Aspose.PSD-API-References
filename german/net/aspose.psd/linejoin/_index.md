## LineJoin enumeration

Gibt an, wie aufeinanderfolgende Linien‑ oder Kurvensegmente in einer Figur (Unterpfad), die in einem [`GraphicsPath`](../graphicspath/)‑Objekt enthalten ist, verbunden werden.

```csharp
public enum LineJoin
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Miter | `0` | Gibt eine Gehrungskupplung an. Dies erzeugt eine spitze Ecke oder eine abgeschnittene Ecke, abhängig davon, ob die Länge der Gehrung die Gehrungsgrenze überschreitet. |
| Bevel | `1` | Gibt eine abgeschrägte Verbindung an. Dies erzeugt eine diagonale Ecke. |
| Round | `2` | Gibt eine kreisförmige Verbindung an. Dies erzeugt einen glatten, kreisförmigen Bogen zwischen den Linien. |
| MiterClipped | `3` | Gibt eine Gehrungskupplung an. Dies erzeugt eine spitze Ecke oder eine abgeschrägte Ecke, abhängig davon, ob die Länge der Gehrung die Gehrungsgrenze überschreitet. |
