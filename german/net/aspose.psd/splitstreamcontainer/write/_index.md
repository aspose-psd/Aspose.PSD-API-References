## Write(byte[], int, int) {#write_1}

Schreibt eine Sequenz von Bytes in den aktuellen Stream und verschiebt die aktuelle Position innerhalb dieses Streams um die Anzahl der geschriebenen Bytes.

```csharp
public override void Write(byte[] buffer, int offset, int count)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Puffer | Byte[] | Ein Byte-Array. Diese Methode kopiert *count* Bytes von *buffer* in den aktuellen Stream. |
| offset | Int32 | Der nullbasierte Byte-Offset in *buffer*, bei dem das Kopieren von Bytes in den aktuellen Stream beginnt. |
| count | Int32 | Die Anzahl der Bytes, die in den aktuellen Stream geschrieben werden sollen. |
