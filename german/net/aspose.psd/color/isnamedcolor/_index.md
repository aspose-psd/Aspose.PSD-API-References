## Color.IsNamedColor property

Gibt einen Wert zurück, der angibt, ob diese [`Color`](../)-Struktur eine benannte Farbe oder ein Mitglied der [`KnownColor`](../../knowncolor/)-Aufzählung ist.

```csharp
public bool IsNamedColor { get; }
```

### Property Value

True, wenn diese [`Color`](../) mithilfe der [`FromName`](../fromname/)-Methode oder der [`FromKnownColor`](../fromknowncolor/)-Methode erstellt wurde; andernfalls false.
