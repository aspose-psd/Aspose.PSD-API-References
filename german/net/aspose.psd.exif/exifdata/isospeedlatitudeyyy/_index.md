## ExifData.ISOSpeedLatitudeYYY property

Liest oder setzt den ISO-Geschwindigkeits-Breitengrad yyy-Wert einer Kamera oder eines Eingabegeräts, wie in ISO 12232 definiert.

```csharp
public uint ISOSpeedLatitudeYYY { get; set; }
```

### Property Value

Der ISO-Geschwindigkeitsbreitenwert yyy einer Kamera oder eines Eingabegeräts, der in ISO 12232 definiert ist.

## Hinweise
