## PlacedResource.IsCustom property

Liest oder legt einen Wert fest, der angibt, ob dieser Instanz-Warp-Stil benutzerdefiniert ist. Wenn true, enthält er Maschenpunkte. Wenn auf false gesetzt, löscht er Maschenpunkte.

```csharp
public bool IsCustom { get; set; }
```

### Property Value

`true`, wenn die platzierte Ebene einen benutzerdefinierten Stil hat; andernfalls `false`.
