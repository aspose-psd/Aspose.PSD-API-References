## LinkDataSource.Type property

Ruft den Adobe® Photoshop® Global Link-Datentyp der Datenquelle ab, der einer der folgenden Werte oder keiner sein kann: Die eingebettete verknüpfte Datei liFD, die der PSD Lnk2Resource entspricht; Die extern verknüpfte Datei liFE, die der PSD LnkeResource entspricht; Der Alias der verknüpften Datei liFA.

```csharp
public LinkDataSourceType Type { get; }
```

### Property Value

Der PSD-Link-Datenquellentyp.
