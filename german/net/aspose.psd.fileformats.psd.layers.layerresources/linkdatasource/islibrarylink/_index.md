## LinkDataSource.IsLibraryLink property

Liest einen Wert, der angibt, ob diese PSD‑Link‑Datenquelle mit dem Adobe® Photoshop® CC‑Bibliothekselement verknüpft ist.

```csharp
public bool IsLibraryLink { get; }
```

### Property Value

`true`, wenn diese Instanz ein Adobe® Photoshop® СС-Bibliothekslink ist; andernfalls `false`.
