## PlLdResource class

Definiert die Klasse PlLdResource, die Informationen über eine platzierte Ebene in der PSD-Datei enthält. Sie wird verwendet, um Smart-Object-Ebenen in Adobe® Photoshop®-Bildern zu unterstützen. Sie wurde durch SoLdResource in Adobe® Photoshop® CS3 ersetzt.

```csharp
public class PlLdResource : PlacedResource
```
