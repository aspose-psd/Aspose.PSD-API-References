Der Namensraum stellt Hilfsklassen und -methoden bereit, um mit verschiedenen Pinseltypen zu arbeiten.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [HatchBrush](./hatchbrush/) | Definiert einen rechteckigen Pinsel mit Schraffurstil, einer Vordergrundfarbe und einer Hintergrundfarbe. Diese Klasse kann nicht abgeleitet werden. |
| [LinearGradientBrush](./lineargradientbrush/) | Kapselt einen [`Brush`](../aspose.psd/brush/) mit einem linearen Farbverlauf. Diese Klasse kann nicht abgeleitet werden. |
| [LinearGradientBrushBase](./lineargradientbrushbase/) | Stellt einen [`Brush`](../aspose.psd/brush/) mit Gradientenfähigkeiten und entsprechenden Eigenschaften dar. |
| [LinearMulticolorGradientBrush](./linearmulticolorgradientbrush/) | Stellt einen [`Brush`](../aspose.psd/brush/) mit linearem Farbverlauf dar, der durch mehrere Farben und entsprechende Positionen definiert ist. Diese Klasse kann nicht abgeleitet werden. |
| [PathGradientBrush](./pathgradientbrush/) | Kapselt ein [`Brush`](../aspose.psd/brush/)‑Objekt mit einem Farbverlauf. Diese Klasse kann nicht abgeleitet werden. |
| [PathGradientBrushBase](./pathgradientbrushbase/) | Stellt einen [`Brush`](../aspose.psd/brush/) mit Basis-Pfad‑Gradientfunktionalität dar. |
| [PathMulticolorGradientBrush](./pathmulticolorgradientbrush/) | Kapselt ein [`Brush`](../aspose.psd/brush/)‑Objekt mit einem Farbverlauf. Diese Klasse kann nicht abgeleitet werden. |
| [SolidBrush](./solidbrush/) | Der Solid‑Pinsel ist zum kontinuierlichen Zeichnen mit einer bestimmten Farbe gedacht. Diese Klasse kann nicht abgeleitet werden. |
| [TextureBrush](./texturebrush/) | Jede Eigenschaft der Klasse [`TextureBrush`](../aspose.psd.brushes/texturebrush/) ist ein [`Brush`](../aspose.psd/brush/)‑Objekt, das ein Bild verwendet, um das Innere einer Form zu füllen. Diese Klasse kann nicht abgeleitet werden. |
| [TransformBrush](./transformbrush/) | Ein [`Brush`](../aspose.psd/brush/) mit Transformationsfähigkeiten. |
