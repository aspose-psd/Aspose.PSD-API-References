## SetBlendTriangularShape(float, float) {#setblendtriangularshape_1}

Erstellt einen linearen Farbverlauf mit einer Mittel-Farbe und einem linearen Abfall zu einer einzelnen Farbe an beiden Enden.

```csharp
public void SetBlendTriangularShape(float focus, float scale)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Fokus | Single | Ein Wert von 0 bis 1, der das Zentrum des Verlaufs angibt (der Punkt, an dem der Verlauf ausschließlich aus der Endfarbe besteht). |
| scale | Single | Ein Wert von 0 bis 1, der angibt, wie schnell die Farben von der Startfarbe zum *Fokus* (Endfarbe) abfallen. |
