Der Namensraum enthält Ausnahmen, die von irgendeiner der Kern‑PSD‑Komponenten ausgelöst werden.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CompressorException](./compressorexception/) | Die Kompressor-Ausnahme. |
| [DataMissmatchError](./datamissmatcherror/) | Dateninkonsistenz-Ausnahmeklasse |
| [FrameworkException](./frameworkexception/) | Die PSD-Framework-Ausnahme. Diese Klasse ist eine Kernklasse für alle Aspose.PSD-Ausnahmen. Eingeführt, um zwischen den von der Aspose.PSD-Engine ausgelösten Ausnahmen und allen anderen Ausnahmetypen zu unterscheiden. |
| [ImageCreateException](./imagecreateexception/) | Die Bild-Erstellungs-Ausnahme. Tritt während der Bild-Erstellung auf. |
| [ImageException](./imageexception/) | Die Bild-Ausnahme. |
| [ImageLoadException](./imageloadexception/) | Die Bild-Lade-Ausnahme. Tritt beim Laden des Bildes auf. |
| [ImageSaveException](./imagesaveexception/) | Die Bild-Speicher-Ausnahme. Tritt beim Speichern des Bildes auf. |
| [IndexOutOFRangeException](./indexoutofrangeexception/) | Die Kompressor-Ausnahme. |
| [LimitMemoryException](./limitmemoryexception/) | Die Speicherbegrenzungs-Ausnahme. Tritt auf, wenn die Speichernutzung reduziert werden sollte. |
| [OperationInterruptedException](./operationinterruptedexception/) | Tritt auf, wenn ein Vorgang unterbrochen wird. |
| [RdOptimizationError](./rdoptimizationerror/) | RD-Optimierungsfehler-Ausnahmeklasse |
| [StreamReadException](./streamreadexception/) | Die Stream-Lese-Ausnahme. Verursacht, wenn das Lesen des Streams aufgrund falscher Offset- und Byte-Anzahl-Anforderung fehlschlägt. |
| [XmpException](./xmpexception/) | Die Ausnahme, die ausgelöst wird, wenn XMP eine ungültige Struktur hat. |
