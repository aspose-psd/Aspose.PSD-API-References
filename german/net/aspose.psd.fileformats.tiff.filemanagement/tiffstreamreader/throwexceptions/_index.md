## TiffStreamReader.ThrowExceptions property

Liest oder setzt einen Wert, der angibt, ob Ausnahmen bei falscher Datenverarbeitung (Lesen oder Schreiben in den Stream) ausgelöst werden.

```csharp
public bool ThrowExceptions { get; set; }
```

### Property Value

`true` wenn Ausnahmen bei fehlerhafter Datenverarbeitung ausgelöst werden; andernfalls werden die Fehlbedingungen stillschweigend ignoriert.
