Der Namensraum enthält XMP-bezogene Hilfsklassen und -methoden.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [LangAlt](./langalt/) | Stellt die XMP Language Alternative dar. |
| [Namespaces](./namespaces/) | Enthält Namespaces, die im RDF‑Dokument verwendet werden. |
| [XmpArray](./xmparray/) | Stellt ein Xmp‑Array in [`XmpPackage`](../aspose.psd.xmp/xmppackage/) dar. TODO: Das Array kann komplexe Daten enthalten. |
| [XmpArrayHelper](./xmparrayhelper/) | Die Hilfsklasse zur Verarbeitung von RDF‑Logik. |
| [XmpElementBase](./xmpelementbase/) | Stellt das Basiselement xmp dar, das Attribute enthält. |
| [XmpHeaderPi](./xmpheaderpi/) | Stellt die XMP‑Header‑Verarbeitungsanweisung dar. |
| [XmpMeta](./xmpmeta/) | Stellt xmpmeta dar. Optional. Der Zweck dieses Elements ist es, XMP‑Metadaten innerhalb allgemeinen XML‑Textes zu identifizieren, der andere nicht‑XMP‑Verwendungen von RDF enthalten kann. |
| [XmpPackage](./xmppackage/) | Definiert die Klasse XmpPackage, die die Grundabstraktion für ein XMP‑Paket darstellt. |
| [XmpPackageBaseCollection](./xmppackagebasecollection/) | Stellt eine Sammlung von [`XmpPackage`](../aspose.psd.xmp/xmppackage/) dar. |
| [XmpPacketWrapper](./xmppacketwrapper/) | Enthält ein serialisiertes XMP‑Paket einschließlich Header und Trailer. |
| [XmpRdfRoot](./xmprdfroot/) | Stellt das rdf:RDF‑Element dar. Ein einzelnes XMP‑Paket muss mit einem einzigen rdf:RDF‑XML‑Element serialisiert werden. Der Inhalt des rdf:RDF‑Elements darf nur aus null oder mehr rdf:Description‑Elementen bestehen. |
| [XmpTrailerPi](./xmptrailerpi/) | Stellt die XMP‑Trailer‑Verarbeitungsanweisung dar. |
