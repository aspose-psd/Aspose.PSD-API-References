## RectangleProjectedShape class

Stellt eine Form dar, die über ein Rechteck projiziert wird, das in eine bestimmte Orientierung gedreht ist. Definiert durch vier Punkte, die im Raum rotiert werden können, wobei die Kantenlänge gleich bleibt und ein Winkel von 90 Grad zwischen benachbarten Kanten besteht.

```csharp
public abstract class RectangleProjectedShape : Shape
```
