Der Namensraum enthält verschiedene Formen, die aus Formsegmenten kombiniert werden.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ArcShape](./arcshape/) | Stellt eine Bogenform dar. |
| [BezierShape](./beziershape/) | Stellt eine Bézier-Kurve dar. |
| [CurveShape](./curveshape/) | Stellt eine gekrümmte Spline-Form dar. |
| [EllipseShape](./ellipseshape/) | Stellt eine Ellipsenform dar. |
| [PieShape](./pieshape/) | Stellt eine Kuchenform dar. |
| [PolygonShape](./polygonshape/) | Stellt eine Polygonform dar. |
| [RectangleProjectedShape](./rectangleprojectedshape/) | Stellt eine Form dar, die über ein Rechteck projiziert wird, das in eine bestimmte Orientierung gedreht ist. Definiert durch vier Punkte, die im Raum rotiert werden können, wobei die Kantenlänge gleich bleibt und ein Winkel von 90 Grad zwischen benachbarten Kanten besteht. |
| [RectangleShape](./rectangleshape/) | Stellt eine rechteckige Form dar. |
| [TextShape](./textshape/) | Stellt eine Textform dar. |
