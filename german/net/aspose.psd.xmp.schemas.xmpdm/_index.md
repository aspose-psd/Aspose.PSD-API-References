Der Namensraum enthält XMP-bezogene Hilfsklassen, Konstanten und Methoden, die von der Adobe Dynamic Media Group verwendet werden.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [AudioChannelType](./audiochanneltype/) | Stellt den Audiokanaltyp dar. |
| [AudioSampleType](./audiosampletype/) | Stellt den Audiosampletyp in [`XmpDynamicMediaPackage`](../aspose.psd.xmp.schemas.xmpdm/xmpdynamicmediapackage/) dar. |
| [ProjectLink](./projectlink/) | Stellt den Pfad des Projekts dar. |
| [Time](./time/) | Darstellung eines Zeitwerts in Sekunden. |
| [Timecode](./timecode/) | Stellt den Timecode-Wert im Video dar. |
| [TimeFormat](./timeformat/) | Stellt das Zeitformat in [`Timecode`](../aspose.psd.xmp.schemas.xmpdm/timecode/) dar. |
| [XmpDynamicMediaPackage](./xmpdynamicmediapackage/) | Stellt den XMP Dynamic Media-Namespace dar. |
