Gibt verschiedene Bitmap-Komprimierungsmethoden an.

**Module:** [aspose.psd.fileformats.bmp](/psd/python-net/aspose.psd.fileformats.bmp/)

**Full Name:** aspose.psd.fileformats.bmp.BitmapCompression

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| ALPHA_BITFIELDS | RGBA-Bitfelder. Können nur mit 16- und 32-Bit/Pixel-Bitmaps verwendet werden. |
| BITFIELDS | RGB-Bitfelder. Können nur mit 16- und 32-Bit/Pixel-Bitmaps verwendet werden. |
| DXT1 | DXT1-Kompression. Das Bitmap enthält eine Textur. |
| JPEG | JPEG-Kompression. Das Bitmap enthält ein JPEG-Bild. |
| PNG | PNG-Kompression. Das Bitmap enthält ein PNG-Bild. |
| RGB | Keine Kompression. |
| RLE4 | RLE 4-Bit/Pixel-Kompression. Kann nur mit 4-Bit/Pixel-Bitmaps verwendet werden. |
| RLE8 | RLE 8-Bit/Pixel-Kompression. Kann nur mit 8-Bit/Pixel-Bitmaps verwendet werden. |
