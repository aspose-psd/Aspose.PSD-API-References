Definiert den Interleave-Modus für mehrkomponentige (Farb‑)Pixeldaten.

**Module:** [aspose.psd.fileformats.jpeg](/psd/python-net/aspose.psd.fileformats.jpeg/)

**Full Name:** aspose.psd.fileformats.jpeg.JpegLsInterleaveMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| LINE | Der Interleavemodus ist zeilenweise. Eine komplette Zeile jeder Komponente wird codiert, bevor zur nächsten Zeile gewechselt wird. |
| KEIN | Die Daten werden kodiert und komponentenweise gespeichert: RRRGGGBBB. |
| SAMPLE | Die Daten werden nach Sample kodiert und gespeichert. Für Farbbilder ist dies das Format wie RGBRGBRGB. |
