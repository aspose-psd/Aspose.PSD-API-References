Optionen zum Ebenensperren

**Module:** [aspose.psd.fileformats.psd.layers.layerresources](/psd/python-net/aspose.psd.fileformats.psd.layers.layerresources/)

**Full Name:** aspose.psd.fileformats.psd.layers.layerresources.LayerLockType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| LOCK_ALL | Alle Eigenschaften einer Ebene sperren |
| LOCK_IMAGE_PIXELS | Teilweise Sperrung einer Ebene  - Verhindert die Modifikation der Pixel der Ebene mit den Malwerkzeugen. |
| LOCK_POSITION | Teilweise Sperrung einer Ebene  - Verhindert, dass die Pixel der Ebene verschoben werden. |
| LOCK_TRANSPARENT_PIXELS | Teilweise Sperrung einer Ebene  - Beschränkt die Bearbeitung auf die undurchsichtigen Teile der Ebene. <br/>            Diese Option entspricht der Option „Transparenz erhalten“ in früheren Photoshop-Versionen. |
| KEIN | Keine Ebenensperre |
