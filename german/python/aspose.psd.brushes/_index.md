Das Modul stellt Hilfsklassen und -methoden zur Verfügung, um mit verschiedenen Pinseltypen zu arbeiten.

## **Classes**
| **Class** | **Beschreibung** |
| :- | :- |
| [HatchBrush](/psd/python-net/aspose.psd.brushes/hatchbrush/) | Definiert einen rechteckigen Pinsel mit Schraffurstil, einer Vordergrundfarbe und einer Hintergrundfarbe. Diese Klasse kann nicht abgeleitet werden. |
| [LinearGradientBrush](/psd/python-net/aspose.psd.brushes/lineargradientbrush/) | Kapselt einen [Brush](/psd/python-net/aspose.psd/brush/) mit einem linearen Farbverlauf. Diese Klasse kann nicht abgeleitet werden. |
| [LinearGradientBrushBase](/psd/python-net/aspose.psd.brushes/lineargradientbrushbase/) | Stellt einen [Brush](/psd/python-net/aspose.psd/brush/) mit Farbverlaufsfähigkeiten und entsprechenden Eigenschaften dar. |
| [LinearMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/linearmulticolorgradientbrush/) | Stellt einen [Brush](/psd/python-net/aspose.psd/brush/) mit linearem Farbverlauf dar, definiert durch mehrere Farben und passende Positionen. Diese Klasse kann nicht abgeleitet werden. |
| [PathGradientBrush](/psd/python-net/aspose.psd.brushes/pathgradientbrush/) | Kapselt ein [Brush](/psd/python-net/aspose.psd/brush/) Objekt mit einem Farbverlauf. Diese Klasse kann nicht abgeleitet werden. |
| [PathGradientBrushBase](/psd/python-net/aspose.psd.brushes/pathgradientbrushbase/) | Stellt einen [Brush](/psd/python-net/aspose.psd/brush/) mit Basis-Pfad-Farbverlaufsfunktionalität dar. |
| [PathMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/pathmulticolorgradientbrush/) | Kapselt ein [Brush](/psd/python-net/aspose.psd/brush/) Objekt mit einem Farbverlauf. Diese Klasse kann nicht abgeleitet werden. |
| [SolidBrush](/psd/python-net/aspose.psd.brushes/solidbrush/) | Ein Vollpinsel ist zum kontinuierlichen Zeichnen mit einer bestimmten Farbe gedacht. Diese Klasse kann nicht abgeleitet werden. |
| [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) | Jede Eigenschaft der [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) Klasse ist ein [Brush](/psd/python-net/aspose.psd/brush/) Objekt, das ein Bild verwendet, um das Innere einer Form zu füllen. Diese Klasse kann nicht abgeleitet werden. |
| [TransformBrush](/psd/python-net/aspose.psd.brushes/transformbrush/) | Ein [Brush](/psd/python-net/aspose.psd/brush/) mit Transformationsfähigkeiten. |
