Gibt an, wie Zeichen aus einer Zeichenkette abgeschnitten werden, die nicht vollständig in eine Layoutform passt.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringTrimming

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| ZEICHEN | Gibt an, dass der Text bis zum nächsten Zeichen gekürzt wird. |
| ELLIPSIS_ZEICHEN | Gibt an, dass der Text bis zum nächsten Zeichen gekürzt wird und am Ende einer gekürzten Zeile ein Auslassungszeichen eingefügt wird. |
| ELLIPSIS_PFAD | Der Mittelteil wird aus gekürzten Zeilen entfernt und durch ein Auslassungszeichen ersetzt. Der Algorithmus behält so viel wie möglich vom letzten slash-getrennten Segment der Zeile bei. |
| ELLIPSIS_WORT | Gibt an, dass der Text bis zum nächsten Wort gekürzt wird und am Ende einer gekürzten Zeile ein Auslassungszeichen eingefügt wird. |
| KEIN | Gibt an, dass nicht gekürzt wird. |
| WORT | Gibt an, dass der Text bis zum nächsten Wort gekürzt wird. |
