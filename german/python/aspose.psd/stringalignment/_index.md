Gibt die Ausrichtung einer Textzeichenkette relativ zu ihrem Layoutrechteck an.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringAlignment

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| CENTER | Gibt an, dass der Text in der Mitte des Layout-Rechtecks ausgerichtet ist. |
| FAR | Gibt an, dass der Text weit von der Ursprungposition des Layout-Rechtecks ausgerichtet ist.<br/>            In einem Links-zu-Rechts-Layout ist die entfernte Position rechts.<br/>            In einem Rechts-zu-Links-Layout ist die entfernte Position links. |
| NEAR | Gibt an, dass der Text nahe am Layout ausgerichtet wird.<br/>            In einem Links-zu-Rechts-Layout ist die nahe Position links.<br/>            In einem Rechts-zu-Links-Layout ist die nahe Position rechts. |
