Gibt die Qualität der Textdarstellung an.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.TextRenderingHint

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| ANTI_ALIAS | Jedes Zeichen wird mit seiner antialiasierten Glyphen-Bitmap ohne Hinting gezeichnet. Bessere Qualität dank Antialiasing. Unterschiede in der Strichstärke können auffallen, da Hinting deaktiviert ist. |
| ANTI_ALIAS_GRID_FIT | Jedes Zeichen wird mit seiner antialiasierten Glyphen-Bitmap mit Hinting gezeichnet. Viel bessere Qualität dank Antialiasing, jedoch mit höherem Leistungsaufwand. |
| CLEAR_TYPE_GRID_FIT | Jedes Zeichen wird mit seiner ClearType-Glyphen-Bitmap mit Hinting gezeichnet. Die höchste Qualitätseinstellung. Wird verwendet, um die ClearType-Schriftmerkmale zu nutzen. |
| SINGLE_BIT_PER_PIXEL | Jedes Zeichen wird mit seiner Glyphen-Bitmap gezeichnet. Hinting wird nicht verwendet. |
| SINGLE_BIT_PER_PIXEL_GRID_FIT | Jedes Zeichen wird mit seiner Glyphen‑Bitmap gezeichnet. Hinting wird verwendet, um das Aussehen der Zeichen an Strichen und Kurven zu verbessern. |
| SYSTEM_DEFAULT | Jedes Zeichen wird mit seiner Glyphen‑Bitmap gezeichnet, wobei der systemstandardmäßige Rendering‑Hinweis verwendet wird. Der Text wird mit den vom Benutzer für das System gewählten Font‑Smoothing‑Einstellungen gezeichnet. |
