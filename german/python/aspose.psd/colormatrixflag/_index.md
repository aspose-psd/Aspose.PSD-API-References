Gibt die Arten von Bildern und Farben an, die von den Farb- und Graustufen-Anpassungseinstellungen eines [ImageAttributes](/psd/python-net/aspose.psd/imageattributes/) betroffen sind.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorMatrixFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| ALT_GRAYS | Nur Graustufen werden angepasst. |
| DEFAULT | Alle Farbwerte, einschließlich Graustufen, werden durch dieselbe Farbkorrekturmatrix angepasst. |
| SKIP_GRAYS | Alle Farben werden angepasst, aber Graustufen werden nicht angepasst. Eine Graustufe ist jede Farbe, die denselben Wert für ihre Rot-, Grün- und Blaukomponenten hat. |
