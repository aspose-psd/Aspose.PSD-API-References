Gibt den Typ der grafischen Form an, die an beiden Enden jedes Strichs in einer gestrichelten Linie verwendet wird.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.DashCap

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| FLAT | Gibt einen quadratischen Abschluss an, der beide Enden jedes Strichs quadratisch abschließt. |
| ROUND | Gibt eine runde Endkappe an, die beide Enden jedes Strichs abrundet. |
| TRIANGLE | Gibt eine dreieckige Endkappe an, die an beiden Enden jedes Strichs zeigt. |
