Die [InterpolationMode](/psd/python-net/aspose.psd/interpolationmode/) Aufzählung gibt den Algorithmus an, der verwendet wird, wenn Bilder skaliert oder rotiert werden.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.InterpolationMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| BICUBIC | Gibt die bikubische Interpolation an. Es wird keine Vorfilterung durchgeführt. Dieser Modus ist nicht geeignet, ein Bild unter 25 % seiner Originalgröße zu verkleinern. |
| BILINEAR | Gibt die bilineare Interpolation an. Es wird keine Vorfilterung durchgeführt. Dieser Modus ist nicht geeignet, ein Bild unter 50 % seiner Originalgröße zu verkleinern. |
| DEFAULT | Gibt den Standardmodus an. |
| HIGH | Gibt eine hochqualitative Interpolation an. |
| HIGH_QUALITY_BICUBIC | Gibt eine hochqualitative, bikubische Interpolation an. Vorfilterung wird durchgeführt, um ein hochwertiges Verkleinern zu gewährleisten. Dieser Modus erzeugt die qualitativ besten transformierten Bilder. |
| HIGH_QUALITY_BILINEAR | Gibt eine hochqualitative, bilineare Interpolation an. Vorfilterung wird durchgeführt, um ein hochwertiges Verkleinern zu gewährleisten. |
| INVALID | Ungültiger Interpolationsmodus. |
| LOW | Gibt eine niedrigqualitative Interpolation an. |
| NEAREST_NEIGHBOR | Gibt die nächstnachbar-Interpolation an. |
