Gibt an, wie aufeinanderfolgende Linien- oder Kurvensegmente in einer Figur (Unterpfad), die in einem [GraphicsPath](/psd/python-net/aspose.psd/graphicspath/) Objekt enthalten ist, verbunden werden.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.LineJoin

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| BEVEL | Gibt einen abgeschrägten Anschluss an. Dies erzeugt eine diagonale Ecke. |
| MITER | Gibt einen Gehrungsanschluss an. Dies erzeugt eine spitze Ecke oder eine abgeschnittene Ecke, abhängig davon, ob die Länge der Gehrung das Gehrungslimit überschreitet. |
| MITER_CLIPPED | Gibt einen Gehrungsanschluss an. Dies erzeugt eine spitze Ecke oder eine abgeschrägte Ecke, abhängig davon, ob die Länge der Gehrung das Gehrungslimit überschreitet. |
| ROUND | Gibt einen kreisförmigen Anschluss an. Dies erzeugt einen glatten, kreisförmigen Bogen zwischen den Linien. |
