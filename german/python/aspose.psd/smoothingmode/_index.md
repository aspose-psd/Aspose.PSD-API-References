Gibt an, ob Glättung (Antialiasing) auf Linien und Kurven sowie die Kanten gefüllter Bereiche angewendet wird.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.SmoothingMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| ANTI_ALIAS | Gibt antialiasiertes Rendering an. |
| DEFAULT | Gibt kein Antialiasing an. |
| HIGH_QUALITY | Gibt antialiasiertes Rendering an. |
| HIGH_SPEED | Gibt kein Antialiasing an. |
| INVALID | Gibt einen ungültigen Modus an. |
| KEIN | Gibt kein Antialiasing an. |
