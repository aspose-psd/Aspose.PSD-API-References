Die Frame-Entsorgungsmethode gibt an, ob der aktuelle Frame vor der Anzeige des nächsten Frames verworfen werden soll.<br/>            Sie wählen eine Entsorgungsmethode für Animationen, die Hintergrundtransparenz enthalten, um anzugeben, ob der aktuelle<br/>            Frame durch die transparenten Bereiche des nächsten Frames sichtbar sein wird.

**Module:** [aspose.psd.fileformats.psd.layers.animation](/psd/python-net/aspose.psd.fileformats.psd.layers.animation/)

**Full Name:** aspose.psd.fileformats.psd.layers.animation.FrameDisposalMethod

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Membername** | **Beschreibung** |
| :- | :- |
| AUTOMATIC | Bestimmt automatisch eine Entsorgungsmethode für das aktuelle Bild und verwirft das aktuelle Bild, wenn das nächste Bild Ebenentransparenz enthält.<br/>            Für die meisten Animationen liefert die Option Automatic (Standard) das gewünschte Ergebnis. |
| DISPOSE | Verwirft das aktuelle Bild aus der Anzeige, bevor das nächste Bild angezeigt wird.<br/>            Es wird jederzeit nur ein einzelnes Bild angezeigt (und das aktuelle Bild erscheint nicht durch die transparenten Bereiche des nächsten Bildes). |
| DO_NOT_DISPOSE | Behält das aktuelle Bild bei, während das nächste Bild zur Anzeige hinzugefügt wird.<br/>            Das aktuelle Bild (und vorherige Bilder) kann durch transparente Bereiche des nächsten Bildes sichtbar werden. |
