Das Modul enthält verschiedene Formsegmente, die Formen kombinieren.

## **Classes**
| **Class** | **Beschreibung** |
| :- | :- |
| [BezierSegment](/psd/python-net/aspose.psd.shapesegments/beziersegment/) | Das Bézier-Segment, das von einem Punkt zum nächsten Punkt verläuft und zwei Kontrollpunkte verwendet. |
| [LineSegment](/psd/python-net/aspose.psd.shapesegments/linesegment/) | Stellt ein Segment dar, das direkt von einem bestimmten Punkt zum nächsten Punkt führt. |
