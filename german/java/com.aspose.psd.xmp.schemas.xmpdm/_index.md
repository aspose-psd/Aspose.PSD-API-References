| [ProjectType](../com.aspose.psd.xmp.schemas.xmpdm/projecttype) | Stellt den Projekttyp in XmpDynamicMediaPackage dar. |

| [Timecode](../com.aspose.psd.xmp.schemas.xmpdm/timecode) | Stellt den Timecode-Wert im Video dar. |
