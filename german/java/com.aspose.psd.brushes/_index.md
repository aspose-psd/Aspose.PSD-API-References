Das Paket stellt Hilfsklassen und Methoden bereit, um mit verschiedenen Pinseltypen zu arbeiten.


## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [HatchBrush](../com.aspose.psd.brushes/hatchbrush) | Definiert einen rechteckigen Pinsel mit einem Schraffurstil, einer Vordergrundfarbe und einer Hintergrundfarbe. |
| [LinearGradientBrush](../com.aspose.psd.brushes/lineargradientbrush) | Kapselt einen  Aspose.Imaging.Brush  mit einem linearen Farbverlauf ein. |
| [LinearGradientBrushBase](../com.aspose.psd.brushes/lineargradientbrushbase) | Stellt einen  Brush  mit Gradientfähigkeiten und entsprechenden Eigenschaften dar. |
| [LinearMulticolorGradientBrush](../com.aspose.psd.brushes/linearmulticolorgradientbrush) | Stellt einen  Brush  mit linearem Farbverlauf dar, definiert durch mehrere Farben und entsprechende Positionen. |
| [PathGradientBrush](../com.aspose.psd.brushes/pathgradientbrush) | Kapselt ein  Aspose.Imaging.Brush  Objekt mit einem Farbverlauf ein. |
| [PathGradientBrushBase](../com.aspose.psd.brushes/pathgradientbrushbase) | Stellt einen  Brush  mit Basis-Pfad-Verlaufsfunktionalität dar. |
| [PathMulticolorGradientBrush](../com.aspose.psd.brushes/pathmulticolorgradientbrush) | Kapselt ein  Aspose.Imaging.Brush  Objekt mit einem Farbverlauf ein. |
| [SolidBrush](../com.aspose.psd.brushes/solidbrush) | Solid brush ist zum kontinuierlichen Zeichnen mit einer bestimmten Farbe vorgesehen. |
| [TextureBrush](../com.aspose.psd.brushes/texturebrush) | Jede Eigenschaft der  Aspose.Imaging.Brushes.TextureBrush  Klasse ist ein  Aspose.Imaging.Brush  Objekt, das ein Bild verwendet, um das Innere einer Form zu füllen. |
| [TransformBrush](../com.aspose.psd.brushes/transformbrush) | Ein  Brush  mit Transformationsfähigkeiten. |
