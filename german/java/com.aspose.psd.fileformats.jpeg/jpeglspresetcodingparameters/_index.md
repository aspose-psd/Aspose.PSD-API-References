```
public class JpegLsPresetCodingParameters
```

Definiert die JPEG-LS-Voreinstellungs-Codierungsparameter gemäß ISO/IEC 14495-1, C.2.4.1.1. JPEG-LS definiert einen Standardsatz von Parametern, aber benutzerdefinierte Parameter können verwendet werden. Wenn sie verwendet werden, werden diese Parameter in den codierten Bitstrom geschrieben, da sie für den Dekodierungsprozess benötigt werden.
