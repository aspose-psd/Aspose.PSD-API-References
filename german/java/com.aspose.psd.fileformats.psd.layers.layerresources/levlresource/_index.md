public LevlResource(byte[] bytes)

Initialisiert eine neue Instanz der Klasse [LevlResource](../../com.aspose.psd.fileformats.psd.layers.layerresources/levlresource). Unterstützt in den Farbmodi GrayScale, Duotone, RGB, CMYK, Lab. 2 Bytes - Version (=2) 29 \* 10 Bytes - Sätze von Level‑Datensätzen mit 5 Short‑Integern 4 Bytes - Lvls‑Header (beginnt bei Index 292) 2 Bytes - Version (=3) 2 Bytes - Anzahl der gesamten Level‑Datensätze 10 \* (Gesamtanzahl - 29) Nullabschluss des Lvls‑Ressource sollte ebenfalls für Vierfachwerte gefaltet werden.
