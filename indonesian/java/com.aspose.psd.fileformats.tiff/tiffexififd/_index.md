Kelas direktori file gambar TIFF Exif.

Menyatukan sebuah pointer ke Exif IFD. Interoperabilitas, Exif IFD memiliki struktur yang sama dengan IFD yang ditentukan dalam TIFF. Namun, biasanya tidak berisi data gambar seperti pada TIFF. Lihat http://www.exiv2.org/tags.html dan http://www.awaresystems.be/imaging/tiff/tifftags/exififd.html untuk detail lebih lanjut.
