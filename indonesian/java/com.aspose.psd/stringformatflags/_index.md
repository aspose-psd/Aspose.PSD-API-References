### FitBlackBox {#FitBlackBox}
```
public static final int FitBlackBox
```


Bagian-bagian karakter diizinkan menjorok keluar dari persegi layout string. Secara default, karakter diposisikan ulang untuk menghindari penjorokan apa pun.

### LineLimit {#LineLimit}
```
public static final int LineLimit
```


Hanya baris penuh yang ditata dalam persegi format. Secara default, tata letak berlanjut hingga akhir teks, atau hingga tidak ada lagi baris yang terlihat akibat pemotongan, mana yang lebih dulu terjadi. Perhatikan bahwa pengaturan default memungkinkan baris terakhir sebagian tertutup oleh persegi format yang tidak merupakan kelipatan penuh dari tinggi baris. Untuk memastikan hanya baris penuh yang terlihat, tentukan nilai ini dan pastikan menyediakan persegi format setidaknya setinggi satu baris.

### MeasureTrailingSpaces {#MeasureTrailingSpaces}
```
public static final int MeasureTrailingSpaces
```


Menyertakan spasi akhir di akhir setiap baris. Secara default, persegi batas yang dikembalikan oleh metode MeasureString tidak menyertakan spasi di akhir setiap baris. Atur flag ini untuk menyertakan spasi tersebut dalam pengukuran.

### NoClip {#NoClip}
```
public static final int NoClip
```


Bagian yang menjorok dari glif, dan teks yang tidak dibungkus yang mencapai di luar persegi format diizinkan untuk ditampilkan. Secara default semua teks dan bagian glif yang mencapai di luar persegi format dipotong.

### NoFontFallback {#NoFontFallback}
```
public static final int NoFontFallback
```


Penurunan ke font alternatif untuk karakter yang tidak didukung oleh font yang diminta dinonaktifkan. Setiap karakter yang hilang ditampilkan dengan glyph yang hilang pada font, biasanya berupa kotak terbuka.

### NoWrap {#NoWrap}
```
public static final int NoWrap
```


Pembungkus teks antar baris saat memformat dalam persegi dinonaktifkan. Flag ini diasumsikan ketika sebuah titik diberikan alih-alih persegi, atau ketika persegi yang ditentukan memiliki panjang baris nol.
