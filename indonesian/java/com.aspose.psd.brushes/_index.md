Paket ini menyediakan kelas pembantu dan metode untuk bekerja dengan berbagai tipe kuas.


## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [HatchBrush](../com.aspose.psd.brushes/hatchbrush) | Mendefinisikan kuas persegi panjang dengan gaya hatch, warna latar depan, dan warna latar belakang. |
| [LinearGradientBrush](../com.aspose.psd.brushes/lineargradientbrush) | Mengkapsulkan sebuah Aspose.Imaging.Brush dengan gradien linier. |
| [LinearGradientBrushBase](../com.aspose.psd.brushes/lineargradientbrushbase) | Mewakili sebuah Brush dengan kemampuan gradien dan properti yang sesuai. |
| [LinearMulticolorGradientBrush](../com.aspose.psd.brushes/linearmulticolorgradientbrush) | Mewakili sebuah Brush dengan gradien linier yang didefinisikan oleh beberapa warna dan posisi yang sesuai. |
| [PathGradientBrush](../com.aspose.psd.brushes/pathgradientbrush) | Mengkapsulkan objek Aspose.Imaging.Brush dengan gradien. |
| [PathGradientBrushBase](../com.aspose.psd.brushes/pathgradientbrushbase) | Mewakili sebuah Brush dengan fungsi gradien jalur dasar. |
| [PathMulticolorGradientBrush](../com.aspose.psd.brushes/pathmulticolorgradientbrush) | Mengkapsulkan objek Aspose.Imaging.Brush dengan gradien. |
| [SolidBrush](../com.aspose.psd.brushes/solidbrush) | Brush solid dimaksudkan untuk menggambar secara berkelanjutan dengan warna tertentu. |
| [TextureBrush](../com.aspose.psd.brushes/texturebrush) | Setiap properti dari kelas Aspose.Imaging.Brushes.TextureBrush adalah objek Aspose.Imaging.Brush yang menggunakan gambar untuk mengisi bagian dalam sebuah bentuk. |
| [TransformBrush](../com.aspose.psd.brushes/transformbrush) | Sebuah Brush dengan kemampuan transformasi. |
