public class JpegLsPresetCodingParameters

Mendefinisikan parameter pengkodean preset JPEG-LS sebagaimana didefinisikan dalam ISO/IEC 14495-1, C.2.4.1.1. JPEG-LS mendefinisikan sekumpulan parameter default, tetapi parameter khusus dapat digunakan. Ketika digunakan, parameter ini ditulis ke dalam aliran bit yang terkodekan sesuai kebutuhan proses dekripsi.
