## Metered.SetMeteredKey method

Mengatur kunci publik dan privat bermeter. Jika Anda membeli lisensi bermeter, saat memulai aplikasi, API ini harus dipanggil, biasanya ini sudah cukup. Namun, jika selalu gagal mengunggah data konsumsi dan melebihi 24 jam, lisensi akan diubah menjadi status evaluasi; untuk menghindari hal tersebut, Anda harus secara teratur memeriksa status lisensi, jika statusnya evaluasi, panggil kembali API ini.

```csharp
public void SetMeteredKey(string publicKey, string privateKey)
```

| --- | --- | --- |
| publicKey | String | kunci publik |
| privateKey | String | kunci pribadi |
