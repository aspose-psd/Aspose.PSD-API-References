## Image.GetOriginalOptions method

Mendapatkan opsi berdasarkan pengaturan file asli. Ini dapat membantu menjaga kedalaman bit dan parameter lain dari gambar asli tetap tidak berubah. Misalnya, jika kita memuat gambar PNG hitam-putih dengan 1 bit per piksel dan kemudian menyimpannya menggunakan metode [`Save`](../../datastreamsupporter/save/), gambar PNG output dengan 8-bit per piksel akan dihasilkan. Untuk menghindarinya dan menyimpan gambar PNG dengan 1-bit per piksel, gunakan metode ini untuk mendapatkan opsi penyimpanan yang sesuai dan berikan ke metode [`Save`](../save/) sebagai parameter kedua.

```csharp
public virtual ImageOptionsBase GetOriginalOptions()
```

### Nilai Kembalian

Opsi berdasarkan pengaturan file asli.
