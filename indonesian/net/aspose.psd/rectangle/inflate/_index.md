## Inflate(Rectangle, int, int)

Membuat dan mengembalikan salinan yang diperbesar dari struktur [`Rectangle`](../) yang ditentukan. Salinan tersebut diperbesar sebesar jumlah yang ditentukan. Struktur [`Rectangle`](../) asli tetap tidak berubah.

```csharp
public static Rectangle Inflate(Rectangle rect, int x, int y)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| rect | Rectangle | [`Rectangle`](../) yang akan dijadikan awal. Rectangle ini tidak dimodifikasi. |
| x | Int32 | Jumlah untuk memperbesar [`Rectangle`](../) ini secara horizontal. |
| y | Int32 | Jumlah untuk memperbesar [`Rectangle`](../) ini secara vertikal. |
