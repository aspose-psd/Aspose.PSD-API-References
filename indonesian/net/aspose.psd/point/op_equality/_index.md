## Point Equality operator

Membandingkan dua objek [`Point`](../). Hasilnya menentukan apakah nilai properti [`X`](../x/) dan [`Y`](../y/) dari kedua objek [`Point`](../) tersebut sama.

```csharp
public static bool operator ==(Point point1, Point point2)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| point1 | Point | Sebuah [`Point`](../) pertama untuk dibandingkan. |
| point2 | Point | Sebuah [`Point`](../) kedua untuk dibandingkan. |

### Nilai Kembalian

True jika nilai [`X`](../x/) dan [`Y`](../y/) dari *point1* dan *point2* sama; jika tidak, false.
