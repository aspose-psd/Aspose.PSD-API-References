## Layer.Flags property

Mendapatkan atau mengatur flag lapisan. bit 0 = transparansi dilindungi; bit 1 = terlihat; bit 2 = usang; bit 3 = 1 untuk Photoshop 5.0 dan yang lebih baru, memberi tahu apakah bit 4 memiliki informasi yang berguna; bit 4 = data piksel tidak relevan dengan tampilan dokumen.

```csharp
public LayerFlags Flags { get; set; }
```

### Property Value

Flag lapisan.
