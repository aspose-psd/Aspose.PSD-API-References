## RawColor.GetBitDepth method

Mendapatkan kedalaman bit dari Raw Color. Misalnya untuk warna ARGB dengan 8 bit per saluran/komponen adalah 32. Kedalaman bit dari warna ARGB penuh dengan 16 bit per saluran/komponen adalah 64. Kedalaman bit dihitung dari jumlah kedalaman bit masing-masing saluran. Hal ini memungkinkan jika saluran yang berbeda memiliki kedalaman bit yang berbeda.

```csharp
public int GetBitDepth()
```

### Nilai Kembalian

Jumlah semua kedalaman bit saluran
