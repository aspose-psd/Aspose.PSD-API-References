Namespace ini berisi hierarki PSD RawColor Class termasuk ColorComponent.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ColorComponent](./colorcomponent/) | Komponen warna adalah abstraksi atas Channel Value dan Channel Value. Setiap warna terdiri dari sebuah array dari ColorComponent. |
| [RawColor](./rawcolor/) | Raw Color Class membantu menyimpan warna dengan jumlah saluran apa pun, mode warna apa pun, dan kedalaman bit apa pun. Harap dicatat, beberapa kelas internal dapat mengalami masalah saat mengonversi RawColor ke format aslinya, jadi jika API menyediakan warna CMYK untuk Anda, lebih dapat diandalkan untuk menggunakan format yang disediakan. Juga, ada beberapa kasus ketika Raw Color dapat dikonversi. |
| [RawColorHelper](./rawcolorhelper/) | Kelas Raw Color Helper membantu membuat RawColor lebih cepat, menggunakan metadata saluran yang telah ditentukan sebelumnya. |
