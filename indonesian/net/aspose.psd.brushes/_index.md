Namespace menyediakan kelas pembantu dan metode untuk bekerja dengan berbagai jenis kuas.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [HatchBrush](./hatchbrush/) | Mendefinisikan kuas persegi panjang dengan gaya hatch, warna latar depan, dan warna latar belakang. Kelas ini tidak dapat diwariskan. |
| [LinearGradientBrush](./lineargradientbrush/) | Mengkapsulkan sebuah [`Brush`](../aspose.psd/brush/) dengan gradien linier. Kelas ini tidak dapat diwariskan. |
| [LinearGradientBrushBase](./lineargradientbrushbase/) | Mewakili sebuah [`Brush`](../aspose.psd/brush/) dengan kemampuan gradien dan properti yang sesuai. |
| [LinearMulticolorGradientBrush](./linearmulticolorgradientbrush/) | Mewakili sebuah [`Brush`](../aspose.psd/brush/) dengan gradien linier yang didefinisikan oleh beberapa warna dan posisi yang sesuai. Kelas ini tidak dapat diwariskan. |
| [PathGradientBrush](./pathgradientbrush/) | Mengkapsulkan sebuah objek [`Brush`](../aspose.psd/brush/) dengan gradien. Kelas ini tidak dapat diwariskan. |
| [PathGradientBrushBase](./pathgradientbrushbase/) | Mewakili sebuah [`Brush`](../aspose.psd/brush/) dengan fungsi gradien jalur dasar. |
| [PathMulticolorGradientBrush](./pathmulticolorgradientbrush/) | Mengkapsulkan sebuah objek [`Brush`](../aspose.psd/brush/) dengan gradien. Kelas ini tidak dapat diwariskan. |
| [SolidBrush](./solidbrush/) | Kuas solid dimaksudkan untuk menggambar secara berkelanjutan dengan warna tertentu. Kelas ini tidak dapat diwariskan. |
| [TextureBrush](./texturebrush/) | Setiap properti dari kelas [`TextureBrush`](../aspose.psd.brushes/texturebrush/) adalah objek [`Brush`](../aspose.psd/brush/) yang menggunakan gambar untuk mengisi interior sebuah bentuk. Kelas ini tidak dapat diwariskan. |
| [TransformBrush](./transformbrush/) | Sebuah [`Brush`](../aspose.psd/brush/) dengan kemampuan transformasi. |
