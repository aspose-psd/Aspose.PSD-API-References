## PsdLoadOptions.ReadOnlyMode property

Mendapatkan atau mengatur nilai yang menunjukkan apakah [use read only mode]. Ini adalah mode hanya-baca, didukung untuk kompatibilitas identik dengan Adobe Photoshop. Ketika opsi ini diatur, semua perubahan yang diterapkan pada lapisan tidak akan disimpan ke gambar akhir. Semua data diambil dari bagian ImageData, sehingga identik dengan Photoshop. Secara default semua gambar yang dimuat tidak identik dengan kompatibilitas Adobe Photoshop.

```csharp
public bool ReadOnlyMode { get; set; }
```

### Property Value

`true` jika [use photoshop compatibility mode]; selainnya, `false`.
