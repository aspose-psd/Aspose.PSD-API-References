### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Rgb | `0` | Tanpa kompresi. |
| Rle8 | `1` | Kompresi RLE 8-bit/piksel. Hanya dapat digunakan dengan bitmap 8-bit/piksel. |
| Rle4 | `2` | Kompresi RLE 4-bit/piksel. Hanya dapat digunakan dengan bitmap 4-bit/piksel. |
| Bitfields | `3` | Bidang bit RGB. Hanya dapat digunakan dengan bitmap 16 dan 32-bit/piksel. |

| Png | `5` | Kompresi PNG. Bitmap berisi gambar PNG. |
| AlphaBitfields | `6` | Bidang bit RGBA. Hanya dapat digunakan dengan bitmap 16 dan 32-bit/piksel. |
| Dxt1 | `827611204` | Kompresi DXT1. Bitmap berisi tekstur. |
