## PdfCoreOptions.ExpandedOutlineLevels property

Menentukan berapa banyak level dalam outline dokumen yang ditampilkan dalam keadaan terbuka saat file PDF dilihat. 0 - outline dokumen tidak terbuka. 1 - item level pertama dalam dokumen terbuka dan seterusnya. Default adalah 0.
