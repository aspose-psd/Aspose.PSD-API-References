## TiffExpectedFormat enumeration

Format file tiff yang diharapkan.

```csharp
public enum TiffExpectedFormat
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Default | `0` | Format tiff default adalah tanpa kompresi dengan format B/W 1 bit per piksel saja. Anda juga dapat menggunakan pengaturan ini untuk mendapatkan opsi kosong dan menginisialisasi dengan tag Anda atau pengaturan lainnya. |
| TiffLzwBw | `1` | Tiff dengan kompresi LZW dan format B/W 1 bit per piksel saja. |
| TiffLzwRgb | `2` | Tiff dengan kompresi LZW dan format warna RGB. |
| TiffLzwRgba | `3` | Tiff dengan kompresi LZW dan format warna RGBA dengan transparansi. |
| TiffLzwCmyk | `4` | Tiff LZW CMYK |
| TiffCcittFax3 | `5` | Enkoding tiff CCITT FAX3. B/W 1 bit per piksel hanya didukung untuk skema tersebut. |
| TiffCcittFax4 | `6` | Enkoding tiff CCITT FAX4. B/W 1 bit per piksel hanya didukung untuk skema tersebut. |
| TiffDeflateBw | `7` | Tiff dengan kompresi deflate dan format B/W 1 bit per piksel saja. |
| TiffDeflateRgb | `8` | Tiff yang memiliki kompresi deflate dan format warna RGB. |
| TiffDeflateRgba | `9` | Tiff yang memiliki kompresi deflate dan format warna RGBA. |
| TiffCcitRle | `10` | Enkoding CCITT RLE pada tiff. Hanya mendukung B/W 1 bit per piksel untuk skema tersebut. |
| TiffJpegRgb | `11` | Tiff yang memiliki kompresi Jpeg dan format warna RGB. |
| TiffJpegYCbCr | `12` | Tiff yang memiliki kompresi Jpeg dan format warna YCBCR. |
| TiffNoCompressionBw | `13` | Tiff yang tidak terkompresi dan hanya format B/W 1 bit per piksel. |
| TiffNoCompressionRgb | `14` | Tiff yang tidak terkompresi dan format warna RGB. |
| TiffNoCompressionRgba | `15` | Tiff yang tidak terkompresi dan format warna RGBA dengan transparansi. |
