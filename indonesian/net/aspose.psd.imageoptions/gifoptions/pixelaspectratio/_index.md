## GifOptions.PixelAspectRatio property

Mendapatkan atau mengatur rasio aspek piksel GIF.

```csharp
public byte PixelAspectRatio { get; set; }
```

### Property Value

Rasio aspek piksel GIF.

## Catatan

Pixel Aspect Ratio - Faktor yang digunakan untuk menghitung perkiraan rasio aspek piksel dalam gambar asli. Jika nilai bidang tidak 0, perkiraan rasio aspek ini dihitung berdasarkan rumus: Aspect Ratio = (Pixel Aspect Ratio + 15) / 64. Pixel Aspect Ratio didefinisikan sebagai hasil bagi lebar piksel dengan tinggi piksel. Rentang nilai dalam bidang ini memungkinkan spesifikasi piksel terlebar 4:1 hingga piksel tertinggi 1:4 dengan kenaikan 1/64. Nilai: 0 - Tidak ada informasi rasio aspek yang diberikan. 1..255 - Nilai yang digunakan dalam perhitungan.
