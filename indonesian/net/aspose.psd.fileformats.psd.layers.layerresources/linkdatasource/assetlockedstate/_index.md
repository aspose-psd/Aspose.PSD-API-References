## LinkDataSource.AssetLockedState property

Mendapatkan atau mengatur nilai yang menunjukkan apakah aset PSD terkunci. Status terkunci aset, untuk aset Adobe® Photoshop® СС Libraries.

```csharp
public bool AssetLockedState { get; set; }
```

### Property Value

`true` jika aset Adobe® Photoshop® terkunci; jika tidak, `false`.
