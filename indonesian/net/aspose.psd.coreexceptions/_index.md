Namespace berisi pengecualian yang dilempar oleh komponen inti PSD mana pun.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [CompressorException](./compressorexception/) | Pengecualian kompresor. |
| [DataMissmatchError](./datamissmatcherror/) | Kelas pengecualian ketidaksesuaian data |
| [FrameworkException](./frameworkexception/) | Pengecualian kerangka kerja PSD. Kelas ini adalah kelas inti untuk semua pengecualian Aspose.PSD. Diperkenalkan untuk membedakan antara pengecualian yang dilemparkan oleh mesin Aspose.PSD dan semua tipe pengecualian lainnya. |
| [ImageCreateException](./imagecreateexception/) | Pengecualian pembuatan gambar. Terjadi selama pembuatan gambar. |
| [ImageException](./imageexception/) | Pengecualian gambar. |
| [ImageLoadException](./imageloadexception/) | Pengecualian pemuatan gambar. Terjadi selama pemuatan gambar. |
| [ImageSaveException](./imagesaveexception/) | Pengecualian penyimpanan gambar. Terjadi selama penyimpanan gambar. |
| [IndexOutOFRangeException](./indexoutofrangeexception/) | Pengecualian kompresor. |
| [LimitMemoryException](./limitmemoryexception/) | Pengecualian batas memori. Terjadi ketika penggunaan memori harus dikurangi. |
| [OperationInterruptedException](./operationinterruptedexception/) | Terjadi ketika operasi terputus. |
| [RdOptimizationError](./rdoptimizationerror/) | Kelas pengecualian kesalahan optimasi RD |
| [StreamReadException](./streamreadexception/) | Pengecualian pembacaan aliran. Disebabkan ketika pembacaan aliran gagal karena offset dan permintaan jumlah byte yang tidak tepat. |
| [XmpException](./xmpexception/) | Pengecualian yang dilemparkan ketika XMP memiliki struktur yang tidak valid. |
