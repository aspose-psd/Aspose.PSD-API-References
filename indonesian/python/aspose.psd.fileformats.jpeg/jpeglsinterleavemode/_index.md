Mendefinisikan mode interleave untuk data piksel multi-komponen (warna).

**Module:** [aspose.psd.fileformats.jpeg](/psd/python-net/aspose.psd.fileformats.jpeg/)

**Full Name:** aspose.psd.fileformats.jpeg.JpegLsInterleaveMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nama anggota** | **Deskripsi** |
| :- | :- |
| LINE | Mode interleave adalah per baris. Seluruh baris setiap komponen dienkode sebelum beralih ke baris berikutnya. |
| NONE | Data dienkode dan disimpan sebagai komponen per komponen: RRRGGGBBB. |
| SAMPLE | Data dienkode dan disimpan per sampel. Untuk gambar berwarna ini adalah format seperti RGBRGBRGB. |
