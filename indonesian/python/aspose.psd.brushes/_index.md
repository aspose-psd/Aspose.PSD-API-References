Modul ini menyediakan kelas pembantu dan metode untuk bekerja dengan berbagai jenis kuas.

## **Classes**
| **Kelas** | **Deskripsi** |
| :- | :- |
| [HatchBrush](/psd/python-net/aspose.psd.brushes/hatchbrush/) | Mendefinisikan kuas persegi panjang dengan gaya hatch, warna latar depan, dan warna latar belakang. Kelas ini tidak dapat diwariskan. |
| [LinearGradientBrush](/psd/python-net/aspose.psd.brushes/lineargradientbrush/) | Mengkapsulkan sebuah [Brush](/psd/python-net/aspose.psd/brush/) dengan gradien linier. Kelas ini tidak dapat diwariskan. |
| [LinearGradientBrushBase](/psd/python-net/aspose.psd.brushes/lineargradientbrushbase/) | Mewakili sebuah [Brush](/psd/python-net/aspose.psd/brush/) dengan kemampuan gradien dan properti yang sesuai. |
| [LinearMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/linearmulticolorgradientbrush/) | Mewakili sebuah [Brush](/psd/python-net/aspose.psd/brush/) dengan gradien linier yang didefinisikan oleh beberapa warna dan posisi yang sesuai. Kelas ini tidak dapat diwariskan. |
| [PathGradientBrush](/psd/python-net/aspose.psd.brushes/pathgradientbrush/) | Mengkapsulkan sebuah objek [Brush](/psd/python-net/aspose.psd/brush/) dengan gradien. Kelas ini tidak dapat diwariskan. |
| [PathGradientBrushBase](/psd/python-net/aspose.psd.brushes/pathgradientbrushbase/) | Mewakili sebuah [Brush](/psd/python-net/aspose.psd/brush/) dengan fungsi gradien jalur dasar. |
| [PathMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/pathmulticolorgradientbrush/) | Mengkapsulkan sebuah objek [Brush](/psd/python-net/aspose.psd/brush/) dengan gradien. Kelas ini tidak dapat diwariskan. |
| [SolidBrush](/psd/python-net/aspose.psd.brushes/solidbrush/) | Kuas solid dimaksudkan untuk menggambar secara berkelanjutan dengan warna tertentu. Kelas ini tidak dapat diwariskan. |
| [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) | Setiap properti dari kelas [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) adalah objek [Brush](/psd/python-net/aspose.psd/brush/) yang menggunakan gambar untuk mengisi interior sebuah bentuk. Kelas ini tidak dapat diwariskan. |
| [TransformBrush](/psd/python-net/aspose.psd.brushes/transformbrush/) | Sebuah [Brush](/psd/python-net/aspose.psd/brush/) dengan kemampuan transformasi. |
