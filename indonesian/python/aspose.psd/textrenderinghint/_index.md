Menentukan kualitas rendering teks.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.TextRenderingHint

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nama anggota** | **Deskripsi** |
| :- | :- |
| ANTI_ALIAS | Setiap karakter digambar menggunakan bitmap glif antialias tanpa hinting. Kualitas lebih baik karena antialiasing. Perbedaan lebar batang dapat terlihat karena hinting dimatikan. |
| ANTI_ALIAS_GRID_FIT | Setiap karakter digambar menggunakan bitmap glif antialias dengan hinting. Kualitas jauh lebih baik karena antialiasing, tetapi dengan biaya kinerja yang lebih tinggi. |
| CLEAR_TYPE_GRID_FIT | Setiap karakter digambar menggunakan bitmap glif ClearType dengan hinting. Pengaturan kualitas tertinggi. Digunakan untuk memanfaatkan fitur font ClearType. |
| SINGLE_BIT_PER_PIXEL | Setiap karakter digambar menggunakan bitmap glifnya. Hinting tidak digunakan. |
| SINGLE_BIT_PER_PIXEL_GRID_FIT | Setiap karakter digambar menggunakan bitmap glifnya. Hinting digunakan untuk meningkatkan tampilan karakter pada batang dan kelengkungan. |
| SYSTEM_DEFAULT | Setiap karakter digambar menggunakan bitmap glifnya, dengan hint rendering default sistem. Teks akan digambar menggunakan pengaturan penyamaran font apa pun yang dipilih pengguna untuk sistem. |
