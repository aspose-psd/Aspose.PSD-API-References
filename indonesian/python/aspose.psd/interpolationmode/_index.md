Enum [InterpolationMode](/psd/python-net/aspose.psd/interpolationmode/) menentukan algoritma yang digunakan ketika gambar diubah skala atau diputar.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.InterpolationMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nama anggota** | **Deskripsi** |
| :- | :- |
| BICUBIC | Menentukan interpolasi bikubik. Tidak ada pra‑filter yang dilakukan. Mode ini tidak cocok untuk memperkecil gambar di bawah 25 persen dari ukuran aslinya. |
| BILINEAR | Menentukan interpolasi bilinear. Tidak ada pra‑filter yang dilakukan. Mode ini tidak cocok untuk memperkecil gambar di bawah 50 persen dari ukuran aslinya. |
| DEFAULT | Menentukan mode default. |
| HIGH | Menentukan interpolasi berkualitas tinggi. |
| HIGH_QUALITY_BICUBIC | Menentukan interpolasi bicubic berkualitas tinggi. Pra-pemfilteran dilakukan untuk memastikan penyusutan berkualitas tinggi. Mode ini menghasilkan gambar yang diubah dengan kualitas tertinggi. |
| HIGH_QUALITY_BILINEAR | Menentukan interpolasi bilinear berkualitas tinggi. Pra-pemfilteran dilakukan untuk memastikan penyusutan berkualitas tinggi. |
| INVALID | Mode interpolasi tidak valid. |
| LOW | Menentukan interpolasi kualitas rendah. |
| NEAREST_NEIGHBOR | Menentukan interpolasi tetangga terdekat. |
