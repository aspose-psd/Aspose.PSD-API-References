Enum tersebut menentukan cara mengganti digit dalam string sesuai dengan locale atau bahasa pengguna.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringDigitSubstitute

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nama anggota** | **Deskripsi** |
| :- | :- |
| NASIONAL | Menentukan digit substitusi yang sesuai dengan bahasa nasional resmi dari locale pengguna. |
| NONE | Menentukan untuk menonaktifkan substitusi. |
| TRADISIONAL | Menentukan digit substitusi yang sesuai dengan skrip atau bahasa asli pengguna, yang mungkin berbeda dari bahasa nasional resmi locale pengguna. |
| PENGGUNA | Menentukan skema substitusi yang didefinisikan pengguna. |
