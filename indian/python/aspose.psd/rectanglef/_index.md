
दो आयतों के प्रतिच्छेदन को दर्शाने वाली एक [RectangleF](/psd/python-net/aspose.psd/rectanglef/) संरचना लौटाता है। यदि कोई प्रतिच्छेदन नहीं है, तो एक खाली [RectangleF](/psd/python-net/aspose.psd/rectanglef/) लौटाया जाता है।

**Parameters:**

| पैरामीटर | प्रकार | विवरण |
| :- | :- | :- |
| a | [RectangleF](/psd/python-net/aspose.psd/rectanglef) | पहला आयत जिसे प्रतिच्छेद करना है। |
| b | [RectangleF](/psd/python-net/aspose.psd/rectanglef) | दूसरा आयत जिसे प्रतिच्छेद करना है। |

**Returns**

| प्रकार | विवरण |
| :- | :- |
| [RectangleF](/psd/python-net/aspose.psd/rectanglef) | तीसरा [RectangleF](/psd/python-net/aspose.psd/rectanglef/) संरचना जिसका आकार दो निर्दिष्ट आयतों के ओवरलैप क्षेत्र को दर्शाता है। |
