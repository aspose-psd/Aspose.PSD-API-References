## Metered.SetMeteredKey method

मीटर सार्वजनिक और निजी कुंजी सेट करता है। यदि आप मीटर लाइसेंस खरीदते हैं, तो एप्लिकेशन शुरू करने पर इस API को कॉल किया जाना चाहिए, सामान्यतः यह पर्याप्त होता है। हालांकि, यदि उपभोग डेटा अपलोड करने में लगातार विफलता रहती है और 24 घंटे से अधिक हो जाता है, तो लाइसेंस को मूल्यांकन स्थिति में सेट कर दिया जाएगा; ऐसी स्थिति से बचने के लिए, आपको नियमित रूप से लाइसेंस स्थिति जांचनी चाहिए, यदि यह मूल्यांकन स्थिति है, तो इस API को फिर से कॉल करें।

```csharp
public void SetMeteredKey(string publicKey, string privateKey)
```
