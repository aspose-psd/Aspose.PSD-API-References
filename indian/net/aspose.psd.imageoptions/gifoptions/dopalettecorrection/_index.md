## GifOptions.DoPaletteCorrection property

पैलेट सुधार लागू है या नहीं, यह दर्शाने वाला मान प्राप्त करता है या सेट करता है।

```csharp
public bool DoPaletteCorrection { get; set; }
```

### Property Value

`true` यदि पैलेट सुधार लागू किया गया है; अन्यथा, `false`।

## टिप्पणियाँ

पैलेट सुधार का अर्थ है कि जब भी छवि को GIF में निर्यात किया जाता है, स्रोत छवि के रंगों का विश्लेषण किया जाता है ताकि सबसे उपयुक्त पैलेट बनाया जा सके (यदि छवि का Palette मौजूद नहीं है या विकल्पों में निर्दिष्ट नहीं है)। विश्लेषण प्रक्रिया में कुछ समय लगता है, लेकिन आउटपुट छवि में सबसे उपयुक्त रंग पैलेट होगा और परिणाम दृश्य रूप से बेहतर होगा।
