नामस्थान कोर PSD घटकों में से किसी द्वारा उत्पन्न अपवादों को शामिल करता है।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [CompressorException](./compressorexception/) | कम्प्रेसर अपवाद। |
| [DataMissmatchError](./datamissmatcherror/) | डेटा मिसमैच अपवाद क्लास |
| [FrameworkException](./frameworkexception/) | PSD फ्रेमवर्क अपवाद। यह क्लास सभी Aspose.PSD अपवादों के लिए एक कोर क्लास है। यह Aspose.PSD इंजन द्वारा फेंके गए अपवादों और अन्य सभी अपवाद प्रकारों के बीच अंतर करने के लिए प्रस्तुत किया गया है। |
| [ImageCreateException](./imagecreateexception/) | छवि निर्माण अपवाद। छवि निर्माण के दौरान होता है। |
| [ImageException](./imageexception/) | छवि अपवाद। |
| [ImageLoadException](./imageloadexception/) | छवि लोड अपवाद। छवि लोडिंग के दौरान होता है। |
| [ImageSaveException](./imagesaveexception/) | छवि सहेजने का अपवाद। छवि सहेजने के दौरान होता है। |
| [IndexOutOFRangeException](./indexoutofrangeexception/) | कम्प्रेसर अपवाद। |
| [LimitMemoryException](./limitmemoryexception/) | सीमित मेमोरी अपवाद। जब मेमोरी उपयोग को कम किया जाना चाहिए तब होता है। |
| [OperationInterruptedException](./operationinterruptedexception/) | जब कोई ऑपरेशन बाधित होता है तब होता है। |
| [RdOptimizationError](./rdoptimizationerror/) | आरडी अनुकूलन त्रुटि अपवाद वर्ग |
| [StreamReadException](./streamreadexception/) | स्ट्रीम पढ़ने का अपवाद। जब गलत ऑफ़सेट और बाइट्स काउंट अनुरोध के कारण स्ट्रीम पढ़ना विफल हो जाता है, तब उत्पन्न होता है। |
| [XmpException](./xmpexception/) | XMP में अमान्य संरचना होने पर फेंका जाने वाला अपवाद। |
