Namespace में Adobe डायनामिक मीडिया ग्रुप द्वारा उपयोग की जाने वाली XMP संबंधित हेल्पर क्लासेस, कॉन्स्टेंट्स और मेथड्स शामिल हैं।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [AudioChannelType](./audiochanneltype/) | ऑडियो चैनल प्रकार को दर्शाता है। |
| [AudioSampleType](./audiosampletype/) | ऑडियो सैंपल प्रकार को दर्शाता है [`XmpDynamicMediaPackage`](../aspose.psd.xmp.schemas.xmpdm/xmpdynamicmediapackage/). |
| [ProjectLink](./projectlink/) | प्रोजेक्ट का पथ दर्शाता है। |
| [Time](./time/) | सेकंड में समय मान का प्रतिनिधित्व। |
| [Timecode](./timecode/) | वीडियो में टाइमकोड मान को दर्शाता है। |
| [TimeFormat](./timeformat/) | टाइमकोड में समय प्रारूप को दर्शाता है [`Timecode`](../aspose.psd.xmp.schemas.xmpdm/timecode/). |
| [XmpDynamicMediaPackage](./xmpdynamicmediapackage/) | XMP डायनेमिक मीडिया नेमस्पेस को दर्शाता है। |
