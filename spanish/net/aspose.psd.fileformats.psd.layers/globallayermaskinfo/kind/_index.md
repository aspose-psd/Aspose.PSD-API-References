## GlobalLayerMaskInfo.Kind property

Obtiene o establece el tipo. 0 = Color seleccionado--es decir, invertido; 1 = Color protegido; 128 = usar el valor almacenado por capa. Este valor es el preferido. Los demás son para compatibilidad con versiones beta.

```csharp
public byte Kind { get; set; }
```
