El espacio de nombres maneja el procesamiento de AsyncTask.

## Clases

| Clase | Descripción |
| --- | --- |
| [AsyncTask](./asynctask/) | La clase estática de fábrica para crear las tareas asíncronas |
| [AsyncTaskAction](./asynctaskaction/) | El delegado de operación larga para la tarea asíncrona sin ningún resultado. |
| [AsyncTaskException](./asynctaskexception/) | La excepción para la tarea asíncrona. |
| [AsyncTaskFunc](./asynctaskfunc/) | El delegado de operación larga para la tarea asíncrona con tipo genérico de resultado. |
| [AsyncTaskProgress](./asynctaskprogress/) | Proporciona información de progreso para la tarea asíncrona. |
| [CompleteCallback](./completecallback/) | Función de devolución de llamada para recibir el evento de finalización de la tarea. |
| [ProgressCallback](./progresscallback/) | Función de devolución de llamada para recibir el evento de cambio de progreso de la tarea. |

| Interfaz | Descripción |
| --- | --- |
| [IAsyncTask](./iasynctask/) | La tarea asíncrona. |
