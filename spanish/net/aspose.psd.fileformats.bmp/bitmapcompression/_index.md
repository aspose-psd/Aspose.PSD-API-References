## BitmapCompression enumeration

Especifica diferentes métodos de compresión de mapas de bits.

```csharp
public enum BitmapCompression : uint
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Rgb | `0` | Sin compresión. |
| Rle8 | `1` | Compresión RLE de 8 bits/píxel. Solo se puede usar con mapas de bits de 8 bits/píxel. |
| Rle4 | `2` | Compresión RLE de 4 bits/píxel. Solo se puede usar con mapas de bits de 4 bits/píxel. |
| Bitfields | `3` | Campos de bits RGB. Solo se pueden usar con mapas de bits de 16 y 32 bits/píxel. |
| Jpeg | `4` | Compresión JPEG. El mapa de bits contiene una imagen JPEG. |
| Png | `5` | Compresión PNG. El mapa de bits contiene una imagen PNG. |
| AlphaBitfields | `6` | Campos de bits RGBA. Solo se pueden usar con mapas de bits de 16 y 32 bits/píxel. |
| Dxt1 | `827611204` | Compresión DXT1. El mapa de bits contiene una textura. |
