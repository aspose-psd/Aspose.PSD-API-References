## VscgResource.KeyForData property

Obtiene la clave entera que define qué tipo de configuraciones de relleno se almacena en el recurso: * Color - 0x536f436f - SoCoResource.TypeToolKey * Gradient - 0x4764466c - GdFlResource.TypeToolKey * Pattern - 0x5074466c - PtFlResource.TypeToolKey ¡Advertencia! El valor de la propiedad KeyForData debe coincidir con el tipo de configuraciones de relleno almacenadas en las estructuras Items.

public int KeyForData { get; }
