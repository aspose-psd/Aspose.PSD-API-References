El espacio de nombres proporciona clases y métodos auxiliares para trabajar con diferentes tipos de pincel.

## Clases

| Clase | Descripción |
| --- | --- |
| [HatchBrush](./hatchbrush/) | Define un pincel rectangular con un estilo de trama, un color de primer plano y un color de fondo. Esta clase no puede heredarse. |
| [LinearGradientBrush](./lineargradientbrush/) | Encapsula un [`Brush`](../aspose.psd/brush/) con un degradado lineal. Esta clase no puede heredarse. |
| [LinearGradientBrushBase](./lineargradientbrushbase/) | Representa un [`Brush`](../aspose.psd/brush/) con capacidades de degradado y propiedades apropiadas. |
| [LinearMulticolorGradientBrush](./linearmulticolorgradientbrush/) | Representa un [`Brush`](../aspose.psd/brush/) con degradado lineal definido por múltiples colores y posiciones apropiadas. Esta clase no puede heredarse. |
| [PathGradientBrush](./pathgradientbrush/) | Encapsula un objeto [`Brush`](../aspose.psd/brush/) con un degradado. Esta clase no puede heredarse. |
| [PathGradientBrushBase](./pathgradientbrushbase/) | Representa un [`Brush`](../aspose.psd/brush/) con funcionalidad de degradado de ruta base. |
| [PathMulticolorGradientBrush](./pathmulticolorgradientbrush/) | Encapsula un objeto [`Brush`](../aspose.psd/brush/) con un degradado. Esta clase no puede heredarse. |
| [SolidBrush](./solidbrush/) | El pincel sólido está destinado a dibujar continuamente con un color específico. Esta clase no puede heredarse. |
| [TextureBrush](./texturebrush/) | Cada propiedad de la clase [`TextureBrush`](../aspose.psd.brushes/texturebrush/) es un objeto [`Brush`](../aspose.psd/brush/) que utiliza una imagen para rellenar el interior de una forma. Esta clase no puede heredarse. |
| [TransformBrush](./transformbrush/) | Un [`Brush`](../aspose.psd/brush/) con capacidades de transformación. |
