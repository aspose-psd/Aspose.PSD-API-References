## PdfCoreOptions.ExpandedOutlineLevels property

Especifica cuántos niveles del esquema del documento se muestran expandidos cuando se visualiza el archivo PDF. 0 - el esquema del documento no está expandido. 1 - los elementos del primer nivel están expandidos y así sucesivamente. El valor predeterminado es 0.

```csharp
public int ExpandedOutlineLevels { get; set; }
```
