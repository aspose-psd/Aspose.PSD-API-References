## TiffExpectedFormat enumeration

El formato de archivo tiff esperado.

```csharp
public enum TiffExpectedFormat
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Default | `0` | El formato tiff predeterminado es sin compresión con formato B/W de 1 bit por píxel únicamente. También puede usar esta configuración para obtener opciones vacías e inicializar con sus etiquetas u otras configuraciones. |
| TiffLzwBw | `1` | El tiff con compresión LZW y formato B/W de 1 bit por píxel únicamente. |
| TiffLzwRgb | `2` | El tiff con compresión LZW y formato de color RGB. |
| TiffLzwRgba | `3` | El tiff con compresión LZW y formato de color RGBA con transparencia. |
| TiffLzwCmyk | `4` | El tiff LZW cmyk |
| TiffCcittFax3 | `5` | El tiff codificación CCITT FAX3. B/W de 1 bit por píxel únicamente soportado para ese esquema. |
| TiffCcittFax4 | `6` | El tiff codificación CCITT FAX4. B/W de 1 bit por píxel únicamente soportado para ese esquema. |
| TiffDeflateBw | `7` | El tiff con compresión deflate y formato B/W de 1 bit por píxel únicamente. |
| TiffDeflateRgb | `8` | El tiff con compresión deflate y formato de color RGB. |
| TiffDeflateRgba | `9` | El tiff con compresión deflate y formato de color RGBA. |
| TiffCcitRle | `10` | La codificación CCITT RLE del tiff. B/N 1 bit por píxel solo compatible con ese esquema. |
| TiffJpegRgb | `11` | El tiff con compresión Jpeg y formato de color RGB. |
| TiffJpegYCbCr | `12` | El tiff con compresión Jpeg y formato de color YCBCR. |
| TiffNoCompressionBw | `13` | El tiff sin comprimir y formato B/N 1 bit por píxel únicamente. |
| TiffNoCompressionRgb | `14` | El tiff sin comprimir y formato de color RGB. |
| TiffNoCompressionRgba | `15` | El tiff sin comprimir y formato de color RGBA con transparencia. |
