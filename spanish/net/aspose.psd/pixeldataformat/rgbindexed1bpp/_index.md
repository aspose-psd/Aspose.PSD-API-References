## PixelDataFormat.RgbIndexed1Bpp property

Obtiene el [`PixelDataFormat`](../) definido para índices de 1 bit por color. El almacenamiento de datos de píxeles indexados está destinado a permitir el almacenamiento y la recuperación de datos donde se usa la paleta de colores. Úselo con precaución, porque puede requerir conversión de una paleta a otra o de RGBA a modelo de color indexado.

```csharp
public static PixelDataFormat RgbIndexed1Bpp { get; }
```

### Property Value

El [`PixelDataFormat`](../) definido para índices de 1 bit por color.
