## SplitStreamContainer.Save method

Guarda (copia) los datos del flujo al flujo especificado.

```csharp
public override void Save(Stream destinationStream, int bufferSize, long length)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| destinationStream | Flujo | El flujo donde guardar los datos. |
| bufferSize | Int32 | El tamaño del búfer. Por defecto se usa el valor !:ReadWriteBytesCount. |
| length | Int64 | La longitud de los datos del flujo a copiar. Por defecto la longitud se establece al valor de [`Length`](../length/) |
