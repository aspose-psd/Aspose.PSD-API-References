## WrapMode enumeration

Especifica cómo se mosaica una textura o degradado cuando es más pequeña que el área a rellenar.

```csharp
public enum WrapMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Tile | `0` | Mosaica el degradado o la textura. |
| TileFlipX | `1` | Invierte la textura o el degradado horizontalmente y luego mosaica la textura o el degradado. |
| TileFlipY | `2` | Invierte la textura o el degradado verticalmente y luego mosaica la textura o el degradado. |
| TileFlipXY | `3` | Invierte la textura o el degradado horizontal y verticalmente y luego mosaica la textura o el degradado. |
| Clamp | `4` | La textura o el degradado no se mosaica. |
