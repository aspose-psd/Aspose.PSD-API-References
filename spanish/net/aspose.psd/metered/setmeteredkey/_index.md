## Metered.SetMeteredKey method

Establece la clave pública y privada medida. Si compras una licencia medida, al iniciar la aplicación, se debe llamar a esta API; normalmente, eso es suficiente. Sin embargo, si siempre falla la carga de los datos de consumo y supera las 24 horas, la licencia se establecerá en estado de evaluación; para evitar ese caso, deberías comprobar regularmente el estado de la licencia y, si está en estado de evaluación, llamar a esta API nuevamente.

```csharp
public void SetMeteredKey(string publicKey, string privateKey)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| publicKey | String | clave pública |
| privateKey | String | clave privada |
