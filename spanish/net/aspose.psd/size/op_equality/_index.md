## Size Equality operator

Prueba si dos estructuras [`Size`](../) son iguales.

```csharp
public static bool operator ==(Size size1, Size size2)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| size1 | Size | La estructura [`Size`](../) en el lado izquierdo del operador de igualdad. |
| size2 | Size | La estructura [`Size`](../) en el lado derecho del operador de igualdad. |

### Valor devuelto

Verdadero si *size1* y *size2* tienen el mismo ancho y alto; de lo contrario, falso.
