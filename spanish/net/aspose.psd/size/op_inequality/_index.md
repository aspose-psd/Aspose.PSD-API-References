## Size Inequality operator

Prueba si dos estructuras [`Size`](../) son diferentes.

```csharp
public static bool operator !=(Size size1, Size size2)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| size1 | Size | La estructura [`Size`](../) a la izquierda del operador de desigualdad. |
| size2 | Size | La estructura [`Size`](../) a la derecha del operador de desigualdad. |

### Valor devuelto

Verdadero si *size1* y *size2* difieren ya sea en ancho o altura; falso si *size1* y *size2* son iguales.
