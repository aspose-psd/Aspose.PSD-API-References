## Pen.SetLineCap method

Establece los valores que determinan el estilo de extremo utilizado para terminar las líneas dibujadas por este [`Pen`](../).

```csharp
public void SetLineCap(LineCap startCap, LineCap endCap, DashCap dashCap)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| startCap | LineCap | Un [`LineCap`](../../linecap/) que representa el estilo de extremo a usar al comienzo de las líneas dibujadas con este [`Pen`](../). |
| endCap | LineCap | Un [`LineCap`](../../linecap/) que representa el estilo de extremo a usar al final de las líneas dibujadas con este [`Pen`](../). |
| dashCap | DashCap | Un [`LineCap`](../../linecap/) que representa el estilo de extremo a usar al comienzo o al final de líneas discontinuas dibujadas con este [`Pen`](../). |
