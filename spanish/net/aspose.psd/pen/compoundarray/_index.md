## Pen.CompoundArray property

Obtiene o establece una matriz de valores que especifica un pen compuesto. Un pen compuesto dibuja una línea compuesta de líneas paralelas y espacios.

```csharp
public float[] CompoundArray { get; set; }
```

### Property Value

Una matriz de números reales que especifica la matriz compuesta. Los elementos de la matriz deben estar en orden creciente, no ser menores que 0 y no ser mayores que 1.

### Excepciones

| excepción | condición |
| --- | --- |
| ArgumentException | La propiedad `CompoundArray` se establece en un [`Pen`](../) inmutable, como los devueltos por la clase [`Pen`](../). |
