## Rectangle Equality operator

Comprueba si dos estructuras [`Rectangle`](../) tienen la misma ubicación y tamaño.

```csharp
public static bool operator ==(Rectangle left, Rectangle right)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| left | Rectangle | La estructura [`Rectangle`](../) que está a la izquierda del operador de igualdad. |
| right | Rectangle | La estructura [`Rectangle`](../) que está a la derecha del operador de igualdad. |

### Valor devuelto

Este operador devuelve true si las dos estructuras [`Rectangle`](../) tienen iguales las propiedades [`X`](../x/), [`Y`](../y/), [`Width`](../width/) y [`Height`](../height/).
