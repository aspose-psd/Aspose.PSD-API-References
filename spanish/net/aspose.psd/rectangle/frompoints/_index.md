## Rectangle.FromPoints method

Crea un nuevo [`Rectangle`](../) a partir de dos puntos especificados. Las dos verticales del [`Rectangle`](../) creado serán iguales a los *point1* y *point2* pasados. Estos serían típicamente los vértices opuestos.

```csharp
public static Rectangle FromPoints(Point point1, Point point2)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| point1 | Point | El primer [`Point`](../../point/) para el nuevo rectángulo. |
| point2 | Point | El segundo [`Point`](../../point/) para el nuevo rectángulo. |

### Valor devuelto

Un [`Rectangle`](../) recién creado.
