## Intersect(Rectangle, Rectangle)

Devuelve una tercera estructura [`Rectangle`](../) que representa la intersección de dos estructuras [`Rectangle`](../) adicionales. Si no hay intersección, se devuelve un [`Rectangle`](../) vacío.

```csharp
public static Rectangle Intersect(Rectangle a, Rectangle b)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| a | Rectangle | Un primer rectángulo para intersectar. |
| b | Rectangle | Un segundo rectángulo para intersectar. |

### Valor devuelto

Un [`Rectangle`](../) que representa la intersección de *a* y *b*.
