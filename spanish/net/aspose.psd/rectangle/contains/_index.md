## Contains(int, int) {#contains_2}

Determina si el punto especificado está contenido dentro de esta estructura [`Rectangle`](../).

```csharp
public bool Contains(int x, int y)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | Int32 | La coordenada x del punto a probar. |
| y | Int32 | La coordenada y del punto a probar. |

### Valor devuelto

Este método devuelve true si el punto definido por *x* y *y* está contenido dentro de esta estructura [`Rectangle`](../); de lo contrario, false.
