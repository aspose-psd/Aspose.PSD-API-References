## Rectangle Inequality operator

Prueba si dos estructuras [`Rectangle`](../) difieren en ubicación o tamaño.

```csharp
public static bool operator !=(Rectangle left, Rectangle right)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| left | Rectangle | La estructura [`Rectangle`](../) que está a la izquierda del operador de desigualdad. |
| right | Rectangle | La estructura [`Rectangle`](../) que está a la derecha del operador de desigualdad. |

### Valor devuelto

Este operador devuelve true si alguna de las propiedades [`X`](../x/), [`Y`](../y/), [`Width`](../width/) o [`Height`](../height/) de las dos estructuras [`Rectangle`](../) es desigual; de lo contrario, false.
