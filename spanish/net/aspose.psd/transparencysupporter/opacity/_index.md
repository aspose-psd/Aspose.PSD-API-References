## TransparencySupporter.Opacity property

Obtiene o establece la opacidad del objeto. El valor debe estar entre 0 y 1. Un valor de 0 significa que el objeto es totalmente visible, un valor de 1 significa que el objeto es totalmente opaco.

```csharp
public float Opacity { get; set; }
```

### Property Value

El valor de opacidad.
