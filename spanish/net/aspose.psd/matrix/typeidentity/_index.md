## Matrix.TypeIdentity field

Una transformación identidad es aquella en la que las coordenadas de salida son siempre las mismas que las coordenadas de entrada. Si esta transformación es diferente de la transformación identidad, el tipo será la constante GENERAL_TRANSFORM o una combinación de los bits de bandera apropiados para las diversas conversiones de coordenadas que realiza esta transformación.

public const int TypeIdentity;
