## RectangleF Inequality operator

Prueba si dos estructuras [`RectangleF`](../) difieren en ubicación o tamaño.

```csharp
public static bool operator !=(RectangleF left, RectangleF right)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| left | RectangleF | La estructura [`RectangleF`](../) que está a la izquierda del operador de desigualdad. |
| right | RectangleF | La estructura [`RectangleF`](../) que está a la derecha del operador de desigualdad. |

### Valor devuelto

Este operador devuelve true si alguna de las propiedades [`X`](../x/), [`Y`](../y/), [`Width`](../width/) o [`Height`](../height/) de las dos estructuras [`RectangleF`](../) es desigual; de lo contrario, false.
