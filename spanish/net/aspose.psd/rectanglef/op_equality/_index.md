## RectangleF Equality operator

Prueba si dos estructuras [`RectangleF`](../) tienen la misma ubicación y tamaño.

```csharp
public static bool operator ==(RectangleF left, RectangleF right)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| left | RectangleF | La estructura [`RectangleF`](../) que está a la izquierda del operador de igualdad. |
| right | RectangleF | La estructura [`RectangleF`](../) que está a la derecha del operador de igualdad. |

### Valor devuelto

Este operador devuelve true si las dos estructuras [`RectangleF`](../) especificadas tienen iguales las propiedades [`X`](../x/), [`Y`](../y/), [`Width`](../width/) y [`Height`](../height/).
