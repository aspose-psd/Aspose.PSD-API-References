## ImageLoadersRegistry.GetFirstSupportedDescriptorByTypeName method

Obtiene el primer descriptor compatible por su nombre de tipo.

```csharp
public static IImageLoaderDescriptor GetFirstSupportedDescriptorByTypeName(
    string descriptorTypeName)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| descriptorTypeName | String | El nombre del tipo de descriptor. |

### Valor devuelto

El primer descriptor de cargador encontrado o null si no se encuentra tal descriptor.

## Observaciones

El primer descriptor de cargador será en realidad el último registrado.
