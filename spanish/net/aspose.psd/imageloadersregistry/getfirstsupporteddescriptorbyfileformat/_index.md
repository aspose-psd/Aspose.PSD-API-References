## ImageLoadersRegistry.GetFirstSupportedDescriptorByFileFormat method

Obtiene el primer formato de archivo compatible por su nombre de tipo.

```csharp
public static IImageLoaderDescriptor GetFirstSupportedDescriptorByFileFormat(FileFormat fileFormat)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| fileFormat | FileFormat | El formato de archivo del descriptor compatible. |

### Valor devuelto

El primer descriptor de cargador encontrado o null si no se encuentra tal descriptor.

## Observaciones

El primer descriptor de cargador será en realidad el último registrado.
