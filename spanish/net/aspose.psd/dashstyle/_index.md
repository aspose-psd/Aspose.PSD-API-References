## DashStyle enumeration

Especifica el estilo de líneas discontinuas dibujadas con un objeto [`Pen`](../pen/).

```csharp
public enum DashStyle
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Solid | `0` | Especifica una línea sólida. |
| Dash | `1` | Especifica una línea compuesta por guiones. |
| Dot | `2` | Especifica una línea compuesta por puntos. |
| DashDot | `3` | Especifica una línea compuesta por un patrón repetido de guión-punto. |
| DashDotDot | `4` | Especifica una línea compuesta por un patrón repetido de guión-punto-punto. |
| Custom | `5` | Especifica un estilo de guión personalizado definido por el usuario. |
