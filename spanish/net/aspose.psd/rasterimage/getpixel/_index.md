## RasterImage.GetPixel method

Obtiene un píxel de la imagen. Advertencia de rendimiento: Evite usar este método para iterar sobre todos los píxeles de la imagen, ya que puede provocar problemas de rendimiento significativos. Para una manipulación de píxeles más eficiente, use el método `LoadArgb32Pixels` para recuperar toda la matriz de píxeles simultáneamente.

```csharp
public Color GetPixel(int x, int y)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | Int32 | La ubicación x del píxel. |
| y | Int32 | La ubicación y del píxel. |

### Valor devuelto

El color del píxel para la ubicación especificada.
