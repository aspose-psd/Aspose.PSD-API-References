## Region.IsEmpty method

Verifica si este [`Region`](../) tiene un interior vacío en la superficie de dibujo especificada.

```csharp
public bool IsEmpty(Graphics g)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| g | Graphics | Un [`Graphics`](../../graphics/) que representa una superficie de dibujo. |

### Valor devuelto

true si el interior de este [`Region`](../) está vacío cuando se aplica la transformación asociada con *g*; de lo contrario, false.

### Excepciones

| excepción | condición |
| --- | --- |
| ArgumentNullException | *g* es null. |
