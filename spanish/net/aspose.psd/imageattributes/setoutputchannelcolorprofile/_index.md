## SetOutputChannelColorProfile(string) {#setoutputchannelcolorprofile}

Establece el archivo de perfil de color del canal de salida para la categoría predeterminada.

```csharp
public void SetOutputChannelColorProfile(string colorProfileFilename)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| colorProfileFilename | String | El nombre de ruta de un archivo de perfil de color. Si el archivo de perfil de color está en el directorio %SystemRoot%\\System32\\Spool\\Drivers\\Color, este parámetro puede ser el nombre del archivo. De lo contrario, este parámetro debe ser la ruta completa. |

## SetOutputChannelColorProfile(string, ColorAdjustType) {#setoutputchannelcolorprofile_1}

| Parámetro | Tipo | Descripción |
