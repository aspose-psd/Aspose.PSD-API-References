## IsOutlineVisible(float, float, Pen) {#isoutlinevisible_6}

Indica si el punto especificado está contenido dentro (bajo) del contorno de este [`GraphicsPath`](../) cuando se dibuja con la [`Pen`](../../pen/).

```csharp
public bool IsOutlineVisible(float x, float y, Pen pen)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | Single | La coordenada x del punto a probar. |
| y | Single | La coordenada y del punto a probar. |
| pen | Pen | La [`Pen`](../../pen/) a probar. |

### Valor devuelto

Este método devuelve true si el punto especificado está contenido dentro del contorno de este [`GraphicsPath`](../) cuando se dibuja con la [`Pen`](../../pen/); de lo contrario, false.
