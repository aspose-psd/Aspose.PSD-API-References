## IsVisible(float, float) {#isvisible_6}

Indica si el punto especificado está contenido dentro de este [`GraphicsPath`](../).

```csharp
public bool IsVisible(float x, float y)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| x | Single | La coordenada x del punto a probar. |
| y | Single | La coordenada y del punto a probar. |

### Valor devuelto

Este método devuelve true si el punto especificado está contenido dentro de este [`GraphicsPath`](../); de lo contrario, false.
