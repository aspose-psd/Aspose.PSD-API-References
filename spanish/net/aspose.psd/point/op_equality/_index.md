## Point Equality operator

Compara dos objetos [`Point`](../). El resultado indica si los valores de las propiedades [`X`](../x/) y [`Y`](../y/) de los dos objetos [`Point`](../) son iguales.

```csharp
public static bool operator ==(Point point1, Point point2)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| point1 | Point | Un primer [`Point`](../) para comparar. |
| point2 | Point | Un segundo [`Point`](../) para comparar. |

### Valor devuelto

True si los valores [`X`](../x/) y [`Y`](../y/) de *point1* y *point2* son iguales; de lo contrario, false.
