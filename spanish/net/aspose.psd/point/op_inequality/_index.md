## Point Inequality operator

Compara dos objetos [`Point`](../). El resultado indica si los valores de las propiedades [`X`](../x/) o [`Y`](../y/) de los dos objetos [`Point`](../) son diferentes.

```csharp
public static bool operator !=(Point point1, Point point2)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| point1 | Point | Un primer [`Point`](../) para comparar. |
| point2 | Point | Un segundo [`Point`](../) para comparar. |

### Valor devuelto

Verdadero si los valores de cualquiera de las propiedades [`X`](../x/) o [`Y`](../y/) de *point1* y *point2* difieren; de lo contrario, falso.
