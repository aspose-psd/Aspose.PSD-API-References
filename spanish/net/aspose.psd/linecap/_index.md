## LineCap enumeration

Especifica los estilos de extremo disponibles con los que un objeto [`Pen`](../pen/) puede terminar una línea.

```csharp
public enum LineCap
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Flat | `0` | Especifica un extremo de línea plano. |
| Square | `1` | Especifica un extremo de línea cuadrado. |
| Round | `2` | Especifica un extremo de línea redondo. |
| Triangle | `3` | Especifica un extremo de línea triangular. |
| NoAnchor | `16` | Especifica sin ancla. |
| SquareAnchor | `17` | Especifica un extremo de línea con ancla cuadrada. |
| RoundAnchor | `18` | Especifica un extremo de ancla redondo. |
| DiamondAnchor | `19` | Especifica un extremo de ancla en forma de diamante. |
| ArrowAnchor | `20` | Especifica un extremo de ancla con forma de flecha. |
| AnchorMask | `240` | Especifica un extremo de línea personalizado. |
| Custom | `255` | Especifica una máscara utilizada para comprobar si un extremo de línea es un extremo de ancla. |
