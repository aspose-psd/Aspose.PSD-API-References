## PointF Inequality operator

Determina si las coordenadas de los puntos especificados no son iguales.

```csharp
public static bool operator !=(PointF point1, PointF point2)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| point1 | PointF | Un primer [`PointF`](../) para comparar. |
| point2 | PointF | Un segundo [`PointF`](../) para comparar. |

### Valor devuelto

True para indicar que los valores [`X`](../x/) y [`Y`](../y/) de *point1* y *point2* no son iguales; de lo contrario, false.
