## GraphicsUnit enumeration

Especifica la unidad de medida para los datos proporcionados.

```csharp
public enum GraphicsUnit
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| World | `0` | Especifica la unidad del sistema de coordenadas mundial como la unidad de medida. |
| Display | `1` | Especifica la unidad de medida del dispositivo de visualización. Normalmente píxeles para pantallas de video y 1/100 de pulgada para impresoras. |
| Pixel | `2` | Especifica un píxel del dispositivo como la unidad de medida. |
| Point | `3` | Especifica el punto de una impresora (1/72 de pulgada) como la unidad de medida. |
| Inch | `4` | Especifica la pulgada como la unidad de medida. |
| Document | `5` | Especifica la unidad del documento (1/300 de pulgada) como la unidad de medida. |
| Millimeter | `6` | Especifica el milímetro como la unidad de medida. |
