## Color.IsKnownColor property

Obtiene un valor que indica si esta estructura [`Color`](../) es un color predefinido. Los colores predefinidos están representados por los elementos de la enumeración [`KnownColor`](../../knowncolor/).

```csharp
public bool IsKnownColor { get; }
```

### Property Value

True si este [`Color`](../) se creó a partir de un color predefinido usando el método [`FromName`](../fromname/) o el método [`FromKnownColor`](../fromknowncolor/); de lo contrario, false.
