El espacio de nombres contiene clases y métodos auxiliares relacionados con XMP.

## Clases

| Clase | Descripción |
| --- | --- |
| [LangAlt](./langalt/) | Representa la alternativa de idioma XMP. |
| [Namespaces](./namespaces/) | Contiene espacios de nombres usados en el documento RDF. |
| [XmpArray](./xmparray/) | Representa la matriz Xmp en [`XmpPackage`](../aspose.psd.xmp/xmppackage/). TODO: La matriz puede contener datos complejos. |
| [XmpArrayHelper](./xmparrayhelper/) | La clase auxiliar para procesar la lógica RDF. |
| [XmpElementBase](./xmpelementbase/) | Representa el elemento xmp base que contiene atributos. |
| [XmpHeaderPi](./xmpheaderpi/) | Representa la instrucción de procesamiento del encabezado XMP. |
| [XmpMeta](./xmpmeta/) | Representa xmpmeta. Opcional. El propósito de este elemento es identificar los metadatos XMP dentro de un texto XML general que podría contener otros usos no XMP de RDF. |
| [XmpPackage](./xmppackage/) | Define la clase XmpPackage que representa la abstracción base para el paquete XMP. |
| [XmpPackageBaseCollection](./xmppackagebasecollection/) | Representa una colección de [`XmpPackage`](../aspose.psd.xmp/xmppackage/). |
| [XmpPacketWrapper](./xmppacketwrapper/) | Contiene el paquete xmp serializado, incluyendo encabezado y trailer. |
| [XmpRdfRoot](./xmprdfroot/) | Representa el elemento rdf:RDF. Un solo paquete XMP debe serializarse usando un único elemento XML rdf:RDF. El contenido del elemento rdf:RDF debe consistir en cero o más elementos rdf:Description. |
| [XmpTrailerPi](./xmptrailerpi/) | Representa la instrucción de procesamiento del trailer XMP. |
