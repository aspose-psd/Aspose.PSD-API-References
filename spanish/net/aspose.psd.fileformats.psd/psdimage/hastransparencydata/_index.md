## PsdImage.HasTransparencyData property

Obtiene o establece un valor que indica si el primer canal alfa contiene los datos de transparencia para el resultado fusionado al especificar datos de capas.

```csharp
public bool HasTransparencyData { get; set; }
```

### Property Value

`true` si el primer canal alfa contiene los datos de transparencia para el resultado combinado al especificar datos de capas; de lo contrario, `false`.
