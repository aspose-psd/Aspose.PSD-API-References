## EventType enumeration

Este enum describe los posibles tipos de eventos de progreso que pueden ocurrir durante las operaciones de procesamiento de imágenes

```csharp
public enum EventType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| RelativeProgress | `0` | Progreso relativo de la etapa actual del procesamiento de la operación |
| StageChange | `1` | La siguiente etapa de la operación ha comenzado |
| Initialization | `2` | La inicialización de la operación |
| PreProcessing | `3` | El preprocesamiento |
| Processing | `4` | El procesamiento |
| Finalization | `5` | La finalización de la operación |
