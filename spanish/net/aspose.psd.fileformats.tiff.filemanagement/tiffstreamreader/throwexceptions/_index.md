## TiffStreamReader.ThrowExceptions property

Obtiene o establece un valor que indica si se lanzan excepciones al procesar datos incorrectos (lectura o escritura en el flujo).

```csharp
public bool ThrowExceptions { get; set; }
```

### Property Value

`true` si se lanzan excepciones al procesar datos incorrectos; de lo contrario, las condiciones de error se ignoran silenciosamente.
