## TiffOptions.XPTitle property

Obtiene o establece información sobre la imagen, que es utilizada por el Explorador de Windows.

```csharp
public string XPTitle { get; set; }
```

### Property Value

Información sobre la imagen, usada por el Explorador de Windows. El `XPTitle` es ignorado por el Explorador de Windows si la etiqueta [`ImageDescription`](../imagedescription/) existe.
