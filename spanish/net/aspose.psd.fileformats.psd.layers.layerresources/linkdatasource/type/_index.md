## LinkDataSource.Type property

Obtiene el tipo de fuente de datos de enlace global de Adobe® Photoshop® que puede ser uno de los siguientes o ninguno: el archivo enlazado incrustado liFD que corresponde al recurso PSD Lnk2, el archivo enlazado externo liFE que corresponde al recurso PSD Lnke, el alias de archivo enlazado liFA.

```csharp
public LinkDataSourceType Type { get; }
```

### Property Value

El tipo de fuente de datos de enlace PSD.
