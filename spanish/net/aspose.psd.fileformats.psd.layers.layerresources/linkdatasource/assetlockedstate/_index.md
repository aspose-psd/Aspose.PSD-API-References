## LinkDataSource.AssetLockedState property

Obtiene o establece un valor que indica si el recurso PSD está bloqueado. El estado bloqueado del recurso, para los recursos de Adobe® Photoshop® СС Libraries.

```csharp
public bool AssetLockedState { get; set; }
```

### Property Value

`true` si el recurso de Adobe® Photoshop® está bloqueado; de lo contrario, `false`.
