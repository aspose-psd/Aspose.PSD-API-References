## LinkDataSource.IsLibraryLink property

Obtiene un valor que indica si esta fuente de datos de enlace PSD enlaza al elemento de la Biblioteca Adobe® Photoshop® СС.

```csharp
public bool IsLibraryLink { get; }
```

### Property Value

`true` si esta instancia es un enlace de biblioteca Adobe® Photoshop® СС; de lo contrario, `false`.
