## LinkDataSource.HasFileOpenDescriptor property

Obtiene o establece un valor que indica si esta fuente de datos de enlace tiene el descriptor de archivo abierto: CompId y OriginalCompId.

```csharp
public bool HasFileOpenDescriptor { get; set; }
```

### Property Value

`true` si esta instancia tiene el descriptor de archivo abierto; de lo contrario, `false`.
