Este enum describe los posibles tipos de eventos de progreso que pueden ocurrir durante las operaciones de procesamiento de imágenes

**Module:** [aspose.psd.progressmanagement](/psd/python-net/aspose.psd.progressmanagement/)

**Full Name:** aspose.psd.progressmanagement.EventType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| FINALIZATION | La finalización de la operación |
| INITIALIZATION | La inicialización de la operación |
| PRE_PROCESSING | El preprocesamiento |
| PROCESSING | El procesamiento |
| RELATIVE_PROGRESS | Progreso relativo de la etapa actual del procesamiento de la operación |
| STAGE_CHANGE | La siguiente etapa de la operación comenzó |
