Define el modo de entrelazado para datos de píxeles multicomponente (color).

**Module:** [aspose.psd.fileformats.jpeg](/psd/python-net/aspose.psd.fileformats.jpeg/)

**Full Name:** aspose.psd.fileformats.jpeg.JpegLsInterleaveMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| LINE | El modo de entrelazado es por línea. Una línea completa de cada componente se codifica antes de pasar a la siguiente línea. |
| NONE | Los datos se codifican y almacenan como componente por componente: RRRGGGBBB. |
| SAMPLE | Los datos se codifican y almacenan por muestra. Para imágenes en color, este es el formato como RGBRGBRGB. |
