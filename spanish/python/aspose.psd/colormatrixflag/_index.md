Especifica los tipos de imágenes y colores que se verán afectados por la configuración de ajuste de color y escala de grises de un [ImageAttributes](/psd/python-net/aspose.psd/imageattributes/).

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorMatrixFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| ALT_GRAYS | Solo se ajustan los tonos de gris. |
| POR DEFECTO | Todos los valores de color, incluidas las sombras grises, se ajustan mediante la misma matriz de ajuste de color. |
| SKIP_GRAYS | Todos los colores se ajustan, pero las sombras grises no se ajustan. Una sombra gris es cualquier color que tiene el mismo valor para sus componentes rojo, verde y azul. |
