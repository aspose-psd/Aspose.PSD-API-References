Especifica cómo recortar caracteres de una cadena que no cabe completamente en una forma de diseño.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringTrimming

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| CARÁCTER | Especifica que el texto se recorta al carácter más cercano. |
| ELLIPSIS_CHARACTER | Especifica que el texto se recorta al carácter más cercano y se inserta una elipsis al final de una línea recortada. |
| ELLIPSIS_PATH | El centro se elimina de las líneas recortadas y se reemplaza por una elipsis. El algoritmo conserva la mayor parte posible del último segmento de la línea delimitado por barras. |
| ELLIPSIS_WORD | Especifica que el texto se recorta a la palabra más cercana y se inserta una elipsis al final de una línea recortada. |
| NONE | Especifica que no hay recorte. |
| PALABRA | Especifica que el texto se recorta a la palabra más cercana. |
