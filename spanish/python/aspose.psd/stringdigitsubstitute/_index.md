La enumeración especifica cómo sustituir dígitos en una cadena según la configuración regional o el idioma del usuario.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringDigitSubstitute

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| NACIONAL | Especifica los dígitos de sustitución que corresponden con el idioma nacional oficial de la configuración regional del usuario. |
| NONE | Especifica desactivar las sustituciones. |
| TRADICIONAL | Especifica los dígitos de sustitución que corresponden con el guion o idioma nativo del usuario, que puede ser diferente del idioma nacional oficial de la configuración regional del usuario. |
| USUARIO | Especifica un esquema de sustitución definido por el usuario. |
