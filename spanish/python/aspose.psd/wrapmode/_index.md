Especifica cómo se mosaica una textura o degradado cuando es más pequeña que el área a rellenar.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.WrapMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| CLAMP | La textura o el degradado no está teselado. |
| TILE | Tesela el degradado o la textura. |
| TILE_FLIP_X | Invierte la textura o el degradado horizontalmente y luego la tesela. |
| TILE_FLIP_XY | Invierte la textura o el degradado horizontal y verticalmente y luego la tesela. |
| TILE_FLIP_Y | Invierte la textura o el degradado verticalmente y luego la tesela. |
