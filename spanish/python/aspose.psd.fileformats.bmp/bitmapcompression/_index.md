**Module:** [aspose.psd.fileformats.bmp](/psd/python-net/aspose.psd.fileformats.bmp/)

**Full Name:** aspose.psd.fileformats.bmp.BitmapCompression

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| ALPHA_BITFIELDS | Campos de bits RGBA. Solo se pueden usar con mapas de bits de 16 y 32 bits/píxel. |

| PNG | Compresión PNG. El mapa de bits contiene una imagen PNG. |

| RLE8 | Compresión RLE de 8 bits/píxel. Solo se puede usar con mapas de bits de 8 bits/píxel. |
