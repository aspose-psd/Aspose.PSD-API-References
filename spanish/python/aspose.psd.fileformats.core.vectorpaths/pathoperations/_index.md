Las operaciones para combinar las formas de ruta (operaciones booleanas).

**Module:** [aspose.psd.fileformats.core.vectorpaths](/psd/python-net/aspose.psd.fileformats.core.vectorpaths/)

**Full Name:** aspose.psd.fileformats.core.vectorpaths.PathOperations

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| COMBINE_SHAPES | Combinar formas (operación OR). Este es el valor predeterminado en Photoshop. |
| EXCLUDE_OVERLAPPING_SHAPES | Excluir formas superpuestas (operación XOR). |
| INTERSECT_SHAPE_AREAS | Intersectar áreas de forma (operación AND). |
| SUBTRACT_FRONT_SHAPE | Restar forma frontal (operación NOT). |
