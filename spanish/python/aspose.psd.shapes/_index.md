El módulo contiene diferentes formas combinadas a partir de segmentos de forma.

## **Classes**
| **Class** | **Descripción** |
| :- | :- |
| [ArcShape](/psd/python-net/aspose.psd.shapes/arcshape/) | Representa una forma de arco. |
| [BezierShape](/psd/python-net/aspose.psd.shapes/beziershape/) | Representa una spline Bézier. |
| [CurveShape](/psd/python-net/aspose.psd.shapes/curveshape/) | Representa una forma de spline curvada. |
| [EllipseShape](/psd/python-net/aspose.psd.shapes/ellipseshape/) | Representa una forma de elipse. |
| [PieShape](/psd/python-net/aspose.psd.shapes/pieshape/) | Representa una forma de pastel. |
| [PolygonShape](/psd/python-net/aspose.psd.shapes/polygonshape/) | Representa una forma de polígono. |
| [RectangleProjectedShape](/psd/python-net/aspose.psd.shapes/rectangleprojectedshape/) | Representa una forma que se proyecta sobre un rectángulo girado a una orientación particular.<br/>            Especificada por cuatro puntos que pueden rotarse en el espacio manteniendo la misma longitud de los bordes y 90 grados entre los bordes adyacentes. |
| [RectangleShape](/psd/python-net/aspose.psd.shapes/rectangleshape/) | Representa una forma rectangular. |
| [TextShape](/psd/python-net/aspose.psd.shapes/textshape/) | Representa una forma de texto. |
