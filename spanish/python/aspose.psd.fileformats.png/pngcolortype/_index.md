Representa el tipo de color de imagen PNG.

**Module:** [aspose.psd.fileformats.png](/psd/python-net/aspose.psd.fileformats.png/)

**Full Name:** aspose.psd.fileformats.png.PngColorType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| GRAYSCALE | Representa el tipo de color donde cada píxel es una muestra en escala de grises. |
| GRAYSCALE_WITH_ALPHA | Representa el tipo de color donde cada píxel es una muestra en escala de grises seguida de una muestra alfa. |
| INDEXED_COLOR | Representa el tipo de color donde cada píxel es un índice de paleta; debe aparecer un bloque PLTE. |
| TRUECOLOR | Representa el tipo de color donde cada píxel es una triple R,G,B. |
| TRUECOLOR_WITH_ALPHA | Representa el tipo de color donde cada píxel es una triple R,G,B seguida de una muestra alfa. |
