**Module:** [aspose.psd.fileformats.psd.layers.layerresources](/psd/python-net/aspose.psd.fileformats.psd.layers.layerresources/)

**Full Name:** aspose.psd.fileformats.psd.layers.layerresources.LayerLockType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Descripción** |
| :- | :- |
| LOCK_ALL | Bloquear todas las propiedades de una capa |
| LOCK_IMAGE_PIXELS | Bloquear parcialmente una capa - Impide la modificación de los píxeles de la capa usando las herramientas de pintura. |
| LOCK_POSITION | Bloquear parcialmente una capa - Impide que los píxeles de la capa se muevan. |
| LOCK_TRANSPARENT_PIXELS | Bloquear parcialmente una capa - Limita la edición a las porciones opacas de la capa. <br/>            Esta opción es equivalente a la opción Preserve Transparency en versiones anteriores de Photoshop. |
| NONE | Sin bloqueo de capa |
