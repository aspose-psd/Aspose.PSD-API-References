El módulo proporciona clases auxiliares y métodos para trabajar con diferentes tipos de pincel.

## **Classes**
| **Class** | **Descripción** |
| :- | :- |
| [HatchBrush](/psd/python-net/aspose.psd.brushes/hatchbrush/) | Define un pincel rectangular con un estilo de trama, un color de primer plano y un color de fondo. Esta clase no puede heredarse. |
| [LinearGradientBrush](/psd/python-net/aspose.psd.brushes/lineargradientbrush/) | Encapsula un [Brush](/psd/python-net/aspose.psd/brush/) con un degradado lineal. Esta clase no puede heredarse. |
| [LinearGradientBrushBase](/psd/python-net/aspose.psd.brushes/lineargradientbrushbase/) | Representa un [Brush](/psd/python-net/aspose.psd/brush/) con capacidades de degradado y propiedades apropiadas. |
| [LinearMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/linearmulticolorgradientbrush/) | Representa un [Brush](/psd/python-net/aspose.psd/brush/) con degradado lineal definido por múltiples colores y posiciones apropiadas. Esta clase no puede heredarse. |
| [PathGradientBrush](/psd/python-net/aspose.psd.brushes/pathgradientbrush/) | Encapsula un objeto [Brush](/psd/python-net/aspose.psd/brush/) con un degradado. Esta clase no puede heredarse. |
| [PathGradientBrushBase](/psd/python-net/aspose.psd.brushes/pathgradientbrushbase/) | Representa un [Brush](/psd/python-net/aspose.psd/brush/) con funcionalidad de degradado de ruta base. |
| [PathMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/pathmulticolorgradientbrush/) | Encapsula un objeto [Brush](/psd/python-net/aspose.psd/brush/) con un degradado. Esta clase no puede heredarse. |
| [SolidBrush](/psd/python-net/aspose.psd.brushes/solidbrush/) | El pincel sólido está destinado a dibujar continuamente con un color específico. Esta clase no puede heredarse. |
| [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) | Cada propiedad de la clase [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) es un objeto [Brush](/psd/python-net/aspose.psd/brush/) que utiliza una imagen para rellenar el interior de una forma. Esta clase no puede heredarse. |
| [TransformBrush](/psd/python-net/aspose.psd.brushes/transformbrush/) | Un [Brush](/psd/python-net/aspose.psd/brush/) con capacidades de transformación. |
