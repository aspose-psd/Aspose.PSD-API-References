### Copyright {#Copyright}
```
public static final int Copyright
```


Información de derechos de autor. En este estándar la etiqueta se usa para indicar tanto los derechos de autor del fotógrafo como del editor. Es el aviso de derechos de autor de la persona u organización que reclama derechos sobre la imagen. La declaración de derechos de autor de Interoperabilidad, incluyendo fecha y derechos, debe escribirse en este campo; por ejemplo, "Copyright, John Smith, 19xx. All rights reserved.". En este estándar el campo registra tanto los derechos de autor del fotógrafo como del editor, cada uno en una parte separada de la declaración. Cuando hay una distinción clara entre los derechos de autor del fotógrafo y del editor, se deben escribir en el orden de fotógrafo seguido por los derechos del editor, separados por NULL (en este caso, como la declaración también termina con un NULL, hay dos códigos NULL). Cuando solo se proporciona el derecho de autor del fotógrafo, se termina con un código NULL. Cuando solo se proporciona el derecho de autor del editor, la parte del fotógrafo consiste en un espacio seguido de un código NULL terminador, y luego se da el derecho de autor del editor. Cuando el campo se deja vacío, se considera desconocido.
