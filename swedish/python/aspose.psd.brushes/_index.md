Modulen tillhandahåller hjälparklasser och metoder för att arbeta med olika penseltyper.

## **Classes**
| **Klass** | **Beskrivning** |
| :- | :- |
| [HatchBrush](/psd/python-net/aspose.psd.brushes/hatchbrush/) | Definierar en rektangulär pensel med ett korsningsmönster, en förgrundsfärg och en bakgrundsfärg. Denna klass kan inte ärvas. |
| [LinearGradientBrush](/psd/python-net/aspose.psd.brushes/lineargradientbrush/) | Inkapslar en [Brush](/psd/python-net/aspose.psd/brush/) med en linjär gradient. Denna klass kan inte ärvas. |
| [LinearGradientBrushBase](/psd/python-net/aspose.psd.brushes/lineargradientbrushbase/) | Representerar en [Brush](/psd/python-net/aspose.psd/brush/) med gradientmöjligheter och lämpliga egenskaper. |
| [LinearMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/linearmulticolorgradientbrush/) | Representerar en [Brush](/psd/python-net/aspose.psd/brush/) med linjär gradient definierad av flera färger och lämpliga positioner. Denna klass kan inte ärvas. |
| [PathGradientBrush](/psd/python-net/aspose.psd.brushes/pathgradientbrush/) | Inkapslar ett [Brush](/psd/python-net/aspose.psd/brush/)‑objekt med en gradient. Denna klass kan inte ärvas. |
| [PathGradientBrushBase](/psd/python-net/aspose.psd.brushes/pathgradientbrushbase/) | Representerar en [Brush](/psd/python-net/aspose.psd/brush/) med grundväg‑gradientfunktionalitet. |
| [PathMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/pathmulticolorgradientbrush/) | Inkapslar ett [Brush](/psd/python-net/aspose.psd/brush/)‑objekt med en gradient. Denna klass kan inte ärvas. |
| [SolidBrush](/psd/python-net/aspose.psd.brushes/solidbrush/) | Solid brush är avsedd för kontinuerlig ritning med en specifik färg. Denna klass kan inte ärvas. |
| [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) | Varje egenskap i klassen [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) är ett [Brush](/psd/python-net/aspose.psd/brush/)‑objekt som använder en bild för att fylla insidan av en form. Denna klass kan inte ärvas. |
| [TransformBrush](/psd/python-net/aspose.psd.brushes/transformbrush/) | Ett [Brush](/psd/python-net/aspose.psd/brush/) med transformeringsmöjligheter. |
