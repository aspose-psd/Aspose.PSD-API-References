Uppräkningen specificerar hur siffror i en sträng ska ersättas enligt en användares språk eller lokala inställning.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringDigitSubstitute

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Medlemsnamn** | **Beskrivning** |
| :- | :- |
| NATIONAL | Anger ersättningssiffror som motsvarar det officiella nationella språket för användarens lokala inställning. |
| NONE | Anger att inaktivera ersättningar. |
| TRADITIONAL | Anger substitutionssiffror som motsvarar användarens inhemska skriftsystem eller språk, vilket kan skilja sig från det officiella nationalspråket för användarens lokala inställning. |
| ANVÄNDARE | Anger ett användardefinierat substitutionsschema. |
