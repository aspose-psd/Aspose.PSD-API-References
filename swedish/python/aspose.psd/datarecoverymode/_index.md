Datåterställningsläget.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.DataRecoveryMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Medlemsnamn** | **Beskrivning** |
| :- | :- |
| CONSISTENT_RECOVER | Det konsekventa återhämtningsläget försöker återställa all data så länge korruption inte bryter filformatet och möjliggör korrekt vidare bearbetning. |
| MAXIMAL_RECOVER | Det maximala återhämtningsläget återställer all data även om filformatet har en korrupt struktur och vidare bearbetning kan ge oönskade effekter. |
| NONE | Ingen dataåterhämtning är underförstådd. När filformatet har korrupt data kastas ett lämpligt undantag. |
