Anger måttenheten för de givna data.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.GraphicsUnit

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Medlemsnamn** | **Beskrivning** |
| :- | :- |
| DISPLAY | Anger måttenheten för displayenheten. Vanligtvis pixlar för videodisplayer och 1/100 tum för skrivare. |
| DOCUMENT | Anger dokumentenheten (1/300 tum) som måttenhet. |
| INCH | Anger tum som måttenhet. |
| MILLIMETER | Anger millimeter som måttenhet. |
| PIXEL | Anger en enhetspixel som måttenhet. |
| POINT | Anger en skrivarpunkt (1/72 tum) som måttenhet. |
| WORLD | Anger världens koordinatsystemenhet som måttenhet. |
