Anger kvaliteten på textåtergivning.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.TextRenderingHint

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Medlemsnamn** | **Beskrivning** |
| :- | :- |
| ANTI_ALIAS | Varje tecken ritas med sin antialiasade glyfbild utan hintning. Bättre kvalitet på grund av antialiasing. Skillnader i stambredd kan märkas eftersom hintning är avstängd. |
| ANTI_ALIAS_GRID_FIT | Varje tecken ritas med sin antialiasade glyfbild med hintning. Mycket bättre kvalitet på grund av antialiasing, men med högre prestandakostnad. |
| CLEAR_TYPE_GRID_FIT | Varje tecken ritas med sin glyf ClearType‑bitmap med hintning. Den högsta kvalitetsinställningen. Används för att utnyttja ClearType‑teckensnittsfunktioner. |
| SINGLE_BIT_PER_PIXEL | Varje tecken ritas med sin glyfbild. Hintning används inte. |
| SINGLE_BIT_PER_PIXEL_GRID_FIT | Varje tecken ritas med sin glyfbild. Hintning används för att förbättra tecknets utseende på stammar och kurvor. |
| SYSTEM_DEFAULT | Varje tecken ritas med sin glyfbild, med systemets standardrenderingstips. Texten kommer att ritas med de teckensnötningsinställningar som användaren har valt för systemet. |
