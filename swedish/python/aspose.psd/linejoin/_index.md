Anger hur man förenar på varandra följande linje- eller kurvsegment i en figur (underbana) som finns i ett [GraphicsPath](/psd/python-net/aspose.psd/graphicspath/)‑objekt.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.LineJoin

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Medlemsnamn** | **Beskrivning** |
| :- | :- |
| BEVEL | Anger en avfasad fog. Detta ger ett diagonalt hörn. |
| MITER | Anger en miterfog. Detta ger ett skarpt hörn eller ett avklippt hörn, beroende på om längden på miteren överstiger mitergränsen. |
| MITER_CLIPPED | Anger en miterfog. Detta ger ett skarpt hörn eller ett avfasat hörn, beroende på om längden på miteren överstiger mitergränsen. |
| ROUND | Anger en cirkulär fog. Detta ger en mjuk, cirkulär båge mellan linjerna. |
