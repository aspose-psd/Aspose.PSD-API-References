Enumen [InterpolationMode](/psd/python-net/aspose.psd/interpolationmode/) anger algoritmen som används när bilder skalas eller roteras.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.InterpolationMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Medlemsnamn** | **Beskrivning** |
| :- | :- |
| BICUBIC | Anger bikubisk interpolation. Ingen förfiltrering utförs. Detta läge är inte lämpligt för att minska en bild till under 25 procent av dess originalstorlek. |
| BILINEAR | Anger bilinjär interpolation. Ingen förfiltrering utförs. Detta läge är inte lämpligt för att minska en bild till under 50 procent av dess originalstorlek. |
| DEFAULT | Anger standardläge. |
| HÖG | Anger högkvalitativ interpolation. |
| HIGH_QUALITY_BICUBIC | Anger högkvalitativ, bikubisk interpolation. Förfiltrering utförs för att säkerställa högkvalitativ minskning. Detta läge producerar de högsta kvalitetsförändrade bilderna. |
| HIGH_QUALITY_BILINEAR | Anger högkvalitativ, bilinjär interpolation. Förfiltrering utförs för att säkerställa högkvalitativ minskning. |
| INVALID | Ogiltigt interpolationsläge. |
| LÅG | Anger lågkvalitativ interpolation. |
| NEAREST_NEIGHBOR | Anger närmaste-granne-interpolation. |
