Anger hur tecken ska trimmas från en sträng som inte helt får plats i en layoutform.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringTrimming

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Medlemsnamn** | **Beskrivning** |
| :- | :- |
| CHARACTER | Anger att texten trimmas till närmaste tecken. |
| ELLIPSIS_CHARACTER | Anger att texten trimmas till närmaste tecken, och ett ellipsis sätts in i slutet av en trimmad rad. |
| ELLIPSIS_PATH | Centrala delen tas bort från trimmade rader och ersätts av ett ellipsis. Algoritmen behåller så mycket som möjligt av det sista snedstreckavgränsade segmentet i raden. |
| ELLIPSIS_WORD | Anger att texten trimmas till närmaste ord, och ett ellipsis sätts in i slutet av en trimmad rad. |
| NONE | Anger ingen trimning. |
| WORD | Anger att texten trimmas till närmaste ord. |
