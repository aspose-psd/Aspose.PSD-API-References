## **Members**
| **Medlemsnamn** | **Beskrivning** |
| :- | :- |
| ASSOCIATED | Alfavärdet lagras i förmultiplicerad form. När alfa återställs kan det uppstå vissa avrundningseffekter och det återställda värdet kan skilja sig från det ursprungliga. |
