## PsdLoadOptions.ReadOnlyMode property

Hämtar eller anger ett värde som indikerar om [use read only mode]. Detta är skrivskyddat läge, stödjt för exakt kompatibilitet med Adobe Photoshop. När detta alternativ är satt sparas inga ändringar som gjorts på lager i den slutliga bilden. All data hämtas från ImageData‑sektionen, så det är identiskt med Photoshop. Som standard är inte alla inlästa bilder identiska med Adobe Photoshop‑kompatibla.

```csharp
public bool ReadOnlyMode { get; set; }
```

### Property Value

`true` om [use photoshop compatibility mode]; annars, `false`.
