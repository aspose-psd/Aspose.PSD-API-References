## Jpeg2000LoadOptions.MaximumDecodingTime property

Hämtar eller anger den maximala avkodningstiden i sekunder (detta alternativ kan användas på mycket långsamma maskiner med lite minne för att förhindra att processen hänger på mycket stora bilder – upplösning mer än 5500x6500 pixlar).

```csharp
public int MaximumDecodingTime { get; set; }
```

### Property Value

Den maximala avkodningstiden.
