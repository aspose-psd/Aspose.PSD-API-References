## TiffDataType.CompareTo method

Jämför den aktuella instansen med ett annat objekt av samma typ och returnerar ett heltal som indikerar om den aktuella instansen föregår, följer eller hamnar på samma position i sorteringsordningen som det andra objektet.

```csharp
public int CompareTo(object obj)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| obj | Object | Ett objekt att jämföra med denna instans. |

### Returvärde

Ett 32‑bitars signerat heltal som indikerar den relativa ordningen för de objekt som jämförs. Returvärdet har följande betydelser: Värde Betydelse Mindre än noll Denna instans är mindre än *obj*. Noll Denna instans är lika med *obj*. Större än noll Denna instans är större än *obj*.
