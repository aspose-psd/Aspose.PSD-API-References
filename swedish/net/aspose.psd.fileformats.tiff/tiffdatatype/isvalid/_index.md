## TiffDataType.IsValid property

Hämtar ett värde som indikerar om taggdata är giltig. En giltig tagg innehåller data som kan bevaras. En ogiltig tagg kan inte lagras.

```csharp
public bool IsValid { get; }
```

### Property Value

`true` om taggdata är giltig; annars `false`.
