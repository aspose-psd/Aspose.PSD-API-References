## RectangleF Inequality operator

Testar om två [`RectangleF`](../) strukturer skiljer sig åt i plats eller storlek.

```csharp
public static bool operator !=(RectangleF left, RectangleF right)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| left | RectangleF | Den [`RectangleF`](../) struktur som är till vänster om ojämlikhetsoperatorn. |
| right | RectangleF | Den [`RectangleF`](../) struktur som är till höger om ojämlikhetsoperatorn. |

### Returvärde

Denna operator returnerar true om någon av egenskaperna [`X`](../x/), [`Y`](../y/), [`Width`](../width/) eller [`Height`](../height/) för de två [`RectangleF`](../) strukturerna är olika; annars false.
