## RectangleF Equality operator

Testar om två [`RectangleF`](../)-strukturer har samma position och storlek.

```csharp
public static bool operator ==(RectangleF left, RectangleF right)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| left | RectangleF | Den [`RectangleF`](../)-struktur som är till vänster om likhetsoperatorn. |
| right | RectangleF | Den [`RectangleF`](../)-struktur som är till höger om likhetsoperatorn. |

### Returvärde

Denna operator returnerar true om de två angivna [`RectangleF`](../)-strukturerna har lika [`X`](../x/), [`Y`](../y/), [`Width`](../width/) och [`Height`](../height/)-egenskaper.
