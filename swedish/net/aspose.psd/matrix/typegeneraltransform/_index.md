## Matrix.TypeGeneralTransform field

Denna konstant indikerar att den transformation som definieras av detta objekt utför en godtycklig konvertering av inmatningskoordinaterna. Om denna transformation kan klassificeras av någon av ovanstående konstanter kommer typen antingen att vara konstanten TypeIdentity eller en kombination av lämpliga flaggbitar för de olika koordinatkonverteringar som denna transformation utför.

```csharp
public const int TypeGeneralTransform;
```
