## Size Inequality operator

Testar om två [`Size`](../) strukturer är olika.

```csharp
public static bool operator !=(Size size1, Size size2)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| size1 | Size | Den [`Size`](../) strukturen till vänster om ojämlikhetsoperatorn. |
| size2 | Size | Den [`Size`](../) strukturen till höger om ojämlikhetsoperatorn. |

### Returvärde

Sant om *size1* och *size2* skiljer sig i bredd eller höjd; falskt om *size1* och *size2* är lika.
