## Size Equality operator

Testar om två [`Size`](../)-strukturer är lika.

```csharp
public static bool operator ==(Size size1, Size size2)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| size1 | Size | Den [`Size`](../)-strukturen på vänster sida av likhetsoperatorn. |
