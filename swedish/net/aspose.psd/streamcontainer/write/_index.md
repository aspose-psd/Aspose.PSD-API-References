## Write(byte[], int, int) {#write_1}

Skriver en sekvens av byte till den aktuella strömmen och förflyttar den aktuella positionen i denna ström med antalet skrivna byte.

```csharp
public virtual void Write(byte[] buffer, int offset, int count)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| buffer | Byte[] | En array av byte. Denna metod kopierar *count* byte från *buffer* till den aktuella strömmen. |
| offset | Int32 | Det nollbaserade byteoffsetet i *buffer* där kopieringen av byte till den aktuella strömmen ska börja. |
| count | Int32 | Antalet byte som ska skrivas till den aktuella strömmen. |
