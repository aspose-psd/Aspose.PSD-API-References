## SizeF Inequality operator

Testar om två [`SizeF`](../)-strukturer är olika.

```csharp
public static bool operator !=(SizeF size1, SizeF size2)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| size1 | SizeF | Den [`SizeF`](../)-struktur som står till vänster om ojämlikhetsoperatorn. |
| size2 | SizeF | Den [`SizeF`](../)-struktur som står till höger om ojämlikhetsoperatorn. |

### Returvärde

Denna operator returnerar true om *size1* och *size2* skiljer sig i bredd eller höjd; false om *size1* och *size2* är lika.
