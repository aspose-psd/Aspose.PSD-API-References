## RasterImage.GetPixel method

Hämtar en bildpixel. Prestandavarning: Undvik att använda denna metod för att iterera över alla bildpixlar eftersom det kan leda till betydande prestandaproblem. För mer effektiv pixelmanipulation, använd metoden `LoadArgb32Pixels` för att hämta hela pixelarrayen samtidigt.

```csharp
public Color GetPixel(int x, int y)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| x | Int32 | Pixelns x‑position. |
| y | Int32 | Pixelns y‑position. |

### Returvärde

Pixelns färg för den angivna platsen.
