## TransparencySupporter.Opacity property

Hämtar eller anger objektets opacitet. Värdet bör vara mellan 0 och 1. Värde 0 betyder att objektet är helt synligt, värde 1 betyder att objektet är helt ogenomskinligt.

```csharp
public float Opacity { get; set; }
```

### Property Value

Opacitetsvärdet.
