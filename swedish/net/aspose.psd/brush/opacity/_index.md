## Brush.Opacity property

Hämtar eller anger penselns opacitet. Värdet ska vara mellan 0 och 1. Värdet 0 betyder att penseln är helt synlig, värdet 1 betyder att penseln är helt ogenomskinlig.

```csharp
public float Opacity { get; set; }
```

### Property Value

Penselns opacitetsvärde.
