## ColorMatrix class

Definierar en 5 x 5-matris som innehåller koordinaterna för RGBA-rymden. Flera metoder i [`ImageAttributes`](../imageattributes/)-klassen justerar bildfärger genom att använda en färgmatris. Denna klass kan inte ärvas.

```csharp
public sealed class ColorMatrix
```
