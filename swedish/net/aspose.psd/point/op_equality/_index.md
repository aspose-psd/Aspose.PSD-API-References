## Point Equality operator

Jämför två [`Point`](../) objekt. Resultatet anger om värdena för [`X`](../x/) och [`Y`](../y/) egenskaperna hos de två [`Point`](../) objekten är lika.

```csharp
public static bool operator ==(Point point1, Point point2)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| point1 | Point | Ett första [`Point`](../) att jämföra. |
| point2 | Point | Ett andra [`Point`](../) att jämföra. |

### Returvärde

Sant om [`X`](../x/) och [`Y`](../y/) värdena för *point1* och *point2* är lika; annars falskt.
