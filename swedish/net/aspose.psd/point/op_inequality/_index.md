## Point Inequality operator

Jämför två [`Point`](../) objekt. Resultatet anger om värdena för [`X`](../x/) eller [`Y`](../y/) egenskaperna hos de två [`Point`](../) objekten är olika.

```csharp
public static bool operator !=(Point point1, Point point2)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| point1 | Point | Ett första [`Point`](../) att jämföra. |
| point2 | Point | Ett andra [`Point`](../) att jämföra. |

### Returvärde

Sant om värdena för antingen [`X`](../x/) egenskaperna eller [`Y`](../y/) egenskaperna för *point1* och *point2* skiljer sig; annars falskt.
