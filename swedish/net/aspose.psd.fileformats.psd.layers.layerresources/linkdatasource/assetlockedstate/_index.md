## LinkDataSource.AssetLockedState property

Hämtar eller anger ett värde som indikerar om PSD‑tillgången är låst. Tillgångens låsta status, för Adobe® Photoshop® CC Libraries‑tillgångar.

```csharp
public bool AssetLockedState { get; set; }
```

### Property Value

`true` om Adobe® Photoshop®‑tillgången är låst; annars `false`.
