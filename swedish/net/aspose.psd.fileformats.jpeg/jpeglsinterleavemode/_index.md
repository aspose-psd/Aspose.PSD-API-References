## JpegLsInterleaveMode enumeration

Definierar interleav‑läget för flerkomponent (färg) pixeldata.

```csharp
public enum JpegLsInterleaveMode
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | `0` | Data kodas och lagras som komponent för komponent: RRRGGGBBB. |
| Line | `1` | Interleavläget är per rad. En hel rad av varje komponent kodas innan nästa rad kodas. |
| Sample | `2` | Data kodas och lagras per prov. För färgbilder är detta formatet som RGBRGBRGB. |
