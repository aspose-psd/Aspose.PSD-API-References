Le package fournit des classes d'assistance et des méthodes pour travailler avec différents types de pinceau.


## Classes

| Classe | Description |
| --- | --- |
| [HatchBrush](../com.aspose.psd.brushes/hatchbrush) | Définit un pinceau rectangulaire avec un style hachuré, une couleur de premier plan et une couleur d'arrière-plan. |
| [LinearGradientBrush](../com.aspose.psd.brushes/lineargradientbrush) | Encapsule un  Aspose.Imaging.Brush  avec un dégradé linéaire. |
| [LinearGradientBrushBase](../com.aspose.psd.brushes/lineargradientbrushbase) | Représente un  Brush  avec des capacités de dégradé et des propriétés appropriées. |
| [LinearMulticolorGradientBrush](../com.aspose.psd.brushes/linearmulticolorgradientbrush) | Représente un  Brush  avec un dégradé linéaire défini par plusieurs couleurs et des positions appropriées. |
| [PathGradientBrush](../com.aspose.psd.brushes/pathgradientbrush) | Encapsule un objet  Aspose.Imaging.Brush  avec un dégradé. |
| [PathGradientBrushBase](../com.aspose.psd.brushes/pathgradientbrushbase) | Représente un Brush avec une fonctionnalité de dégradé de chemin de base. |
| [PathMulticolorGradientBrush](../com.aspose.psd.brushes/pathmulticolorgradientbrush) | Encapsule un objet  Aspose.Imaging.Brush  avec un dégradé. |
| [SolidBrush](../com.aspose.psd.brushes/solidbrush) | Solid brush est destiné au dessin en continu avec une couleur spécifique. |
| [TextureBrush](../com.aspose.psd.brushes/texturebrush) | Chaque propriété de la classe Aspose.Imaging.Brushes.TextureBrush est un objet Aspose.Imaging.Brush qui utilise une image pour remplir l'intérieur d'une forme. |
| [TransformBrush](../com.aspose.psd.brushes/transformbrush) | Un Brush avec des capacités de transformation. |
