## SetOutputChannelColorProfile(string) {#setoutputchannelcolorprofile}

Définit le fichier de profil couleur du canal de sortie pour la catégorie par défaut.

```csharp
public void SetOutputChannelColorProfile(string colorProfileFilename)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| colorProfileFilename | String | Le chemin d'accès d'un fichier de profil couleur. Si le fichier de profil couleur se trouve dans le répertoire %SystemRoot%\\System32\\Spool\\Drivers\\Color, ce paramètre peut être le nom du fichier. Sinon, ce paramètre doit être le chemin d'accès complet. |

## SetOutputChannelColorProfile(string, ColorAdjustType) {#setoutputchannelcolorprofile_1}

Définit le fichier de profil couleur du canal de sortie pour une catégorie spécifiée.

```csharp
public void SetOutputChannelColorProfile(string colorProfileFilename, ColorAdjustType type)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| colorProfileFilename | String | Le chemin d'accès d'un fichier de profil couleur. Si le fichier de profil couleur se trouve dans le répertoire %SystemRoot%\\System32\\Spool\\Drivers\\Color, ce paramètre peut être le nom du fichier. Sinon, ce paramètre doit être le chemin d'accès complet. |
| type | ColorAdjustType | Un élément de [`ColorAdjustType`](../../coloradjusttype/) qui spécifie la catégorie pour laquelle le fichier de profil couleur du canal de sortie est défini. |
