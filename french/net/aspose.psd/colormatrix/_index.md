## ColorMatrix class

Définit une matrice 5 x 5 qui contient les coordonnées de l'espace RGBA. Plusieurs méthodes de la classe [`ImageAttributes`](../imageattributes/) ajustent les couleurs de l'image en utilisant une matrice de couleur. Cette classe ne peut pas être héritée.

```csharp
public sealed class ColorMatrix
```
