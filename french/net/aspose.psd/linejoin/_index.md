## LineJoin enumeration

Spécifie comment joindre des segments de ligne ou de courbe consécutifs dans une figure (sous-chemin) contenue dans un objet [`GraphicsPath`](../graphicspath/).

```csharp
public enum LineJoin
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Miter | `0` | Spécifie une jointure en onglet. Cela produit un coin aigu ou un coin tronqué, selon que la longueur de l'onglet dépasse la limite d'onglet. |
| Bevel | `1` | Spécifie une jointure biseautée. Cela produit un coin diagonal. |
| Round | `2` | Spécifie une jointure circulaire. Cela produit un arc circulaire lisse entre les lignes. |
| MiterClipped | `3` | Spécifie une jointure en onglet. Cela produit un coin aigu ou un coin biseauté, selon que la longueur de l'onglet dépasse la limite d'onglet. |
