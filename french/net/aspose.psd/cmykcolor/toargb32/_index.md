## CmykColor.ToArgb32 method

La conversion de CMYKColor en couleur ARGB 32 bits utilisant la conversion icc avec les profils par défaut. Cette méthode est obsolète. Veuillez utiliser une version plus efficace [`ToArgb32`](../../cmykcolorhelper/toargb32/).

```csharp
[Obsolete]
public static int[] ToArgb32(CmykColor[] cmykPixels)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| cmykPixels | CmykColor[] | Les pixels du type CMYKColor au format CMYK. |

### Valeur de retour

Le tableau de la couleur ARGB 32 bits.
