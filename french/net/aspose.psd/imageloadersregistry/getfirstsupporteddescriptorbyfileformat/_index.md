## ImageLoadersRegistry.GetFirstSupportedDescriptorByFileFormat method

Obtient le premier format de fichier pris en charge par son nom de type.

```csharp
public static IImageLoaderDescriptor GetFirstSupportedDescriptorByFileFormat(FileFormat fileFormat)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| fileFormat | FileFormat | Le format de fichier du descripteur pris en charge. |

### Valeur de retour

Le premier descripteur de chargeur trouvé ou null si aucun tel descripteur n'est trouvé.

## Remarques

Le premier descripteur de chargeur sera en fait le dernier enregistré.
