## RasterImage.VerticalResolution property

Obtient ou définit la résolution verticale, en pixels par pouce, de ce [`RasterImage`](../).

```csharp
public virtual double VerticalResolution { get; set; }
```

### Property Value

La résolution verticale.

## Remarques

Remarque : par défaut, cette valeur est toujours de 96 car les différentes plateformes ne peuvent pas renvoyer la résolution de l'écran. Vous pouvez envisager d'utiliser la méthode SetResolution pour mettre à jour les deux valeurs de résolution en un seul appel.
