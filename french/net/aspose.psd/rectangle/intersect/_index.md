## Intersect(Rectangle, Rectangle)

Retourne une troisième structure [`Rectangle`](../) qui représente l'intersection de deux autres structures [`Rectangle`](../). S'il n'y a pas d'intersection, un [`Rectangle`](../) vide est retourné.

```csharp
public static Rectangle Intersect(Rectangle a, Rectangle b)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| a | Rectangle | Un premier rectangle à intersecter. |
| b | Rectangle | Un deuxième rectangle à intersecter. |

### Valeur de retour

Un [`Rectangle`](../) qui représente l'intersection de *a* et *b*.
