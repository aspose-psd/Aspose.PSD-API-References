## Rectangle Equality operator

Vérifie si deux structures [`Rectangle`](../) ont le même emplacement et la même taille.

```csharp
public static bool operator ==(Rectangle left, Rectangle right)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| left | Rectangle | La structure [`Rectangle`](../) qui se trouve à gauche de l'opérateur d'égalité. |
| right | Rectangle | La structure [`Rectangle`](../) qui se trouve à droite de l'opérateur d'égalité. |

### Valeur de retour

Cet opérateur renvoie true si les deux structures [`Rectangle`](../) ont des propriétés [`X`](../x/), [`Y`](../y/), [`Width`](../width/) et [`Height`](../height/) égales.
