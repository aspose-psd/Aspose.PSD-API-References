## TransparencySupporter.Opacity property

Obtient ou définit l'opacité de l'objet. La valeur doit être comprise entre 0 et 1. Une valeur de 0 signifie que l'objet est entièrement visible, une valeur de 1 signifie que l'objet est entièrement opaque.

```csharp
public float Opacity { get; set; }
```

### Property Value

La valeur d'opacité.
