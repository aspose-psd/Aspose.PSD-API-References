## Matrix.TypeGeneralTransform field

Cette constante indique que la transformation définie par cet objet effectue une conversion arbitraire des coordonnées d'entrée. Si cette transformation peut être classée par l'une des constantes ci‑dessus, le type sera soit la constante TypeIdentity, soit une combinaison des bits de drapeau appropriés pour les différentes conversions de coordonnées que cette transformation effectue.

```csharp
public const int TypeGeneralTransform;
```
