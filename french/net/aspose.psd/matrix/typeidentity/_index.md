## Matrix.TypeIdentity field

Une transformation identité est celle dans laquelle les coordonnées de sortie sont toujours identiques aux coordonnées d'entrée. Si cette transformation n'est pas la transformation identité, le type sera soit la constante GENERAL_TRANSFORM, soit une combinaison des bits de drapeau appropriés pour les différentes conversions de coordonnées que cette transformation effectue.

```csharp
public const int TypeIdentity;
```
