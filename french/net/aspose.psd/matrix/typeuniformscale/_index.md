## Matrix.TypeUniformScale field

Une mise à l'échelle uniforme multiplie la longueur des vecteurs par la même quantité dans les directions x et y sans changer l'angle entre les vecteurs. Ce bit de drapeau est mutuellement exclusif avec le drapeau TypeGeneralScale.

```csharp
public const int TypeUniformScale;
```
