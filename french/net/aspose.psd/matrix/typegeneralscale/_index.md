## Matrix.TypeGeneralScale field

Une échelle générale multiplie la longueur des vecteurs par des valeurs différentes dans les directions x et y sans changer l'angle entre les vecteurs perpendiculaires. Ce bit de drapeau est mutuellement exclusif avec le drapeau TypeUniformScale.

```csharp
public const int TypeGeneralScale;
```
