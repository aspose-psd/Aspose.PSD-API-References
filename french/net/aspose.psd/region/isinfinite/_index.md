## Region.IsInfinite method

Vérifie si ce [`Region`](../) a un intérieur infini sur la surface de dessin spécifiée.

```csharp
public bool IsInfinite(Graphics g)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| g | Graphics | Un [`Graphics`](../../graphics/) qui représente une surface de dessin. |

### Valeur de retour

vrai si l'intérieur de ce [`Region`](../) est infini lorsque la transformation associée à *g* est appliquée ; sinon, faux.

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | *g* est nul. |
