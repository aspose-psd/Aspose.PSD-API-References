## RectangleF Inequality operator

Vérifie si deux structures [`RectangleF`](../) diffèrent en position ou en taille.

```csharp
public static bool operator !=(RectangleF left, RectangleF right)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| left | RectangleF | La structure [`RectangleF`](../) qui se trouve à gauche de l'opérateur d'inégalité. |
| right | RectangleF | La structure [`RectangleF`](../) qui se trouve à droite de l'opérateur d'inégalité. |

### Valeur de retour

Cet opérateur renvoie true si l'une des propriétés [`X`](../x/) , [`Y`](../y/), [`Width`](../width/) ou [`Height`](../height/) des deux structures [`RectangleF`](../) est différente ; sinon false.
