## IOrderedShape interface

Représente une forme ordonnée. Une forme ordonnée est un ensemble continu de points ayant un point de départ et un point d'arrivée. L'ensemble continu de points est connecté selon une règle spécifique.

```csharp
public interface IOrderedShape
```

| Nom | Description |
| --- | --- |
| [EndPoint](../../aspose.psd/iorderedshape/endpoint/) { get; } | Obtient le point final de la forme. |
| [IsClosed](../../aspose.psd/iorderedshape/isclosed/) { get; set; } | Obtient ou définit une valeur indiquant si la forme ordonnée est fermée. Lors du traitement d'une forme ordonnée fermée, les points de départ et d'arrivée n'ont aucune signification. |
| [StartPoint](../../aspose.psd/iorderedshape/startpoint/) { get; } | Obtient le point de départ de la forme. |
