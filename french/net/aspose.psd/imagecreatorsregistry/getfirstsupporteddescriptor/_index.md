## ImageCreatorsRegistry.GetFirstSupportedDescriptor method

Obtient le premier descripteur pris en charge trouvé adapté à la spécification.

```csharp
public static IImageCreatorDescriptor GetFirstSupportedDescriptor(ImageOptionsBase imageOptions)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| imageOptions | ImageOptionsBase | Les options d'image. |

### Valeur de retour

Le descripteur du créateur qui prend en charge le spécifié ou null si aucun descripteur de ce type n'est trouvé.

## Remarques

Le premier descripteur de créateur sera en fait le dernier enregistré.
