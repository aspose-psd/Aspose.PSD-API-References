## Pen.SetLineCap method

Définit les valeurs qui déterminent le style de terminaison utilisé pour finir les lignes tracées par ce [`Pen`](../).

```csharp
public void SetLineCap(LineCap startCap, LineCap endCap, DashCap dashCap)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| startCap | LineCap | Un [`LineCap`](../../linecap/) qui représente le style de terminaison à utiliser au début des lignes tracées avec ce [`Pen`](../). |
| endCap | LineCap | Un [`LineCap`](../../linecap/) qui représente le style de terminaison à utiliser à la fin des lignes tracées avec ce [`Pen`](../). |
| dashCap | DashCap | Un [`LineCap`](../../linecap/) qui représente le style de terminaison à utiliser au début ou à la fin des lignes en pointillé tracées avec ce [`Pen`](../). |
