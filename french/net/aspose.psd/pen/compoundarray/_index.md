## Pen.CompoundArray property

Obtient ou définit un tableau de valeurs qui spécifie un stylo composé. Un stylo composé trace une ligne composée de lignes parallèles et d’espaces.

```csharp
public float[] CompoundArray { get; set; }
```

### Property Value

Un tableau de nombres réels qui spécifie le tableau composé. Les éléments du tableau doivent être en ordre croissant, pas moins que 0, et pas plus que 1.

| exception | condition |
| --- | --- |
| ArgumentException | La propriété `CompoundArray` est définie sur un [`Pen`](../) immuable, comme ceux retournés par la classe [`Pen`](../). |
