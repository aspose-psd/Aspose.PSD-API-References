## SplitStreamContainer.Save method

Enregistre (copie) les données du flux vers le flux spécifié.

```csharp
public override void Save(Stream destinationStream, int bufferSize, long length)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| destinationStream | Stream | Le flux dans lequel enregistrer les données. |
| bufferSize | Int32 | La taille du tampon. Par défaut, la valeur !:ReadWriteBytesCount est utilisée. |
| length | Int64 | La longueur des données du flux à copier. Par défaut, la longueur est définie sur la valeur [`Length`](../length/). |
