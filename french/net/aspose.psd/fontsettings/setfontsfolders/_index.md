## FontSettings.SetFontsFolders method

Définit les dossiers d'où les polices TrueType sont chargées et efface toutes les polices chargées. Aucun contrôle n'est effectué sur les dossiers de polices.

```csharp
public static void SetFontsFolders(string[] fontsFolders, bool recursive)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| fontsFolders | String[] | Les dossiers de polices. |
| récursif | Booléen | si défini sur `true` [recursive]. |
