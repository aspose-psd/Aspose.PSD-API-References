## Figure.IsClosed property

Obtient ou définit une valeur indiquant si cette figure est fermée. Une figure fermée ne fera une différence que dans le cas où les formes de la première et de la dernière figure sont continues. Dans ce cas, le premier point de la première forme sera relié par une ligne droite au dernier point de la dernière forme.

```csharp
public bool IsClosed { get; set; }
```

### Property Value

`True` si cette figure est fermée ; sinon, `false`.
