## LineCap enumeration

Spécifie les styles de terminaison disponibles avec lesquels un objet [`Pen`](../pen/) peut terminer une ligne.

```csharp
public enum LineCap
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Flat | `0` | Spécifie une terminaison de ligne plate. |
| Square | `1` | Spécifie une terminaison de ligne carrée. |
| Round | `2` | Spécifie une terminaison de ligne ronde. |
| Triangle | `3` | Spécifie une terminaison de ligne triangulaire. |
| NoAnchor | `16` | Spécifie aucune ancre. |
| SquareAnchor | `17` | Spécifie une terminaison de ligne à ancre carrée. |
| RoundAnchor | `18` | Spécifie une terminaison d'ancre ronde. |
| DiamondAnchor | `19` | Spécifie une terminaison d'ancre en diamant. |
| ArrowAnchor | `20` | Spécifie une terminaison d'ancre en forme de flèche. |
| AnchorMask | `240` | Spécifie une terminaison de ligne personnalisée. |
| Custom | `255` | Spécifie un masque utilisé pour vérifier si une terminaison de ligne est une terminaison d'ancre. |
