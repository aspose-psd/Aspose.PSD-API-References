## SizeF Inequality operator

Vérifie si deux structures [`SizeF`](../) sont différentes.

```csharp
public static bool operator !=(SizeF size1, SizeF size2)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| size1 | SizeF | La structure [`SizeF`](../) à gauche de l'opérateur d'inégalité. |
| size2 | SizeF | La structure [`SizeF`](../) à droite de l'opérateur d'inégalité. |

### Valeur de retour

Cet opérateur renvoie vrai si *size1* et *size2* diffèrent soit en largeur, soit en hauteur ; faux si *size1* et *size2* sont égaux.
