## Color.IsKnownColor property

Obtient une valeur indiquant si cette structure [`Color`](../) est une couleur prédéfinie. Les couleurs prédéfinies sont représentées par les éléments de l'énumération [`KnownColor`](../../knowncolor/).

```csharp
public bool IsKnownColor { get; }
```

### Property Value

Vrai si cette [`Color`](../) a été créée à partir d'une couleur prédéfinie en utilisant soit la méthode [`FromName`](../fromname/), soit la méthode [`FromKnownColor`](../fromknowncolor/); sinon, faux.
