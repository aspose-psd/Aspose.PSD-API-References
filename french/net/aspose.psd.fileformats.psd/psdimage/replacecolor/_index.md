## PsdImage.ReplaceColor method

Remplace une couleur par une autre avec une différence autorisée et préserve la valeur alpha originale pour conserver des bords lisses.

```csharp
public override void ReplaceColor(int oldColorArgb, byte oldColorDiff, int newColorArgb)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| oldColorArgb | Int32 | Valeur ARGB de l'ancienne couleur à remplacer. |
| oldColorDiff | Octet | Différence autorisée dans l'ancienne couleur pour pouvoir élargir la teinte de la couleur remplacée. |
| newColorArgb | Int32 | Valeur ARGB de la nouvelle couleur pour remplacer l'ancienne couleur. |
