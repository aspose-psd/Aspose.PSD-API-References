## PsdImage.HasTransparencyData property

Obtient ou définit une valeur indiquant si le premier canal alpha contient les données de transparence pour le résultat fusionné lors de la spécification des données de calques.

```csharp
public bool HasTransparencyData { get; set; }
```

### Property Value

`true` si le premier canal alpha contient les données de transparence pour le résultat fusionné lors de la spécification des données de calques ; sinon, `false`.
