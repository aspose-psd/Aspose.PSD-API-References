## RectangleProjectedShape class

Représente une forme projetée sur un rectangle orienté dans une direction particulière. Spécifiée par quatre points pouvant être tournés dans l'espace tout en conservant la même longueur des arêtes et 90 degrés entre les arêtes adjacentes.

public abstract class RectangleProjectedShape : Shape
