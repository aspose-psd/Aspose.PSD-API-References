| [BezierShape](./beziershape/) | Représente une spline de Bézier. |
| [CurveShape](./curveshape/) | Représente une forme de spline courbée. |
| [EllipseShape](./ellipseshape/) | Représente une forme d'ellipse. |
| [PieShape](./pieshape/) | Représente une forme de secteur. |
| [PolygonShape](./polygonshape/) | Représente une forme de polygone. |
| [RectangleProjectedShape](./rectangleprojectedshape/) | Représente une forme projetée sur un rectangle orienté dans une direction particulière. Spécifiée par quatre points pouvant être tournés dans l'espace tout en conservant la même longueur des arêtes et 90 degrés entre les arêtes adjacentes. |
| [RectangleShape](./rectangleshape/) | Représente une forme rectangulaire. |
| [TextShape](./textshape/) | Représente une forme de texte. |
