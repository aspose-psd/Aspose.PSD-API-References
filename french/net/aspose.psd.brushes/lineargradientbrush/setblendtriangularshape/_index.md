## SetBlendTriangularShape(float) {#setblendtriangularshape}

Crée un dégradé linéaire avec une couleur centrale et une décroissance linéaire vers une seule couleur aux deux extrémités.

```csharp
public void SetBlendTriangularShape(float focus)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| focus | Single | Une valeur comprise entre 0 et 1 qui spécifie le centre du dégradé (le point où le dégradé est composé uniquement de la couleur de fin). |

## SetBlendTriangularShape(float, float) {#setblendtriangularshape_1}

Crée un dégradé linéaire avec une couleur centrale et une décroissance linéaire vers une seule couleur aux deux extrémités.

```csharp
public void SetBlendTriangularShape(float focus, float scale)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| focus | Single | Une valeur comprise entre 0 et 1 qui spécifie le centre du dégradé (le point où le dégradé est composé uniquement de la couleur de fin). |
| scale | Single | Une valeur comprise entre 0 et 1 qui spécifie la rapidité avec laquelle les couleurs s’atténuent de la couleur de départ vers le *focus* (couleur de fin). |
