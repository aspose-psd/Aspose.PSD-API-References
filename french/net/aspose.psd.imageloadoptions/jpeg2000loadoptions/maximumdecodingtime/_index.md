## Jpeg2000LoadOptions.MaximumDecodingTime property

Obtient ou définit le temps maximal de décodage en secondes (cette option peut être utilisée sur des machines très lentes ou à faible mémoire pour éviter le blocage du processus sur des images très grandes - résolution supérieure à 5500x6500 pixels).

```csharp
public int MaximumDecodingTime { get; set; }
```

### Property Value

Le temps de décodage maximal.
