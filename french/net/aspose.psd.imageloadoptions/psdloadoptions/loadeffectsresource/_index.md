## PsdLoadOptions.LoadEffectsResource property

Obtient ou définit une valeur indiquant si [load effects resource] (par défaut la ressource n'est pas chargée). Lorsque cette option est définie, seuls les effets pris en charge seront rendus dans l'image fusionnée finale.

```csharp
public bool LoadEffectsResource { get; set; }
```

### Property Value

`true` si [load effects resource] ; sinon, `false`.
