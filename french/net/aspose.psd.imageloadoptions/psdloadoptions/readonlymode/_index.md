## PsdLoadOptions.ReadOnlyMode property

Obtient ou définit une valeur indiquant si [use read only mode]. Il s'agit d'un mode lecture seule, pris en charge pour une compatibilité identique avec Adobe Photoshop. Lorsque cette option est activée, toutes les modifications appliquées aux calques ne seront pas enregistrées dans l'image finale. Toutes les données proviennent de la section ImageData, ce qui la rend identique à Photoshop. Par défaut, toutes les images chargées ne sont pas compatibles identiquement avec Adobe Photoshop.

```csharp
public bool ReadOnlyMode { get; set; }
```

### Property Value

`true` si [utiliser le mode de compatibilité Photoshop]; sinon, `false`.
