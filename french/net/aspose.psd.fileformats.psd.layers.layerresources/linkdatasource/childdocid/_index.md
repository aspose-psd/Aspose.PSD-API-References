## LinkDataSource.ChildDocId property

Obtient ou définit l'identifiant du document enfant dans la source de données liFE ou liFD de la ressource Lnk2 / LnkE Adobe® Photoshop®.

```csharp
public string ChildDocId { get; set; }
```
