## LinkDataSource.IsLibraryLink property

Obtient une valeur indiquant si cette source de données de lien PSD se lie à l'élément Adobe® Photoshop® СС Library.

```csharp
public bool IsLibraryLink { get; }
```

### Property Value

`true` si cette instance est un lien de bibliothèque Adobe® Photoshop® СС ; sinon, `false`.
