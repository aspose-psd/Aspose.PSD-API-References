## LayerLockType enumeration

Options de verrouillage du calque

```csharp
[Flags]
public enum LayerLockType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Pas de verrouillage de calque |
| LockTransparentPixels | `1` | Verrouillage partiel d'un calque - Limite l'édition aux parties opaques du calque. Cette option est équivalente à l'option Préserver la transparence dans les versions antérieures de Photoshop. |
| LockImagePixels | `2` | Verrouillage partiel d'un calque - Empêche la modification des pixels du calque à l'aide des outils de peinture. |
| LockPosition | `4` | Verrouillage partiel d'un calque - Empêche le déplacement des pixels du calque. |
| LockAll | `7` | Verrouiller toutes les propriétés d'un calque |
