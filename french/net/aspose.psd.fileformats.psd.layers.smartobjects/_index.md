L'espace de noms contient une API pour manipuler les données des calques d'objet intelligent

## Classes

| Classe | Description |
| --- | --- |
| [SmartObjectLayer](./smartobjectlayer/) | Définit la classe SmartObjectLayer qui contient un objet intelligent intégré dans le fichier PSD ou lié dans le fichier externe. Avec les objets intelligents, vous pouvez : Effectuer des transformations non destructives. Vous pouvez mettre à l'échelle, faire pivoter, incliner, déformer, appliquer une transformation de perspective ou déformer une couche sans perdre les données ou la qualité de l'image originale, car les transformations n'affectent pas les données d'origine. Travailler avec des données vectorielles, telles que des illustrations vectorielles d'Illustrator, qui seraient autrement rasterisées. Effectuer un filtrage non destructif. Vous pouvez modifier les filtres appliqués aux objets intelligents à tout moment. Modifier un objet intelligent et mettre à jour automatiquement toutes ses instances liées. Appliquer un masque de calque qui est soit lié, soit non lié au calque d'objet intelligent. Essayer diverses conceptions avec des images de substitution à basse résolution que vous remplacerez plus tard par les versions finales. Dans Adobe Photoshop, vous pouvez intégrer le contenu d'une image dans un document PSD. Plus d'informations ici : [https://helpx.adobe.com/photoshop/using/create-smart-objects.html](https://helpx.adobe.com/photoshop/using/create-smart-objects.html) Un calque contenant un objet intelligent intégré contient des ressources placées (PlLd) et SoLd avec les propriétés de l'objet intelligent. La ressource PlLd peut être seule pour les versions PSD antérieures à 10. Ces ressources contiennent l'UniqueId du LiFdDataSource dans la ressource globale Lnk2Resource avec le nom de fichier intégré et d'autres paramètres, y compris le contenu du fichier intégré au format original sous forme de tableau d'octets. |
