## ExifOrientation enumeration

Orientation d'image Exif.

```csharp
public enum ExifOrientation
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| TopLeft | `1` | En haut à gauche. Orientation par défaut. |
| TopRight | `2` | En haut à droite. Inversé horizontalement. |
| BottomRight | `3` | En bas à droite. Tourné de 180 degrés. |
| BottomLeft | `4` | En bas à gauche. Tourné de 180 degrés puis inversé horizontalement. |
| LeftTop | `5` | En haut à gauche. Tourné de 90 degrés dans le sens antihoraire puis inversé horizontalement. |
| RightTop | `6` | En haut à droite. Tourné de 90 degrés dans le sens horaire. |
| RightBottom | `7` | En bas à droite. Tourné de 90 degrés dans le sens horaire puis inversé horizontalement. |
| LeftBottom | `8` | En bas à gauche. Tourné de 90 degrés dans le sens antihoraire. |
