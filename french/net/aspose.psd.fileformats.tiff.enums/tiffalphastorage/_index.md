## TiffAlphaStorage enumeration

Spécifie le stockage alpha pour les documents TIFF.

```csharp
public enum TiffAlphaStorage : ushort
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Unspecified | `0` | L'alpha n'est pas spécifié et est stocké dans le fichier tiff. |
| Associated | `1` | La valeur alpha est stockée sous forme prémultipliée. Lors de la restauration de l'alpha, il peut y avoir des effets d'arrondi et la valeur restaurée peut différer de l'originale. |
| Unassociated | `2` | La valeur alpha est stockée sous forme non associée. Cela signifie que l'alpha restauré est exactement identique à celui qui a été stocké dans le tiff. |
