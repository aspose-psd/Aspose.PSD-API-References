L'espace de noms contient des classes et méthodes d'assistance liées à XMP.

## Classes

| Classe | Description |
| --- | --- |
| [LangAlt](./langalt/) | Représente l'alternative de langue XMP. |
| [Namespaces](./namespaces/) | Contient les espaces de noms utilisés dans le document RDF. |
| [XmpArray](./xmparray/) | Représente le tableau Xmp dans [`XmpPackage`](../aspose.psd.xmp/xmppackage/). TODO: le tableau peut contenir des données complexes. |
| [XmpArrayHelper](./xmparrayhelper/) | La classe d'assistance pour le traitement de la logique RDF. |
| [XmpElementBase](./xmpelementbase/) | Représente l'élément xmp de base contenant des attributs. |
| [XmpHeaderPi](./xmpheaderpi/) | Représente l'instruction de traitement de l'en-tête XMP. |
| [XmpMeta](./xmpmeta/) | Représente xmpmeta. Optionnel. Le but de cet élément est d'identifier les métadonnées XMP dans un texte XML général qui pourrait contenir d'autres utilisations non XMP de RDF. |
| [XmpPackage](./xmppackage/) | Définit la classe XmpPackage qui représente l'abstraction de base pour le paquet XMP. |
| [XmpPackageBaseCollection](./xmppackagebasecollection/) | Représente la collection de [`XmpPackage`](../aspose.psd.xmp/xmppackage/). |
| [XmpPacketWrapper](./xmppacketwrapper/) | Contient le paquet xmp sérialisé incluant l'en-tête et le pied de page. |
| [XmpRdfRoot](./xmprdfroot/) | Représente l'élément rdf:RDF. Un seul paquet XMP doit être sérialisé en utilisant un seul élément XML rdf:RDF. Le contenu de l'élément rdf:RDF doit se composer de zéro ou plusieurs éléments rdf:Description. |
| [XmpTrailerPi](./xmptrailerpi/) | Représente l'instruction de traitement du trailer XMP. |
## Interfaces

| Interface | Description |
