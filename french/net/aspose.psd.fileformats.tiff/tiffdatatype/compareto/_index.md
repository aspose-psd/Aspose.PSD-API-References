## TiffDataType.CompareTo method

Compare l'instance actuelle avec un autre objet du même type et renvoie un entier qui indique si l'instance actuelle précède, suit ou se trouve à la même position dans l'ordre de tri que l'autre objet.

```csharp
public int CompareTo(object obj)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| obj | Object | Un objet à comparer avec cette instance. |

### Valeur de retour

Un entier signé de 32 bits qui indique l'ordre relatif des objets comparés. La valeur de retour a les significations suivantes : Valeur Signification Inférieur à zéro Cette instance est inférieure à *obj*. Zéro Cette instance est égale à *obj*. Supérieur à zéro Cette instance est supérieure à *obj*.
