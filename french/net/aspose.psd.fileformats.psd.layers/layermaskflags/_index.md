## LayerMaskFlags enumeration

Les indicateurs du masque de calque

```csharp
[Flags]
public enum LayerMaskFlags : byte
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Aucun indicateur défini. |
| RelativeToLayer | `1` | La position est relative au calque. |
| Disabled | `2` | Le masque de calque est désactivé. |
| InvertedWhenBlending | `4` | Inverser le masque de calque lors du mélange. |
| UserMaskFromRenderingOtherData | `8` | Indique que le masque utilisateur provient réellement du rendu d'autres données. |
| UserOrVectorMasksHaveParameters | `10` | Indique que le(s) masque(s) utilisateur et/ou vecteur ont des paramètres appliqués. |
