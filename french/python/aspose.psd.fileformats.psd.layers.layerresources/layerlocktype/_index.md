Options de verrouillage du calque

**Module:** [aspose.psd.fileformats.psd.layers.layerresources](/psd/python-net/aspose.psd.fileformats.psd.layers.layerresources/)

**Full Name:** aspose.psd.fileformats.psd.layers.layerresources.LayerLockType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Description** |
| :- | :- |
| LOCK_ALL | Verrouiller toutes les propriétés d’un calque |
| LOCK_IMAGE_PIXELS | Verrouillage partiel d’un calque  - Empêche la modification des pixels du calque à l’aide des outils de peinture. |
| LOCK_POSITION | Verrouillage partiel d’un calque  - Empêche le déplacement des pixels du calque. |
| LOCK_TRANSPARENT_PIXELS | Verrouillage partiel d’un calque  - Limite l’édition aux parties opaques du calque. <br/>            Cette option est équivalente à l’option Préserver la transparence dans les versions antérieures de Photoshop. |
| NONE | Aucun verrouillage de calque |
