Spécifie le stockage alpha pour les documents TIFF.

**Module:** [aspose.psd.fileformats.tiff.enums](/psd/python-net/aspose.psd.fileformats.tiff.enums/)

**Full Name:** aspose.psd.fileformats.tiff.enums.TiffAlphaStorage

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Description** |
| :- | :- |
| ASSOCIATED | La valeur alpha est stockée sous forme prémultipliée. Lors de la restauration de l'alpha, il peut y avoir des effets d'arrondi et la valeur restaurée peut différer de l'originale. |
| UNASSOCIATED | La valeur alpha est stockée sous forme non associée. Cela signifie que l'alpha restauré est exactement identique à celui qui a été stocké dans le TIFF. |
| UNSPECIFIED | L'alpha n'est pas spécifié et est stocké dans le fichier tiff. |
