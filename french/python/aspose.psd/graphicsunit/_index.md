Spécifie l'unité de mesure des données fournies.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.GraphicsUnit

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Description** |
| :- | :- |
| AFFICHAGE | Spécifie l'unité de mesure du dispositif d'affichage. Typiquement des pixels pour les écrans vidéo, et 1/100 de pouce pour les imprimantes. |
| DOCUMENT | Spécifie l'unité de document (1/300 de pouce) comme unité de mesure. |
| POUCE | Spécifie le pouce comme unité de mesure. |
| MILLIMÈTRE | Spécifie le millimètre comme unité de mesure. |
| PIXEL | Spécifie un pixel de dispositif comme unité de mesure. |
| POINT | Spécifie le point d'une imprimante (1/72 de pouce) comme unité de mesure. |
| MONDE | Spécifie l'unité du système de coordonnées du monde comme unité de mesure. |
