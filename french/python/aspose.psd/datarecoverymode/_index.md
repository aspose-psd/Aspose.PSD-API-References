Le mode de récupération des données.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.DataRecoveryMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Description** |
| :- | :- |
| CONSISTENT_RECOVER | Le mode de récupération cohérent tente de récupérer toutes les données tant que la corruption ne casse pas le format du fichier et permet un traitement ultérieur correct. |
| MAXIMAL_RECOVER | Le mode de récupération maximal récupère toutes les données même si le format du fichier possède une structure corrompue et que le traitement ultérieur peut produire des effets inattendus. |
| NONE | Aucune récupération de données n'est implicite. Chaque fois que le format du fichier contient des données corrompues, l'exception appropriée est levée. |
