Spécifie le niveau de conformité PDF du fichier de sortie.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.PdfComplianceVersion

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Description** |
| :- | :- |
| PDF15 | Le fichier de sortie sera conforme à PDF 1.5. |
| PDF_A1A | Le fichier de sortie sera conforme à PDF/A-1a. |
| PDF_A1B | Le fichier de sortie sera conforme à PDF/A-1b. |
