Spécifie le type d'affichage des préfixes de raccourci clavier liés au texte.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.HotkeyPrefix

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Description** |
| :- | :- |
| MASQUER | Ne pas afficher le préfixe du raccourci clavier. |
| NONE | Pas de préfixe de raccourci clavier. |
| AFFICHER | Afficher le préfixe du raccourci clavier. |
