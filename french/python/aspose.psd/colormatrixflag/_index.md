Spécifie les types d'images et de couleurs qui seront affectés par les paramètres d'ajustement des couleurs et des niveaux de gris d'un [ImageAttributes](/psd/python-net/aspose.psd/imageattributes/).

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorMatrixFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Description** |
| :- | :- |
| ALT_GRAYS | Seules les nuances de gris sont ajustées. |
| PAR DÉFAUT | Toutes les valeurs de couleur, y compris les nuances de gris, sont ajustées par la même matrice d'ajustement des couleurs. |
| SKIP_GRAYS | Toutes les couleurs sont ajustées, mais les nuances de gris ne le sont pas. Une nuance de gris est toute couleur dont les composantes rouge, verte et bleue ont la même valeur. |
