Le module fournit des classes d'assistance et des méthodes pour travailler avec différents types de pinceaux.

## **Classes**
| **Classe** | **Description** |
| :- | :- |
| [HatchBrush](/psd/python-net/aspose.psd.brushes/hatchbrush/) | Définit un pinceau rectangulaire avec un style hachuré, une couleur de premier plan et une couleur d'arrière-plan. Cette classe ne peut pas être héritée. |
| [LinearGradientBrush](/psd/python-net/aspose.psd.brushes/lineargradientbrush/) | Encapsule un [Brush](/psd/python-net/aspose.psd/brush/) avec un dégradé linéaire. Cette classe ne peut pas être héritée. |
| [LinearGradientBrushBase](/psd/python-net/aspose.psd.brushes/lineargradientbrushbase/) | Représente un [Brush](/psd/python-net/aspose.psd/brush/) avec des capacités de dégradé et des propriétés appropriées. |
| [LinearMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/linearmulticolorgradientbrush/) | Représente un [Brush](/psd/python-net/aspose.psd/brush/) avec un dégradé linéaire défini par plusieurs couleurs et des positions appropriées. Cette classe ne peut pas être héritée. |
| [PathGradientBrush](/psd/python-net/aspose.psd.brushes/pathgradientbrush/) | Encapsule un objet [Brush](/psd/python-net/aspose.psd/brush/) avec un dégradé. Cette classe ne peut pas être héritée. |
| [PathGradientBrushBase](/psd/python-net/aspose.psd.brushes/pathgradientbrushbase/) | Représente un [Brush](/psd/python-net/aspose.psd/brush/) avec une fonctionnalité de dégradé de chemin de base. |
| [PathMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/pathmulticolorgradientbrush/) | Encapsule un objet [Brush](/psd/python-net/aspose.psd/brush/) avec un dégradé. Cette classe ne peut pas être héritée. |
| [SolidBrush](/psd/python-net/aspose.psd.brushes/solidbrush/) | Le pinceau solide est destiné à dessiner continuellement avec une couleur spécifique. Cette classe ne peut pas être héritée. |
| [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) | Chaque propriété de la classe [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) est un objet [Brush](/psd/python-net/aspose.psd/brush/) qui utilise une image pour remplir l'intérieur d'une forme. Cette classe ne peut pas être héritée. |
| [TransformBrush](/psd/python-net/aspose.psd.brushes/transformbrush/) | Un [Brush](/psd/python-net/aspose.psd/brush/) avec des capacités de transformation. |
