Spécifie différentes méthodes de compression bitmap.

**Module:** [aspose.psd.fileformats.bmp](/psd/python-net/aspose.psd.fileformats.bmp/)

**Full Name:** aspose.psd.fileformats.bmp.BitmapCompression

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Description** |
| :- | :- |
| ALPHA_BITFIELDS | Champs de bits RGBA. Ne peut être utilisé qu'avec des images bitmap de 16 ou 32 bits par pixel. |
| BITFIELDS | Champs de bits RGB. Ne peut être utilisé qu'avec des images bitmap de 16 et 32 bits/pixel. |
| DXT1 | Compression DXT1. L'image bitmap contient une texture. |
| JPEG | Compression JPEG. L'image bitmap contient une image JPEG. |
| PNG | Compression PNG. L'image bitmap contient une image PNG. |
| RGB | Pas de compression. |
| RLE4 | Compression RLE 4 bits/pixel. Ne peut être utilisé qu'avec des images bitmap de 4 bits/pixel. |
| RLE8 | Compression RLE 8 bits/pixel. Ne peut être utilisé qu'avec des images bitmap de 8 bits/pixel. |
