Le module contient des classes et méthodes d'aide liées à XMP.

## **Classes**
| **Classe** | **Description** |
| :- | :- |
| [IXmlValue](/psd/python-net/aspose.psd.xmp/ixmlvalue/) | Convertit les valeurs xmp en représentation de chaîne XML. |
| [LangAlt](/psd/python-net/aspose.psd.xmp/langalt/) | Représente l'alternative de langue XMP. |
| [Namespaces](/psd/python-net/aspose.psd.xmp/namespaces/) | Contient les espaces de noms utilisés dans le document RDF. |
| [XmpArray](/psd/python-net/aspose.psd.xmp/xmparray/) | Représente le tableau Xmp dans [XmpPackage](/psd/python-net/aspose.psd.xmp/xmppackage/). TODO : le tableau peut contenir des données complexes. |
| [XmpArrayHelper](/psd/python-net/aspose.psd.xmp/xmparrayhelper/) | La classe d'assistance pour le traitement de la logique RDF. |
| [XmpElementBase](/psd/python-net/aspose.psd.xmp/xmpelementbase/) | Représente l'élément xmp de base contenant des attributs. |
| [XmpHeaderPi](/psd/python-net/aspose.psd.xmp/xmpheaderpi/) | Représente l'instruction de traitement de l'en-tête XMP. |
| [XmpMeta](/psd/python-net/aspose.psd.xmp/xmpmeta/) | Représente xmpmeta. Optionnel.<br/>            Le but de cet élément est d'identifier les métadonnées XMP au sein d'un texte XML général qui pourrait contenir d'autres utilisations non XMP de RDF. |
| [XmpPackage](/psd/python-net/aspose.psd.xmp/xmppackage/) | Définit la classe XmpPackage qui représente l'abstraction de base pour le paquet XMP. |
| [XmpPackageBaseCollection](/psd/python-net/aspose.psd.xmp/xmppackagebasecollection/) | Représente la collection de [XmpPackage](/psd/python-net/aspose.psd.xmp/xmppackage/). |
| [XmpPacketWrapper](/psd/python-net/aspose.psd.xmp/xmppacketwrapper/) | Contient le paquet xmp sérialisé incluant l'en-tête et la bande-annonce. |
| [XmpRdfRoot](/psd/python-net/aspose.psd.xmp/xmprdfroot/) | Représente l'élément rdf:RDF.<br/>            Un seul paquet XMP doit être sérialisé en utilisant un seul élément XML rdf:RDF. Le contenu de l'élément rdf:RDF doit se composer uniquement de zéro ou plusieurs éléments rdf:Description. |
| [XmpTrailerPi](/psd/python-net/aspose.psd.xmp/xmptrailerpi/) | Représente l'instruction de traitement du trailer XMP. |
