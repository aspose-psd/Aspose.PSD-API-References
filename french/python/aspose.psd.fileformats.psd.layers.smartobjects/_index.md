| [SmartObjectLayer](/psd/python-net/aspose.psd.fileformats.psd.layers.smartobjects/smartobjectlayer/) | Définit la classe SmartObjectLayer qui contient un objet intelligent intégré dans le fichier PSD ou un objet intelligent lié dans le fichier externe.<br/>            Avec les objets intelligents, vous pouvez :<br/>            Effectuer des transformations non destructives. Vous pouvez mettre à l'échelle, faire pivoter, incliner, déformer, appliquer une transformation de perspective ou déformer une couche<br/>            sans perdre les données d'image originales ni la qualité, car les transformations n'affectent pas les données d'origine.<br/>            Travailler avec des données vectorielles, telles que des illustrations vectorielles d'Illustrator, qui seraient autrement rasterisées.<br/>            Effectuer un filtrage non destructif. Vous pouvez modifier les filtres appliqués aux objets intelligents à tout moment.<br/>            Modifier un objet intelligent et mettre à jour automatiquement toutes ses instances liées.<br/>            Appliquer un masque de calque qui est soit lié, soit non lié au calque d'objet intelligent.<br/>            Essayer diverses conceptions avec des images de substitution à basse résolution que vous remplacerez plus tard par les versions finales.<br/>            Dans Adobe® Photoshop®, vous pouvez intégrer le contenu d'une image dans un document PSD.<br/>            Plus d'informations ici : <see href="https://helpx.adobe.com/photoshop/using/create-smart-objects.html" /><br/>            Un calque contenant un objet intelligent intégré possède des ressources placées (PlLd) et SoLd avec les propriétés de l'objet intelligent.<br/>            La ressource PlLd peut être seule pour les versions PSD antérieures à 10.<br/>            Ces ressources contiennent l'UniqueId du LiFdDataSource dans le Lnk2Resource global avec le nom de fichier intégré<br/>            et d'autres paramètres, y compris le contenu du fichier intégré au format original sous forme de tableau d'octets. |
