Cette énumération décrit les types d'événements de progression possibles qui peuvent survenir lors des opérations de traitement d'image

**Module:** [aspose.psd.progressmanagement](/psd/python-net/aspose.psd.progressmanagement/)

**Full Name:** aspose.psd.progressmanagement.EventType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Member name** | **Description** |
| :- | :- |
| FINALIZATION | La finalisation de l'opération |
| INITIALIZATION | L'initialisation de l'opération |
| PRE_PROCESSING | Le prétraitement |
| PROCESSING | Le traitement |
| RELATIVE_PROGRESS | Progression relative de l'étape actuelle du traitement de l'opération |
| STAGE_CHANGE | La prochaine étape de l'opération a commencé |
