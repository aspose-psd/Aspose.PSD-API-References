## Jpeg2000Options.CompressionRatios property

Получает или задает массив коэффициентов сжатия. Разные коэффициенты сжатия для последовательных слоёв. Указанный коэффициент для каждого уровня качества является желаемым фактором сжатия. Требуется уменьшение коэффициентов.

```csharp
public int[] CompressionRatios { get; set; }
```

### Property Value

Коэффициенты сжатия.
