## GifOptions.DoPaletteCorrection property

Получает или задает значение, указывающее, применяется ли коррекция палитры.

```csharp
public bool DoPaletteCorrection { get; set; }
```

### Property Value

`true`, если коррекция палитры применена; иначе `false`.

## Примечания

Коррекция палитры означает, что при экспорте изображения в GIF цвета исходного изображения будут проанализированы для построения наиболее подходящей палитры (в случае, если палитра изображения отсутствует или не указана в параметрах). Процесс анализа занимает некоторое время, однако результирующее изображение получит оптимальную цветовую палитру, и результат будет визуально лучше.
