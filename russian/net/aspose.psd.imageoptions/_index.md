Пространство имён содержит классы, подходящие для экспорта, сохранения или создания различных форматов файлов.

## Классы

| Класс | Описание |
| --- | --- |
| [BmpOptions](./bmpoptions/) | Параметры создания файлового формата BMP. |
| [CmxRasterizationOptions](./cmxrasterizationoptions/) | параметры экспортёра CMX. |
| [GifOptions](./gifoptions/) | Параметры создания файлового формата GIF. |
| [GraphicsOptions](./graphicsoptions/) | Представляет графические параметры для встроенного растрового изображения. |
| [Jpeg2000Options](./jpeg2000options/) | Параметры формата файла Jpeg2000. |
| [JpegOptions](./jpegoptions/) | Параметры создания формата файла jpeg. |
| [MultiPageOptions](./multipageoptions/) | Базовый класс для форматов, поддерживающих несколько страниц. |
| [PdfOptions](./pdfoptions/) | Параметры PDF. |
| [PngOptions](./pngoptions/) | Параметры создания формата файла png. |
| [PsdOptions](./psdoptions/) | Параметры создания формата файла psd. |
| [RdOptimizerSettings](./rdoptimizersettings/) | Класс настроек оптимизатора RD. |
| [RenderResult](./renderresult/) | Представляет информацию с результатами рендеринга. |
| [TiffOptions](./tiffoptions/) | Параметры формата файла tiff. Обратите внимание, что теги ширины и высоты будут перезаписаны при создании изображения параметрами ширины и высоты, поэтому нет необходимости указывать их напрямую. Также обратите внимание, что многие параметры возвращают значение по умолчанию, но это не означает, что параметр установлен явно как значение тега. Чтобы проверить наличие тега, используйте свойство Tags или соответствующий метод IsTagPresent. |
| [TiffOptionsUtils](./tiffoptionsutils/) | Утилитный класс параметров формата файла tiff. |
| [VectorRasterizationOptions](./vectorrasterizationoptions/) | Параметры векторного растеризования. |
