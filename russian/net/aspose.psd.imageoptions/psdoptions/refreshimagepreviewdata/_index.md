## PsdOptions.RefreshImagePreviewData property

Получает или задает значение, указывающее, следует ли [refresh image preview data] — параметр, используемый для максимизации совместимости с другими просмотрщиками PSD‑изображений. Обратите внимание, что отрисовка текстовых слоёв в окончательную компоновку не поддерживается на платформе Compact Framework.

```csharp
public bool RefreshImagePreviewData { get; set; }
```

### Property Value

`true`, если [refresh image preview data]; иначе `false`.
