## LinkDataSource.HasFileOpenDescriptor property

Получает или задает значение, указывающее, содержит ли этот источник данных ссылки дескриптор открытого файла: CompId и OriginalCompId.

```csharp
public bool HasFileOpenDescriptor { get; set; }
```

### Property Value

`true` если у этого экземпляра есть дескриптор открытого файла; иначе `false`.
