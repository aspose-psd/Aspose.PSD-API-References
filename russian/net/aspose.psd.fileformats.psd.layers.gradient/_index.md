Пространство имён обрабатывает формат файлов PSD.

## Классы

| Класс | Описание |
| --- | --- |
| [BaseGradient](./basegradient/) | Базовый класс определения градиента. Содержит общие свойства для обоих типов градиента (сплошного и шумового). |
| [NoiseGradient](./noisegradient/) | Класс определения шумового градиента. |
| [SolidGradient](./solidgradient/) | Настройки эффекта заливки градиентом. |
## Перечисление

| Перечисление | Описание |
| --- | --- |
| [GradientKind](./gradientkind/) | Перечисление типов градиента. |
| [NoiseColorModel](./noisecolormodel/) | Цветовая модель. Когда 'Тип градиента' = 'Шум', мы можем задать 'Цветовую модель' как RGB/SHB/LAB (3/4/6). |
