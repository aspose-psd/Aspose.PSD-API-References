## TransformBrush.IsTransformChanged property

Получает значение, указывающее, были ли трансформации изменены каким-либо образом. Например, установка матрицы трансформации или вызов любого из методов, изменяющих матрицу трансформации. Свойство введено для обратной совместимости с GDI+.

```csharp
public bool IsTransformChanged { get; }
```

### Property Value

`True`, если преобразование было изменено; иначе `false`.
