## SetBlendTriangularShape(float) {#setblendtriangularshape}

Создает градиент с центральным цветом и линейным спадом к одному окружающему цвету.

```csharp
public void SetBlendTriangularShape(float focus)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| фокус | Single | Значение от 0 до 1, указывающее, где вдоль любого радиуса от центра пути к его границе будет находиться центр‑цвет с наивысшей интенсивностью. Значение 1 (по умолчанию) размещает наивысшую интенсивность в центре пути. |

## SetBlendTriangularShape(float, float) {#setblendtriangularshape_1}

Создает градиент с центральным цветом и линейным спадом к каждому окружающему цвету.

```csharp
public void SetBlendTriangularShape(float focus, float scale)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| фокус | Single | Значение от 0 до 1, указывающее, где вдоль любого радиуса от центра пути к его границе будет находиться центр‑цвет с наивысшей интенсивностью. Значение 1 (по умолчанию) размещает наивысшую интенсивность в центре пути. |
| scale | Single | Значение от 0 до 1, определяющее максимальную интенсивность центр‑цвета, смешиваемого с цветом границы. Значение 1 задаёт наивысшую возможную интенсивность центр‑цвета и является значением по умолчанию. |
