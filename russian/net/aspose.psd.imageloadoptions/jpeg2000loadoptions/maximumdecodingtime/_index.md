## Jpeg2000LoadOptions.MaximumDecodingTime property

Получает или задает максимальное время декодирования в секундах (этот параметр можно использовать на очень медленных или малопроизводительных машинах, чтобы предотвратить зависание процесса при работе с очень большими изображениями — разрешение более 5500x6500 пикселей).

```csharp
public int MaximumDecodingTime { get; set; }
```

### Property Value

Максимальное время декодирования.
