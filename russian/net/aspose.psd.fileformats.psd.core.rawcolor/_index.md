Пространство имён содержит иерархию класса PSD RawColor, включая ColorComponent.

## Классы

| Класс | Описание |
| --- | --- |
| [ColorComponent](./colorcomponent/) | Компонент цвета — это абстракция над значением канала и значением канала. Любой цвет состоит из массива ColorComponent. |
| [RawColor](./rawcolor/) | Raw Color Class помогает хранить цвета с любым количеством каналов, любым режимом цвета и любой разрядностью. Обратите внимание, что некоторые внутренние классы могут иметь проблемы с преобразованием RawColor в его родной формат, поэтому, если API предоставляет вам CMYK‑цвет, надежнее использовать предоставленный формат. Также могут быть случаи, когда Raw Color можно преобразовать. |
| [RawColorHelper](./rawcolorhelper/) | Raw Color Helper Class помогает быстрее создавать RawColor, используя предопределённые метаданные каналов. |
