## ExifData.CommonTags property

Получает или задаёт теги, принадлежащие общей секции. Это применяется только к jpeg‑изображениям, в формате tiff вместо этого используются tiffOptions.

```csharp
public TiffDataType[] CommonTags { get; set; }
```

### Property Value

Теги общей секции.
