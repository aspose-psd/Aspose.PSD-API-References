## Layer.IsVisibleInGroup property

Получает значение, указывающее, видим ли этот экземпляр в группе (Если слой не находится в группе, это означает корневую группу).

```csharp
public virtual bool IsVisibleInGroup { get; }
```

### Property Value

`true`, если этот экземпляр видим в группе; иначе `false`.
