## GlobalLayerMaskInfo.Kind property

Получает или задает тип. 0 = выбранный цвет — т.е. инвертированный; 1 = защищенный цвет; 128 = использовать значение, хранящееся для каждого слоя. Это значение предпочтительно. Остальные предназначены для обратной совместимости с бета-версиями.

```csharp
public byte Kind { get; set; }
```
