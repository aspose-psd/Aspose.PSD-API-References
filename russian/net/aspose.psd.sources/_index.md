Пространство имен содержит различные источники потоков, подходящие для входного или выходного потока данных.

## Классы

| Класс | Описание |
| --- | --- |
| [FileCreateSource](./filecreatesource/) | Представляет файловый источник для создания. |
| [FileOpenSource](./fileopensource/) | Представляет файловый источник для открытия. |
| [FileSource](./filesource/) | Представляет файловый источник, способный к манипуляции файлами. |
| [StreamSource](./streamsource/) | Представляет источник потока. |
