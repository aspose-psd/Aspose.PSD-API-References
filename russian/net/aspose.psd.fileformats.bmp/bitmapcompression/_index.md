## BitmapCompression enumeration

Указывает различные методы сжатия битмапа.

```csharp
public enum BitmapCompression : uint
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Rgb | `0` | Без сжатия. |
| Rle8 | `1` | Сжатие RLE 8‑бит/пиксель. Может использоваться только с 8‑битными/пиксельными битмапами. |
| Rle4 | `2` | Сжатие RLE 4‑бит/пиксель. Может использоваться только с 4‑битными/пиксельными битмапами. |
| Bitfields | `3` | RGB-битовые поля. Может использоваться только с растровыми изображениями 16 и 32 бита на пиксель. |
| Jpeg | `4` | Сжатие JPEG. Растровое изображение содержит JPEG‑изображение. |
| Png | `5` | Сжатие PNG. Растровое изображение содержит PNG‑изображение. |
| AlphaBitfields | `6` | RGBA-битовые поля. Может использоваться только с растровыми изображениями 16 и 32 бита на пиксель. |
