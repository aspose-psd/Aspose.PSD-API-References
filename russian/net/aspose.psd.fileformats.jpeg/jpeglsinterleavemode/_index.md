## JpegLsInterleaveMode enumeration

Определяет режим чередования для многокомпонентных (цветных) пиксельных данных.

```csharp
public enum JpegLsInterleaveMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Данные кодируются и сохраняются по компоненту за компонентом: RRRGGGBBB. |
| Line | `1` | Режим чередования — по строкам. Полная строка каждого компонента кодируется перед переходом к следующей строке. |
| Sample | `2` | Данные кодируются и сохраняются по образцу. Для цветных изображений это формат типа RGBRGBRGB. |
