## VscgResource.KeyForData property

Получает целочисленный ключ, определяющий, какой тип настроек заливки хранится в ресурсе: * Color - 0x536f436f - SoCoResource.TypeToolKey * Gradient - 0x4764466c - GdFlResource.TypeToolKey * Pattern - 0x5074466c - PtFlResource.TypeToolKey Предупреждение! Значение свойства KeyForData должно соответствовать типу настроек заливки, хранящихся в структурах Items.

```csharp
public int KeyForData { get; }
```
