Пространство имен содержит различные формы, объединённые из сегментов формы.

## Классы

| Класс | Описание |
| --- | --- |
| [ArcShape](./arcshape/) | Представляет дуговую форму. |
| [BezierShape](./beziershape/) | Представляет сплайн Безье. |
| [CurveShape](./curveshape/) | Представляет изогнутую форму сплайна. |
| [EllipseShape](./ellipseshape/) | Представляет форму эллипса. |
| [PieShape](./pieshape/) | Представляет форму сектора. |
| [PolygonShape](./polygonshape/) | Представляет форму многоугольника. |
| [RectangleProjectedShape](./rectangleprojectedshape/) | Представляет форму, проецируемую на прямоугольник, повернутый в определённую ориентацию. Задаётся четырьмя точками, которые могут вращаться в пространстве, сохраняя одинаковую длину сторон и 90‑градусный угол между соседними сторонами. |
| [RectangleShape](./rectangleshape/) | Представляет прямоугольную форму. |
| [TextShape](./textshape/) | Представляет текстовую форму. |
