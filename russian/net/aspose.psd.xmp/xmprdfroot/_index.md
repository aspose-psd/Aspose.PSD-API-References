## XmpRdfRoot class

Представляет элемент rdf:RDF. Один пакет XMP должен быть сериализован с использованием единственного XML‑элемента rdf:RDF. Содержание элемента rdf:RDF должно состоять только из нуля или более элементов rdf:Description.

public sealed class XmpRdfRoot : XmpElementBase, IXmlValue
