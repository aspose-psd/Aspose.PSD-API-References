## PsdImage.HorizontalResolution property

Получает или задает горизонтальное разрешение в пикселях на дюйм этого [`PsdImage`](../).

```csharp
public override double HorizontalResolution { get; set; }
```

### Property Value

Горизонтальное разрешение.

### Исключения

| исключение | условие |
| --- | --- |
| [PsdImageException](../../../aspose.psd.coreexceptions.imageformats/psdimageexception/) | Ресурс ResolutionInfo не найден, и невозможно установить правильное разрешение |

## Примечания

Значение по умолчанию для PSD равно 72, поэтому если [`ResolutionInfoResource`](../../../aspose.psd.fileformats.psd.resources/resolutioninforesource/) не найден, возвращается это значение.
