## SplitStreamContainer.Save method

```csharp
public override void Save(Stream destinationStream, int bufferSize, long length)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| destinationStream | Stream | Поток, в который сохраняются данные. |
| bufferSize | Int32 | Размер буфера. По умолчанию используется значение !:ReadWriteBytesCount. |
| length | Int64 | Длина данных потока для копирования. По умолчанию длина устанавливается в значение [`Length`](../length/). |
