## ColorAdjustType enumeration

```csharp
public enum ColorAdjustType
```

| Имя | Значение | Описание |
| --- | --- | --- |
| Default | `0` | Информация о коррекции цвета, используемая всеми объектами GDI+, которые не имеют собственной информации о коррекции цвета. |
| Bitmap | `1` | Информация о коррекции цвета для объектов Bitmap. |
| Brush | `2` | Информация о коррекции цвета для объектов Brush. |
| Pen | `3` | Информация о коррекции цвета для объектов Pen. |

| Count | `5` | Указанное количество типов. |
| Any | `6` | Указанное количество типов. |
