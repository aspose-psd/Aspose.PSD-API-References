## DashCap enumeration

Указывает тип графической формы, используемой на обоих концах каждого штриха в пунктирной линии.

```csharp
public enum DashCap
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Flat | `0` | Указывает квадратную заглушку, которая делает квадратные окончания на обоих концах каждого тире. |
| Round | `2` | Указывает круглую заглушку, которая скругляет оба конца каждого тире. |
| Triangle | `3` | Указывает треугольную заглушку, которая образует острые концы на обоих концах каждого тире. |
