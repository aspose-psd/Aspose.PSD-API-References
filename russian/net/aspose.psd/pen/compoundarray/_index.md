## Pen.CompoundArray property

Получает или задает массив значений, определяющий составную ручку. Составная ручка рисует составную линию, состоящую из параллельных линий и промежутков.

```csharp
public float[] CompoundArray { get; set; }
```

### Property Value

Массив действительных чисел, определяющий составной массив. Элементы массива должны быть упорядочены по возрастанию, не менее 0 и не более 1.

### Исключения

| исключение | условие |
| --- | --- |
| ArgumentException | Свойство `CompoundArray` устанавливается для неизменяемого [`Pen`](../), например, возвращаемого классом [`Pen`](../). |
