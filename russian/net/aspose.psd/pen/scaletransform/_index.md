## ScaleTransform(float, float) {#scaletransform}

Масштабирует локальное геометрическое преобразование на указанные коэффициенты. Этот метод добавляет матрицу масштабирования в начало преобразования.

```csharp
public void ScaleTransform(float sx, float sy)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| sx | Single | Коэффициент, на который масштабируется преобразование по оси x. |
| sy | Single | Коэффициент, на который масштабируется преобразование по оси y. |

## ScaleTransform(float, float, MatrixOrder) {#scaletransform_1}

```csharp
public void ScaleTransform(float sx, float sy, MatrixOrder order)
```

| Параметр | Тип | Описание |

| sx | Single | Коэффициент, на который масштабируется преобразование по оси x. |
