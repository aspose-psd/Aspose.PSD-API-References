## RasterImage.UseRawData property

Получает или задает значение, указывающее, следует ли использовать загрузку необработанных данных, когда такая загрузка доступна.

```csharp
public virtual bool UseRawData { get; set; }
```

### Property Value

`true` если используется загрузка необработанных данных, когда она доступна; в противном случае `false`.
