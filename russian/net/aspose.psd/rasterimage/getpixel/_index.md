## RasterImage.GetPixel method

Получает пиксель изображения. Предупреждение о производительности: избегайте использования этого метода для перебора всех пикселей изображения, так как это может привести к значительным проблемам с производительностью. Для более эффективного управления пикселями используйте метод `LoadArgb32Pixels` для одновременного получения всего массива пикселей.

```csharp
public Color GetPixel(int x, int y)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x | Int32 | Координата x пикселя. |
| y | Int32 | Координата y пикселя. |

### Возвращаемое значение

Цвет пикселя для указанного положения.
