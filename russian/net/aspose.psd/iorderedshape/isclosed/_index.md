## IOrderedShape.IsClosed property

Получает или задает значение, указывающее, закрыта ли упорядоченная форма. При обработке закрытой упорядоченной формы начальная и конечная точки не имеют значения.

```csharp
public bool IsClosed { get; set; }
```

### Property Value

`True` если эта упорядоченная фигура замкнута; иначе `false`.
