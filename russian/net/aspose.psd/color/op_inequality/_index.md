## Color Inequality operator

Проверяет, различаются ли две указанные структуры [`Color`](../).

```csharp
public static bool operator !=(Color left, Color right)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| left | Color | Элемент [`Color`](../), который находится слева от оператора неравенства. |
| right | Color | Элемент [`Color`](../), который находится справа от оператора неравенства. |

### Возвращаемое значение

Истина, если две структуры [`Color`](../) различаются; в противном случае — ложь.
