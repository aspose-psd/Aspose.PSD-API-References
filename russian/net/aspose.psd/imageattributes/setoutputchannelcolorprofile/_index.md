## SetOutputChannelColorProfile(string) {#setoutputchannelcolorprofile}

Устанавливает файл цветового профиля канала вывода для категории по умолчанию.

```csharp
public void SetOutputChannelColorProfile(string colorProfileFilename)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| colorProfileFilename | String | Путь к файлу цветового профиля. Если файл цветового профиля находится в каталоге %SystemRoot%\\System32\\Spool\\Drivers\\Color, этот параметр может быть именем файла. В противном случае этот параметр должен быть полным путём к файлу. |
