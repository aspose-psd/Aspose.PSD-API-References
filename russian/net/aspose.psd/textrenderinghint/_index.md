## TextRenderingHint enumeration

Указывает качество рендеринга текста.

```csharp
public enum TextRenderingHint
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| SystemDefault | `0` | Каждый символ отрисовывается с использованием его битмапа глифа, с системным режимом рендеринга по умолчанию. Текст будет отрисован с учётом любых настроек сглаживания шрифтов, выбранных пользователем в системе. |
| SingleBitPerPixelGridFit | `1` | Каждый символ отрисовывается с использованием битмапа глифа. Хинтинг используется для улучшения внешнего вида символов на штрихах и изгибах. |
| SingleBitPerPixel | `2` | Каждый символ отрисовывается с использованием битмапа глифа. Хинтинг не используется. |
| AntiAliasGridFit | `3` | Каждый символ отрисовывается с использованием его сглаженного битмапа глифа с хинтингом. Качество значительно лучше благодаря сглаживанию, но за счёт более высокой нагрузки на производительность. |
| AntiAlias | `4` | Каждый символ отрисовывается с использованием его сглаженного битмапа глифа без хинтинга. Качество лучше благодаря сглаживанию. Различия в ширине штрихов могут быть заметны, поскольку хинтинг отключён. |
| ClearTypeGridFit | `5` | Каждый символ отрисовывается с использованием его битмапа глифа ClearType с хинтингом. Наивысшая настройка качества. Используется для применения возможностей шрифтов ClearType. |
