## GraphicsUnit enumeration

Указывает единицу измерения для заданных данных.

```csharp
public enum GraphicsUnit
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| World | `0` | Указывает единицу измерения системы мировых координат. |
| Display | `1` | Указывает единицу измерения устройства отображения. Обычно пиксели для видеодисплеев и 1/100 дюйма для принтеров. |
| Pixel | `2` | Указывает пиксель устройства как единицу измерения. |
| Point | `3` | Указывает точку принтера (1/72 дюйма) как единицу измерения. |
| Inch | `4` | Указывает дюйм как единицу измерения. |
| Document | `5` | Указывает единицу измерения документа (1/300 дюйма). |
| Millimeter | `6` | Указывает миллиметр как единицу измерения. |
