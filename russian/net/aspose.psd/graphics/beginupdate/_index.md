## Graphics.BeginUpdate method

Начинает кэширование последующих графических операций. Графические эффекты, применяемые после этого, не будут применяться немедленно; вместо этого вызов EndUpdate приведёт к одновременному применению всех эффектов.

```csharp
public void BeginUpdate()
```

## Примечания

Обратите внимание, что эффекты после вызова BeginUpdate не будут применены, если EndUpdate не будет вызван.
