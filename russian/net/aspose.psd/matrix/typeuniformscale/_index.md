## Matrix.TypeUniformScale field

Однородное масштабирование умножает длину векторов на одинаковую величину как по оси x, так и по оси y без изменения угла между векторами. Этот бит флага взаимоисключающ с флагом TypeGeneralScale.

```csharp
public const int TypeUniformScale;
```
