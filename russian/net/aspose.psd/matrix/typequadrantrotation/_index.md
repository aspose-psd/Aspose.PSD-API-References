## Matrix.TypeQuadrantRotation field

Этот бит флага указывает, что преобразование, определённое этим объектом, выполняет вращение квадранта на кратное 90 градусов в дополнение к преобразованиям, указанным другими битами флага. Вращение изменяет углы векторов на одинаковую величину независимо от исходного направления вектора и без изменения длины вектора. Этот бит флага взаимоисключающ с флагом TypeGeneralRotation.

```csharp
public const int TypeQuadrantRotation;
```
