## Point Inequality operator

Сравнивает два объекта [`Point`](../). Результат указывает, различаются ли значения свойств [`X`](../x/) или [`Y`](../y/) у двух объектов [`Point`](../).

```csharp
public static bool operator !=(Point point1, Point point2)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| point1 | Point | Первый [`Point`](../) для сравнения. |
| point2 | Point | Второй [`Point`](../) для сравнения. |

### Возвращаемое значение

True, если значения свойств [`X`](../x/) или [`Y`](../y/) у *point1* и *point2* различаются; иначе — false.
