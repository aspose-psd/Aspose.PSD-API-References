## InterpolationMode enumeration

Перечисление `InterpolationMode` указывает алгоритм, используемый при масштабировании или вращении изображений.

```csharp
public enum InterpolationMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Invalid | `-1` | Недопустимый режим интерполяции. |
| Default | `0` | Указывает режим по умолчанию. |
| Low | `1` | Указывает интерполяцию низкого качества. |
| High | `2` | Указывает интерполяцию высокого качества. |
| Bilinear | `3` | Указывает билинейную интерполяцию. Предфильтрация не выполняется. Этот режим не подходит для уменьшения изображения ниже 50 % от его исходного размера. |
| Bicubic | `4` | Указывает бикубическую интерполяцию. Предфильтрация не выполняется. Этот режим не подходит для уменьшения изображения ниже 25 % от его исходного размера. |
| NearestNeighbor | `5` | Указывает интерполяцию ближайшего соседа. |
| HighQualityBilinear | `6` | Указывает высококачественную билинейную интерполяцию. Выполняется предфильтрация для обеспечения высококачественного уменьшения. |
| HighQualityBicubic | `7` | Указывает высококачественную бикубическую интерполяцию. Выполняется предфильтрация для обеспечения высококачественного уменьшения. Этот режим обеспечивает наивысшее качество преобразованных изображений. |
