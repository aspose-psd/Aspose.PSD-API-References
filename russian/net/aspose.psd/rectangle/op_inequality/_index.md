## Rectangle Inequality operator

Проверяет, отличаются ли две структуры [`Rectangle`](../) по расположению или размеру.

```csharp
public static bool operator !=(Rectangle left, Rectangle right)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| left | Rectangle | Структура [`Rectangle`](../), находящаяся слева от оператора неравенства. |
| right | Rectangle | Структура [`Rectangle`](../), находящаяся справа от оператора неравенства. |

### Возвращаемое значение

Этот оператор возвращает true, если любое из свойств [`X`](../x/), [`Y`](../y/), [`Width`](../width/) или [`Height`](../height/) двух структур [`Rectangle`](../) не равно; в противном случае — false.
