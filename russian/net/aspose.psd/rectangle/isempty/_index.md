## Rectangle.IsEmpty property

Возвращает значение, указывающее, имеют ли все числовые свойства этого [`Rectangle`](../) значение ноль.

```csharp
public bool IsEmpty { get; }
```

### Property Value

Это свойство возвращает true, если свойства [`Width`](../width/), [`Height`](../height/), [`X`](../x/) и [`Y`](../y/) этого [`Rectangle`](../) все имеют значение ноль; в противном случае — false.
