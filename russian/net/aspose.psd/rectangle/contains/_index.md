## Contains(int, int) {#contains_2}

Определяет, содержится ли указанная точка в этой структуре [`Rectangle`](../).

```csharp
public bool Contains(int x, int y)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x | Int32 | Координата x проверяемой точки. |
| y | Int32 | Координата y проверяемой точки. |

### Возвращаемое значение

Этот метод возвращает true, если точка, определённая параметрами *x* и *y*, содержится в этой структуре [`Rectangle`](../); в противном случае false.
