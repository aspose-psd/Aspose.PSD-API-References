## LineCap enumeration

Указывает доступные стили окончаний, которыми объект [`Pen`](../pen/) может завершать линию.

```csharp
public enum LineCap
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Flat | `0` | Указывает плоское окончание линии. |
| Square | `1` | Указывает квадратное окончание линии. |
| Round | `2` | Указывает круглое окончание линии. |
| Triangle | `3` | Указывает треугольное окончание линии. |
| NoAnchor | `16` | Указывает отсутствие привязки. |
| SquareAnchor | `17` | Указывает квадратное окончание линии с привязкой. |
| RoundAnchor | `18` | Указывает круглое окончание с привязкой. |
| DiamondAnchor | `19` | Указывает ромбовидное окончание с привязкой. |
| ArrowAnchor | `20` | Указывает окончание в виде стрелки с привязкой. |
| AnchorMask | `240` | Указывает пользовательское окончание линии. |
| Custom | `255` | Указывает маску, используемую для проверки, является ли окончание линии привязкой. |
