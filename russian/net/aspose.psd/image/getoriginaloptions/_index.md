## Image.GetOriginalOptions method

Получает параметры на основе настроек оригинального файла. Это может быть полезно для сохранения глубины цвета и других параметров оригинального изображения без изменений. Например, если мы загружаем черно‑белое PNG‑изображение с 1 битом на пиксель, а затем сохраняем его с помощью метода [`Save`](../../datastreamsupporter/save/), будет создано PNG‑изображение с 8‑битным цветом на пиксель. Чтобы избежать этого и сохранить PNG‑изображение с 1‑битным цветом, используйте этот метод для получения соответствующих параметров сохранения и передайте их в метод [`Save`](../save/) в качестве второго параметра.

```csharp
public virtual ImageOptionsBase GetOriginalOptions()
```

### Возвращаемое значение

Параметры, основанные на настройках оригинального файла.
