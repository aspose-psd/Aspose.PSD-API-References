## DashStyle enumeration

Указывает стиль пунктирных линий, рисуемых объектом [`Pen`](../pen/).

```csharp
public enum DashStyle
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Solid | `0` | Указывает сплошную линию. |
| Dash | `1` | Указывает линию, состоящую из тире. |
| Dot | `2` | Указывает линию, состоящую из точек. |
| DashDot | `3` | Указывает линию, состоящую из повторяющегося шаблона тире-точка. |
| DashDotDot | `4` | Указывает линию, состоящую из повторяющегося шаблона тире-точка-точка. |
| Custom | `5` | Указывает пользовательский стиль пунктиров, определённый пользователем. |
