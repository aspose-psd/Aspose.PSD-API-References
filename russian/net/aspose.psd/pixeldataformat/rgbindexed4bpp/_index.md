## PixelDataFormat.RgbIndexed4Bpp property

Возвращает [`PixelDataFormat`](../), определённый для индексированных 4‑битных цветов. Индексированное хранение пиксельных данных предназначено для обеспечения хранения и извлечения данных везде, где используется цветовая палитра. Используйте с осторожностью, так как может потребоваться преобразование из одной палитры в другую или из RGBA в индексированную цветовую модель.

```csharp
public static PixelDataFormat RgbIndexed4Bpp { get; }
```

### Property Value

Элемент [`PixelDataFormat`](../) определённый для индексированных 4‑битных цветов.
