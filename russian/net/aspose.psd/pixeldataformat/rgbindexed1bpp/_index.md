## PixelDataFormat.RgbIndexed1Bpp property

Возвращает [`PixelDataFormat`](../), определённый для индексированного 1‑битного цвета. Хранилище индексированных пиксельных данных предназначено для обеспечения хранения и извлечения данных везде, где используется цветовая палитра. Используйте с осторожностью, так как может потребоваться преобразование из одной палитры в другую или из RGBA в индексированную цветовую модель.

```csharp
public static PixelDataFormat RgbIndexed1Bpp { get; }
```
