## PixelDataFormat.RgbIndexed2Bpp property

Возвращает [`PixelDataFormat`](../), определённый для индексированных 2 бит на цвет. Хранилище индексированных пиксельных данных предназначено для обеспечения хранения и получения данных везде, где используется цветовая палитра. Используйте с осторожностью, так как может потребоваться преобразование из одной палитры в другую или из RGBA в индексированную цветовую модель.

public static PixelDataFormat RgbIndexed2Bpp { get; }
