## PixelDataFormat Equality operator

Возвращает результат сравнения на равенство для двух классов [`PixelDataFormat`](../).

```csharp
public static bool operator ==(PixelDataFormat pixelFormat1, PixelDataFormat pixelFormat2)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| pixelFormat1 | PixelDataFormat | Первый [`PixelDataFormat`](../) для сравнения. |
| pixelFormat2 | PixelDataFormat | Второй [`PixelDataFormat`](../) для сравнения. |

### Возвращаемое значение

True если оба *pixelFormat1* и *pixelFormat2* содержат одинаковые данные или оба параметра равны null.
