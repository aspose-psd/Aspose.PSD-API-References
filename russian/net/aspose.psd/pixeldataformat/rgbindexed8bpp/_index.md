## PixelDataFormat.RgbIndexed8Bpp property

Возвращает [`PixelDataFormat`](../), определённый для индексированных 8 бит на цвет. Хранилище индексированных пиксельных данных предназначено для обеспечения хранения и получения данных везде, где используется цветовая палитра. Используйте с осторожностью, так как может потребоваться преобразование из одной палитры в другую или из RGBA в индексированную цветовую модель.

```csharp
public static PixelDataFormat RgbIndexed8Bpp { get; }
```
