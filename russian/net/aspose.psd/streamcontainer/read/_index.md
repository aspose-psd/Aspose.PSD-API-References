## Read(byte[]) {#read}

Читает байты, чтобы заполнить указанный буфер байтов.

```csharp
public virtual int Read(byte[] bytes)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| байты | Byte[] | Байты для заполнения. |

### Возвращаемое значение

Количество считанных байтов. Это значение может быть меньше количества байтов в буфере, если в потоке недостаточно байтов.

## Read(byte[], int, int) {#read_1}

Читает последовательность байтов из текущего потока и перемещает позицию в потоке на количество прочитанных байтов.

```csharp
public virtual int Read(byte[] buffer, int offset, int count)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| буфер | Byte[] | Массив байтов. После возврата этого метода буфер содержит указанный массив байтов, где значения между *offset* и (*offset* + *count* - 1) заменены байтами, считанными из текущего источника. |
| offset | Int32 | Нулевой (отсчёт с нуля) смещение байта в *buffer*, с которого следует начать сохранять данные, считанные из текущего потока. |
| count | Int32 | Максимальное количество байтов, которое будет считано из текущего потока. |

### Возвращаемое значение

Общее количество байтов, считанных в буфер. Оно может быть меньше запрошенного количества байтов, если столько байтов в данный момент недоступно, или равно нулю (0), если достигнут конец потока.
