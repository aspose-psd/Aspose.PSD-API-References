## FontSettings.GetFontsFolders method

Получает копию массива, содержащего список папок, где Aspose.Words ищет TrueType‑шрифты.

```csharp
public static string[] GetFontsFolders()
```

### Возвращаемое значение

Копия текущих расположений шрифтов.

## Примечания

Возвращаемое значение является копией данных, используемых Aspose.Words. Если изменить элементы в возвращённом массиве, это не повлияет на рендеринг документа. Чтобы указать новые расположения шрифтов, используйте метод [`SetFontsFolders`](../setfontsfolders/).
