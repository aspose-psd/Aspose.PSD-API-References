## FontSettings.SetFontsFolders method

Устанавливает папки, из которых загружаются TrueType‑шрифты, и очищает все загруженные шрифты. Проверки папок шрифтов не выполняются.

```csharp
public static void SetFontsFolders(string[] fontsFolders, bool recursive)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| fontsFolders | String[] | Папки шрифтов. |
| рекурсивно | Boolean | если установлено `true` [рекурсивно]. |
