## FontSettings.UpdateFonts method

Обновляет кэш шрифтов для PSD‑файлов, содержащих текстовые слои. Этот метод гарантирует, что шрифты из папки fontsFolder, использующие метод FontSettings.SetFontsFolder(fontsFolder), или после сброса шрифтов с помощью FontSettings.Reset(), будут учитываться при обработке PSD‑файлов. Пожалуйста, вызывайте этот метод каждый раз, когда вызываются FontSettings.SetFontsFolder(fontsFolder) или FontSettings.Reset() для PSD‑изображений. Без вызова этого метода нет гарантии, что шрифты будут обновлены.
