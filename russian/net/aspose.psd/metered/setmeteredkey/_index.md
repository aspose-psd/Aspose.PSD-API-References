## Metered.SetMeteredKey method

Устанавливает публичный и приватный измеряемый ключ. Если вы приобрели измеряемую лицензию, при запуске приложения этот API должен быть вызван, обычно этого достаточно. Однако, если постоянно не удаётся загрузить данные о потреблении и проходит более 24 часов, лицензия будет переключена в статус оценки; чтобы избежать этого, следует регулярно проверять статус лицензии, и если он находится в статусе оценки, вызвать этот API снова.

```csharp
public void SetMeteredKey(string publicKey, string privateKey)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| publicKey | String | публичный ключ |
| privateKey | String | закрытый ключ |
