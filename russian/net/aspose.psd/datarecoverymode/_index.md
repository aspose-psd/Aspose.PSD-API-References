## DataRecoveryMode enumeration

Режим восстановления данных.

```csharp
public enum DataRecoveryMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Восстановление данных не предполагается. Когда формат файла содержит повреждённые данные, выбрасывается соответствующее исключение. |
| ConsistentRecover | `1` | Последовательный режим восстановления пытается восстановить все данные, пока повреждение не нарушает структуру формата файла и позволяет корректную дальнейшую обработку. |
| MaximalRecover | `2` | Максимальный режим восстановления восстанавливает все данные, даже если структура формата файла повреждена, и дальнейшая обработка может привести к непредвиденным эффектам. |
