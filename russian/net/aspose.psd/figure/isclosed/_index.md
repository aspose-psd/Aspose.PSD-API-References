## Figure.IsClosed property

Получает или задает значение, указывающее, закрыта ли эта фигура. Закрытая фигура будет иметь значение только в случае, когда первая и последняя формы фигуры являются непрерывными. В таком случае первая точка первой формы будет соединена прямой линией с последней точкой последней формы.

```csharp
public bool IsClosed { get; set; }
```

### Property Value

`True` если эта фигура закрыта; иначе `false`.
