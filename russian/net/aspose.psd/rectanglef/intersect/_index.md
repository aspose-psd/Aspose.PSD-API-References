## Intersect(RectangleF, RectangleF)

Возвращает структуру [`RectangleF`](../), представляющую пересечение двух прямоугольников. Если пересечения нет, и возвращается пустой [`RectangleF`](../).

```csharp
public static RectangleF Intersect(RectangleF a, RectangleF b)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| a | RectangleF | Первый прямоугольник для пересечения. |
| b | RectangleF | Второй прямоугольник для пересечения. |

### Возвращаемое значение

Третья структура [`RectangleF`](../), размер которой представляет перекрывающуюся область двух указанных прямоугольников.
