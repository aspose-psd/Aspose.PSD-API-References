## Contains(float, float) {#contains_2}

Определяет, содержится ли указанная точка внутри этой структуры [`RectangleF`](../).

```csharp
public bool Contains(float x, float y)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| x | Single | Координата x проверяемой точки. |
| y | Single | Координата y проверяемой точки. |

### Возвращаемое значение

Этот метод возвращает true, если точка, определённая *x* и *y*, содержится внутри этой структуры [`RectangleF`](../); в противном случае false.
