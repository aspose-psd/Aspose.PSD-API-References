## RectangleF.Equals method

Проверяет, является ли *obj* объектом [`RectangleF`](../) с тем же расположением и размером, что и этот [`RectangleF`](../).

```csharp
public override bool Equals(object obj)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| obj | Object | Объект для тестирования. |

### Возвращаемое значение

Этот метод возвращает true, если *obj* является [`RectangleF`](../) и его свойства X, Y, Width и Height равны соответствующим свойствам этого [`RectangleF`](../); иначе false.
