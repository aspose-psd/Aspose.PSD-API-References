java.lang.Object
```
public class JpegLsPresetCodingParameters
```

Определяет предустановленные параметры кодирования JPEG-LS, как указано в ISO/IEC 14495-1, C.2.4.1.1. JPEG-LS задает набор параметров по умолчанию, но могут использоваться пользовательские параметры. При использовании эти параметры записываются в закодированный битовый поток, поскольку они необходимы для процесса декодирования.
