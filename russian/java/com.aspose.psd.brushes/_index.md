Пакет предоставляет вспомогательные классы и методы для работы с различными типами кистей.


## Классы

| Класс | Описание |
| --- | --- |
| [HatchBrush](../com.aspose.psd.brushes/hatchbrush) | Определяет прямоугольную кисть с штриховкой, цветом переднего плана и цветом фона. |
| [LinearGradientBrush](../com.aspose.psd.brushes/lineargradientbrush) | Инкапсулирует  Aspose.Imaging.Brush  с линейным градиентом. |
| [LinearGradientBrushBase](../com.aspose.psd.brushes/lineargradientbrushbase) | Представляет  Brush  с возможностями градиента и соответствующими свойствами. |
| [LinearMulticolorGradientBrush](../com.aspose.psd.brushes/linearmulticolorgradientbrush) | Представляет  Brush  с линейным градиентом, определённым несколькими цветами и соответствующими позициями. |
| [PathGradientBrush](../com.aspose.psd.brushes/pathgradientbrush) | Инкапсулирует объект  Aspose.Imaging.Brush  с градиентом. |
| [PathGradientBrushBase](../com.aspose.psd.brushes/pathgradientbrushbase) | Представляет Brush с функцией градиента базового пути. |
| [PathMulticolorGradientBrush](../com.aspose.psd.brushes/pathmulticolorgradientbrush) | Инкапсулирует объект  Aspose.Imaging.Brush  с градиентом. |
| [SolidBrush](../com.aspose.psd.brushes/solidbrush) | Сплошная кисть предназначена для непрерывного рисования определённым цветом. |
| [TextureBrush](../com.aspose.psd.brushes/texturebrush) | Каждое свойство класса Aspose.Imaging.Brushes.TextureBrush является объектом Aspose.Imaging.Brush, который использует изображение для заполнения внутренней части фигуры. |
| [TransformBrush](../com.aspose.psd.brushes/transformbrush) | Кисть с возможностями трансформации. |
