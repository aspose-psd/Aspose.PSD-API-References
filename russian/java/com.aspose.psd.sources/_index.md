Пакет содержит различные источники потоков, подходящие для входного или выходного потока данных.


## Классы

| Класс | Описание |
| --- | --- |
| [FileCreateSource](../com.aspose.psd.sources/filecreatesource) | Представляет источник файла для создания. |
| [FileOpenSource](../com.aspose.psd.sources/fileopensource) | Представляет источник файла для открытия. |
| [FileSource](../com.aspose.psd.sources/filesource) | Представляет файловый источник, способный к манипуляции файлами. |
| [StreamSource](../com.aspose.psd.sources/streamsource) | Представляет потоковый источник. |
