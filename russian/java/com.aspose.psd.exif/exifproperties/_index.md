### Artist {#Artist}
```
public static final int Artist
```


Этот тег сохраняет имя владельца камеры, фотографа или создателя изображения. Подробный формат не указан, но рекомендуется записывать информацию, как в примере ниже, для упрощения совместимости. Если поле оставлено пустым, оно считается неизвестным. Пример: "Camera owner, John Smith; Photographer, Michael Brown; Image creator, Ken James"

### BitsPerSample {#BitsPerSample}
```
public static final int BitsPerSample
```


Количество бит на компонент изображения. В этом стандарте каждый компонент изображения составляет 8 бит, поэтому значение этого тега равно 8.

### YCbCrPositioning {#YCbCrPositioning}
```
public static final int YCbCrPositioning
```


Позиция компонентов хроминанс относительно компонента яркости. Это поле назначается только для данных JPEG‑сжатия или несжатых данных YCbCr. Значение по умолчанию TIFF — 1 (центрировано); однако при Y:Cb:Cr = 4:2:2 в данном стандарте рекомендуется использовать 2 (совместно расположено) для записи данных, чтобы улучшить качество изображения при просмотре на телевизионных системах. Если это поле отсутствует, считыватель должен предполагать значение по умолчанию TIFF. В случае Y:Cb:Cr = 4:2:0 рекомендуется значение по умолчанию TIFF (центрировано). Если у считывателя нет возможности поддерживать оба типа YCbCrPositioning, он должен следовать значению по умолчанию TIFF независимо от значения в этом поле. Желательно, чтобы считыватели могли поддерживать как центрированное, так и совместно расположенное позиционирование.
