Тип фильтра PNG.

**Module:** [aspose.psd.fileformats.png](/psd/python-net/aspose.psd.fileformats.png/)

**Full Name:** aspose.psd.fileformats.png.PngFilterType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| ADAPTIVE | Адаптивная фильтрация, означает, что процесс сохранения выбирает наиболее подходящий фильтр для каждой строки данных. Наилучшее сжатие, самая медленная скорость выполнения. |
| AVG | Фильтр avg, означает, что к данным изображения будет применён средний фильтр. |
| NONE | Фильтр null, означает отсутствие фильтрации строк данных изображения. |
| PAETH | Фильтр предиктора Paeth. |
| SUB | Фильтр sub, означает, что к данным изображения будет применена субтрактивная фильтрация. |
| UP | Фильтр up, означает, что будет применён построчный фильтр вычитания. |
