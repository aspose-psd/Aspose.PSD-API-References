Определяет режим чередования для многокомпонентных (цветных) пиксельных данных.

**Module:** [aspose.psd.fileformats.jpeg](/psd/python-net/aspose.psd.fileformats.jpeg/)

**Full Name:** aspose.psd.fileformats.jpeg.JpegLsInterleaveMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| LINE | Режим чередования — по строке. Полная строка каждого компонента кодируется перед переходом к следующей строке. |
| NONE | Данные кодируются и сохраняются по компоненту за компонентом: RRRGGGBBB. |
| SAMPLE | Данные кодируются и сохраняются по образцу. Для цветных изображений это формат типа RGBRGBRGB. |
