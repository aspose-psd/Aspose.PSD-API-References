Указывает способ хранения альфа‑канала для TIFF‑документов.

**Module:** [aspose.psd.fileformats.tiff.enums](/psd/python-net/aspose.psd.fileformats.tiff.enums/)

**Full Name:** aspose.psd.fileformats.tiff.enums.TiffAlphaStorage

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| ASSOCIATED | Значение альфа хранится в предварительно умноженной форме. При восстановлении альфа может возникнуть некоторое округление, и восстановленное значение может отличаться от оригинального. |
| UNASSOCIATED | Значение альфа хранится в несвязанной форме. Это означает, что восстановленная альфа будет точно такой же, как была сохранена в tiff. |
| UNSPECIFIED | Альфа не указана и сохраняется в файле tiff. |
