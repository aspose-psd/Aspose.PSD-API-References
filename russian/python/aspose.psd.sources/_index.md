Модуль содержит различные источники потоков, подходящие для входного или выходного потока данных.

## **Classes**
| **Класс** | **Описание** |
| :- | :- |
| [FileCreateSource](/psd/python-net/aspose.psd.sources/filecreatesource/) | Представляет файловый источник для создания. |
| [FileOpenSource](/psd/python-net/aspose.psd.sources/fileopensource/) | Представляет файловый источник для открытия. |
| [FileSource](/psd/python-net/aspose.psd.sources/filesource/) | Представляет файловый источник, способный к манипуляции файлами. |
| [StreamSource](/psd/python-net/aspose.psd.sources/streamsource/) | Представляет потоковый источник. |
