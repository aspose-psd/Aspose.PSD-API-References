Модуль предоставляет вспомогательные классы и методы для работы с различными типами кистей.

## **Classes**
| **Класс** | **Описание** |
| :- | :- |
| [HatchBrush](/psd/python-net/aspose.psd.brushes/hatchbrush/) | Определяет прямоугольную кисть с штриховкой, цветом переднего плана и цветом фона. Этот класс не может быть унаследован. |
| [LinearGradientBrush](/psd/python-net/aspose.psd.brushes/lineargradientbrush/) | Инкапсулирует [Brush](/psd/python-net/aspose.psd/brush/) с линейным градиентом. Этот класс не может быть унаследован. |
| [LinearGradientBrushBase](/psd/python-net/aspose.psd.brushes/lineargradientbrushbase/) | Представляет [Brush](/psd/python-net/aspose.psd/brush/) с возможностями градиента и соответствующими свойствами. |
| [LinearMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/linearmulticolorgradientbrush/) | Представляет [Brush](/psd/python-net/aspose.psd/brush/) с линейным градиентом, определённым несколькими цветами и соответствующими позициями. Этот класс не может быть унаследован. |
| [PathGradientBrush](/psd/python-net/aspose.psd.brushes/pathgradientbrush/) | Инкапсулирует объект [Brush](/psd/python-net/aspose.psd/brush/) с градиентом. Этот класс не может быть унаследован. |
| [PathGradientBrushBase](/psd/python-net/aspose.psd.brushes/pathgradientbrushbase/) | Представляет [Brush](/psd/python-net/aspose.psd/brush/) с функциональностью градиента базового пути. |
| [PathMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/pathmulticolorgradientbrush/) | Инкапсулирует объект [Brush](/psd/python-net/aspose.psd/brush/) с градиентом. Этот класс не может быть унаследован. |
| [SolidBrush](/psd/python-net/aspose.psd.brushes/solidbrush/) | Твёрдая кисть предназначена для непрерывного рисования определённым цветом. Этот класс не может быть унаследован. |
| [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) | Каждое свойство класса [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) является объектом [Brush](/psd/python-net/aspose.psd/brush/), который использует изображение для заполнения внутренней части фигуры. Этот класс не может быть унаследован. |
| [TransformBrush](/psd/python-net/aspose.psd.brushes/transformbrush/) | Кисть [Brush](/psd/python-net/aspose.psd/brush/) с возможностями трансформации. |
