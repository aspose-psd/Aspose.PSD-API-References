**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| LOCK_ALL | Блокировать все свойства слоя |
| LOCK_IMAGE_PIXELS | Частичное блокирование слоя  - Prevents modification of the layer’s pixels using the painting tools. |
| LOCK_POSITION | Частичное блокирование слоя  - Prevents the layer’s pixels from being moved. |
| LOCK_TRANSPARENT_PIXELS | Частичное блокирование слоя  - Confines editing to the opaque portions of the layer. <br/>            This option is equivalent to the Preserve Transparency option in earlier versions of Photoshop. |
| NONE | Без блокировки слоя |
