| [BezierShape](/psd/python-net/aspose.psd.shapes/beziershape/) | Представляет сплайн Безье. |
| [CurveShape](/psd/python-net/aspose.psd.shapes/curveshape/) | Представляет форму изогнутого сплайна. |
| [EllipseShape](/psd/python-net/aspose.psd.shapes/ellipseshape/) | Представляет форму эллипса. |

| [PolygonShape](/psd/python-net/aspose.psd.shapes/polygonshape/) | Представляет форму многоугольника. |
| [RectangleProjectedShape](/psd/python-net/aspose.psd.shapes/rectangleprojectedshape/) | Представляет форму, проецируемую на прямоугольник, повернутый в определённую ориентацию.<br/>            Задаётся четырьмя точками, которые могут вращаться в пространстве, сохраняя одинаковую длину сторон и 90 градусов между соседними сторонами. |
| [RectangleShape](/psd/python-net/aspose.psd.shapes/rectangleshape/) | Представляет форму прямоугольника. |
