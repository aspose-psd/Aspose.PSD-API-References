Указывает отдельные каналы в цветовом пространстве CMYK (циан, маджента, желтый, чёрный). Этот перечисление используется методами SetOutputChannel.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorChannelFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| COLOR_CHANNEL_C | Циановый цветовой канал. |
| COLOR_CHANNEL_K | Черный цветовой канал. |
| COLOR_CHANNEL_LAST | Следует использовать последний выбранный канал. |
| COLOR_CHANNEL_M | Пурпурный цветовой канал. |
| COLOR_CHANNEL_Y | Желтый цветовой канал. |
