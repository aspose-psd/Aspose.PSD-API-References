**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.CacheType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| AUTO | Указывает тип автоматического кэша. Схема автоматического кэширования будет пытаться сначала кэшировать в памяти, а затем на диске. |
| CACHE_IN_MEMORY_ONLY | Только кэш в памяти. |
| CACHE_ON_DISK_ONLY | Только кэш на диске. |
