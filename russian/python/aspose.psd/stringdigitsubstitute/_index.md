Перечисление указывает, как заменять цифры в строке в соответствии с локалью или языком пользователя.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringDigitSubstitute

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| НАЦИОНАЛЬНЫЙ | Указывает цифры замены, соответствующие официальному национальному языку локали пользователя. |
| NONE | Указывает отключить замены. |
| ТРАДИЦИОННЫЙ | Указывает цифры замены, соответствующие родному письму или языку пользователя, которые могут отличаться от официального национального языка локали пользователя. |
| ПОЛЬЗОВАТЕЛЬ | Указывает пользовательскую схему замены. |
