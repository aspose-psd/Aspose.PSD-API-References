Указывает типы изображений и цветов, которые будут затронуты настройками коррекции цвета и градаций серого объекта [ImageAttributes](/psd/python-net/aspose.psd/imageattributes/).

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorMatrixFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| ALT_GRAYS | Только оттенки серого корректируются. |
| ПО УМОЛЧАНИЮ | Все цветовые значения, включая оттенки серого, корректируются одной и той же матрицей цветокоррекции. |
| SKIP_GRAYS | Все цвета корректируются, но оттенки серого не корректируются. Оттенок серого — это любой цвет, у которого одинаковые значения красного, зелёного и синего компонентов. |
