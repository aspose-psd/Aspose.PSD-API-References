Режим восстановления данных.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.DataRecoveryMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| CONSISTENT_RECOVER | Режим согласованного восстановления пытается восстановить все данные, пока повреждение не нарушает формат файла и позволяет корректно продолжать обработку. |
| MAXIMAL_RECOVER | Режим максимального восстановления восстанавливает все данные, даже если структура формата файла повреждена, и дальнейшая обработка может привести к непредвиденным эффектам. |
| NONE | Восстановление данных не предполагается. Если в формате файла присутствуют повреждённые данные, выбрасывается соответствующее исключение. |
