Перечисление [InterpolationMode](/psd/python-net/aspose.psd/interpolationmode/) указывает алгоритм, используемый при масштабировании или вращении изображений.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.InterpolationMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| BICUBIC | Указывает бикубическую интерполяцию. Предварительная фильтрация не выполняется. Этот режим не подходит для уменьшения изображения ниже 25 % от его исходного размера. |
| BILINEAR | Указывает билинейную интерполяцию. Предварительная фильтрация не выполняется. Этот режим не подходит для уменьшения изображения ниже 50 % от его исходного размера. |
| ПО УМОЛЧАНИЮ | Указывает режим по умолчанию. |
| HIGH | Указывает интерполяцию высокого качества. |
| HIGH_QUALITY_BICUBIC | Указывает высококачественную бикубическую интерполяцию. Выполняется предварительная фильтрация, чтобы обеспечить высококачественное уменьшение. Этот режим обеспечивает наивысшее качество преобразованных изображений. |
| HIGH_QUALITY_BILINEAR | Указывает высококачественную билинейную интерполяцию. Выполняется предварительная фильтрация, чтобы обеспечить высококачественное уменьшение. |
| INVALID | Недопустимый режим интерполяции. |
| LOW | Указывает низкокачественную интерполяцию. |
| NEAREST_NEIGHBOR | Указывает интерполяцию ближайшего соседа. |
