Указывает, какие объекты используют информацию о коррекции цвета.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorAdjustType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| ANY | Количество указанных типов. |
| BITMAP | Информация о коррекции цвета для объектов Bitmap. |
| BRUSH | Информация о коррекции цвета для объектов Brush. |
| COUNT | Количество указанных типов. |
| ПО УМОЛЧАНИЮ | Информация о коррекции цвета, используемая всеми объектами GDI+, которые не имеют собственной информации о коррекции цвета. |
| PEN | Информация о коррекции цвета для объектов Pen. |
| TEXT | Информация о коррекции цвета для текста. |
