Указывает доступные стили окончаний, с которыми объект [Pen](/psd/python-net/aspose.psd/pen/) может завершать линию.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.LineCap

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| ANCHOR_MASK | Указывает пользовательский конец линии. |
| ARROW_ANCHOR | Указывает якорный конец в виде стрелки. |
| CUSTOM | Указывает маску, используемую для проверки, является ли конец линии якорным. |
| DIAMOND_ANCHOR | Указывает якорный конец в виде ромба. |
| FLAT | Указывает плоский конец линии. |
| NO_ANCHOR | Указывает отсутствие привязки. |
| ROUND | Указывает круглую заглушку линии. |
| ROUND_ANCHOR | Указывает круглую заглушку привязки. |
| SQUARE | Указывает квадратную заглушку линии. |
| SQUARE_ANCHOR | Указывает квадратную заглушку линии привязки. |
| TRIANGLE | Указывает треугольную заглушку линии. |
