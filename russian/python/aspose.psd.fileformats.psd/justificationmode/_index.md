Режим выравнивания текста.

**Module:** [aspose.psd.fileformats.psd](/psd/python-net/aspose.psd.fileformats.psd/)

**Full Name:** aspose.psd.fileformats.psd.JustificationMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| CENTER | Текст по центру. |
| LEFT | Текст выравнивается по левому краю.<br/>            В режиме слева направо позиция Left соответствует левому.<br/>            В режиме справа налево позиция Left соответствует правому. |
| RIGHT | Текст выравнивается по правому краю.<br/>            В режиме слева направо позиция Right соответствует правому.<br/>            В режиме справа налево позиция Right соответствует левому. |
