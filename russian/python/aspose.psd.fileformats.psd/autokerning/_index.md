Режим автоматического кернинга Photoshop (расстояние между символами).

**Module:** [aspose.psd.fileformats.psd](/psd/python-net/aspose.psd.fileformats.psd/)

**Full Name:** aspose.psd.fileformats.psd.AutoKerning

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| MANUAL | Значение ручного кернинга. |
| METRIC | Кернинг по метрикам использует пары кернинга, которые включены в большинство шрифтов (от их дизайнеров). |
| OPTICAL | Оптический кернинг регулирует расстояние между соседними символами на основе их форм. |
