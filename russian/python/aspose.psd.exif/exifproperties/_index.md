| SCENE_TYPE | Указывает тип сцены. Если изображение записано DSC, значение этого тега всегда должно быть 1, что означает, что изображение было снято напрямую. |

| SHARPNESS | Этот тег указывает направление обработки резкости, применяемой камерой при съемке изображения. |
| SHUTTER_SPEED_VALUE | Значение выдержки. |
| SOFTWARE | Этот тег сохраняет название и версию программного обеспечения или прошивки камеры или устройства ввода изображения, использованных для создания изображения. Подробный формат не указан, но рекомендуется следовать приведённому ниже примеру. Если поле оставлено пустым, оно считается неизвестным. |
| SPATIAL_FREQUENCY_RESPONSE | Этот тег сохраняет таблицу пространственной частоты камеры или устройства ввода и значения SFR в направлениях ширины изображения, высоты изображения и диагонали, как указано в ISO 12233. |
| SPECTRAL_SENSITIVITY | Указывает спектральную чувствительность каждого канала используемой камеры. |
| STANDARD_OUTPUT_SENSITIVITY | Указывает стандартную выходную чувствительность камеры. |
| STRIP_BYTE_COUNTS | Общее количество байтов в каждой полосе. |
| STRIP_OFFSETS | Для каждой полосы указывается смещение байтов этой полосы. Рекомендуется выбирать значение так, чтобы количество байтов в полосе не превышало 64 Кбайт.<br/>                Вспомогательный тег. |
| SUBJECT_AREA | Этот тег указывает расположение и площадь главного объекта в общей сцене. |
| SUBJECT_DISTANCE | Расстояние до объекта, указываемое в метрах. |
| SUBJECT_DISTANCE_RANGE | Этот тег указывает расстояние до объекта. |
| SUBJECT_LOCATION | Указывает расположение главного объекта в сцене. Значение этого тега представляет пиксель в центре главного объекта относительно левого края, до обработки вращения согласно тегу Rotation. |
| SUBSEC_TIME | Тег, используемый для записи долей секунды для тега DateTime. |
| SUBSEC_TIME_DIGITIZED | Тег, используемый для записи долей секунды в теге DateTimeDigitized. |
| SUBSEC_TIME_ORIGINAL | Тег, используемый для записи долей секунды в теге DateTimeOriginal. |
| TRANSFER_FUNCTION | Функция передачи для изображения, описанная в табличном виде. Обычно этот тег не требуется, поскольку цветовое пространство указывается в теге информации о цветовом пространстве ColorSpace. |
| USER_COMMENT | Тег для пользователей Exif, позволяющий записывать ключевые слова или комментарии к изображению помимо тех, что находятся в ImageDescription, и без ограничений кодировки символов тега ImageDescription. |
| WHITE_BALANCE | Этот тег указывает режим баланса белого, установленный при съемке изображения. |
| WHITE_POINT | Хроматичность белой точки изображения. Обычно этот тег не требуется, поскольку цветовое пространство указывается в теге информации о цветовом пространстве ColorSpace. |
| X_RESOLUTION | Количество пикселей на ResolutionUnit в направлении ImageWidth. Когда разрешение изображения неизвестно, назначается 72 [dpi]. |
| Y_CB_CR_COEFFICIENTS | Коэффициенты матрицы для преобразования из RGB в данные изображения YCbCr. |
| Y_CB_CR_POSITIONING | Позиция компонентов хроминанс относительно<br/>                компоненты яркости. Это поле назначено только для<br/>                JPEG‑сжатых данных или несжатых данных YCbCr. Значение по умолчанию TIFF — 1 (центрировано); но когда Y:Cb:Cr = 4:2:2, в данном стандарте рекомендуется использовать 2 (совместно расположено) для<br/>                записи данных, чтобы улучшить качество изображения при просмотре<br/>                на телевизионных системах. Если это поле отсутствует, чтитель должен<br/>                предполагать значение по умолчанию TIFF. В случае Y:Cb:Cr = 4:2:0, рекомендуется значение по умолчанию TIFF (центрировано). Если у чтителя<br/>                нет возможности поддерживать оба типа<br/>                YCbCrPositioning, он должен следовать значению по умолчанию TIFF независимо<br/>                от значения в этом поле. Желательно, чтобы чтители \"<br/>                могли поддерживать как центрированное, так и совместно расположенное позиционирование. |
| Y_CB_CR_SUB_SAMPLING | Отношение дискретизации компонентов хроминанс относительно компоненты яркости. |
| Y_RESOLUTION | Количество пикселей на ResolutionUnit в направлении ImageLength. То же значение, что и XResolution, назначается. |
