Метод утилизации кадра указывает, следует ли отбрасывать текущий кадр перед отображением следующего кадра.<br/>            Вы выбираете метод утилизации для анимаций, включающих прозрачность фона, чтобы указать, будет ли текущий<br/>            кадр виден через прозрачные области следующего кадра.

**Module:** [aspose.psd.fileformats.psd.layers.animation](/psd/python-net/aspose.psd.fileformats.psd.layers.animation/)

**Full Name:** aspose.psd.fileformats.psd.layers.animation.FrameDisposalMethod

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Имя члена** | **Описание** |
| :- | :- |
| AUTOMATIC | Определяет метод удаления текущего кадра автоматически, отбрасывая текущий кадр, если следующий кадр содержит прозрачность слоя.<br/>            Для большинства анимаций параметр Automatic (по умолчанию) даёт желаемый результат. |
| DISPOSE | Отбрасывает текущий кадр с отображения перед тем, как будет отображён следующий кадр.<br/>            В любой момент отображается только один кадр (и текущий кадр не виден через прозрачные области следующего кадра). |
| DO_NOT_DISPOSE | Сохраняет текущий кадр при добавлении следующего кадра к отображению.<br/>            Текущий кадр (и предыдущие кадры) могут просвечивать через прозрачные области следующего кадра. |
