Модуль содержит вспомогательные классы и методы, связанные с XMP.

## **Classes**
| **Класс** | **Описание** |
| :- | :- |
| [IXmlValue](/psd/python-net/aspose.psd.xmp/ixmlvalue/) | Преобразует значения xmp в строковое представление XML. |
| [LangAlt](/psd/python-net/aspose.psd.xmp/langalt/) | Представляет альтернативный язык XMP. |
| [Namespaces](/psd/python-net/aspose.psd.xmp/namespaces/) | Содержит пространства имён, используемые в документе RDF. |
| [XmpArray](/psd/python-net/aspose.psd.xmp/xmparray/) | Представляет массив Xmp в [XmpPackage](/psd/python-net/aspose.psd.xmp/xmppackage/). TODO: Массив может содержать сложные данные. |
| [XmpArrayHelper](/psd/python-net/aspose.psd.xmp/xmparrayhelper/) | Вспомогательный класс для обработки логики RDF. |
| [XmpElementBase](/psd/python-net/aspose.psd.xmp/xmpelementbase/) | Представляет базовый элемент xmp, содержащий атрибуты. |
| [XmpHeaderPi](/psd/python-net/aspose.psd.xmp/xmpheaderpi/) | Представляет инструкцию обработки заголовка XMP. |
| [XmpMeta](/psd/python-net/aspose.psd.xmp/xmpmeta/) | Представляет xmpmeta. Необязательно.<br/>            Цель этого элемента — идентифицировать метаданные XMP в общем XML‑тексте, который может содержать другие не‑XMP использования RDF. |
| [XmpPackage](/psd/python-net/aspose.psd.xmp/xmppackage/) | Определяет класс XmpPackage, который представляет базовую абстракцию для пакета XMP. |
| [XmpPackageBaseCollection](/psd/python-net/aspose.psd.xmp/xmppackagebasecollection/) | Представляет коллекцию [XmpPackage](/psd/python-net/aspose.psd.xmp/xmppackage/). |
| [XmpPacketWrapper](/psd/python-net/aspose.psd.xmp/xmppacketwrapper/) | Содержит сериализованный пакет xmp, включая заголовок и трейлер. |
| [XmpRdfRoot](/psd/python-net/aspose.psd.xmp/xmprdfroot/) | Представляет элемент rdf:RDF.<br/>            Один пакет XMP должен сериализоваться с использованием одного XML‑элемента rdf:RDF. Содержание элемента rdf:RDF должно состоять только из нуля или более элементов rdf:Description. |
| [XmpTrailerPi](/psd/python-net/aspose.psd.xmp/xmptrailerpi/) | Представляет инструкцию обработки трейлера XMP. |
