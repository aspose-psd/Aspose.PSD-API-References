Questo enum descrive i possibili tipi di eventi di progresso che possono verificarsi durante le operazioni di elaborazione delle immagini

**Module:** [aspose.psd.progressmanagement](/psd/python-net/aspose.psd.progressmanagement/)

**Full Name:** aspose.psd.progressmanagement.EventType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nome membro** | **Description** |
| :- | :- |
| FINALIZATION | La finalizzazione dell'operazione |
| INITIALIZATION | L'inizializzazione dell'operazione |
| PRE_PROCESSING | Il pre-elaborazione |
| PROCESSING | L'elaborazione |
| RELATIVE_PROGRESS | Progresso relativo della fase corrente dell'elaborazione dell'operazione |
| STAGE_CHANGE | La fase successiva dell'operazione è iniziata |
