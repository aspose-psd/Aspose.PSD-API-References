Specifica l'archiviazione alfa per i documenti TIFF.

**Module:** [aspose.psd.fileformats.tiff.enums](/psd/python-net/aspose.psd.fileformats.tiff.enums/)

**Full Name:** aspose.psd.fileformats.tiff.enums.TiffAlphaStorage

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nome membro** | **Description** |
| :- | :- |
| ASSOCIATED | Il valore alfa è memorizzato in forma premoltiplicata. Quando l'alfa viene ripristinato potrebbero verificarsi alcuni effetti di arrotondamento e il valore ripristinato potrebbe differire dall'originale. |
| UNASSOCIATED | Il valore alfa è memorizzato in forma non associata. Ciò significa che l'alfa ripristinato è esattamente lo stesso di quello memorizzato nel tiff. |
| UNSPECIFIED | L'alpha non è specificato e memorizzato nel file tiff. |
