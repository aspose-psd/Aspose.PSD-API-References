La modalità di kerning automatico di Photoshop (distanza tra i simboli).

**Module:** [aspose.psd.fileformats.psd](/psd/python-net/aspose.psd.fileformats.psd/)

**Full Name:** aspose.psd.fileformats.psd.AutoKerning

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nome membro** | **Description** |
| :- | :- |
| MANUAL | Valore di kerning manuale. |
| METRICO | Il kerning metrico utilizza coppie di kern, che sono incluse nella maggior parte dei caratteri (dai loro designer). |
| OTTICO | Il kerning ottico regola la spaziatura tra caratteri adiacenti in base alle loro forme. |
