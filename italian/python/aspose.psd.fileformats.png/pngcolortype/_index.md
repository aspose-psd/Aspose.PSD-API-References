Rappresenta il tipo di colore dell'immagine PNG.

**Module:** [aspose.psd.fileformats.png](/psd/python-net/aspose.psd.fileformats.png/)

**Full Name:** aspose.psd.fileformats.png.PngColorType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nome membro** | **Description** |
| :- | :- |
| GRAYSCALE | Rappresenta il tipo di colore in cui ogni pixel è un campione in scala di grigi. |
| GRAYSCALE_WITH_ALPHA | Rappresenta il tipo di colore in cui ogni pixel è un campione in scala di grigi seguito da un campione alfa. |
| INDEXED_COLOR | Rappresenta il tipo di colore in cui ogni pixel è un indice della palette; deve comparire un chunk PLTE. |
| TRUECOLOR | Rappresenta il tipo di colore in cui ogni pixel è una tripla R,G,B. |
| TRUECOLOR_WITH_ALPHA | Rappresenta il tipo di colore in cui ogni pixel è una tripla R,G,B seguita da un campione alfa. |
