Il modulo contiene classi e metodi di supporto relativi a XMP.

## **Classes**
| **Classe** | **Description** |
| :- | :- |
| [IXmlValue](/psd/python-net/aspose.psd.xmp/ixmlvalue/) | Converte i valori xmp nella rappresentazione stringa XML. |
| [LangAlt](/psd/python-net/aspose.psd.xmp/langalt/) | Rappresenta l'Alternativa Linguistica XMP. |
| [Namespaces](/psd/python-net/aspose.psd.xmp/namespaces/) | Contiene gli spazi dei nomi usati nel documento RDF. |
| [XmpArray](/psd/python-net/aspose.psd.xmp/xmparray/) | Rappresenta l'Array Xmp in [XmpPackage](/psd/python-net/aspose.psd.xmp/xmppackage/). TODO: L'array può contenere dati complessi. |
| [XmpArrayHelper](/psd/python-net/aspose.psd.xmp/xmparrayhelper/) | La classe di supporto per l'elaborazione della logica RDF |
| [XmpElementBase](/psd/python-net/aspose.psd.xmp/xmpelementbase/) | Rappresenta l'elemento xmp di base che contiene attributi. |
| [XmpHeaderPi](/psd/python-net/aspose.psd.xmp/xmpheaderpi/) | Rappresenta l'istruzione di elaborazione dell'intestazione XMP. |
| [XmpMeta](/psd/python-net/aspose.psd.xmp/xmpmeta/) | Rappresenta xmpmeta. Opzionale.<br/>            Lo scopo di questo elemento è identificare i metadati XMP all'interno di testo XML generale che potrebbe contenere altri usi non XMP di RDF. |
| [XmpPackage](/psd/python-net/aspose.psd.xmp/xmppackage/) | Definisce la classe XmpPackage che rappresenta l'astrazione di base per il pacchetto XMP. |
| [XmpPackageBaseCollection](/psd/python-net/aspose.psd.xmp/xmppackagebasecollection/) | Rappresenta la collezione di [XmpPackage](/psd/python-net/aspose.psd.xmp/xmppackage/). |
| [XmpPacketWrapper](/psd/python-net/aspose.psd.xmp/xmppacketwrapper/) | Contiene il pacchetto xmp serializzato, inclusi intestazione e trailer. |
| [XmpRdfRoot](/psd/python-net/aspose.psd.xmp/xmprdfroot/) | Rappresenta l'elemento rdf:RDF.<br/>            Un singolo pacchetto XMP deve essere serializzato usando un unico elemento XML rdf:RDF. Il contenuto dell'elemento rdf:RDF deve consistere solo di zero o più elementi rdf:Description. |
| [XmpTrailerPi](/psd/python-net/aspose.psd.xmp/xmptrailerpi/) | Rappresenta l'istruzione di elaborazione del trailer XMP. |
