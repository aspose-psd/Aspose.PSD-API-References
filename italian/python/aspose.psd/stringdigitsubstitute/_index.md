L'enumerazione specifica come sostituire le cifre in una stringa in base alla locale o alla lingua dell'utente.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.StringDigitSubstitute

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nome membro** | **Description** |
| :- | :- |
| NAZIONALE | Specifica le cifre di sostituzione che corrispondono alla lingua nazionale ufficiale della località dell'utente. |
| NONE | Specifica di disabilitare le sostituzioni. |
| TRADIZIONALE | Specifica le cifre di sostituzione che corrispondono alla scrittura o lingua nativa dell'utente, che può differire dalla lingua nazionale ufficiale della località dell'utente. |
| UTENTE | Specifica uno schema di sostituzione definito dall'utente. |
