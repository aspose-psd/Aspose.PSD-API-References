Specifica i canali individuali nello spazio colore CMYK (ciano, magenta, giallo, nero). Questa enumerazione è usata dai metodi SetOutputChannel.

**Module:** [aspose.psd](/psd/python-net/aspose.psd/)

**Full Name:** aspose.psd.ColorChannelFlag

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nome membro** | **Description** |
| :- | :- |
| COLOR_CHANNEL_C | Il canale di colore ciano. |
| COLOR_CHANNEL_K | Il canale di colore nero. |
| COLOR_CHANNEL_LAST | Il canale selezionato per ultimo dovrebbe essere usato. |
| COLOR_CHANNEL_M | Il canale di colore magenta. |
| COLOR_CHANNEL_Y | Il canale di colore giallo. |
