Il modulo fornisce classi di supporto e metodi per lavorare con diversi tipi di pennello.

## **Classes**
| **Classe** | **Description** |
| :- | :- |
| [HatchBrush](/psd/python-net/aspose.psd.brushes/hatchbrush/) | Definisce un pennello rettangolare con uno stile a tratteggio, un colore di primo piano e un colore di sfondo. Questa classe non può essere ereditata. |
| [LinearGradientBrush](/psd/python-net/aspose.psd.brushes/lineargradientbrush/) | Incapsula un [Brush](/psd/python-net/aspose.psd/brush/) con un gradiente lineare. Questa classe non può essere ereditata. |
| [LinearGradientBrushBase](/psd/python-net/aspose.psd.brushes/lineargradientbrushbase/) | Rappresenta un [Brush](/psd/python-net/aspose.psd/brush/) con capacità di gradiente e proprietà appropriate. |
| [LinearMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/linearmulticolorgradientbrush/) | Rappresenta un [Brush](/psd/python-net/aspose.psd/brush/) con gradiente lineare definito da più colori e posizioni appropriate. Questa classe non può essere ereditata. |
| [PathGradientBrush](/psd/python-net/aspose.psd.brushes/pathgradientbrush/) | Incapsula un oggetto [Brush](/psd/python-net/aspose.psd/brush/) con un gradiente. Questa classe non può essere ereditata. |
| [PathGradientBrushBase](/psd/python-net/aspose.psd.brushes/pathgradientbrushbase/) | Rappresenta un [Brush](/psd/python-net/aspose.psd/brush/) con funzionalità di gradiente di percorso di base. |
| [PathMulticolorGradientBrush](/psd/python-net/aspose.psd.brushes/pathmulticolorgradientbrush/) | Incapsula un oggetto [Brush](/psd/python-net/aspose.psd/brush/) con un gradiente. Questa classe non può essere ereditata. |
| [SolidBrush](/psd/python-net/aspose.psd.brushes/solidbrush/) | Il pennello solido è destinato al disegno continuo con un colore specifico. Questa classe non può essere ereditata. |
| [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) | Ogni proprietà della classe [TextureBrush](/psd/python-net/aspose.psd.brushes/texturebrush/) è un oggetto [Brush](/psd/python-net/aspose.psd/brush/) che utilizza un'immagine per riempire l'interno di una forma. Questa classe non può essere ereditata. |
| [TransformBrush](/psd/python-net/aspose.psd.brushes/transformbrush/) | Un [Brush](/psd/python-net/aspose.psd/brush/) con capacità di trasformazione. |
