Definisce la modalità di interlacciamento per dati pixel multicomponente (colore).

**Module:** [aspose.psd.fileformats.jpeg](/psd/python-net/aspose.psd.fileformats.jpeg/)

**Full Name:** aspose.psd.fileformats.jpeg.JpegLsInterleaveMode

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nome membro** | **Description** |
| :- | :- |
| LINE | La modalità di interlacciamento è per riga. Una riga completa di ciascun componente viene codificata prima di passare alla riga successiva. |
| NONE | I dati sono codificati e memorizzati componente per componente: RRRGGGBBB. |
| SAMPLE | I dati sono codificati e memorizzati per campione. Per le immagini a colori questo è il formato tipo RGBRGBRGB. |
