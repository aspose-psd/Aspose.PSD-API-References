| [SmartObjectLayer](/psd/python-net/aspose.psd.fileformats.psd.layers.smartobjects/smartobjectlayer/) | Definisce la classe SmartObjectLayer che contiene oggetti smart incorporati nel file PSD o collegati a un file esterno.<br/>            Con gli Smart Objects, è possibile:<br/>            Eseguire trasformazioni non distruttive. È possibile scalare, ruotare, inclinare, distorcere, trasformare in prospettiva o deformare un livello<br/>            senza perdere i dati o la qualità dell'immagine originale perché le trasformazioni non influenzano i dati originali.<br/>            Lavorare con dati vettoriali, come grafica vettoriale da Illustrator, che altrimenti verrebbero rasterizzati.<br/>            Eseguire filtraggio non distruttivo. È possibile modificare i filtri applicati agli Smart Objects in qualsiasi momento.<br/>            Modificare un Smart Object e aggiornare automaticamente tutte le sue istanze collegate.<br/>            Applicare una maschera di livello che è collegata o scollegata dal livello Smart Object.<br/>            Provare vari design con immagini segnaposto a bassa risoluzione che si sostituiranno successivamente con le versioni finali.<br/>            In Adobe® Photoshop®, è possibile incorporare il contenuto di un'immagine in un documento PSD.<br/>            Maggiori informazioni sono qui: <see href="https://helpx.adobe.com/photoshop/using/create-smart-objects.html" /><br/>            Un livello con un oggetto smart incorporato contiene risorse placed (PlLd) e SoLd con le proprietà dell'oggetto smart.<br/>            La risorsa PlLd può essere presente da sola per versioni PSD precedenti alla 10.<br/>            Queste risorse contengono l'UniqueId del LiFdDataSource nella Lnk2Resource globale con il nome file incorporato<br/>            e altri parametri, incluso il contenuto del file incorporato nel formato originale come array di byte. |
