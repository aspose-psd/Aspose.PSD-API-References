Le operazioni per la combinazione delle forme di percorso (operazioni booleane).

**Module:** [aspose.psd.fileformats.core.vectorpaths](/psd/python-net/aspose.psd.fileformats.core.vectorpaths/)

**Full Name:** aspose.psd.fileformats.core.vectorpaths.PathOperations

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nome membro** | **Description** |
| :- | :- |
| COMBINE_SHAPES | Combina forme (operazione OR). Questo è il valore predefinito in Photoshop. |
| EXCLUDE_OVERLAPPING_SHAPES | Escludi forme sovrapposte (operazione XOR). |
| INTERSECT_SHAPE_AREAS | Interseca le aree delle forme (operazione AND). |
| SUBTRACT_FRONT_SHAPE | Sottrai forma anteriore (operazione NOT). |
