**Module:** [aspose.psd.fileformats.psd.layers.layerresources](/psd/python-net/aspose.psd.fileformats.psd.layers.layerresources/)

**Full Name:** aspose.psd.fileformats.psd.layers.layerresources.LayerLockType

**Aspose.PSD Version:** 24.12.0

## **Members**
| **Nome membro** | **Description** |
| :- | :- |
| LOCK_ALL | Blocca tutte le proprietà di un livello |
| LOCK_IMAGE_PIXELS | Blocca parzialmente un livello  - Impedisce la modifica dei pixel del livello usando gli strumenti di pittura. |
| LOCK_POSITION | Blocca parzialmente un livello  - Impedisce lo spostamento dei pixel del livello. |
| LOCK_TRANSPARENT_PIXELS | Blocca parzialmente un livello  - Limita la modifica alle parti opache del livello. <br/>            Questa opzione è equivalente all'opzione Preserva Trasparenza nelle versioni precedenti di Photoshop. |
| NONE | Nessun blocco del livello |
