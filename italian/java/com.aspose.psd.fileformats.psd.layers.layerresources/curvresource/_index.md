Classe CurvResource. Risorsa del livello di regolazione Curve 1 byte - 0 se si usano le curve, 1 se si usano i pixel sulla mappa; se 0 allora: 2 byte - short. Predefinito è 1 4 byte - int. Utilizzato solo l'ultimo byte per bit. Il primo bit è per 1 canale, il quarto bit per 4 canali, per esempio 2 byte - short conteggio punti 4 byte \* conteggio punti - punti della curva 2 short: prima posizione, seconda altezza 4 byte - word "Crv " 2 byte - short predefinito è 4 per Curve 4 byte - int. Predefinito è 1 4 byte - conteggio punti 4 byte \* conteggio punti - punti della curva 2 short: prima posizione, seconda altezza 0-4 byte - Leading da arrotondare per quattro se 1 allora: 2 byte - short. Predefinito è 1 4 byte - int. Utilizzato solo l'ultimo byte. Un canale è in un bit. Il primo bit è per 1 canale, il quarto bit per 4 canali, per esempio 256 \* conteggio canali modificati - valori ordinati del canale nell'intervallo 0 - 255 4 byte - word "Crv " 2 byte - short. Predefinito è 3 per pixel sulla mappa 4 byte - int Conteggio canali (2 + 256) byte - short 2 per indice canale, 256 è valori ordinati del canale nell'intervallo 0 - 255
