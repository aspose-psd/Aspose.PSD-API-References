Il pacchetto fornisce classi di supporto e metodi per lavorare con diversi tipi di pennello.


## Classi

| Classe | Descrizione |
| --- | --- |
| [HatchBrush](../com.aspose.psd.brushes/hatchbrush) | Definisce un pennello rettangolare con uno stile a trama, un colore di primo piano e un colore di sfondo. |
| [LinearGradientBrush](../com.aspose.psd.brushes/lineargradientbrush) | Incapsula un  Aspose.Imaging.Brush  con un gradiente lineare. |
| [LinearGradientBrushBase](../com.aspose.psd.brushes/lineargradientbrushbase) | Rappresenta un  Brush  con capacità di gradiente e proprietà appropriate. |
| [LinearMulticolorGradientBrush](../com.aspose.psd.brushes/linearmulticolorgradientbrush) | Rappresenta un  Brush  con gradiente lineare definito da più colori e posizioni appropriate. |
| [PathGradientBrush](../com.aspose.psd.brushes/pathgradientbrush) | Incapsula un oggetto  Aspose.Imaging.Brush  con un gradiente. |
| [PathGradientBrushBase](../com.aspose.psd.brushes/pathgradientbrushbase) | Rappresenta un  Brush  con funzionalità di gradiente a percorso di base. |
| [PathMulticolorGradientBrush](../com.aspose.psd.brushes/pathmulticolorgradientbrush) | Incapsula un oggetto  Aspose.Imaging.Brush  con un gradiente. |
| [SolidBrush](../com.aspose.psd.brushes/solidbrush) | Solid brush è destinato al disegno continuo con un colore specifico. |
| [TextureBrush](../com.aspose.psd.brushes/texturebrush) | Ogni proprietà della classe  Aspose.Imaging.Brushes.TextureBrush  è un oggetto  Aspose.Imaging.Brush  che utilizza un'immagine per riempire l'interno di una forma. |
| [TransformBrush](../com.aspose.psd.brushes/transformbrush) | Un  Brush  con capacità di trasformazione. |
