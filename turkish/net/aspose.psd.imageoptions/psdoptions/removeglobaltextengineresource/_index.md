## PsdOptions.RemoveGlobalTextEngineResource property

Kaldırma işlemini gösteren bir değeri alır veya ayarlar - Global metin motoru kaynağını kaldır - Bazı metin katmanlı PSD dosyaları için kullanılır; yalnızca işleme sonrasında Adobe Photoshop'ta açılamadığında (çoğunlukla eksik fontlarla ilgili metin katmanları). Bu seçeneği kullandıktan sonra, kullanıcı Photoshop'ta açılan dosyada şu adımları izlemelidir: Menü \"Text\" -> \"Process absent fonts\". Bu işlemden sonra tüm metin tekrar görünecektir. Lütfen, bu işlemin bazı son düzen değişikliklerine neden olabileceğini unutmayın.

```csharp
public bool RemoveGlobalTextEngineResource { get; set; }
```

### Property Value

`true` eğer [remove global text engine resource]; aksi takdirde `false`.
