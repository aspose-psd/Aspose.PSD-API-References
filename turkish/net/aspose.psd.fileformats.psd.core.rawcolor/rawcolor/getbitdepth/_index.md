## RawColor.GetBitDepth method

Raw Color'ın bit derinliğini alır. Örneğin, kanal/bileşen başına 8 bit olan ARGB renk için toplam 32 bit derinlik, kanal/bileşen başına 16 bit olan tam ARGB renk için ise 64'tür. Bit derinliği, kanalların bit derinliklerinin toplamından elde edilir. Farklı kanalların farklı bit derinliklerine sahip olması mümkündür.

```csharp
public int GetBitDepth()
```
