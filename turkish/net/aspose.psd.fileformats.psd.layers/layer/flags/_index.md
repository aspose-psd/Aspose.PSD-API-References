## Layer.Flags property

Katman bayraklarını alır veya ayarlar. bit 0 = şeffaflık korumalı; bit 1 = görünür; bit 2 = eski; bit 3 = Photoshop 5.0 ve sonrası için 1, bit 4'ün faydalı bilgi içerip içermediğini belirtir; bit 4 = piksel verileri belgenin görünümüne alakasız.

```csharp
public LayerFlags Flags { get; set; }
```

### Property Value

Katman bayrakları.
